# 🔐 密码管理器

本地安全密码管理工具，所有数据使用 AES 加密存储，支持分类管理、搜索、导入导出和自动备份。

## 安装

```bash
cd password-manager
npm install
```

## 启动方式

### Electron 桌面版（推荐）

独立桌面应用，无需浏览器，适合日常使用。

```bash
npm start
```

打包为 exe：

```bash
npm run build
```

打包后在 `dist/` 目录生成可执行文件，可直接运行或拷贝到其他电脑使用。

### Web 版

通过浏览器访问，适合临时使用或局域网内其他设备访问。

```bash
npm run web
```

打开浏览器访问 `http://localhost:3000`（端口被占用时自动切换到下一个可用端口）。

Web 版提供了便捷启动脚本：
- `启动密码管理器.vbs` — 双击启动服务并自动打开浏览器（后台运行，无黑窗口）
- `创建桌面快捷方式.ps1` — 运行后在桌面创建快捷方式，之后双击快捷方式即可启动

## 首次使用

1. 启动后会看到"设置主密码"界面
2. 输入主密码（至少 4 个字符），再次确认
3. 可选：设置密码提示帮助回忆
4. 点击"设置主密码"完成初始化

> ⚠️ 主密码遗忘后无法恢复数据，请务必牢记。

## 功能说明

### 添加密码
点击"添加密码"按钮，填写以下信息：
- **标题**（必填）
- **分类**（可选，支持自定义分类）
- **用户名/邮箱**
- **密码**（必填，内置强度检测）
- **网址**
- **备注**

### 分类管理
预置 7 个默认分类（网站、应用、邮箱、金融、社交、工作、其他），支持新建自定义分类。

### 搜索
顶部搜索框支持按标题、用户名、网址、备注模糊搜索。

### 导出/导入
- **导出**：将所有密码导出为 JSON 文件
- **导入**：从 JSON 文件导入密码数据

### 备份恢复
- 每次修改数据自动创建备份，保留最近 7 天
- 支持手动从历史备份恢复

## 数据存储

| 文件 | 说明 |
|------|------|
| `data.enc` | 加密的密码数据库 |
| `hint.txt` | 密码提示（明文） |
| `backups/` | 自动备份目录 |

数据存储位置：
- **Electron 版**：`%APPDATA%/password-manager/`
- **Web 版**：项目目录下
