# 泰坦尼克号 - Titanic

> **分类**：`#vibeart` 数字艺术　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

照 `docs/` 里的四张参考图（乐高 10294 泰坦尼克号）做的参数化三维模型：Blender 脚本化建模，四座烟囱、双桅索具、十六艘救生艇、三色船壳与艏艉属具均按图落位。

## 素材与工程

| 项 | 说明 |
|----|------|
| 建模 | Blender 5.2，脚本化建模（`blender/build_ship.py`），经 Blender MCP 实时构建与校形 |
| 规模 | 41 个部件 · 32,352 三角面 · 4 烟囱 / 2 桅 / 16 救生艇 |
| 参数 | `assets/titanic-params.js` 为唯一真源；Blender 侧经 `node blender/export_params.js` 取 JSON |
| 模型格式 | glTF / GLB（已导出，1.5 MB） |
| 预览 | `blender/out/preview_*.png` 四机位（正侧视 / 左舷艏 / 右舷艉 / 艏部特写） |

## 尺度来源

船的形制不是照实船原始数据拍的，而是**照参考图逐像素丈量**：`docs/10294_alt4.png` 正侧视图中船体全长 985 px，对应总长 269.1 m，故 1 px = 0.2732 m。各色带边界、烟囱与桅的落位都由这张图量出，量得的比例直接写进参数表：

| 量得项 | 参考图 | 本模型 |
|--------|--------|--------|
| 红防污带高 / 总长 | 0.0426 | 0.0446 |
| 黑舷侧带高 / 总长 | 0.0437 | 0.0427 |
| 白色上层建筑高 / 总长 | 0.0579 | 0.0580 |
| 烟囱高 / 总长 | 0.0711 | 0.0730 |
| 烟囱基径 / 总长 | 0.0335 | 0.0342 |
| 龙骨至桅顶 / 总长 | 0.310 | 0.310 |

> 乐高模型是按积木颗粒比例做的，比真船更「高更胖」（艇甲板高出真船约 1.4 倍）。本模型照**模型**还原，不追实船数据；`assets/titanic-params.js` 里 `beam` 29.5 也比实船 28.19 略宽。

## 形制要点

| 要点 | 落实 |
|------|------|
| 三色船壳 | 红防污 / 黑舷侧 / 舷顶金线，**同一 Object 的逐面材质**，不拆三块 |
| 船壳肌理 | 两排浅色舷孔 + 上缘一排深色舷侧板 + 七处装货门 |
| 舷弧 | 中段甲板线基本水平，首尾抬起（照模型的积木式平甲板，不做真船的强舷弧） |
| 上层建筑 | 四级台阶块逐级收进，随平面线型收放；四排窗列 |
| 四烟囱 | 后倾 8.5°，黄罐 + 黑顶罩（顶罩外扩「套」上去），每座两支蒸汽管 |
| 双桅 | 主桅偏后 / 前桅偏前（各距同侧端约 0.18 总长），均后倾，前桅带了望台与横桁 |
| 索具 | 主桅—前桅横拉线 + 八角支索，细杆成线 |
| 救生艇 | 两舷各 8 艘 + 每艘两副吊艇架 |
| 艏部 | 锚、起锚机、防浪板、白色锚吊车、信号杆、舷侧船名 |
| 艉部 | 舵、四叶中桨 + 三叶双翼桨、艉吊臂、旗杆与蓝旗 |
| 展示底座 | 八组垫木（立柱 + 外扩底座脚）+ 独立铭牌 |

## 自检

```bash
# 参数表 → JSON
node blender/export_params.js

# 几何层：无头建模 + 62 项几何审计 + 导出 GLB
blender --background --factory-startup --python blender/headless_check.py

# 预览渲染（四机位）
blender --background blender/out/titanic.blend --python blender/render_preview.py
```

审计覆盖：部件齐全度、主尺度（以船壳为准）、船体三色的逐面材质、材质取色是否真的写进
Principled BSDF、舷孔与窗列的高度带、救生艇数量与左右对称、烟囱后倾方向、退化面占比、
铭牌与船体不重叠。

## 两个踩过的坑（写在这里免得重犯）

1. **`bpy.ops.wm.read_factory_settings` 会掐断 MCP 连接** —— 它把 Blender 重载回出厂状态，
   顺带卸载 blender-mcp 插件，会话当场断线且端口不再监听。清场改为逐个删除数据块。
2. **Blender 5.x 中文界面下节点名与插槽名都被本地化** —— 节点叫「原理化 BSDF」、插槽叫
   「基础色」，按 `nodes.get("Principled BSDF")` / `inputs["Base Color"]` 取会静默拿到
   `None`，结果是整船渲染成白模。改为按 `bl_idname` 与 socket `identifier` 取。
