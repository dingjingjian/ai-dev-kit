# #vibeart　数字艺术

把情绪和想象，做成可以观看、聆听和互动的艺术体验。

## 当前状态

本分类现有 2 个项目（均由 `#vibeknow` 人文知识迁移而来，定位为可观赏的 3D 船模作品）：

- [`Titanic/`](Titanic/) — 照乐高 10294 参考图逐像素丈量建模的泰坦尼克号，四烟囱双桅十六艇。
- [`zhenghe-treasure-ship/`](zhenghe-treasure-ship/) — Blender 建模的明代宝船，九桅十二帆、水密隔舱、七下西洋航线。

不硬凑：工具或科普作品不应随意贴艺术标签顶数；这两件以"观看 / 感受"为主价值，归入本目录更贴切。

## 补位方向

1. **新开作品**：做一个以「观看 / 聆听 / 互动」本身为主价值的东西，而不是"能用的软件"或"能学的知识"。
2. **改造 `vibetool/pixel-art-editor/`**：给它加生成式艺术层，让它从"画画的软件"变成"艺术作品本身"。这条路成本低，但要看改造后主价值是否真的移位到了"感受"而不是"产出"。

新项目落地时直接放在本目录下，并同步更新根目录 `TRACKS.md`。
