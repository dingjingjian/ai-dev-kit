# #vibeart　数字艺术

把情绪和想象，做成可以观看、聆听和互动的艺术体验。

## 当前状态

**本赛道暂无项目。**

不硬凑。宁可空着，也不把工具或科普作品贴一个艺术标签来顶数——那样只会让分类失去意义。

## 补位方向

1. **新开作品**：做一个以「观看 / 聆听 / 互动」本身为主价值的东西，而不是"能用的软件"或"能学的知识"。
2. **改造 `vibetool/pixel-art-editor/`**：给它加生成式艺术层，让它从"画画的软件"变成"艺术作品本身"。这条路成本低，但要看改造后主价值是否真的移位到了"感受"而不是"产出"。

新项目落地时直接放在本目录下，并同步更新根目录 `TRACKS.md`。
