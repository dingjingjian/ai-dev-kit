# 人工智能 OS · v2 设计规范（DESIGN.md）

> 本文件是 ai-os v2 的**设定与规范唯一真源**：容器适配、导航结构、视觉语言、布局、兼容基线、工程与分期都以本文为准。实现（`_dev/build.py` 单源）与验收都必须对照本文。
> 容器与兼容细则引用仓库内 Skill：`.skill/minitool-zip-builder/`（SKILL.md 及其 references），本文不重复抄录，只落本项目的设计决策。

---

## 0. 背景：v1 的问题与 v2 的目标

v1（当前根目录构建产物，React + Tailwind 产物归档）实测（390×844 移动视口）暴露四类问题：

1. **不像真机**：深紫近黑的"霓虹雾"背景 + 满屏文字辉光，是"赛博面板"而非"手机"；缺少真机的状态栏、壁纸、Dock 质感与应用切换动效。
2. **顶部与宿主冲突**：v1 用 `base.css` 里 `left:35px` 硬偏移返回按钮去避让小红书容器自带按钮，属脆弱 hack；且各页返回钮样式不统一。
3. **纵向留白失控**：主屏第二行图标到 Dock 之间约 1/3 屏空洞；计算器键盘不贴底；助手页单条气泡下整屏空白。
4. **无源码**：v1 仅构建产物，无法可持续地改结构；v2 必须建立单源工程。

v2 目标：**一眼是一部真手机**（浅色壁纸 + 状态栏 + 图标网格 + Dock + 底部三大金刚键），同时满足小红书小工具容器与 Chrome 61 兼容基线。

## 1. 版本与归档策略

- v1 原样保留，整体移入 `archive/v1/`（`git mv`，可追溯），**不做任何修改**。
- 根目录成为 v2 源码工程，目录约定对齐 `perler-bead-game`：

  - `_dev/build_zip.py` —— 校验并打包小红书规范 zip。
  - `_dev/smoke_test.py` —— 无头自检（导航栈、安全区变量、Chrome61 语法扫描）。

## 2. 容器适配规范（顶部留白 / 左右净空 / 底部金刚键）

参照 `perler-bead-game` 的 `--top-gap` 机制与 `.skill/minitool-zip-builder/references/cross-platform-h5.md §3`：

```css
:root{
  /* 顶部强制留白：小红书 iframe 内 env(safe-area-inset-top) 恒为 0，
     必须用显式常量兜底，保证顶栏不顶到屏幕最上沿。改这一个值即可全局调整。 */
  --top-gap:50px;
  --safe-top:calc(var(--top-gap) + var(--safe-area-inset-top, env(safe-area-inset-top, 0px)));
  --safe-bottom:var(--safe-area-inset-bottom, env(safe-area-inset-bottom, 0px));
  --safe-l:0px;
  --safe-r:0px;
}
/* 宿主内嵌：左右给小红书自带按钮预留净空 */
body.in-app{ --safe-l:48px; --safe-r:92px; }
```

硬规则：

- **顶部预留带**（高度 = `--safe-top`）内：**禁止任何可交互元素**（按钮/链接/手势区）；**静态展示内容允许贴边**，但必须收在净空之内（所在栏的 padding 含 `--safe-l`/`--safe-r`），不得压到宿主自带按钮。状态栏即按此采用真机布局（§4.1）。
- **禁止顶部返回按钮**。一切"返回/主页/多任务"由**底部三大金刚键**承担（§3）。v1 的 `left:35px` 偏移 hack 废除。
- 所有贴边栏（状态栏、Dock、金刚键栏、页内工具条）的水平内边距统一为 `calc(Npx + var(--safe-l))` / `calc(Npx + var(--safe-r))`，垂直为 `--safe-top` / `--safe-bottom`。
- `body.in-app` 由容器注入；PC 模拟器未注入时左右净空为 0，布局仍成立（贴边内容自然回到屏幕两侧）。

## 3. 导航结构：底部三大金刚键 + 应用栈

- 屏幕最底部（`--safe-bottom` 之上）固定一条**系统导航栏**，内含三枚金刚键（Android 风格几何 glyph，纯 CSS/SVG 绘制，不引图标字体）：
  - **返回 ◁**：弹出应用栈顶；栈空时回主屏。
  - **主页 ○**：直接回主屏（清空 transient 视图，保留各应用状态）。
  - **多任务 ▢**：打开最近应用卡片轮播（横向滚动卡片，点击恢复、上滑/点 × 关闭）。
- 导航栏为半透明实色底（基线）+ `@supports` 增强毛玻璃；高度 ≥ 48px，键触控区 ≥ 48×48px。
- **应用栈**：主屏 → 应用 → 应用内二级页，统一入栈；返回键逐层出栈。页内不再各自画返回钮。
- 多任务卡片记录 {应用 id, 快照标题, 进入时间}；不截图（容器内 canvas 快照成本高），用「应用图标 + 名称 + 主题色标题条 + 骨架内容块」（`.rc-bar` / `.rc-mini` / `.rc-sk`）拼出可辨认的缩略卡，**不得只留一块空渐变**。
- 多任务遮罩 `position:absolute` 于视图容器内，只铺内容区，**不得盖住底部金刚键**（多任务下金刚键必须仍可按）。
- 视图切换用 `opacity + transform:scale(.965)` 短过渡（`.view.entering`），不用单一淡入。

## 4. 视觉规范：像一部真手机

### 4.1 状态栏（真机布局，纯展示无交互）
- 采用真机排布：**时间居左，信号格 / WiFi / 电池% 居右**（`justify-content:space-between`）。约束只针对"可交互元素"，静态内容贴边不影响宿主按钮。
- 左右两组内容收在净空之内：状态栏 padding 为 `calc(14px + var(--safe-l))` / `calc(14px + var(--safe-r))`，in-app 时不会压到小红书自带按钮。
- 字号：时间 14px/600，电量 11px；颜色随壁纸明暗取 `--status-ink`。
- 信号/WiFi/电池为纯 CSS/SVG 小图形；电池百分比为模拟值（固定 87%）。
- 状态栏内**不得出现任何按钮或手势区**。

### 4.2 壁纸与主题（默认浅色）
- **默认浅色壁纸**：柔和网格渐变（如 `#EAF1FF → #FDF4EC` 的对角 mesh + 极淡噪点），深色文字 `#1C1B1F`。
- 提供 3–4 款壁纸（浅 mesh / 浅纯色 / 深 mesh / 深色纯），设置内切换，`localStorage` 持久化（key 前缀 `aios_`）；设置页 swatch 预览必须与实际壁纸**同色系**，不得另画一套配色。
- **壁纸只属于主屏**：进入任意应用后，状态栏区、内容区、底部导航一起铺**应用底色** `--app-bg`（浅 `#F3F3F7` / 深 `#121216`，导航用 `--app-nav`），壁纸完全让位——真机只有主屏见壁纸。实现由 `body.on-app` 单一 class 控制（`showOnly(node, isApp)` 切换），回主屏即移除。
- **深色模式**作为可选项（跟随壁纸 or 独立开关），但**默认浅色**；所有组件 token 化，切换只换变量。
- 文字辉光**全面移除**（v1 的 glow 是"不像真机"的主因之一）；仅保留图标自身的彩色渐变与投影。

### 4.3 主屏
- 壁纸铺满；图标网格 4 列（390px 宽下每格 ≥ 72px 触控区），图标为圆角方形（squircle 观感：`border-radius:23%`）彩色渐变 + 白色 glyph + 底部 12px 名称（400 字重）。
- 主屏图标**色相必须拉开**：计算器靛蓝 / 助手天蓝 / 日历橙 / 日程绿 / 闹钟紫 / 统计青 / 电话绿 / 短信深蓝 / 相机玫红 / 设置灰——不得出现两个近似橙或近似绿。
- **副标题/ slogan 不上主屏**（v1 的两行折行孤字问题直接取消）；slogan 移入"关于本机/应用详情"。
- 网格从顶部往下排（`align-content:start`、`flex:0 0 auto`），像真机启动器；最后一行之后的空白留在 Dock 上方（真机少应用时亦然），**不得让网格在剩余空间里垂直居中**（那会让图标"悬空"）。主屏整体（组件+网格）在 `.home-body` 内可滚动，小屏不裁切。
- Dock：半透明白（浅壁纸）/ 半透明黑（深壁纸）圆角条，**圆角独立取 28px**（明显大于普通卡片），4 枚常用应用**与主屏图标同尺寸（62px）**、`justify-content:space-between` 等距铺开、**不带文字标签**（真机 Dock 不带标签）。

#### 4.3.1 小组件（首页丰富度与设计感）
组件区位于图标网格之上、Dock 之外。三种质感拉开层次：**主视觉渐变卡（时钟）→ 玻璃卡（天气）→ 银行卡质感深色卡（钱包）**；玻璃卡为 `.widget`（radius 20px，`@supports` 毛玻璃增强），渐变卡用 `.widget.w-xxx`（特异性 0,2,0）压过玻璃增强层。
- **时钟组件**（整行·品牌紫渐变卡）：内边距 20/18px 撑出英雄卡高度；白字 46px/800 大时间 + 11px 副行「M月D日 星期X · 本地时间，大概准」；右侧 60px 白环模拟小表盘（时/分针 `tick()` 按角度 `rotate()`，金色轴点）。**点击进闹钟**。
- **天气组件**（半行·玻璃卡）：**一眼假的设定数据**（恶搞内核）：「月球 · 静海」+ 26px 「-173°」与月牙 glyph 圆 chip 同行、「晴 · 流星雨概率 40%」、10px 免责行「数据来源：AI 编的，别当真」。纯展示不可点（不联网）。
- **钱包组件**（半行·深色银行卡）：顶行「灵光银行 · 数字卡」+ 金色芯片；「余额（透支中）」+ 25px 假余额「￥ -99,999」；底行「今日支出 ￥9,999 / **** 2333」。**窄卡内数字一律 `white-space:nowrap`，不得折行**（字号按半行卡可用宽度定，宁可缩小也不允许"￥"独占一行）。**点按打码/还原**（`￥ -****`），状态持久化 `localStorage aios_wmask`。
- 半行组件用 `.w-half + .w-half{margin-left:10px}` 形成间距（Flex margin 基线，不用 gap）。
- 组件内交互仅限组件自身语义；不得在组件里放全局导航。
- 图标 glyph 一律手绘简单几何（矩形/圆/环组合），禁止凭记忆写复杂单 path（v2 初版齿轮曾糊成一团）。

### 4.4 应用内页面（三段式，杜绝留白失控）
统一骨架：`状态栏(固定) + 页头(标题居中, 无返回钮) + 内容区(flex-1, 可滚动) + 页内操作区(贴内容区底) `，整屏高度 = `100% - 金刚键栏 - safe`。
- 内容区用 `flex:1; min-height:0; overflow-y:auto`（基线写法），保证"内容撑满、操作贴底"。
- **禁止中段空洞**：内容少时不得出现"顶部堆叠 → 中段大片空白 → 操作区贴底"。显示类应用（计算器）把主显示卡设为 `flex:1` 并由其内部 `justify-content:flex-end` 吃掉剩余高度；列表/聊天类由列表或消息流 `flex:1` 撑满。
- 游戏页的操作键盘/输入区**锚定内容区底部**，不再悬空。
- **页脚操作区统一控件语言**：贴底操作区里的按钮一律**等分满宽**（`grid` 等分或 `flex:1`）、高度 48–64px、圆角 `--r-md`、双层投影 `--sh-1 + --hl`；主操作/选中态复用主 CTA 渐变（同 `.key.eq`/`.ring-btn`）。**禁止**靠左排列、按文字自适应宽度的小胶囊——它与键盘、判定按钮不成一体，会显得违和。
- **计算器页是固定页（内容区滚动的唯一例外）**：真机计算器不翻页。`.pbody.calc-body` 关掉内容区滚动（`overflow:hidden` 且不参与压缩 `flex-shrink:0`），显示卡 `.calc-display` 不压缩（表达式/大数不裁切、按键不跳动），净高不足全部由键盘行高消化（`.keypad` 行高 `minmax(0,64px)` 上限，`.pfoot.calc-foot` 可纵向压缩）——任何净高下都不得出现滚动条；净高 ≤700px 时指标条/显示卡紧凑化（`@media (max-height:700px)`），把高度让给键盘。判定阶段键盘**原位**隐藏（`visibility:hidden`）而非 `display:none`，「对 / 错」绝对定位覆盖在键盘区，页脚高度全程不变。覆盖层左右复用 `.pfoot` 的 `--foot-px-l/-r` 内缩量与键盘**同宽对齐，不得贴屏边**；提示行 `.calc-feedback` 是“怎么玩 / 现在要做什么”的关键指令，常驻可读（14px `--ink`，不被按键清空），`ask/ok/no` 三态分别取 accent/ok/danger 加粗，行高恒定 20px（切换状态不改变高度）。
- 空态必须有引导文案或示例 chips（推广 v1 日历页"点击任意日期开始排雷"的好实践）。

### 4.5 组件与色彩 token
- 语义色一套全 App 复用：`--accent`(品牌紫) / `--ok` / `--warn` / `--danger` / `--combo`(连击橙)；得分=accent、连击=combo、中性=前景色，**不再随意着色**。
- 圆角两档：卡片 16px、控件 10px；描边 1px `rgba(0,0,0,.06)`（浅）/`rgba(255,255,255,.08)`（深）。
- 顶栏指标条：主指标（分数）放大突出，次要指标降级为小字一行；≥5 个指标时折叠。
- 字体用系统栈（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`），不引 webfont（性能与兼容）。

### 4.6 质感系统（去廉价感，v2.1 增补）
廉价感五根源：单层硬投影、灰玻璃+灰描边一刀切、糖果随机渐变、字重字距无层级、壁纸平涂无颗粒。对策全部落在 token：
- **圆角三档** `--r-lg:24 / --r-md:18 / --r-sm:12`；组件用 lg，卡片 md，控件 sm；**Dock 独立取 28px**（真机 Dock 圆角明显大于普通卡）。
- **双层投影** `--sh-1`(环境 0 1px 2px) + `--sh-2`(主光 0 10px 28px)；深色模式整体加重。图标用**中性主光** `0 6px 14px rgba(20,20,40,.18)`（深色 `rgba(0,0,0,.52)`）——真机图标不用同色彩色光晕，彩色光晕显廉价，`--icon-sh` 已废除。
- **内高光/内底影** `--hl: inset 0 1px 0 rgba(255,255,255,.55)`（深色 .08）给材质厚度；图标加 `inset 0 1px 0 rgba(255,255,255,.35)` + `inset 0 -1px 0 rgba(0,0,0,.10)`。
- **发丝描边** `--hair`：浅色 rgba(255,255,255,.6)、深色 rgba(255,255,255,.10)，替代灰 line 用于玻璃面。
- **颗粒** `--grain`：feTurbulence SVG data-URI（opacity .045）作为每张壁纸的第一背景层，消除平涂塑料感；渐变卡另叠顶部 radial 高光纹理。
- **排版层级**：英雄数字 800 字重 + `letter-spacing:-1px` + `font-variant-numeric:tabular-nums`；标签 10–11px + `.3px` 字距；应用名 500 字重。
- **微动效**：`.app-tile:active{transform:scale(.94)}` + `transition:transform .16s ease`（transform/opacity 均在 Chrome 61 基线内）。

### 4.7 游戏玩法（二期a：计算器 / 闹钟 / 日历 —— 以 v1 逆向为准，禁止臆改）
三个游戏统一遵循 §4.4 三段式（指标条 + 主显示卡 + 贴底操作区），**机制规则以 v1 构建产物逆向为唯一真源**（v2 初版曾按文案臆造机制，已回炉）。指标条主指标 accent 色、连击 combo 色，数字一律 `tabular-nums`；分数/最高分等跨会话持久化于 `localStorage aios_stats`。
- **计算器（v1 规则）**：用户在键盘上自己按表达式（`+ − × ÷ . C =`，递归下降解析、一元负号、除零/非法显示 Error）；按 `=` 后 **50% 概率注入错误**（四种策略：±1~2 / 替换一位数字 / 交换相邻数字 / 量级偏移；偏差超 `max(30%,5)` 兜底小偏移，保留 2 位小数），随后进入判定阶段（键盘**原位**隐藏、出现「对 / 错」，页脚不塌陷、页面不跳动）。判对 `+10`，连击 ≥3 再 `+5`；判错连击清零、`score-5`（下限 0）；轮次 +1、准确率与最高分滚动更新；判定反馈 1.2s/1.6s 后回到键盘。恶搞内核：它真会算错，考的是玩家验算。
- **闹钟（v1 规则）**：目标时间对齐到整 `:00`/`:30` 刻度（生成器移植 v1 `$a`）；100ms 心跳，**响铃窗口 ±500ms**，窗口外「响铃」按钮禁用，窗口开启按钮脉冲高亮；**错过窗口自动记一次「晚了」**，窗口内按下记「准时」。结果文案「你比我准时 / 你和我一样睡过啦？」+「再来一次」（retry 顺延到下一刻度）。指标：准时次数 / 尝试次数 / 准时率。**自动判晚的判定必须用 `delta > 500`，不得用 `alarmState.ringing` 当哨兵**——目标设下时就已过期的情况（如 `:00.6` 打开闹钟，目标对齐到已过的 `:00`）`ringing` 仍为 false，两条分支都不命中，会死锁成「按钮永远按不动、也不自动判晚」。
- **日历（v1 规则）**：7 列棋盘；难度 简单 5 行 5 雷 / 中等 5 行 8 雷 / 困难 6 行 12 雷（默认中等），banner「本月由 AI 重新排期，共 N 天」。**整屏摆下、不上下翻页**：格子是正方形（`padding-top:100%`），`fitBoard()` 先按自然尺寸布局，内容区溢出时按溢出量反推应缩到的棋盘宽度（`.ms-week`/`.ms-grid` 同宽 + `margin:0 auto` 居中，`MS_GAP=6` 与 CSS 的 `grid-gap` 一致，迭代几次收敛、格子下限 14px），宽屏保持自然尺寸；难度切换 / 结算文案折行 / 旋屏（resize）后都要重算。**棋盘视觉与版式**（全部落在 §4.5/§4.6 既有 token 与控件语言内，不另造一套）：未开口面格=抬起块（`--cell-hi/--cell` 双色渐变 + 外发丝环 + 环境影 + 内高光，全走 `box-shadow` 所以不占布局、格子仍是正方形），已开口=凹陷平底（`--cell-rev` + 内影）；格子圆角取 **23%**（与主屏图标同一套 squircle 观感，随格子大小自适应）；星期行=浅底圆角日期条（六/日只做中性加重 `--ink`，**不占用语义色**，与棋盘同宽对齐）；提示文案沿用站内通知条形态（卡面 + 发丝描边 + `--r-md`，同 `.sms-banner`）；**底部难度选择=等分满宽的三段控件**（`grid-template-columns:repeat(3,1fr)` + `--r-md` + 双层投影，高度 48px，与 `.key`/`.judge-btn` 同一套控件语言），选中态复用主 CTA 渐变（同 `.key.eq`/`.ring-btn`），**不做散在左侧的小胶囊**；棋盘卡用 `margin:auto 0` 在内容区剩余空间里**垂直居中**，消除 §4.4 禁止的中段空洞；净高 ≤700px 时指标条/通知条/星期条/状态条/难度按钮紧凑化（`.cal-body` 作用域，难度按钮在页脚故用 `.ms-foot` 限定），把高度还给棋盘。**首点布雷且避开首点 3×3**（首点必安全）；flood-fill 揭空；**长按 400ms / 右键 / 标旗模式** 三种插旗方式；计时 1s 上限 999s。胜利得分 `base(20/35/55) + (用时<60s ? 10 : 0)`；胜率与轮次为**移动平均**（失败也 +1 轮次摊薄胜率）；最高分/最快纪录持久化。指标条：分数/最高分/胜率/最快；第二行：用时/剩余雷/标旗模式。方格用 `padding-top:100%` 比例盒（Chrome 61 基线，不用 aspect-ratio）。
- **统计存储键**：`calc{score,highScore,streak,maxStreak,rounds,accuracy}` / `alarm{onTime,attempts}` / `cal{score,highScore,winRate,rounds,fastest}`，供二期b 统计应用消费。
- 保留的 v2 改良（非机制）：未开局面格显示日期数字、v2 视觉 token、三段式布局、**计算器 Error 态后再输入自动清空重来**（v1 需手动按 `C`；Error 态显示卡描边转红，下一次输入即复位）。

### 4.8 其余应用（二期b：助手 / 日程 / 电话 / 短信 / 相机 / 统计 —— 同样以 v1 逆向为准）
- **助手**：聊天式问答。随机问候语（`AI_GREET`）→ 打字气泡 1.5s → 从 80 题常识库（`QUIZ`）抽题（`used` 去重、抽空重置），底部 2×2 选项；答对 `+10`、连击≥3 `+5`、答错清零 `-5`（下限 0），准确率移动平均；AI 用 `AI_RIGHT/AI_WRONG` 文案点评（答错时把 `{answer}` 换成正确项）。**聊天区贴底**：选项上屏会加高页脚、压矮内容区，`scrollBottom()` 必须在该布局变化后再调一次（并在下一拍补一次），否则最新一条会被页脚增量顶出可视区。
- **日程**：select→memorize→recall→result 四相。难度 3条/10s、5条/8s、8条/5s（`SCHED_DIFF`）；日程池 `SCHED_POOL`（带时间，按时间排序）随机抽 N 条记忆；回忆逐条四选一（正确项+其余记忆项+干扰池 `SCHED_DISTRACT` 补足打乱）；每条 `+5`、全对 `+10`，准确率=正确/总数 移动平均。**版式**（与日历/助手/闹钟统一页脚操作区语言，§4.4）：四相内容装进 `.sched-block`（`margin:auto 0` 在内容区剩余空间里**垂直居中**，溢出时 auto 归零、交内容区滚动，消除中段空洞）；**操作全部下移 `.pfoot`**——难度选择复用日历的 `.ms-foot`+`.diff-btn`（等分满宽三段控件，选中态主 CTA 渐变），回忆四选一复用助手的 `.opt-grid`+`.opt`（2×2 选项），结算用 `.act-grid`+`.act-btn`（两枚等分满宽，主 CTA 渐变 + 次级卡面，同键盘/判定按钮语言）；记忆相 pfoot 放 `.pfoot-hint` 提示（等待状态）；记忆列表收进 `.sched-list` 卡面、时间用 accent 胶囊；阶段标题 700/19px（800 字重是英雄数字专用，§4.6）；净高 ≤700px 时标题/倒计时/列表行紧凑化，8 条困难列表也能一屏看全。
- **电话**：拨号盘（`*#0-9`，最长 11 位，3-4-4 格式化）；拨打后 dialing 3–8s → connected 计时 → 5–15s 自动挂断，20% 概率 `callEnded2` 否则 `callEnded1`；记录存 `aios_phone_records`（最多 5 条，点击复拨）；通话中按钮变红色挂断态。
- **短信**：种子收件箱 `SMS_SEED` 5 条（横幅「AI 已为您智能分类——全部分到'不重要'文件夹」）；会话内可发送，AI 延迟 2s 从 `SMS_REPLY` 敷衍回复池随机应答；已读/未读点、消息持久化 `aios_sms_messages`。
- **相机**：**纯模拟**（v1 即无 getUserMedia）：随机渐变场景 + 3–7 个圆/★/♥ 元素每 3s 刷新，HUD「镜头温度 36.x–42.x℃」；快门闪光 150ms（⚡可关）→ 预览页「重拍 / 预览 / 保存」，保存 1.5s「已保存 ✓」回取景。
- **统计**：canvas 六维雷达（计算力/知识量/记忆力/排雷力/守时度/连击力，v1 `Y0` 算法：连击力=`avg(maxStreak/rounds)`×100，排雷力=胜率）+ 综合评分（六维均值）+ 四卡（最高总分/总轮次/平均准确率/闹钟准时）+ 分游戏记录与重置（确认弹窗，`重置全部数据` 在页脚）。

## 5. 兼容基线（硬门禁）

对齐 `.skill/minitool-zip-builder` 的 `js-compatibility.md` / `css-compatibility.md` / `device-capabilities.md` / `performance-budget.md`：

- **JS**：交付代码 ES2017 / Chrome 61。`_dev/build.py` 产出即为最终代码，不写 `??`、`?.`、`class fields`、`async generators` 等超基线语法；用 `var`/`function` 或 ES2017 内能力。Web API 超基线先检测再增强。
- **CSS**：Chrome 61 基线层 + `@supports` 增强层，不维护两套样式表。
  - Flex 间距基线用子项 `margin`；`gap` 仅作增强（沿用 v1 `flex-gap-polyfill` 的行为检测思路，或干脆全用 margin 基线、不增强）。
  - 不用 `aspect-ratio` / `inset` / `min|max|clamp()` / 逻辑属性 / `dvh` 作为唯一实现；`backdrop-filter` 必有实色兜底。
  - 多行截断用 `-webkit-box` 套件并保证失效仍可用。
- **禁用能力**：不联网（无 fetch/外链/外字体）、无 Worker/SW、无 `window.open`/`prompt`、无剪贴板/ geolocation / 传感器、无 eval、无 iframe、无 blob 下载。相机用 `getUserMedia`（手势触发）或降级为模拟取景框。
- **存储**：`localStorage`，key 前缀 `aios_`。
- **性能**：zip ≤ 2MiB 建议线；单条 Base64 解码 ≤ 1MiB（壁纸用 CSS 渐变而非位图，天然达标）；不引入 WebGL。
- **自检**：`_dev/smoke_test.py` 扫描产物不含超基线语法 token、不含禁用 API 字符串； playwright 无头跑导航栈与安全区变量断言。
