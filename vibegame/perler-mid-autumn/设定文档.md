# 中秋拼豆坊 · 设定文档

## 一、项目概述
- **是什么**：基于拼豆（Perler Bead）钉板填色玩法的**中秋主题版**网页小游戏。逐格填豆拼成月夜纹样即过关；拼成可点亮中秋灯谜。
- **背景**：为小红书「邀你把月亮写进提示词 · 中秋国风 vibecoding」活动开发，对应官方灵感方向：🎮 中秋小游戏（灯谜）、🌙 沉浸赏月（夜空皮肤与月夜图案库）。
- **形态**：纯前端零依赖，脚本外置（`index.html` + `main.js`），离线可用，移动端优先。
- **基底**：[`vibegame/perler-bead-game`](../perler-bead-game/) 的拼豆引擎（钉板、拟真拼豆、熨烫融合、五声音阶音效、双模式、星级评价、独立进度存档）。

## 三、技术栈与硬约束
- Canvas 2D（拟真拼豆、钉板、熨烫）+ DOM/CSS（UI 外壳）。
- Web Audio 程序化合成音效/BGM，零音频文件。
- 兼容老 WebView：无 `padStart`、无 flex gap 依赖、`padding-bottom` 撑正方形、Pointer Events + Touch/Mouse 双监听。
- **小红书小工具规范**：脚本外置经典脚本、无内联 `on*=`、无外部资源、无下载/剪贴板/传感器等能力、zip 根为 `index.html`、体积 ≤2MB。

### 画圆的约定（`G.ring2`）
小尺寸像素圆极易被削平或变尖，统一用**两圆相减**而非 `ring()`：

```python
g.ring2(cx, cy, r_out, r_in, c_out, c_in)   # 先填外圆 c_out，再用内圆覆盖 c_in
```

两个理由：
1. **外沿形状由 `r_out` 精确决定**，圆才是圆的。`ring()` 用距离区间判定，在偏离圆心的行上环带横向投影会变宽甚至整行消失。
2. 半径差建议 **≥ 1.0**。格子中心的偏移量是整数（圆心取格线交点时），差 < 1 时某些行会一个环带格子都没有，金边断成虚线。

圆心必须取在**格线交点**（如 13×13 取 6.5）或半格点，使 dx/dy 同时为整数，否则上下左右不对称。

验收用 `python _dev/check.py 明月` 看行宽序列，13×13 满圆应为 `[5,9,11,11,13,13,13,13,13,11,11,9,5]`。

### 中秋增量
1. **猜灯谜（`pma_riddle`）**
   - 8 条中秋灯谜（谜面 + 4 选项 + 注解），入口两处：首页「猜灯谜」横幅、底栏「更多」菜单。

   - 答对点亮（金色灯笼 + 光晕）、播放通关音、飘桂花、显示注解与「下一盏」；答错抖动 + 错误音。
   - 状态 `{solved:[riddleId]}` 持久化；首页横幅与菜单实时同步「已点亮 N/8 盏」。
2. **沉浸赏月皮肤**
   - 全局夜空底色（月晕 radial + 夜蓝渐变 + 宣纸噪点），背景粒子由金尘改为**闪烁星尘**（正弦呼吸透明度）。

   - 拼豆台外框保留暖木色，与夜空形成冷暖对比。

## 七、音频系统

- **实现方式**：Web Audio API 实时合成，**不引入任何外部音频文件**（符合小工具离线与体积约束）。
- **音频总线**：`master(0.85)` → `sfxBus(0.95)`（干声，保持音效清脆）/ `bgmBus(0.42)` → 混响送出 → `wet(0.30)` → `master`。
- **程序化混响**：`makeReverb(2.6, 0.72)` 用噪声生成脉冲响应，配一阶低通（系数 0.36）让尾巴越拖越暗，模拟月下空庭的余韵。
  - `ConvolverNode` 在部分老 WebView 上不存在，`ensure()` 内做特性检测 + try/catch，缺失时**静默降级为无混响干声**。

### 音色（全部程序化合成）
| 函数 | 音色 | 实现 | 用途 |
|------|------|------|------|
| `pluck` | 古筝拨弦 | 三角波主体 + 二倍泛音，低通随时间收敛模拟弦振衰减；可选 `rev` 参数送混响 | BGM 全部音、选色 |
| `mallet` | 木鱼/梆子 | 带通噪声瞬态 + 下滑三角波共鸣 | 放豆 |
| `bell` | 编钟/铃 | 基频叠加 2.0 / 2.76 / 5.4 非谐泛音 + 长衰减 | 提示、通关 |
| `sweep` | 噪声扫频 | 带通频率指数滑动 | 擦除、熨烫 |

### 背景音乐：《月下》A 羽调式
- **调式**：A 羽（羽 A–宫 C–商 D–角 E–徵 G），跨三个八度。
  - 选羽调式而非宫调式，因羽调式色彩清冷幽远，更贴合月夜；主音 A 落在低音区做根音。
- **结构**：慢板 **52 BPM**（每拍 ≈1.154 s），**8 拍一句，四句循环（起承转合）**：
  - 起 `[5,7,6,5,4,-,3,-]`　承 `[7,8,7,6,5,4,-,-]`
  - 转 `[5,6,5,3,4,5,-,-]`　合 `[8,-,7,6,5,-,4,-]`
  - 值为 `PENTA` 索引，`-1` = 留白。留白比填满更空灵，也更省 CPU（移动端省电）。
- **配器**：
  - 旋律：`pluck` 中高音区，混响送出 0.5。
  - 低音衬底：第 1、5 拍落点，低八度（`PENTA[i]/2`），送出 0.25，撑住调性。
  - 装饰音：16% 概率在高音区加一个邻音（模拟古筝「按滑」），避免每句完全一样。
  - 风铃：每 4 句一次极轻的高音（送出 0.85），打破循环的机械感。
- **为什么不用随机游走**：首版是五声音阶随机取音，听感像试音、没有主题，也记不住。改成固定乐句循环后才是「一首曲子」。
- **开关与持久化**：底栏「更多」菜单两项——「音效」（总开关）、「背景音乐」（单独开关），状态存 `pma_audio = {s,b}`。
- **移动端解锁**：`AudioContext` 必须在用户手势内创建/恢复，`init()` 对 `pointerdown / touchstart / keydown` 各绑一次 `once` 监听触发 `SFX.unlock()`，解锁后才启动 BGM。

## 九、宿主 App 安全区适配

## 九点五、导出图纸与小红书容器适配（与 perler-zodiac 同款）
- **三个入口**：首页卡片左上角「导图纸」（`stopPropagation`，不进拼豆台）、底栏更多菜单「导出图纸」、结算弹窗「存图纸」。
- **画布规格**（逻辑坐标，2x 输出，唯一真源 `exportCanvas`）：标题区 82 → 编号网格 cell=26 → 图例两列 40/行 → 页脚 46；朱红印章取图案名**首字**（如「千里共婵娟」取「千」）。
- **预览默认全景**：面板 90vh + 内部 flex 分配，画布 `contain` 等比缩放，整张图纸一屏看全无需滚动；点画布切放大模式，换图自动复位。
- **容器适配**：小红书容器 §4.2 禁用 `a[download]`/blob 下载，故保存走 `canvas.toDataURL` → `writeTempFile` → `saveImageToPhotosAlbum`；容器内隐藏打印按钮、主按钮文案改「存到相册」。
- **反馈链路**：toast `z-index:200`（否则被面板 z-95 盖住变成静默保存）；按钮态「生成中… → 已保存到相册 ✓ → 复位」；成功/失败配 SFX；8 秒 watchdog 兜底容器回调不上行。
- **防回退**：`build_zip.py` 前置校验必须含 `saveImageToPhotosAlbum` 且保留 `.download=` 降级，缺一拒绝打包。
- 自检：`_dev/_shot_container.py`（mock SDK / 无 SDK 两环境）、`_dev/_shot_export.py`（多视口全景体检）。

## 十、扩展指引
- 新增图案：`patterns.py` 写图案函数 + 追加 `ALL` 条目 → `python _dev/patterns.py` → `python _dev/build.py` → `python _dev/build_zip.py`。画圆一律用 `ring2` 并用 `check.py` 验行宽。
- 改色卡：同步改 `patterns.py` 的 `PAL` 与 `build.py` 的 `PALETTE`（两处必须一致），然后 `python _dev/check.py pal` 确认无难区分色对。
- 新增灯谜：直接改 `build.py` 内的 `RIDDLES`（HTML 里「N/8 盏」文案需同步）。
- 评分阈值、熨烫时长、音色参数均在 `build.py` 的 `JS_TEMPLATE` 中调整。
