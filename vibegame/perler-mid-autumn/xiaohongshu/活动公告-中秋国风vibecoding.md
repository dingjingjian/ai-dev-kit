## 六、参赛硬约束（来自本仓库既有小工具规范）

上传的「小工具」为**离线 H5 zip**，须满足仓库内既有规范（参见 `vibeknow/rocket-launch/.skill/minitool-zip-builder/` 与 `vibeknow/function-visualization/.skill/references/`）：

- `index.html` 必须在 **zip 根目录**；压缩的是目录"内容"而非目录本身
- **纯离线**：不得引用任何外部 CDN / 在线字体 / 在线图片
- **脚本必须外置**：禁止内联 `<script>`、行内 `onclick=`、`eval` / `new Function`
- **禁用能力**：定位、剪贴板、传感器、WebSocket、Worker、屏幕录制、`window.open`
- **禁止文件下载**：`a[download]`、blob 下载均不可用 → 生成类功能的交付方式只能是"页面内展示结果 + 引导用户截屏"
- **体积**：上限 10MB，建议 ≤ 2MB（当前 `moon-3d` 资源：`three.min.js` 594KB + `moon.jpg` 233KB ≈ 0.85MB，可控）
- 仅支持 `.html / .css / .js / .png / .jpg / .jpeg / .gif / .webp / .svg / .woff / .woff2 / .json`（**不含音频**，音效方案不可用）
