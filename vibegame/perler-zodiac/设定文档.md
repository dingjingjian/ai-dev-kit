# 十二生肖拼豆坊 · 设定文档

## 一、项目概述
- **是什么**：基于拼豆（Perler Bead）钉板填色玩法，在十二生肖图案上逐格填豆，拼成图案即过关的网页小游戏；**核心差异化是「导出图纸」**——任意生肖可导出带色号编号的线下制作图纸（PNG / 打印 PDF）。
- **形态**：纯前端零依赖，脚本外置（`index.html` + `main.js`），浏览器直接打开即可运行，离线可用，移动端优先。
- **血缘**：与 `perler-bead-game`（国风）、`perler-mid-autumn`（中秋）同构引擎。改引擎 bug 时三处同步；本版独有改动集中在「导出图纸」模块与品牌/存档键。

## 三、技术栈与硬约束
- 渲染：Canvas 2D（拟真拼豆、钉板、熨烫动画、**导出图纸绘制**）+ DOM/CSS（UI 外壳）。
- 音效：Web Audio 程序化合成，零音频文件。
- 图案数据：以几何图元程序化生成于 `patterns.py`；生肖一律画**正面头像**（圆脸 + 大眼），小尺寸辨识度最高。
- 兼容老 WebView：无 `padStart`、无 flex gap 依赖、`padding-bottom` 撑正方形、Pointer Events + Touch/Mouse 双监听。
- **色卡硬约束**：任意两色 RGB 欧氏距离 ≥ 60（`python _dev/check.py pal` 复验）；`patterns.py` 的 `PAL` 与 `build.py` 的 `PALETTE` 两处必须一致。
- **画圆硬约束**：像素圆环一律用 `G.ring2`（两圆相减）。
- **导出图纸约束**：`exportCanvas` 是唯一真源，「保存 PNG」与「打印存 PDF」共用同一张画布；画布以 2x 分辨率输出保证打印清晰。
- **打印样式约束**：`@media print` 里必须显式隐藏 `#homeView`（z-index 90 的全屏遮罩）等一切 UI，只留 `#sheetExport`。
- **弹层层级**：`#homeView` z-index 90，因此 `#sheetExport` 必须 ≥ 95，否则从首页卡片打开时被首页盖住（已踩过）。
- 小工具规范沿用：脚本外置经典脚本、无内联 `on*=`、无外部资源、zip 根为 `index.html`、体积 ≤2MB。**注**：导出用 `a.download` + `canvas.toBlob`，不在禁用能力清单内（禁的是 WebSocket/Worker/geolocation/clipboard/window.open）。
- 存档键前缀 `pzd_`（Perler Zelda? 不，Perler **Z**odiac），与国风版 `pbg_`、中秋版 `pma_` 完全隔离。

### 生肖画法备忘（patterns.py 踩坑记录）
- **螺旋（巳蛇）**：圈与圈半径差必须 ≥ 2.5、线宽 ≤ 1.0，否则糊成一团；斑纹沿螺旋按步数等距取样。
- **横向矩形条纹（寅虎「王」）**：`rect` 的 y 必须取**整数**、h=1.0，否则一条条纹会铺满两行格与相邻元素粘连；条纹与眼睛之间至少留 1 行空。
- **波浪剪影（未羊卷毛）**：底圆半径要小于凸出小圆的外沿，让小圆真正凸出轮廓，同色叠加才有剪影效果。
- **鬃毛/毛发**：单侧垂落比两侧对称更易读（对称黑曲线在小尺寸下像犄角，午马踩过）。

## 六、玩法机制
与国风版一致（临摹/挑战双模式、提示五优先级、熨烫融合、星级结算、独立进度存档），差异点：
- **首页卡片左上角新增「导图纸」按钮**：`stopPropagation`，点击直接对该生肖打开导出面板，不进拼豆台。
- **底栏「更多」菜单新增「导出图纸」项**：对当前图案打开导出面板。
- **结算弹窗新增「存图纸」按钮**：拼成后顺手把图纸带走。
- 图纸面板底部两键：「保存图片」（PNG 下载）、「打印 / 存 PDF」（`window.print()`，打印样式只出图纸画布）。
- **图纸预览默认全景**：面板固定 90vh 内 flex 分配，画布按容器 `contain` 等比缩放，整张图纸（标题+网格+图例+页脚）一屏看全、无需滚动；**点图纸切换放大模式**（按容器高度撑满、可拖动看色号，再点回全景），换图自动复位全景。

## 七、导出图纸规格
- 画布布局（逻辑坐标，2x 输出）：标题区（82px）→ 编号网格（cell=26px/格）→ 图例（两列，40px/行）→ 页脚（46px）。
- 网格：每格画拼豆圆 + **大写色号字母**（深色豆写浅字、浅色豆写深字，按亮度 150 阈值切换）；每 5 行列画粗线并标注数字（列号在顶部、行号在左侧，从 5 起计）。
- 图例：色样圆 + 大写色号 + 色名 + `× 数量`（即用料清单，线下备料直接照抄）。
- 右上角朱红小印：取生肖名末字。

## 七之二、小红书小工具容器适配（离线导出必须走端能力）
容器能力清单（2026-09-01 版）§4.2 明确禁用 **`a[download]` 与 blob 下载**，因此导出按环境三级降级：
1. **容器内**（`window.xhs.miniTool` 存在）：`canvas.toDataURL('image/png')` → `writeTempFile` 换 `filePath` → `saveImageToPhotosAlbum` 存相册；大图（25×25 图纸 base64 约 430 KB）必须先 writeTempFile，勿直接塞超长 data URI。
2. **普通浏览器**（无 SDK）：保留 `a[download]` + `window.print()`。
3. 全程失败：toast 提示截图留档。
- 容器内自动隐藏「打印 / 存 PDF」按钮，主按钮文案改「存到相册」（移动端 WebView 无打印能力，文档未承诺支持）。
- **保存反馈链路**：toast z-200（高于面板 z-95，否则被遮成静默）；按钮态「生成中…→已保存到相册 ✓→复位」busy 期间禁点；成功/失败配 SFX；8 秒 watchdog 兜底容器回调不上行（按钮复位 + 「已提交保存，请到相册查看」）。
- 其余合规项：脚本外置、无 `on*` 行内事件、无 eval/WASM/Worker、无网络请求、zip 仅 index.html+main.js；CSS 三处间距为 grid 且带 `grid-gap` 旧前缀，满足 Chrome 61 基线。
- 防回退：`build_zip.py` 增加两条前置校验（必须含 `saveImageToPhotosAlbum`、必须保留 `.download=` 降级），缺失即拒绝打包。
- 分支实测：`python _dev/_shot_container.py`（注入 mock SDK 与不注入两种环境各跑一遍）。

## 九、扩展指引
- 新增生肖/图案：`patterns.py` 写图案函数 + 追加 `ALL` 条目 → `python _dev/patterns.py` → 目视 `preview.png` → `python _dev/check.py <名>` → `python _dev/build.py` → `python _dev/build_zip.py`。
- 改导出图纸样式：`build.py` 内搜 `renderExportSheet`，画布布局参数（cell/headH/legendRowH 等）集中在函数开头。
- 全景布局坑：`.exp-scroll` 是 flex 居中 + overflow 容器，画布必须 `margin:auto`（不能只靠 justify-content），否则放大模式横向溢出时左边界会被裁掉滚不到；`.exp-panel` 固定高 + 内部 flex 分配是「一屏看全」的前提，勿改回 `max-height` + 固定 `54vh` 旧写法。
- 改色卡：同步 `patterns.py` 的 `PAL` 与 `build.py` 的 `PALETTE`，跑 `python _dev/check.py pal`。
- 改完务必跑 `cd _dev && node smoke_test.js`（含导出闭环断言），动过导出相关代码再跑 `_shot_export.py` 目视复核。
