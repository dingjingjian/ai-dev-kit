# 流浪地球 · 引力弹弓

> **分类**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)
>
> **状态**：玩法完成、可玩（固定航线时机节奏 + 掠过评级 + 用时成绩与分享，无头自检 **265/265** 全绿）。设计与数值真源见 [`DESIGN.md`](DESIGN.md)。

太阳氦闪的膨胀壳从第 0 秒就在地球身后追。地球沿一条**固定航线**自动冲向太阳系外缘，你唯一的操作是**什么时候按住点火**：

- **过早** — 推力照烧，但吃不到引力弹弓的放大，还白烧掉温度额度；
- **最佳时机**（时机条上的绿色区间）— 弹弓把速度拉向该行星的弹弓速度，这是唯一能把速度拉到门槛之上的办法；
- **过晚** — 判定点速度不够，**被行星捕获，或直接被拽进大气层**。

**目标只有一个：用最短的时间把地球开出太阳系，然后把成绩分享给朋友比一比。**

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录；贴图与背景音乐都以 base64 内联，`file://` 直接打开即可运行，**无需联网**。

## 玩法

| 项 | 说明 |
|----|------|
| **操控** | **按住屏幕任意位置**＝推力（整块画布就是按钮，没有落点也没有死角）。松手停机。双指捏合缩放 |
| **加速时机条** | 屏幕底部（驾驶舱内、仪表行正上方，**只在窗口内出现**）：`过早` / **`最佳加速时机`** / `过晚` 三段 + 一根扫过的判定针；头条一行三件 = 哪颗行星 → 现在踩在哪一段 → （右端）`速度 X / 门槛 Y km/s`（与身边三张表盘同一套单位）。指针进绿色区间再按住屏幕。**三段宽度与窗口时长逐行星不同**——由该行星质量（引力强度 √(2GM/R)）决定：木星 2.80 秒里绿色占 44%，冥王星 2.50 秒里只占 28% |
| **引力弹弓** | 只在最佳区间生效：速度**按比例**向该行星的弹弓速度逼近（差得越多拉得越猛），所以前面吃得少也能追回来。逼近速率按区间宽度反向补偿 → **吃满的收益五颗行星一致**，窄区间只是更难按准 |
| **过早的代价** | 温度总量只够**满功率连点 1.33 秒**（冷机起按住 1.58 秒——功率要先起转 0.5 秒才到满额），而窗口有 2.5–2.8 秒——窗口里全程死按，会在最佳区间之前就把温度烧穿。**更关键：本次掠过一旦在「过早」区间点过火（哪怕只有一帧），弹弓机会整次作废**——之后即便续按进绿色区间也只有普通推力，**判定点速度必然够不到门槛**。但代价不是当场终结：**地球照常掠过，欠账留给身后的氦闪壳**。实测：木星上过早点火 → 整局拖到 32.3 秒、进度 76% 才被壳追平；土星 / 天王星上过早 → 36.7 / 36.9 秒、93–94% 被追上（差一点就出去了）；海王星 / 冥王星上过早，前面跑得够好的话还追得回来（37.7 / 35.4 秒逃出）。**注：只有窗口内的「过早」区如此** —— 行星之间的巡航段（含两次耀斑脉冲）随便按，不作废弹弓 |
| **其他行星** | 水星 / 金星 / 火星按真实半径与真实轨道也在场上（只是不参与判定）：内侧的水星金星在地球身后——**后视镜**与**小地图**上看得见；火星在起手正前方约 1 秒处经过，**看得见但没有加速窗口** |
| **过热** | **温度按功率涨**（温度 = ∫ 功率，见功率表那一行）：烧满即进入**强制降温**（3.85 秒）—— 推力归零、功率熄火，温度按固定速率强制下降。**降温期间点也白点：按着既不升温、也不重新起转、更不打断降温进度**（旧版要玩家「先松手」才能降温，等于把抬指本身当惩罚）；降到 0 解锁，**解锁那一刻手指还在屏幕上就立即复机**，不用松手再按。底部**温度表盘**整表转红并呼吸（功率表同时归零），`过热` 警报灯常亮 |
| **仪表盘（屏幕底部平铺）** | 驾驶舱最下沿是**汽车驾驶舱式**的一整条：**功率 / 温度 / 速度**三个 270° 表盘并排（指针 + 随值生长的值弧），顺序就是驾驶时的手上顺序 —— 先看这一下**多大力**、再看**烫不烫**、最后看**够不够门槛**。功率表上有一道**额定线**（100%，脉冲乘波会推过它 —— 这就是「乘波」看得见的样子）、速度表上有一道**门槛刻度**（当前行星判定速度的位置，速度够了转绿）；温度表 `>70%` 整表转暖色、烧满锁定转红并呼吸。三格的数字与标题在同一条水平线上，所以余光一次扫完。右端竖排四盏警报灯 —— `过热`（红）/ `弹弓`（绿＝弹弓生效、红＝本次已作废）/ `耀斑`（琥珀）/ `氦闪`（距壳 < 28 AU 转琥珀、< 12 AU 转红闪烁）；灯下面是 `距日 / 距壳` 两条读数。**说明文案仍归消息槽**，灯只负责「有没有事」 |
| **功率表（发动机输出功率）** | 仪表行第一张**指针表盘**（最左，最先被读到），现在是一条**油门斜坡**：按住 0.5 秒从 0 爬到额定线（100%），松手 0.5 秒归零 —— 指针的高度就是「按下去了多久」。四档读数：**0% 停机或过热锁定（指针与弧转灰）/ 20% 过晚残效（红）/ 100% 额定推力 / 160% 耀斑脉冲乘波（琥珀，指针推过额定线）**；满量程 160%、额定 100% 处有一道细刻度。**温度就是按这张表积出来的：指针越高越烫**（过晚 20% 只涨 15/s、额定 75/s、乘波 120/s）—— 于是「在过晚区死按」不再白烧温度、而「在脉冲期死按」烫得最快 |
| **计时 / 进度 / 小地图 / 后视镜** | 这些与「点火」无关，全部放在**屏幕顶部**——想起来再抬头看一眼：左上依次是 `m:ss.mmm` 正计时（毫秒单独一段小字；它就是成绩本体，结算与分享仍按 0.1 s 记）、`逃逸进度 X%` 细条、太阳系小地图；顶部中间是后视镜；右上角是 BGM 开关 |
| **提示条** | 挂在**时机条正上方**（驾驶舱上沿、向上生长），全屏只有这一条，**只在发动机出状况时才出现**：过热时报归零冷却倒计时（赶不上绿色区间就直说 `这站来不及解锁`）、耀斑脉冲预警与生效时给动作指令。**巡航段保持空**——不预告窗口还剩几秒（旧版会一路数到窗口开启），也不报速度缺口（过早区间速度必然低于门槛，那不是危险）。它与**掠过评级**共用同一槽位（紧急的过热／脉冲抢屏、其次评级），所以屏幕上永远不会同时挂两条文案；窗口临近靠行星越长越大、时机条滑入、绿色边缘光和进绿色区间的音效告诉你 |
| **过晚 / 错过** | **只有这一种情况会被行星当场抓住**：这一关的窗口根本没碰（完全没按，或只在过晚区间按）→ 判定点速度 < 门槛被捕获，再低一档（< 门槛 ×0.72）坠入大气层。即「即时失败」留给「错过时机」，「延迟失败」留给「过早烧废弹弓」 |
| **掠过评级** | 每过一颗行星都会弹一条评级：`完美弹弓` / `差一口气` / `按早了` / `按晚了` / `没点火` / `速度没拉起来`，并给出**这次绿色区间实际点了多少秒（对照完美线）**与一句改进提示 |
| **脉冲乘波** | 2 次耀斑脉冲（12 / 26 秒，各 1 秒）期间推力 ×1.6，且**提前 2 秒预警**（提示条倒数 `耀斑脉冲 1.4 s 后 · 推力 ×1.6`）；脉冲到时提示条直接给动作：巡航段 `现在按住`、过早段 `别按（会作废弹弓）`。**乘波把功率推过额定线，温升也 ×1.6**：老实等脉冲亮了再按满 1 秒只涨到 90（安全），**在预警期就按住则会在脉冲没结束时烧穿**——所以预警期绝不说「按住」 |
| **不设时限** | 左上只是正计时（标着 `逃逸用时`，它同时就是成绩）。唯一的死线是身后那层壳 |
| **后视镜** | 顶部常驻回望视角，看身后的氦闪壳追到哪了 |
| **胜利** | 走完航线，冲出太阳系 |
| **成绩** | **逃逸用时**越短越强；本站最快记在本地，结算页可一键分享战绩 |

不操作的话，木星这一关就过不去（约 5.8 秒）。

## 通关梯度（自检实测）

| 打法 | 结果 |
|---|---|
| 弹弓全吃满 | **34.7 秒逃出**，5/5 完美弹弓（每次掠过壳余量 2.9–6.4 秒） |
| 吃个大概（区间内提前松手 25%） | 38.5 秒逃出，冥王星处只剩 **0.8 秒**壳余量 |
| 只吃到一半（55%） | 进度 60% 被壳追上（27.8 秒） |
| 只擦到一点（35%） | 进度 36% 被壳追上（19.8 秒） |
| 乱按 / 一直按着 / 从不点火 | 木星处出局（5.1–5.7 秒） |
| 窗口内全程死按 | 土星处撞毁（11.8 秒：过早先烧废弹弓，温度又按功率烧穿） |

## 自检

```bash
node tests/headless_escape.js
```

共 **265 项**断言。除物理核心外还含**静态契约**（沙箱里没有 `document`/`THREE`，渲染层会被整段跳过，改名漏改不会被运行期发现）：

- **工程**：导出齐全；**DOM/样式契约**——引用的每个 id 都在 `index.html` 里、新 HUD 元素与状态类齐全、旧机制无残留、**天球不用贴图**、**app.js 全文 ES5**
- **驾驶舱布局契约**：`#cockpit` 贴底并叠底部安全区；仪表行不再是右上那块浮动面板（平铺在驾驶舱内）；时机条与仪表行都不写死像素 `bottom`（靠 flex 排版 + margin 留缝）；`#warn` 与评级条都在 `#cockpit-msg` 这个**零高度槽位**里、排在时机条之前；逃逸进度搬到左上列
- **仪表盘契约（汽车驾驶舱式）**：声音开关在**右上**；`#clock / #mute / #mirror-frame / #radar / #progress` 五个顶部元素**都叠了 `--top-gap`**（少一个就会钻进宿主顶栏）；计时带 3 位毫秒（`#clock-ms` 独立节点，不能被 `textContent` 冲掉）；**指针用 SVG `rotate` 属性**（断言 app.js 走 `setAttribute('transform', …)` 且 CSS 里没有 `transform-origin`）；速度表 80 km/s、**功率表 160%** 各有满量程与弧长常量；**第三个表盘 = 发动机功率**（DOM 齐全 + 接进 `updateHUD`，四档读数被 `功率 × zoneEff × PULSE_THRUST_BOOST` 锁死，且是 `PWR_UP = 200/s` 的起转斜坡、过晚红态按区间判）；**温度 = ∫ 功率**（静态断言 `TEMP_RATE` 与那一行积分式）；**仪表行顺序 = 功率 → 温度 → 速度**（锁 DOM 次序）；三格都是指针表盘；**两个历史 bug 的回归契约**——① 功率指针刻度把小数折成百分数再除 160 满量程（`power * 100 / PWR_VMAX`，旧写法 `power / PWR_VMAX` 让指针全程只转 1°）；② 值弧进度走 **inline style**（CSS 里 `.dg-arc{stroke-dashoffset:179.1}` 是声明，会压过同名 SVG 表现属性 → 旧写法三条值弧永远是空的）；四盏警报灯 id 齐全；**旧的一维温度条（`#heat-wrap/#heat-fill/#heat-track`）与文字遥测面板（`#telemetry`）已彻底移除、旧 id 不复用**
- **开场引导**：仍是「MOSS：航线已解算 / 你：决定点火时刻」的对照（改排成**终端样式**：左缘青条 + 微青底 + 「你」行末呼吸光标），但规则拆成**三步操作卡**（第三条为代价、单独标红，1→2 之间有一条绿色渐隐流程线），并保留「绿色区间」「弹弓作废」「唯一目标」三处关键措辞
- **简报篇幅契约**：三条指令**各占一行**（`.bf-step` 内不得再出现 `<i>`）、航线示意图必须是**扁版**（`viewBox` 高 ≤ 90）、正文**字数 ≤ 125 且实测 118**。三条合起来锁住「面板一屏放得下」——曾经三张两行卡片 + 210×130 示意图把面板顶到 620px，320×568 上「点火启航」要滚动才看得见
- **BGM**：确实解出 MPEG 音频、时长合理、加载顺序正确、有静音开关与持久化、切后台挂起
- **分享**：用时/最快纪录区块、成绩持久化、首选 `interactionOpenApi`（`post_comment + media_bean`，媒体只喂本地句柄）、按 `buildVersion` 判 9.49 客户端版本、回退 `postNote + image_resources`、配图 Canvas 现画、标题/正文长度上限、**不出现容器禁用能力**
- **常量互锁**：速度换算、星点尺寸下限、**冷机按住 1.58 s / 满功率恒温 1.33 s 烧穿 < 每颗行星窗口时长**、**冷机只按整段绿色区间只涨到 73.7 < 100**（三条逐行星验）、**熄火 0.5 s 比散热 3.85 s 快**、掠过行星名单、`vSling > vNeed`
- **功率 → 温度**：功率是 0.5 s 起转斜坡（0.25 s 约半、0.5 s 满额，推力随之长）且过热熄火；**温度 = ∫ 功率**（满功率 75/s、50% 减半、20% 只有 1/5）；过晚区间因残效 20% 只涨 15/s、过早区仍 75/s；**脉冲乘波 120/s（额定 ×1.6），冷机按满 1 s 到 90、满功率进脉冲 0.83 s 烧穿**；解锁后功率从 0 重新起转
- **航线几何**：弧长表精确、行星依次排列、掠过距离 = 半径 + 净空、**行星距日 = 真实轨道半径**、行星正对掠过点
- **天体尺度**：半径 = 真实半径 × 统一倍率（偏差 0）、4 组实测半径比 = 真实半径比、**太阳显式例外**、屏幕大小次序 = 真实次序、木星仍占 ~57% 屏高而冥王星 <5%
- **质量 → 时机窗口**：质量序 = 逃逸速度序、v_esc 与真实同量级、引力越强窗口越长/绿色区间越宽、两端锚定、**吃满区间的增益逐行星恒为 87.3%**、评级阈值随区间折算、海王星 ≥ 天王星
- **场上其他行星**：水星/金星/火星都在场景且不在掠过名单、半径同一条换算、**距日 = 真实轨道半径**、不穿模、内侧行星在起点内侧、火星站台在木星之前
- **时机窗口 / 掠过评级**：相位与区间映射（**参数逐行星**）、7 种评级判定、同一 0.45 s 在不同行星评级不同、物理核心分区累计点火时长
- **配色语义**：「最佳加速时机」整段是绿色（节奏游戏惯例：绿 = 命中区），与「红色危险」构成红绿灯对照；全屏「该按了」呼吸光与 3D 判定环同色；**金色只剩「评价/结算」轴**（完美弹弓、结算用时、新纪录），时机轴不得再出现金色
- **提示文案**：**巡航段消息槽保持空**（不预告窗口、不报速度缺口）、窗口内不再刷任何提示、过热时解锁倒计时 = 热量 ÷ 冷却率、**赶不上绿色区间就报「这站来不及解锁」**（判据是绿色区间开始，不是窗口开启）、过晚文案、耀斑脉冲两条（预警 / 生效）都还在
- **耀斑脉冲**：只两次且都落在单局时长内（被删掉的第 3 次 @40 s 走不到）、预警提前量 ≥1.5 s、`pulseIn` 倒数、**提示按区间分叉**（巡航段「现在按住」/ 过早段「别按（会作废弹弓）」/ 绿色与过晚不抢屏）、**预警期绝不说「按住」**（连按会烧穿）、预警 2 s 与生效 1 s 逐帧成立、**乘波把温升也 ×1.6**（冷机按满 1 s 只到 90、满功率进脉冲 0.83 s 必烧穿）
- **弹弓 / 过热 / 判定 / 氦闪壳**：最佳区间显著快于过早、过晚几乎无收益、**过早区点火哪怕 1/120 s → 该次掠过记为 `速度没拉起来`（不判死）且整局延后到 30 s 之后才被壳追平**（逐颗行星跑）、**不点火 / 只在过晚区间点仍在当场被捕获**、**冷机烧穿耗时 = 起转三角 + 满功率段**、**强制降温**（按着也照降且速率 = COOL_RATE、整个降温阶段功率与推力恒为 0、降到 0 才解锁、解锁后手指还在屏幕上就立即复机）、三档判定、壳吞没
- **相机**：跟拍距离有界、**偏移窗口单侧**、**注视距离不因行星偏移而改变**、注视方向不翻折
- **构图不变式**：掠过时地球离画面中心 < 26°、行星近缘 < 30°（两者始终同框）、注视方向被行星拉走的夹角 ≤ `CAM_PAN_TILT_MAX`
- **土星光环**：按渲染层同一个环面法线验算「航线穿过环带时的最小垂距 > 地球半径」（地球绝不穿环）、环带与轴倾用真实值
- **胜负**：满弹弓逃出、75% 也能逃出但更慢、其余逃不出、**10fps 与 60fps 状态完全一致**
