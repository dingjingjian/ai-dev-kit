# 流浪地球 · 引力弹弓

> **分类**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)
>
> **状态**：玩法完成、可玩（固定航线时机节奏 + 掠过评级 + 用时成绩与分享 + MOSS 启动自检页，无头自检 **336/336** 全绿）。设计与数值真源见 [`DESIGN.md`](DESIGN.md)。

太阳氦闪的膨胀壳从第 0 秒就在地球身后追。地球沿一条**固定航线**自动冲向太阳系外缘，你唯一的操作是**什么时候按住点火**：

- **过早** — 推力照烧，但吃不到引力弹弓的放大，还白烧掉温度额度；
- **最佳时机**（时机条上的绿色区间）— 弹弓把速度拉向该行星的弹弓速度，这是唯一能把速度拉到门槛之上的办法；
- **过晚** — 判定点速度不够，**被行星捕获，或直接被拽进大气层**。

**目标只有一个：用最短的时间把地球开出太阳系，然后把成绩分享给朋友比一比。**

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录；贴图与背景音乐都以 base64 内联，`file://` 直接打开即可运行，**无需联网**。

开场顺序：**MOSS 启动自检（3.0 s，逐项打勾）→ 出发过场（2.6 s）→ 简报**。资源全内联，真实加载只要一两百毫秒，所以启动页的停留是**刻意给的**（`BOOT_MIN_MS`，唯一旋钮）—— 让「这是谁的屏、在为出发做什么准备」读得出来。

## 玩法

| 项 | 说明 |
|----|------|
| **操控** | **按住屏幕任意位置**＝推力（整块画布就是按钮，没有落点也没有死角）。松手停机。双指捏合缩放 |
| **加速时机条** | 屏幕底部（驾驶舱内、**固定**在仪表行正上方）：**一个盒子两种内容**——窗口内是 `过早` / **`引力窗口`** / `过晚` 三段 + 一根扫过的判定针；巡航段换成**下一站进度条**（按弧长填，**填满就是窗口亮起那一刻**，只给进度不给秒数）。头条一行三件 = 哪颗行星 → 现在踩在哪一段 → （右端）`速度 X / 门槛 Y km/s`（与身边三张表盘同一套单位）。**只报窗口状态**：三态 tag 都是短词 —— 命中 `引力窗口` / 窗口外 `窗口外点火` / 过晚 `窗口关闭`（「全功率推进」那截功率信息 2026-09-27 删，「· 增益作废」那截同日也删 —— 后者在 320px 窄屏上会被省略号吃掉半截；作废这件事由琥珀色带 + 掠过后的评级卡交代）。**五站过完之后**这条带不隐掉，终点改指 **比邻星**（`比邻星 / 航向 · 冲出太阳系`，条按 冥王星 → 航线末端 的弧长填，此时不再有判定点、门槛读数收掉）。指针进绿色区间再按住屏幕。**三段宽度与窗口时长逐行星不同**——由该行星质量（引力强度 √(2GM/R)）决定：木星 2.80 秒里绿色占 44%，冥王星 2.50 秒里只占 28%。外框**没有描边也没有折角**，三态（绿 / 琥珀 / 红）靠整块外发光表达 |
| **引力弹弓** | 只在最佳区间生效：速度**按比例**向该行星的弹弓速度逼近（差得越多拉得越猛），所以前面吃得少也能追回来。逼近速率按区间宽度反向补偿 → **吃满的收益五颗行星一致**，窄区间只是更难按准 |
| **过早的代价** | 温度总量只够**满功率连点 1.33 秒**（冷机起按住 1.58 秒——功率要先起转 0.5 秒才到满额），而窗口有 2.5–2.8 秒——窗口里全程死按，会在最佳区间之前就把温度烧穿。**更关键：本次掠过一旦在「过早」区间点过火（哪怕只有一帧），弹弓机会整次作废**——之后即便续按进绿色区间也只有普通推力，**判定点速度必然够不到门槛**。但代价不是当场终结：**地球照常掠过，欠账留给身后的氦闪壳**。实测：木星上过早点火 → 整局拖到 32.3 秒、进度 76% 才被壳追平；土星 / 天王星上过早 → 36.7 / 36.9 秒、93–94% 被追上（差一点就出去了）；海王星 / 冥王星上过早，前面跑得够好的话还追得回来（37.7 / 35.4 秒逃出）。**注：只有窗口内的「过早」区如此** —— 行星之间的巡航段（含两次耀斑脉冲）随便按，不作废弹弓 |
| **其他行星** | 水星 / 金星 / 火星按真实半径与真实轨道也在场上（只是不参与判定）：内侧的水星金星在地球身后——**尾向观测窗**与**小地图**上看得见；火星在起手正前方约 1 秒处经过，**看得见但没有加速窗口** |
| **过热** | **温度按功率涨**（温度 = ∫ 功率，见功率表那一行）：烧满即进入**强制降温**（3.85 秒）—— 推力归零、功率熄火，温度按固定速率强制下降。**降温期间点也白点：按着既不升温、也不重新起转、更不打断降温进度**（旧版要玩家「先松手」才能降温，等于把抬指本身当惩罚）；降到 0 解锁，**解锁那一刻手指还在屏幕上就立即复机**，不用松手再按。底部**温度表盘**整表转红并呼吸（功率表同时归零），`过热` 警报灯常亮 |
| **仪表盘（屏幕底部平铺）** | 驾驶舱最下沿是**汽车驾驶舱式**的一整条：**功率 / 温度 / 速度**三个 270° 表盘并排（指针 + 随值生长的值弧），顺序就是驾驶时的手上顺序 —— 先看这一下**多大力**、再看**烫不烫**、最后看**够不够门槛**。功率表上有一道**额定线**（100%，脉冲乘波会推过它 —— 这就是「乘波」看得见的样子）、速度表上有一道**门槛刻度**（当前行星判定速度的位置，速度够了转绿）；温度表 `>70%` 整表转暖色、烧满锁定转红并呼吸。ⓘ **功率表读的是发动机的输出功率（油门 × 乘波），与区间、弹弓都无关**：过晚区间照样满表 100%（红态 = 这一份功率兑不出推力，画面读作「满功率白烧」），弹弓期也不会被放大 —— 区间只影响「多少功率能变成推力」。三格的数字与标题在同一条水平线上（**三格在列内居中**，2026-09-27：旧版吃满上限后余量全堆在右侧，看着是「贴左的一坨」），所以余光一次扫完。右端竖排四盏警报灯 —— `过热`（红）/ `弹弓`（绿＝弹弓生效、红＝本次已作废）/ `耀斑`（琥珀）/ `氦闪`（距壳 < 28 AU 转琥珀、< 12 AU 转红闪烁）；灯下面是 `距日 / 距壳` 两条读数。**说明文案仍归消息槽**，灯只负责「有没有事」 |
| **功率表（发动机输出功率）** | 仪表行第一张**指针表盘**（最左，最先被读到），现在是一条**油门斜坡**：按住 0.5 秒从 0 爬到额定线（100%），松手 0.5 秒归零 —— 指针的高度就是「按下去了多久」。三档读数：**0% 停机或过热锁定（指针与弧转灰）/ 100% 额定（过晚区间也是满表，但整表转红 = 这一份功率兑不出推力）/ 160% 耀斑脉冲乘波（琥珀，指针推过额定线）**；满量程 160%、额定 100% 处有一道细刻度。**温度就是按这张表积出来的：指针越高越烫**（过晚残效只涨 15/s、额定 75/s、乘波 120/s）—— 温升读的是「有效推力档位」，所以「在过晚区死按」白给的是推力而不是温度，而「在脉冲期死按」烫得最快 |
| **顶栏：观测窗 / 计时 / 导航图 + 声音** | 与「点火」无关的信息全在**一条顶栏**里（左 **尾向观测窗** 方形 ┊ 中 `m:ss.xx` 正计时，**36px**、两位小数 18px 单独一段小字（它就是成绩本体 —— 结算页与分享卡**同样是两位小数**，三处读的是同一个数）┊ 右 **导航图 + 它下面的 BGM 开关**）：左右两块是**同尺寸方形显示窗**（一左一右对称，都**没有卡片外框**、标识文字嵌在**画面顶部左上角**；两块窗的显示 / 隐藏行为完全一致 —— 简报与结算盖上来时连画布带标识一起退场），计时夹在中间因而天然居中；**逃逸进度在屏幕最底部的信息栏里** —— 最下沿既不挡画面，也不逼视线往上跑 |
| **底部信息栏（`#dash`）** | 上排 = **控制台两列**：① 功率/温度/速度三张表盘 ② 参数（四盏警报灯 + `距日 / 距壳`）；下排 = **逃逸进度独占一行的通宽细条**。两排之间只用留白分隔、**不加横线**，列间只用一条竖线（2026-09-26 先把进度与小地图从左上角并进来、定稿成三列，同日又把 42px 的小地图搬到右上角放大到 76px —— 信息栏退回两列，高度仍 112px，表盘从 43px 长到 59px） |
| **提示条** | **浮在时机条上方 6px**（零高度槽位，不推挤布局 —— 时机条因此位置恒定），全屏只有这一条，只报三类状态：**过热**（`发动机过热 · 强制冷却 X s`；赶不上绿色区间就直说 `发动机过热锁定 · 本站窗口前无法解锁`）、**耀斑脉冲**（预警 `⚠ 太阳耀斑脉冲 2.0 s 后 · 推力 ×1.6`；生效期巡航段 `… · 全功率推进`、过早段 `… · 窗口外禁止点火`）、**过晚**（`窗口关闭 · 已错过`）。**巡航段保持空**——不预告窗口还剩几秒（旧版会一路数到窗口开启），也不报速度缺口（过早区间速度必然低于门槛，那不是危险）。它与**掠过评级**共用同一槽位与**同一张「终端消息卡」样式**（紧急的过热／脉冲抢屏、其次评级），所以屏幕上永远不会同时挂两条文案；窗口临近靠行星越长越大、进度条走满、绿色边缘光和进绿色区间的音效告诉你 |
| **过晚 / 错过** | **只有这一种情况会被行星当场抓住**：这一关的窗口根本没碰（完全没按，或只在过晚区间按）→ 判定点速度 < 门槛被捕获，再低一档（< 门槛 ×0.72）坠入大气层。即「即时失败」留给「错过时机」，「延迟失败」留给「过早烧废弹弓」 |
| **掠过评级** | 每过一颗行星都会弹一条评级（**只有成功掠过才弹**，被抓住那次由结算页解释）：`完美弹弓` / `弹弓增益未满` / `弹弓增益损失` / `提前点火` / `点火延迟` / `无效点火` / `发动机未点火` / `轨道速度不足` / `引力捕获`，并给出**这次绿色区间实际点了多少秒（对照完美线）**与一句改进提示（完整判定顺序见 [`DESIGN.md`](DESIGN.md) §8） |
| **脉冲乘波** | 2 次耀斑脉冲（12 / 26 秒，各 1 秒）期间推力 ×1.6，且**提前 2 秒预警**（提示条倒数 `⚠ 太阳耀斑脉冲 2.0 s 后 · 推力 ×1.6`）；脉冲到时提示条直接给动作：巡航段 `⚠ 太阳耀斑脉冲 ×1.6 · 全功率推进`、过早段 `⚠ 太阳耀斑脉冲 ×1.6 · 窗口外禁止点火`。**乘波把功率推过额定线，温升也 ×1.6**：老实等脉冲亮了再按满 1 秒只涨到 90（安全），**在预警期就按住则会在脉冲没结束时烧穿**——所以预警期只说倒计时、绝不说「按住」 |
| **不设时限** | 顶栏中间只是正计时（标着 `逃逸用时`，它同时就是成绩）。唯一的死线是身后那层壳 |
| **尾向观测窗** | 顶栏左端的常驻**方形**回望视角（朝舰尾方向 = 地球身后），看氦闪壳追到哪了、以及那两颗永远在身后的内侧行星。**标识嵌在画面顶部左上角**（单行 `▍尾向观测`，不带底板；2026-09-27 把第二行「氦闪壳」删了 —— 壳本来就看得见，字是多余的；位置与右侧导航图严格同一处 `left:2px / top:2px`），窗本身**没有卡片外框**（2026-09-27 去卡片化：描边 / 投影 / 窗下那条独立标签条一并撤掉）；旧名「后视镜」已按世界观改掉，代码里 id 仍是 `#mirror-frame` |
| **胜利** | 走完航线，冲出太阳系 |
| **成绩** | **逃逸用时**越短越强（**两位小数**：局内计时器 / 结算页 / 分享卡 / 最快记录同一个精度，由 `t2()` 统一取整）；**最快记录**记在本地，结算页可一键分享战绩（**结算页只有屏底两个按钮有动作** —— 点正文不再重开，免得想点分享却按到正文、整页重开） |

## 通关梯度（自检实测）

| 打法 | 结果 |
|---|---|
| 弹弓全吃满 | **34.7 秒逃出**，5/5 完美弹弓（掠过那一刻若熄火，壳追上还需 3.9 / 7.8 / 8.7 / 7.3 / 2.6 秒 —— 最紧是末站冥王星） |
| 吃个大概（绿色区间只按前 75% 就松手） | **38.3 秒逃出**，五次都只到「弹弓增益未满」；冥王星处只剩 **2.8 秒**余量 |
| 只按前 55% | 进度 **58.7%** 被壳追上（**27.3 秒**，落在天王星与海王星之间） |
| 只按前 35% | 进度 **35.8%** 被壳追上（**19.6 秒**，落在土星与天王星之间） |
| 乱按 / 一直按着 / 从不点火 | 木星处出局（5.1–5.7 秒） |
| 窗口内全程死按（过早 + 绿色 + 过晚都不松手） | 土星处**坠入大气层**（11.5 秒、进度 20%：过早先烧废弹弓，温度又按功率烧穿） |

## 素材与工程

| 项 | 说明 |
|----|------|
| 引擎 | Three.js（`assets/three.min.js`，外置同目录、无 CDN） |
| 航线 | 对数螺旋 + 轻环绕 + 垂直起伏；行星位置**由航线反推**（距日 = 真实轨道半径，掠过距离 = 半径 + 设计净空） |
| 天体尺度 | **行星半径 = 真实半径 × 统一 800×**（唯一真源是 `rKm`，`rad` 派生）：木 37.4 / 土 31.1 / 天 13.6 / 海 13.2 / 冥 0.64 / **地球 3.41（= 手调时代的 3.4，占屏 13%）** —— 比例与真实一致，倍率以地球的观感为锚点。**太阳是唯一例外**（同比会是 372 单位 > 航线起点 95，会把地球装进太阳里） |
| 掠过构图 | 净空随半径等比放大（×2.667）→ 「掠距 : 半径」与放大前一致；**注视偏移上限 `CAM_PAN_TILT_MAX = 9°`**（否则视线被抬高几十度会把地球顶出画面）→ 掠过时行星压上半屏、地球带判定环留在下半 |
| 土星光环 | 环带用**真实比例 1.11 ~ 2.27 倍半径**，环面摆在**土星赤道面**上并叠加真实轴倾角 **26.73°**。「穿环」原来是**朝向**问题：`RingGeometry` 默认法线 +Z、代码没旋转 → 航线在环带内穿过环面（实测最小垂距 0.15 单位 ≪ 地球半径）；摆到赤道面后同一测法 **30.5 单位** → 永不穿环。**2026-09-27 视觉优化**：从「一块纯色圆环」改成按**真实环结构**画的**径向色带纹理**（`satRingTex`：D / C / B 环 + **卡西尼缝** + A 环 + **恩克缝**，段间线性插值 + 确定性细环纹噪声，内缘 / 外缘 alpha 收到 0 → 边缘渐隐而不是硬切；`RingGeometry` 的 UV 重映射成「归一化半径」、各向异性过滤拉满）。掠过时镜头会**从环带里穿过去**，那几道缝与色带就是这一站的第二个看点 |
| 时机窗口 | **逐行星由质量派生**（唯一真源是 `mEarth`）：`v_esc = √(2GM/R)` → 窗口 2.50–2.80 s、绿色区间占比 28%–44%、`slingK` 反向补偿（吃满收益恒为 87.3%）、评级阈值按各自区间折算 |
| 场上其他行星 | 水星 1.30 / 金星 3.24 / 火星 1.81 单位，距日 = 真实轨道半径（0.387 / 0.723 / 1.524 AU）；**不参与判定**，没有判定环与窗口 |
