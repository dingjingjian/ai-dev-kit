# 流浪地球 · 逃出太阳系

> **分类**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)
>
> **状态**：可玩（三段式剧情 + 轨道预测玩法 + 双档相机完成，无头自检 34/34 通过）。设计真源见 [`DESIGN.md`](DESIGN.md)。

按《流浪地球》原著的三段结构推进：**刹车时代**（过场，不可操作）→ **逃逸时代**（玩家拖出点火箭头，绕日 15 圈加速）→ 叛乱与**太阳氦闪**，最终带着地球飞出太阳系。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录；贴图以内联 data URI 提供，`file://` 直接打开即可运行，无需联网。

## 流程

| 段 | 内容 | 可操作 |
|----|------|--------|
| **序章 · 刹车时代** | 氦闪预警 → 飞船派/地球派之争 → 万台行星发动机点火 → 月球被推离（海啸）→ 停止自转 → 迁入地下城，年份从第 0 年滚动到第 42 年 | 否（点击推进，可跳过） |
| **逃逸时代** | 绕日 15 圈，一圈圈把轨道推大，攒够逃逸速度 | **是** |
| 叛乱 · 氦闪 | 第 10 圈触发：叛乱 → 处决 → 太阳氦闪爆发，太阳膨胀吞没水星与金星——此时离太阳太近会被一并吞没 | 氦闪幕可操作（自救） |
| 终局 | 飞出 20 AU 即胜利 | 结算 |

## 玩法（逃逸时代）

| 项 | 说明 |
|----|------|
| **操控** | 在屏幕上**按住并拖出箭头**：方向 = 点火方向，长度 = 点火量（Δv）。拖动时**橙色虚线实时预演点火后的新轨道**，松手执行，发动机烧完预定量自动停机 |
| **近日点点火** | 轨道上标出**近日点**。靠近它点火有**效率加成**（奥伯特效应的游戏化：同样燃料换更多速度，最高 +55%），标记变橙并脉冲提示"点火窗口" |
| **相机** | 双档自动切换：平时拉远以太阳为中心**看整条轨道**（轨道怎么变一目了然），点火时自动拉近看地球与尾焰。滚轮 / 双指可额外缩放；地球出画时屏幕边缘有方向指示 |
| **燃料** | 总速度增量约 54 km/s（真实单位），单次点火最多约 8.5 km/s——省着用，配合近日点窗口与木星弹弓 |
| **逃逸比** | 遥测里的关键数字：当前速度 ÷ 该位置的太阳逃逸速度，**≥ 1.00 即具备脱离太阳引力的能量** |
| **失败** | 撞上太阳 / 行星；进入行星引力范围且相对速度不足（被捕获）；氦闪时仍留在膨胀半径内（被吞没） |

## 天体

| 天体 | 角色 |
|------|------|
| 太阳 | 引力主源，坠入即失败；第 10 圈后氦闪膨胀，吞没内圈 |
| 水星 / 金星 | 内圈干扰；氦闪时被太阳吞没 |
| 火星 | 逃逸路上的第一道坎 |
| **木星** | **主要威胁**：影响球大、引力强，也是最好的引力弹弓 |
| 土星 | 更外侧的挑战 |
| 月球 | 序章中被发动机推离地球轨道（潮汐失控引发全球海啸），随后退场 |
| 比邻星 | 胜利方向的目标星 |

## 关于尺度与物理（如实说明）

- **天体半径与行星引力做了放大**。真实比例下地球在屏幕上小到看不见，且真实行星引力不足以在游戏时间内捕获地球。放大后"擦边就被抓住"才成为可玩的机制。
- **遥测是真实的**：HUD 里的 km/s 与"年"由游戏单位换算而来，换算系数经过校验——1 AU 处的圆轨道速度恰为 **29.8 km/s**，地球公转一圈恰为 **1 年**（`tests/headless_wandering.js` 有对应断言）。
- **轨道预测是真实的开普勒轨道**：由当前位置与速度解算轨道要素（半长轴 / 偏心率 / 近日点方向），画出的实线就是地球接下来要走的路，橙色虚线是点火后的路。
- 行星为共面圆轨道、不受地球影响（单向引力），物理积分为半隐式欧拉 + 固定子步。
- 剧情按小说设定推进（刹车时代 42 年、绕日 15 圈、叛乱与氦闪）；数值与事件节奏为可玩性做了压缩。

## 素材与工程

| 项 | 说明 |
|----|------|
| 引擎 | 复用手写 WebGL 引擎（`assets/engine.js`）；另有一层 2D canvas（`#fx`）画轨道线 / 预测线 / 近日点 / 影响球 / 点火箭头 |
| 地球 / 云层贴图 | 内联 data URI（`earth-data.js` / `clouds-data.js`） |
| 行星贴图 | 水星 / 金星 / 火星 / 木星 / 土星，取自 `vibeknow/solar-system-3d/assets/`，内联为 `*-data.js` |
| 物理与判定 | `assets/game.js`（唯一真源）：引力、预定量点火、奥伯特加成、圈数、氦闪判定 |
| 轨道解算 | `assets/orbit.js`：开普勒要素、轨道采样、Δv 预测、点火窗口 |
| 剧情 | `assets/story.js`（唯一真源）：序章 7 幕 + 叛乱 3 幕，每幕带场景指令 |
| 天体与参数 | `assets/bodies.js`：尺度、行星参数、发动机阵列（56 道表面光柱）、月球 |
| 构建 | `build.mjs`（构建 `dist/`）、`verify-minitool.mjs`（合规校验）、`pack.mjs`（打包 zip） |

贴图重新生成：`node tools/make-texture-data.mjs`。脚本一律使用相对路径，禁止硬编码绝对路径（参考根目录 `TRACKS.md` 维护约定）。

## 自检

```bash
node tests/headless_wandering.js
```

在 Node 沙箱里真的跑一遍玩法内核，共 34 项断言：不操作稳定绕日、顺向点火逃逸、逆向减速坠日、木星捕获/弹弓、燃料耗尽停机，以及新增的——轨道解算自洽（圆轨道周期 ≈ 60 游戏秒）、10 年 ≈ 10 圈、**奥伯特效应**（近日点点火实测多换 52% 速度）、预定量点火按量扣燃料、氦闪吞没判定。

## 分类判定

有明确的目标、失败与胜负反馈，用户点开的第一动机是"玩"——算点火窗口、贴近日点、赌一把木星弹弓，而不是"搞懂一件事" → `#vibegame`。与 `moon-landing-3d`、`solar-system-3d`、`earth-3d` 共用素材与引擎，但价值取向不同（前者是看与懂，这里是玩与赢）。
