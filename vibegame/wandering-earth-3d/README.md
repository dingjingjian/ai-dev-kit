# 流浪地球 · 引力弹弓

> **分类**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)
>
> **状态**：玩法完成、可玩（固定航线时机节奏 + 掠过评级 + 用时成绩与分享 + MOSS 启动自检页，无头自检 **298/298** 全绿）。设计与数值真源见 [`DESIGN.md`](DESIGN.md)。

太阳氦闪的膨胀壳从第 0 秒就在地球身后追。地球沿一条**固定航线**自动冲向太阳系外缘，你唯一的操作是**什么时候按住点火**：

- **过早** — 推力照烧，但吃不到引力弹弓的放大，还白烧掉温度额度；
- **最佳时机**（时机条上的绿色区间）— 弹弓把速度拉向该行星的弹弓速度，这是唯一能把速度拉到门槛之上的办法；
- **过晚** — 判定点速度不够，**被行星捕获，或直接被拽进大气层**。

**目标只有一个：用最短的时间把地球开出太阳系，然后把成绩分享给朋友比一比。**

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录；贴图与背景音乐都以 base64 内联，`file://` 直接打开即可运行，**无需联网**。

开场顺序：**MOSS 启动自检（3.0 s，逐项打勾）→ 出发过场（2.6 s）→ 简报**。资源全内联，真实加载只要一两百毫秒，所以启动页的停留是**刻意给的**（`BOOT_MIN_MS`，唯一旋钮）—— 让「这是谁的屏、在为出发做什么准备」读得出来。

## 玩法

| 项 | 说明 |
|----|------|
| **操控** | **按住屏幕任意位置**＝推力（整块画布就是按钮，没有落点也没有死角）。松手停机。双指捏合缩放 |
| **加速时机条** | 屏幕底部（驾驶舱内、**固定**在仪表行正上方）：**一个盒子两种内容**——窗口内是 `过早` / **`最佳加速时机`** / `过晚` 三段 + 一根扫过的判定针；巡航段换成**下一站进度条**（按弧长填，**填满就是窗口亮起那一刻**，只给进度不给秒数）。头条一行三件 = 哪颗行星 → 现在踩在哪一段 → （右端）`速度 X / 门槛 Y km/s`（与身边三张表盘同一套单位）。指针进绿色区间再按住屏幕。**三段宽度与窗口时长逐行星不同**——由该行星质量（引力强度 √(2GM/R)）决定：木星 2.80 秒里绿色占 44%，冥王星 2.50 秒里只占 28% |
| **引力弹弓** | 只在最佳区间生效：速度**按比例**向该行星的弹弓速度逼近（差得越多拉得越猛），所以前面吃得少也能追回来。逼近速率按区间宽度反向补偿 → **吃满的收益五颗行星一致**，窄区间只是更难按准 |
| **过早的代价** | 温度总量只够**满功率连点 1.33 秒**（冷机起按住 1.58 秒——功率要先起转 0.5 秒才到满额），而窗口有 2.5–2.8 秒——窗口里全程死按，会在最佳区间之前就把温度烧穿。**更关键：本次掠过一旦在「过早」区间点过火（哪怕只有一帧），弹弓机会整次作废**——之后即便续按进绿色区间也只有普通推力，**判定点速度必然够不到门槛**。但代价不是当场终结：**地球照常掠过，欠账留给身后的氦闪壳**。实测：木星上过早点火 → 整局拖到 32.3 秒、进度 76% 才被壳追平；土星 / 天王星上过早 → 36.7 / 36.9 秒、93–94% 被追上（差一点就出去了）；海王星 / 冥王星上过早，前面跑得够好的话还追得回来（37.7 / 35.4 秒逃出）。**注：只有窗口内的「过早」区如此** —— 行星之间的巡航段（含两次耀斑脉冲）随便按，不作废弹弓 |
| **其他行星** | 水星 / 金星 / 火星按真实半径与真实轨道也在场上（只是不参与判定）：内侧的水星金星在地球身后——**尾向观测窗**与**小地图**上看得见；火星在起手正前方约 1 秒处经过，**看得见但没有加速窗口** |
| **过热** | **温度按功率涨**（温度 = ∫ 功率，见功率表那一行）：烧满即进入**强制降温**（3.85 秒）—— 推力归零、功率熄火，温度按固定速率强制下降。**降温期间点也白点：按着既不升温、也不重新起转、更不打断降温进度**（旧版要玩家「先松手」才能降温，等于把抬指本身当惩罚）；降到 0 解锁，**解锁那一刻手指还在屏幕上就立即复机**，不用松手再按。底部**温度表盘**整表转红并呼吸（功率表同时归零），`过热` 警报灯常亮 |
| **仪表盘（屏幕底部平铺）** | 驾驶舱最下沿是**汽车驾驶舱式**的一整条：**功率 / 温度 / 速度**三个 270° 表盘并排（指针 + 随值生长的值弧），顺序就是驾驶时的手上顺序 —— 先看这一下**多大力**、再看**烫不烫**、最后看**够不够门槛**。功率表上有一道**额定线**（100%，脉冲乘波会推过它 —— 这就是「乘波」看得见的样子）、速度表上有一道**门槛刻度**（当前行星判定速度的位置，速度够了转绿）；温度表 `>70%` 整表转暖色、烧满锁定转红并呼吸。三格的数字与标题在同一条水平线上，所以余光一次扫完。右端竖排四盏警报灯 —— `过热`（红）/ `弹弓`（绿＝弹弓生效、红＝本次已作废）/ `耀斑`（琥珀）/ `氦闪`（距壳 < 28 AU 转琥珀、< 12 AU 转红闪烁）；灯下面是 `距日 / 距壳` 两条读数。**说明文案仍归消息槽**，灯只负责「有没有事」 |
| **功率表（发动机输出功率）** | 仪表行第一张**指针表盘**（最左，最先被读到），现在是一条**油门斜坡**：按住 0.5 秒从 0 爬到额定线（100%），松手 0.5 秒归零 —— 指针的高度就是「按下去了多久」。四档读数：**0% 停机或过热锁定（指针与弧转灰）/ 20% 过晚残效（红）/ 100% 额定推力 / 160% 耀斑脉冲乘波（琥珀，指针推过额定线）**；满量程 160%、额定 100% 处有一道细刻度。**温度就是按这张表积出来的：指针越高越烫**（过晚 20% 只涨 15/s、额定 75/s、乘波 120/s）—— 于是「在过晚区死按」不再白烧温度、而「在脉冲期死按」烫得最快 |
| **顶栏：观测窗 / 计时 / 小地图 + 声音** | 与「点火」无关的信息全在**一条顶栏**里（左 **尾向观测窗** 方形 ┊ 中 `m:ss.mmm` 正计时，毫秒单独一段小字（它就是成绩本体，结算与分享仍按 0.1 s 记）┊ 右 **小地图 + 它下面的 BGM 开关**）：左右两块是**同尺寸方形显示窗**（一左一右对称），计时夹在中间因而天然居中；**逃逸进度在屏幕最底部的信息栏里** —— 最下沿既不挡画面，也不逼视线往上跑 |
| **底部信息栏（`#dash`）** | 上排 = **控制台两列**：① 功率/温度/速度三张表盘 ② 参数（四盏警报灯 + `距日 / 距壳`）；下排 = **逃逸进度独占一行的通宽细条**。两排之间只用留白分隔、**不加横线**，列间只用一条竖线（2026-09-26 先把进度与小地图从左上角并进来、定稿成三列，同日又把 42px 的小地图搬到右上角放大到 76px —— 信息栏退回两列，高度仍 112px，表盘从 43px 长到 59px） |
| **提示条** | **浮在时机条上方 6px**（零高度槽位，不推挤布局 —— 时机条因此位置恒定），全屏只有这一条，**只在发动机出状况时才出现**：过热时报归零冷却倒计时（赶不上绿色区间就直说 `这站来不及解锁`）、耀斑脉冲预警与生效时给动作指令。**巡航段保持空**——不预告窗口还剩几秒（旧版会一路数到窗口开启），也不报速度缺口（过早区间速度必然低于门槛，那不是危险）。它与**掠过评级**共用同一槽位与**同一张「终端消息卡」样式**（紧急的过热／脉冲抢屏、其次评级），所以屏幕上永远不会同时挂两条文案；窗口临近靠行星越长越大、进度条走满、绿色边缘光和进绿色区间的音效告诉你 |
| **过晚 / 错过** | **只有这一种情况会被行星当场抓住**：这一关的窗口根本没碰（完全没按，或只在过晚区间按）→ 判定点速度 < 门槛被捕获，再低一档（< 门槛 ×0.72）坠入大气层。即「即时失败」留给「错过时机」，「延迟失败」留给「过早烧废弹弓」 |
| **掠过评级** | 每过一颗行星都会弹一条评级：`完美弹弓` / `差一口气` / `按早了` / `按晚了` / `没点火` / `速度没拉起来`，并给出**这次绿色区间实际点了多少秒（对照完美线）**与一句改进提示 |
| **脉冲乘波** | 2 次耀斑脉冲（12 / 26 秒，各 1 秒）期间推力 ×1.6，且**提前 2 秒预警**（提示条倒数 `耀斑脉冲 1.4 s 后 · 推力 ×1.6`）；脉冲到时提示条直接给动作：巡航段 `现在按住`、过早段 `别按（会作废弹弓）`。**乘波把功率推过额定线，温升也 ×1.6**：老实等脉冲亮了再按满 1 秒只涨到 90（安全），**在预警期就按住则会在脉冲没结束时烧穿**——所以预警期绝不说「按住」 |
| **不设时限** | 左上只是正计时（标着 `逃逸用时`，它同时就是成绩）。唯一的死线是身后那层壳 |
| **尾向观测窗** | 顶栏左端的常驻**方形**回望视角（朝舰尾方向 = 地球身后），看氦闪壳追到哪了、以及那两颗永远在身后的内侧行星；标签 `尾向观测 · 氦闪壳` 就写在这块窗下面（旧名「后视镜」已按世界观改掉，代码里 id 仍是 `#mirror-frame`） |
| **胜利** | 走完航线，冲出太阳系 |
| **成绩** | **逃逸用时**越短越强；本站最快记在本地，结算页可一键分享战绩（**结算页只有屏底两个按钮有动作** —— 点正文不再重开，免得想点分享却按到正文、整页重开） |

不操作的话，木星这一关就过不去（约 5.8 秒）。

## 通关梯度（自检实测）

| 打法 | 结果 |
|---|---|
| 弹弓全吃满 | **34.7 秒逃出**，5/5 完美弹弓（每次掠过壳余量 2.9–6.4 秒） |
| 吃个大概（区间内提前松手 25%） | 38.5 秒逃出，冥王星处只剩 **0.8 秒**壳余量 |
| 只吃到一半（55%） | 进度 60% 被壳追上（27.8 秒） |
| 只擦到一点（35%） | 进度 36% 被壳追上（19.8 秒） |
| 乱按 / 一直按着 / 从不点火 | 木星处出局（5.1–5.7 秒） |
| 窗口内全程死按 | 土星处撞毁（11.8 秒：过早先烧废弹弓，温度又按功率烧穿） |

## 素材与工程

| 项 | 说明 |
|----|------|
| 引擎 | Three.js（`assets/three.min.js`，外置同目录、无 CDN） |
| 航线 | 对数螺旋 + 轻环绕 + 垂直起伏；行星位置**由航线反推**（距日 = 真实轨道半径，掠过距离 = 半径 + 设计净空） |
| 天体尺度 | **行星半径 = 真实半径 × 统一 800×**（唯一真源是 `rKm`，`rad` 派生）：木 37.4 / 土 31.1 / 天 13.6 / 海 13.2 / 冥 0.64 / **地球 3.41（= 手调时代的 3.4，占屏 13%）** —— 比例与真实一致，倍率以地球的观感为锚点。**太阳是唯一例外**（同比会是 372 单位 > 航线起点 95，会把地球装进太阳里） |
| 掠过构图 | 净空随半径等比放大（×2.667）→ 「掠距 : 半径」与放大前一致；**注视偏移上限 `CAM_PAN_TILT_MAX = 9°`**（否则视线被抬高几十度会把地球顶出画面）→ 掠过时行星压上半屏、地球带判定环留在下半 |
| 土星光环 | 环带用**真实比例 1.11 ~ 2.27 倍半径**，环面摆在**土星赤道面**上并叠加真实轴倾角 **26.73°**。「穿环」原来是**朝向**问题：`RingGeometry` 默认法线 +Z、代码没旋转 → 航线在环带内穿过环面（实测最小垂距 0.15 单位 ≪ 地球半径）；摆到赤道面后同一测法 **30.5 单位** → 永不穿环 |
| 时机窗口 | **逐行星由质量派生**（唯一真源是 `mEarth`）：`v_esc = √(2GM/R)` → 窗口 2.50–2.80 s、绿色区间占比 28%–44%、`slingK` 反向补偿（吃满收益恒为 87.3%）、评级阈值按各自区间折算 |
| 场上其他行星 | 水星 1.31 / 金星 3.23 / 火星 1.81 单位，距日 = 真实轨道半径（0.387 / 0.723 / 1.524 AU）；**不参与判定**，没有判定环与窗口 |
| 星空 | 天球**不用贴图**（顶点色给出底色与银河带）；星点用 `THREE.Points` 点精灵，`STAR_SIZE = 9` |
| 地球贴图 | 内联 base64（`earth-data.js`），叠加程序化冰封壳 + 稀薄云 |
| 行星贴图 | **八颗全部真实影像**（NASA 影像，取自 `vibeknow/solar-system-3d/assets/`）：掠过五站（木 / 土 / 天 / 海 / 冥）+ 场上三颗（水 / 金 / 火）都内联 base64，由 `tools/make-texture-data.mjs` 生成；程序化贴图只作兜底 |
| **背景音乐** | 整曲 base64 内联（`assets/bgm-data.js`）+ Web Audio 解码循环（尾/头交叠淡入淡出，接缝无感） |
| 音效 | 程序化 WebAudio：点火隆隆、脉冲爆音、过热告警、冷却归零、掠过评级音、胜负音 |
| 分享 | 结算页 Canvas 现画战绩卡 → 容器 JSBridge `interactionOpenApi`（带图文评论草稿 + 存相册，客户端 9.49+）；低版本回退 `postNote` 发笔记，桌面退化为选中文案 |
| 尾向观测窗 | 单 renderer + `setScissor/setViewport`，不额外开 WebGL context（帧矩形直接读 DOM，`mirrorCam.aspect` 随矩形变 —— 所以 120×62 改 80×80 方窗画面也不拉扁） |
| 物理与渲染 | `assets/app.js`（唯一真源）：物理核心（纯 JS，可无头调用）+ Three.js 渲染 + 输入 + 相机 + HUD + 音频 + 分享 |
| **HUD 顶部预留** | `--top-gap:50px` 无条件叠在安全区之上（同 `moon-myths` / `world-food-3d` / `perler-city`）：小红书容器自带一排顶部按钮，而容器内 `env(safe-area-inset-top)` 恒为 0，只靠安全区会把顶栏顶到宿主按钮底下 —— 现在整条顶栏 `#topbar` 只有**一处**承载这条常量。另有一条 `--top-sq:80px` = 左右两块方形窗的边长（观测窗 / 小地图 / 声音条同宽，也决定中间计时那格多宽），改它就能整体缩放顶栏那一排 |
| **底部信息栏 + 驾驶舱** | 屏幕底部 `#cockpit` 自下而上两块：**信息栏 `#dash`**（上排**两列** = 仪表盘 │ 参数；下排 逃逸进度独占一行）与**时机条**（+ 与它同带的零高度消息槽）。顶部只留「与驾驶无关、想起来才抬头看」的信息。理由：一次点火窗口只有 2.5–2.8 秒，判定针、温度、速度、功率必须在同一条水平带上一次读完（旧版仪表盘在右上、时机条在屏幕中下，等于逼玩家在窗口期上下往返） |
| **操作界面无横线滤镜** | 全屏扫描线（原先那层 `body::before`）2026-09-26 已撤：它压在 3D 之上、HUD 之下，半透明仪表盘会把下面的画面透出来 → 操作界面看起来自带横条纹。现在只保留暗角（`body::after`），终端纹理只留在**简报 / 结算 / 加载**三块整屏上 |
| 行星贴图（工程） | 八颗行星的真实影像由 `node tools/make-texture-data.mjs` 从 `vibeknow/solar-system-3d/assets/`（NASA 影像）内联成 `assets/*-data.js`（base64，`file://` 下零 CORS）；改贴图后重跑该脚本即可，**不要手工编辑 `*-data.js`** |
