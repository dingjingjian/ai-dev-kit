# 流浪地球 · 逃逸截断

> **分类**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)
>
> **状态**：核心玩法可玩（第三人称现时躲避逃离 + 发动机过热节奏，无头自检 81/81 通过）。设计真源见 [`DESIGN.md`](DESIGN.md)。

太阳氦闪膨胀壳从第 0 秒就追上来，你以第三人称实时驾驶地球往外飞——管住发动机温度、躲耀斑脉冲、躲八颗行星、借行星弹弓加速，飞出 42 AU 逃出太阳系。**不设时限，唯一的死线是身后那层壳。**

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录；贴图以内联 base64 data URI 提供，`file://` 直接打开即可运行，无需联网。

## 玩法

| 项 | 说明 |
|----|------|
| **操控** | 触屏按下并拖动 = 点火方向 + 强度（拖得越远推力越大），松手停机。双指捏合缩放 |
| **过热节奏** | 推力升温、松手降温。**没烧满时可随意断续使用且推力不打折**；一旦烧满触发过热锁定——推力归零，且**必须松手**才能降温，要冷却到 **0** 才解锁 |
| **不设时限** | 左上只是正计时。慢慢磨也行，但壳不会等你 |
| **脉冲乘波** | 5 次耀斑脉冲（10/20/35/55/75 秒，各 1 秒）期间推力效率 ×1.8，把温度额度留给脉冲是高分解 |
| **后视镜** | 顶部常驻一路回望视角，从地球前上方看地球背面与身后追来的壳——判断「还剩多少余量」主要靠它 |
| **弹弓引导** | 屏幕投影出「下一颗要穿越轨道的行星」，直读当前相对速度能否安全掠射加速 |
| **行星** | 八颗行星沿圆轨道公转，撞上失败；进影响球且相对速度不足被捕获失败；高速掠过可借弹弓加速 |
| **相机** | 第三人称跟拍地球**运动方向的正后方**，正对地球背面的 48 台行星发动机；地球位于画面**中心偏下**；氦闪逼近时自动拉远 |
| **胜利** | 逃逸比 ≥ 1（达到逃逸能量）且距日 > 42 AU（越过冥王星） |
| **失败** | 撞太阳 / 撞行星 / 被捕获 / 被氦闪壳吞没 |

## 玩法前提（重要，如实说明）

**当前数值下引力弹弓对结果几乎无影响**：实测把八颗行星全挪到对侧（基本吃不到弹弓），逃逸用时只从 55.2s 变到 55.4s，**收益 0.3%**。原因是 1 秒推力 = 20 km/s，而整个木星飞掠在影响球边缘的逃逸速只有 13.4 km/s（≈0.7 秒推力）。弹弓引导 HUD 已经把「能不能掠射」讲清楚，但要让它成为最优解，需要重调行星 `gm` 或 `THRUST_ACC`（见 [`DESIGN.md` §9](DESIGN.md)）。

## 节奏（不限时）

| 时段 | 发生什么 |
|---|---|
| 0–2.8s 过场 | 镜头从太阳系俯视推到地球后方，物理冻结；随后弹任务简报，点「出发」计时 |
| 起步 | 地球 1 AU 圆轨道往外推，建立外飞速度 |
| 中段 | 5 次脉冲要乘波；穿火星(1.52 AU)、木星(5.20 AU)、土星(9.54 AU)轨道，按引导选掠射时机 |
| 终局 | 20s 后壳二次加速大爆发；穿天王星(19.2 AU)、海王星(30.1 AU)，42 AU 越过冥王星即胜 |

不操作的话，壳会在 **t ≈ 19.6 秒**吞没地球。

## 关于尺度与物理（如实说明）

- **天体半径与行星引力做了放大**。真实比例下地球在屏幕上小到看不见，且真实行星引力不足以在游戏时间内捕获地球。
- **遥测是真实的**：HUD 里的 km/s 与"年"由游戏单位换算而来，1 AU 处圆轨道速度恰为 **29.8 km/s**，地球公转一圈恰为 **1 年**（自检有断言）。
- 行星为共面圆轨道、不受地球影响（单向引力），物理积分为半隐式欧拉 + 固定子步（10fps 与 60fps 步进结果一致，含开局保护窗口，自检有断言）。
- 行星初始相位**每次开局相同**（不是随机），由离线数值求解得到。
- 氦闪壳膨胀为游戏化模型（非真实物理），壳从第 0 秒持续外胀，脉冲时 ×4、20 秒后二次加速。

## 素材与工程

| 项 | 说明 |
|----|------|
| 引擎 | Three.js（`assets/three.min.js`，外置同目录、无 CDN） |
| 星空 | 天球（半径 4000）**不用贴图**：底色与斜向银河带由顶点色给出（贴图在球内会被放大数倍，色阶与合成台阶变成「白色方格子」）；星点用 `THREE.Points` 点精灵，`STAR_SIZE = 9` —— 点精灵把整张贴图铺到 N 个像素上，N 太小时只会采到贴图中心那点纯白，退化成实心白方块 |
| 地球贴图 | 内联 base64（`earth-data.js`），叠加程序化冰封壳 + 稀薄云 |
| 行星贴图 | 水星 / 金星 / 火星 / 木星 / 土星 内联 base64；天王星 / 海王星 / 冥王星为程序化贴图 |
| 后视镜 | 单 renderer + `setScissor/setViewport`，不额外开 WebGL context |
| 物理与渲染 | `assets/app.js`（唯一真源）：物理核心（纯 JS，可无头调用）+ Three.js 渲染 + 输入 + 相机 + HUD + 程序化音效 |
| 兼容性基线 | Chrome / WebView 61（ES2017）：游戏 JS 全文 ES5；WebGL2 优先、回退 WebGL；顶部安全区用「容器注入变量 + `env()` + 纯像素基线」三重兜底 |
| 构建 | `build.mjs`（构建 `dist/`）、`verify-minitool.mjs`（合规校验）、`pack.mjs`（打包 zip） |

## 自检

```bash
node tests/headless_escape.js
```

共 **81 项**断言，除物理核心外还含**静态契约**（沙箱里没有 `document`/`THREE`，渲染层会被整段跳过，改名漏改不会被运行期发现）：

- **工程**：导出齐全；**DOM/样式契约**——`app.js` 引用的每个 id 都在 `index.html` 里、新 HUD 元素样式规则齐全、已删除的旧元素无残留引用、**天球不用贴图**（用了就退回「白色方格子」）
- **常量**：换算互锁（29.8 km/s / 1/60 年）、脉冲时刻、过热常量、无时限、星点尺寸下限、行星数、42 AU 门槛
- **物理**：稳定绕日、壳吞没、顺向外飞、引力坠日、**开局保护按时间计（帧率无关）**
- **弹弓 / 氦闪**：低速捕获、高速掠过、壳持续膨胀、脉冲加速、壳吞没判定
- **推力 / 过热**：脉冲乘波冲量、烧满锁定、锁定期间按着不降温而松手才降温、必须归零才解锁、断续推效率恒为 1
- **相机 / 地球模型 / 输入**：跟拍距离有界且地球偏下、发动机一律平行朝后、斜拖角度 1:1 保真
- **胜负**：逃逸判定、控温策略逃出、帧率无关、无脑满推逃不出、只乘波明显更慢
