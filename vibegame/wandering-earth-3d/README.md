# 流浪地球 · 逃逸截断

> **分类**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)
>
> **状态**：核心玩法可玩（第三人称现时躲避逃离，无头自检 19/19 通过）。设计真源见 [`DESIGN.md`](DESIGN.md)。

太阳氦闪膨胀壳从第 0 秒就追上来，你以第三人称实时驾驶地球往外飞——躲耀斑脉冲、躲五颗行星、借木星弹弓加速，30 秒内逃出太阳系。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录；贴图以内联 base64 data URI 提供，`file://` 直接打开即可运行，无需联网。

## 玩法

| 项 | 说明 |
|----|------|
| **操控** | 触屏按下并拖动 = 点火方向 + 强度（拖得越远推力越大），松手停机。双指捏合缩放 |
| **核心张力** | 太阳壳从第 0 秒持续膨胀追击，必须在壳追上之前把地球加速到逃逸速度 |
| **耀斑脉冲** | 第 10、16 秒两次脉冲：壳突胀 1 秒 + 红边预警，要猛推远离 |
| **行星** | 五颗行星沿圆轨道公转，撞上失败；进影响球且相对速度不足被捕获失败；高速掠过可借弹弓加速 |
| **相机** | 第三人称跟拍地球，速度方向跟随，氦闪时拉远看壳追上来 |
| **胜利** | 逃逸比 ≥ 1（达到逃逸能量）且在壳外 |
| **失败** | 撞太阳 / 撞行星 / 被捕获 / 被氦闪壳吞没 / 30 秒耗尽 |
| **一局** | 30 秒，重开 1 秒，行星相位随机，复玩高 |

## 30 秒节奏

| 时段 | 发生什么 |
|---|---|
| 0–8s 起步 | 地球 1 AU 圆轨道往外推，建立外飞速度 |
| 8–20s 脉冲 + 火星关 | 2 次耀斑脉冲要躲；穿火星轨道间隙 |
| 20–30s 木星土星关 + 终局 | 木星弹弓 + 土星穿间隙；壳加速大爆发冲刺逃出 |

## 关于尺度与物理（如实说明）

- **天体半径与行星引力做了放大**。真实比例下地球在屏幕上小到看不见，且真实行星引力不足以在游戏时间内捕获地球。
- **遥测是真实的**：HUD 里的 km/s 与"年"由游戏单位换算而来，1 AU 处圆轨道速度恰为 **29.8 km/s**，地球公转一圈恰为 **1 年**（自检有断言）。
- 行星为共面圆轨道、不受地球影响（单向引力），物理积分为半隐式欧拉 + 固定子步。
- 氦闪壳膨胀为游戏化模型（非真实物理），壳从第 0 秒持续外胀，脉冲时加速生长率。

## 自检

```bash
node tests/headless_escape.js
```

在 Node 沙箱里跑物理核心，共 19 项断言：工程导出、常量换算、稳定绕日、壳追上吞没、顺向外飞、引力坠日、木星捕获/弹弓、壳持续膨胀、脉冲加速、吞没判定、逃逸判定、超时判定。
