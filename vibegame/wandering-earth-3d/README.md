# 流浪地球 · 引力弹弓

> **分类**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)
>
> **状态**：玩法完成、可玩（固定航线时机节奏 + 掠过评级 + 用时成绩与分享，无头自检 **209/209** 全绿）。设计与数值真源见 [`DESIGN.md`](DESIGN.md)。

太阳氦闪的膨胀壳从第 0 秒就在地球身后追。地球沿一条**固定航线**自动冲向太阳系外缘，你唯一的操作是**什么时候按住点火**：

- **过早** — 推力照烧，但吃不到引力弹弓的放大，还白烧掉温度额度；
- **最佳时机**（时机条上的绿色区间）— 弹弓把速度拉向该行星的弹弓速度，这是唯一能把速度拉到门槛之上的办法；
- **过晚** — 判定点速度不够，**被行星捕获，或直接被拽进大气层**。

**目标只有一个：用最短的时间把地球开出太阳系，然后把成绩分享给朋友比一比。**

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录；贴图与背景音乐都以 base64 内联，`file://` 直接打开即可运行，**无需联网**。

## 玩法

| 项 | 说明 |
|----|------|
| **操控** | **按住屏幕任意位置**＝推力（整块画布就是按钮，没有落点也没有死角）。松手停机。双指捏合缩放 |
| **加速时机条** | 屏幕中下（**只在窗口内出现**）：`过早` / **`最佳加速时机`** / `过晚` 三段 + 一根扫过的判定针；头条给「哪颗行星 + 现在踩在哪一段」，脚注给 `速度 / 门槛 km/s`（与右上遥测同一套单位）。指针进绿色区间再按住屏幕。**三段宽度与窗口时长逐行星不同**——由该行星质量（引力强度 √(2GM/R)）决定：木星 2.80 秒里绿色占 44%，冥王星 2.50 秒里只占 28% |
| **引力弹弓** | 只在最佳区间生效：速度**按比例**向该行星的弹弓速度逼近（差得越多拉得越猛），所以前面吃得少也能追回来。逼近速率按区间宽度反向补偿 → **吃满的收益五颗行星一致**，窄区间只是更难按准 |
| **过早的代价** | 温度总量只够连续点 1.43 秒，而窗口有 2.5–2.8 秒——窗口里全程死按，会在最佳区间之前就把温度烧穿。**更关键：本次掠过一旦在「过早」区间点过火（哪怕只有一帧），弹弓机会整次作废**——之后即便续按进绿色区间也只有普通推力，**判定点速度必然够不到门槛**。但代价不是当场终结：**地球照常掠过，欠账留给身后的氦闪壳**。实测：木星上过早点火 → 整局拖到 34.1 秒、进度 82% 才被壳追平；土星 / 天王星上过早 → 38 秒上下、98–99% 被追上（差一点就出去了）；海王星 / 冥王星上过早，前面跑得够好的话还追得回来。**注：只有窗口内的「过早」区如此** —— 行星之间的巡航段（含两次耀斑脉冲）随便按，不作废弹弓 |
| **其他行星** | 水星 / 金星 / 火星按真实半径与真实轨道也在场上（只是不参与判定）：内侧的水星金星在地球身后——**后视镜**与**小地图**上看得见；火星在起手正前方约 1 秒处经过，**看得见但没有加速窗口** |
| **过热** | 烧满触发锁定：推力归零，且**按着不降温**，必须松手冷却到 0 才解锁。过热条标签会变红报警 |
| **提示条** | 挂在**时机条正上方**，全屏只有这一条，**只在发动机出状况时才出现**：过热时报归零冷却倒计时（赶不上绿色区间就直说 `这站来不及解锁`）、耀斑脉冲预警与生效时给动作指令。**巡航段保持空**——不预告窗口还剩几秒（旧版会一路数到窗口开启），也不报速度缺口（过早区间速度必然低于门槛，那不是危险）。它与**掠过评级**共用同一槽位（紧急的过热／脉冲抢屏、其次评级），所以屏幕上永远不会同时挂两条文案；窗口临近靠行星越长越大、时机条滑入、绿色边缘光和进绿色区间的音效告诉你 |
| **过晚 / 错过** | **只有这一种情况会被行星当场抓住**：这一关的窗口根本没碰（完全没按，或只在过晚区间按）→ 判定点速度 < 门槛被捕获，再低一档（< 门槛 ×0.72）坠入大气层。即「即时失败」留给「错过时机」，「延迟失败」留给「过早烧废弹弓」 |
| **掠过评级** | 每过一颗行星都会弹一条评级：`完美弹弓` / `差一口气` / `按早了` / `按晚了` / `没点火` / `速度没拉起来`，并给出**这次绿色区间实际点了多少秒（对照完美线）**与一句改进提示 |
| **脉冲乘波** | 2 次耀斑脉冲（12 / 26 秒，各 1 秒）期间推力 ×1.6，且**提前 2 秒预警**（提示条倒数 `耀斑脉冲 1.4 s 后 · 推力 ×1.6`）；脉冲到时提示条直接给动作：巡航段 `现在按住`、过早段 `别按（会作废弹弓）`。**不要在预警期就按住**——预警 2 s + 生效 1 s 连按会烧穿温度，实测会在天王星被捕获 |
| **不设时限** | 左上只是正计时（标着 `逃逸用时`，它同时就是成绩）。唯一的死线是身后那层壳 |
| **后视镜** | 顶部常驻回望视角，看身后的氦闪壳追到哪了 |
| **胜利** | 走完航线，冲出太阳系 |
| **成绩** | **逃逸用时**越短越强；本站最快记在本地，结算页可一键分享战绩 |

不操作的话，木星这一关就过不去（约 5.8 秒）。

## 通关梯度（自检实测）

| 打法 | 结果 |
|---|---|
| 弹弓全吃满 | **34.7 秒逃出**，5/5 完美弹弓 |
| 吃个大概（区间内提前松手 25%） | 38.3 秒逃出，冥王星处只剩 1.0 秒壳余量 |
| 只吃到一半（50%） | 土星处被捕获 |
| 乱按 / 一直按着 / 从不点火 | 木星处出局 |

## 素材与工程

| 项 | 说明 |
|----|------|
| 引擎 | Three.js（`assets/three.min.js`，外置同目录、无 CDN） |
| 航线 | 对数螺旋 + 轻环绕 + 垂直起伏；行星位置**由航线反推**（距日 = 真实轨道半径，掠过距离 = 半径 + 设计净空） |
| 天体尺度 | **行星半径 = 真实半径 × 统一 800×**（唯一真源是 `rKm`，`rad` 派生）：木 37.4 / 土 31.1 / 天 13.6 / 海 13.2 / 冥 0.64 / **地球 3.41（= 手调时代的 3.4，占屏 13%）** —— 比例与真实一致，倍率以地球的观感为锚点。**太阳是唯一例外**（同比会是 372 单位 > 航线起点 95，会把地球装进太阳里） |
| 掠过构图 | 净空随半径等比放大（×2.667）→ 「掠距 : 半径」与放大前一致；**注视偏移上限 `CAM_PAN_TILT_MAX = 9°`**（否则视线被抬高几十度会把地球顶出画面）→ 掠过时行星压上半屏、地球带判定环留在下半 |
| 土星光环 | 环带用**真实比例 1.11 ~ 2.27 倍半径**，环面摆在**土星赤道面**上并叠加真实轴倾角 **26.73°**。「穿环」原来是**朝向**问题：`RingGeometry` 默认法线 +Z、代码没旋转 → 航线在环带内穿过环面（实测最小垂距 0.15 单位 ≪ 地球半径）；摆到赤道面后同一测法 **30.5 单位** → 永不穿环 |
| 时机窗口 | **逐行星由质量派生**（唯一真源是 `mEarth`）：`v_esc = √(2GM/R)` → 窗口 2.50–2.80 s、绿色区间占比 28%–44%、`slingK` 反向补偿（吃满收益恒为 87.3%）、评级阈值按各自区间折算 |
| 场上其他行星 | 水星 1.31 / 金星 3.23 / 火星 1.81 单位，距日 = 真实轨道半径（0.387 / 0.723 / 1.524 AU）；**不参与判定**，没有判定环与窗口 |
| 星空 | 天球**不用贴图**（顶点色给出底色与银河带）；星点用 `THREE.Points` 点精灵，`STAR_SIZE = 9` |
| 地球贴图 | 内联 base64（`earth-data.js`），叠加程序化冰封壳 + 稀薄云 |
| 行星贴图 | 木星 / 土星 内联 base64；天王星 / 海王星 / 冥王星为程序化贴图 |
| **背景音乐** | 整曲 base64 内联（`assets/bgm-data.js`）+ Web Audio 解码循环（尾/头交叠淡入淡出，接缝无感） |
| 音效 | 程序化 WebAudio：点火隆隆、脉冲爆音、过热告警、冷却归零、掠过评级音、胜负音 |
| 分享 | 结算页 Canvas 现画战绩卡 → 容器 JSBridge `postNote`；桌面退化为复制文案 |
| 后视镜 | 单 renderer + `setScissor/setViewport`，不额外开 WebGL context |
| 物理与渲染 | `assets/app.js`（唯一真源）：物理核心（纯 JS，可无头调用）+ Three.js 渲染 + 输入 + 相机 + HUD + 音频 + 分享 |
| 兼容性基线 | Chrome / WebView 61（ES2017）：游戏 JS 全文 ES5；WebGL2 优先、回退 WebGL；安全区三重兜底 |
| 构建 | `build.mjs`（构建 `dist/`）、`verify-minitool.mjs`（合规校验）、`pack.mjs`（打包 zip） |

## 自检

```bash
node tests/headless_escape.js
```

共 **209 项**断言。除物理核心外还含**静态契约**（沙箱里没有 `document`/`THREE`，渲染层会被整段跳过，改名漏改不会被运行期发现）：

- **工程**：导出齐全；**DOM/样式契约**——引用的每个 id 都在 `index.html` 里、新 HUD 元素与状态类齐全、旧机制无残留、**天球不用贴图**、**app.js 全文 ES5**
- **HUD 布局契约**：提示条挂在底部（不再 `top:` 悬浮画面中间）且允许换行（旧版 `nowrap` 会裁掉长文案）、提示条与评级条同槽且在时机条上方留缝、点火提示在开场简报内（局内底部只剩消息槽/时机条/进度）、时机条脚注用 km/s（与遥测同一套单位）
- **BGM**：确实解出 MPEG 音频、时长合理、加载顺序正确、有静音开关与持久化、切后台挂起
- **分享**：用时/最快纪录区块、成绩持久化、`postNote + image_resources`、配图 Canvas 现画、标题/正文长度上限、**不出现容器禁用能力**
- **常量互锁**：速度换算、星点尺寸下限、**温度满箱时间 < 每颗行星窗口时长 且 > 每颗最佳区间时长**（逐行星验）、掠过行星名单、`vSling > vNeed`
- **航线几何**：弧长表精确、行星依次排列、掠过距离 = 半径 + 净空、**行星距日 = 真实轨道半径**、行星正对掠过点
- **天体尺度**：半径 = 真实半径 × 统一倍率（偏差 0）、4 组实测半径比 = 真实半径比、**太阳显式例外**、屏幕大小次序 = 真实次序、木星仍占 ~57% 屏高而冥王星 <5%
- **质量 → 时机窗口**：质量序 = 逃逸速度序、v_esc 与真实同量级、引力越强窗口越长/绿色区间越宽、两端锚定、**吃满区间的增益逐行星恒为 87.3%**、评级阈值随区间折算、海王星 ≥ 天王星
- **场上其他行星**：水星/金星/火星都在场景且不在掠过名单、半径同一条换算、**距日 = 真实轨道半径**、不穿模、内侧行星在起点内侧、火星站台在木星之前
- **时机窗口 / 掠过评级**：相位与区间映射（**参数逐行星**）、7 种评级判定、同一 0.45 s 在不同行星评级不同、物理核心分区累计点火时长
- **配色语义**：「最佳加速时机」整段是绿色（节奏游戏惯例：绿 = 命中区），与「红色危险」构成红绿灯对照；全屏「该按了」呼吸光与 3D 判定环同色；**金色只剩「评价/结算」轴**（完美弹弓、结算用时、新纪录），时机轴不得再出现金色
- **提示文案**：**巡航段消息槽保持空**（不预告窗口、不报速度缺口）、窗口内不再刷任何提示、过热时解锁倒计时 = 热量 ÷ 冷却率、**赶不上绿色区间就报「这站来不及解锁」**（判据是绿色区间开始，不是窗口开启）、过晚文案、耀斑脉冲两条（预警 / 生效）都还在
- **耀斑脉冲**：只两次且都落在单局时长内（被删掉的第 3 次 @40 s 走不到）、预警提前量 ≥1.5 s、`pulseIn` 倒数、**提示按区间分叉**（巡航段「现在按住」/ 过早段「别按（会作废弹弓）」/ 绿色与过晚不抢屏）、**预警期绝不说「按住」**（连按会烧穿）、预警 2 s 与生效 1 s 逐帧成立
- **弹弓 / 过热 / 判定 / 氦闪壳**：最佳区间显著快于过早、过晚几乎无收益、**过早区点火哪怕 1/120 s → 该次掠过记为 `速度没拉起来`（不判死）且整局延后到 30 s 之后才被壳追平**（逐颗行星跑）、**不点火 / 只在过晚区间点仍在当场被捕获**、烧满锁定必须归零解锁、三档判定、壳吞没
- **相机**：跟拍距离有界、**偏移窗口单侧**、**注视距离不因行星偏移而改变**、注视方向不翻折
- **构图不变式**：掠过时地球离画面中心 < 26°、行星近缘 < 30°（两者始终同框）、注视方向被行星拉走的夹角 ≤ `CAM_PAN_TILT_MAX`
- **土星光环**：按渲染层同一个环面法线验算「航线穿过环带时的最小垂距 > 地球半径」（地球绝不穿环）、环带与轴倾用真实值
- **胜负**：满弹弓逃出、75% 也能逃出但更慢、其余逃不出、**10fps 与 60fps 状态完全一致**
