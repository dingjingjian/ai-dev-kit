# 流浪地球 · 逃出太阳系

> **分类**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)
>
> **状态**：可玩（玩法内核 + 3D 渲染 + HUD 完成，无头自检 16/16、小工具合规校验 27/27 通过）。音效与特效待补。设计真源见 [`DESIGN.md`](DESIGN.md)。

滑动屏幕点燃行星发动机，推着地球穿越太阳系。太阳与五颗行星的引力实时作用在你身上——**被行星引力吸走，或者撞上任何天体，任务就失败了**；带着地球飞出太阳系，才算赢。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录；贴图以内联 data URI 提供，`file://` 直接打开即可运行，无需联网。

## 玩法

| 项 | 说明 |
|----|------|
| **操控** | 在屏幕上滑动 = 行星发动机点火，**推力方向就是滑动方向**（世界平面内）。滑一段距离后按住不动，可保持方向持续加速；松手即停 |
| **燃料** | 行星发动机燃料有限（约 19 km/s 量级的总速度增量），用光就只能靠引力了 |
| **目标** | 带着地球飞出太阳系（距日 > 20 AU），奔向比邻星 |
| **失败 · 撞毁** | 撞上太阳或任何行星 |
| **失败 · 被吸走** | 进入行星引力范围后，**相对速度低于该处的逃逸速度**就会被捕获——地球变成它的卫星 |
| **关键机制** | 掠过行星时速度决定命运：够快就是**引力弹弓**（免费加速），不够快就被拽走 |

实时 HUD 显示距日距离、速度（km/s）、任务时间（年）与燃料余量；接近行星引力范围时会弹出相对速度与逃逸阈值的对照警告。

## 关卡与天体

| 天体 | 角色 |
|------|------|
| 太阳 | 引力主源，坠入即失败 |
| 水星 / 金星 | 内圈干扰，影响较小 |
| 火星 | 逃逸路上的第一道坎 |
| **木星** | **主要威胁**：影响球大、引力强，逃逸轨道必然经过；也是最好的引力弹弓 |
| 土星 | 更外侧的挑战 |
| 比邻星 | 胜利方向的目标星 |
| 月球 | 仅开场剧情出现：地球自转暂停、发动机点火后，月球被留在原地，独自绕日（地球"独自上路"） |

## 关于尺度与物理（如实说明）

- **天体半径与行星引力做了放大**。真实比例下地球在屏幕上小到看不见，且真实行星引力不足以在游戏时间内捕获地球。放大后"擦边就被抓住"才成为可玩的机制。
- **遥测是真实的**：HUD 里的 km/s 与"年"由游戏单位换算而来，换算系数经过校验——1 AU 处的圆轨道速度恰为 **29.8 km/s**，地球公转一圈恰为 **1 年**（`tests/headless_wandering.js` 有对应断言）。
- 轨道为共面圆轨道（不做真实倾角与偏心率），行星不受地球影响（单向引力），物理积分为半隐式欧拉 + 固定子步。
- 玩法概念取自《流浪地球》"带着地球去流浪"，但**不是原著剧情复刻**：这里没有刹车时代、木星点火等过程演出，只保留"行星发动机推动地球、穿越太阳系"的核心意象。

## 素材与工程

| 项 | 说明 |
|----|------|
| 引擎 | 复用手写 WebGL 引擎（`assets/engine.js`）：球体 / 环面 / 旋转体等几何工厂、粒子池、星空、大气辉光、多光源分支 |
| 地球 / 云层贴图 | 内联 data URI（`earth-data.js` / `clouds-data.js`） |
| 行星贴图 | 水星 / 金星 / 火星 / 木星 / 土星，取自 `vibeknow/solar-system-3d/assets/`，内联为 `*-data.js` |
| 太阳 | 程序化 canvas 贴图 + 加色光晕壳，零贴图资源 |
| 物理与判定 | `assets/game.js`（唯一真源）：引力、推力、燃料、胜负判定 |
| 天体与参数 | `assets/bodies.js`（唯一真源）：尺度、行星参数、网格装配 |
| 构建 | `build.mjs`（构建 `dist/`）、`verify-minitool.mjs`（合规校验）、`pack.mjs`（打包 zip） |

贴图重新生成：`node tools/make-texture-data.mjs`（把源 jpg/png 内联为 `*-data.js`）。

脚本一律使用相对路径，禁止硬编码绝对路径（参考根目录 `TRACKS.md` 维护约定）。

## 自检

```bash
node tests/headless_wandering.js
```

在 Node 沙箱里真的跑一遍玩法内核：不操作能稳定绕日、顺向点火能逃逸、逆向减速会坠日、低速进木星影响球被捕获、高速掠过则安全通过、燃料会耗尽——共 16 项断言。

## 打包（小红书小工具）

按 [`.skill/minitool-zip-builder`](../../.skill/minitool-zip-builder/SKILL.md) 规范打包：

```bash
node build.mjs && node verify-minitool.mjs dist && node pack.mjs
```

## 分类判定

有明确的目标、失败与胜负反馈，用户点开的第一动机是"玩"——掠行星、算速度、赌一把引力弹弓，而不是"搞懂一件事" → `#vibegame`。与 `moon-landing-3d`、`solar-system-3d`、`earth-3d` 共用素材与引擎，但价值取向不同（前者是看与懂，这里是玩与赢）。
