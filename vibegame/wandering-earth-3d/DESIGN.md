# 流浪地球 · 逃逸截断 —— 设计与数值真源

> 本文件是玩法的**设计与数值唯一真源**。改数值先改本文，再改 `assets/app.js`；面向玩家的说明见 [`README.md`](README.md)。
>
> 本设计于 2026-09-24 完全重构定稿：从原「三段式剧情 + 轨道预测 + 预定量点火」转向「第三人称现时躲避逃离 + 实时推力 + 氦闪膨胀追击」。

---

## 1. 定位

`#vibegame`。一句话：**太阳氦闪膨胀壳从第 0 秒就追上来，你以第三人称实时驾驶地球往外飞——躲耀斑脉冲、躲五颗行星、借木星弹弓加速，30 秒内逃出太阳系。**

平台：**专注移动端**，触屏单手操作，竖屏布局。双击 `index.html` 即开（`file://` 零 CORS，贴图全部 base64 内联）。

## 2. 核心玩法（实时躲避逃离）

- **开场即操作**：无序章、无剧情幕。进入即见地球在 1 AU 圆轨道，太阳壳已开始膨胀，玩家立刻动手往外推。
- **实时推力**：触屏按下并拖动 = 点火方向 + 强度（拖得越远推力越大），松手停机。**按住即烧**，不是预定量点火。
- **第三人称跟拍相机**：相机锚在地球后方偏上，看地球与前方太空。地球朝哪飞相机跟到哪，太阳在身后膨胀追来。
- **氦闪膨胀追击**：太阳壳从第 0 秒持续外胀，半径 = `SUN_R + ∫生长率 dt`。中段 2–3 次耀斑脉冲（壳突胀 1 秒 + 红边预警 + 回落），终局壳加速到大爆发。
- **躲行星 + 借弹弓**：五颗行星沿圆轨道公转，各有引力与影响球。地球撞上 = 失败；低速进入影响球 = 被捕获失败；高速掠过 = 引力弹弓借力加速（玩法双向机会）。
- **动态胜利**：地球在壳外 且 速度 > 壳膨胀速度（真逃出去，不是暂时在壳外但会被追上）。不再固定 20 AU 阈值。
- 一局 30 秒，重开 1 秒，复玩高。

## 3. 30 秒节奏

| 时段 | 发生什么 | 玩家在干啥 |
|---|---|---|
| 0–8s 起步 | 地球 1 AU 圆轨道，太阳壳缓慢外胀（壳半径 10→30） | 打破圆轨道往外推，建立外飞速度 |
| 8–20s 脉冲 + 内圈关 | 2–3 次耀斑脉冲（壳突胀 1s + 红边预警 + 回落）；~12s 接近火星轨道(1.52 AU) | 看预警猛推躲脉冲；选时机穿火星轨道间隙 |
| 20–30s 外圈关 + 终局 | ~22s 木星轨道(5.2 AU)穿间隙/借弹弓；~27s 土星轨道(9.5 AU)；壳加速大爆发追上来 | 穿木星借弹弓加速；冲刺逃出，看壳追上来 |

水星金星在地球内侧（0.39/0.72 AU），往外飞不经过，但保留作视觉完整性 + 万一玩家误操作往内飞会撞。

## 4. 操控（移动端触屏）

| 操作 | 行为 |
|---|---|
| 单指按下并拖动 | 点火：方向 = 拖动方向，强度 = 拖动距离（死区 12px，拖过屏幕短边 25% 达满推） |
| 单指松开 | 停机 |
| 双指捏合 | 相机距离微调（0.5–2×） |
| 双击 / 点结算页 | 重开（结算页出现 1 秒后生效，防误触） |

无 WASD / 方向键 / Shift / 滚轮等桌面键鼠操作。

## 5. 相机（第三人称跟拍）

- **锚点**：地球后方 `camBack` 单位 + 上方 `camUp` 单位，`lookAt(地球)`。
- **朝向跟随地球速度方向**：相机后方轴对齐地球速度向量的反方向，地球往哪飞相机就在它正后方看它往前冲。
- **平滑插值**：地球速度方向变时相机 lerp 0.1，避免快速转向时画面甩。
- **氦闪时拉远**：壳膨胀时相机自动拉远到能同时看到地球和膨胀壳前缘，强化"被追"的压迫感。
- **捏合缩放**：用户手动微调相机距离，叠加在自动跟拍之上。

## 6. 物理模型

| 项 | 做法 |
|---|---|
| 运动平面 | 共面（XZ 平面），太阳静止于原点 |
| 太阳 | 引力 `a = −G_SUN · p / |p|³`，唯一引力主源 |
| 行星 | 圆轨道匀速公转，位置与速度解析给出；**各有引力 gm + 影响球 capR**；不受地球影响（单向引力，保证可预测） |
| 地球 | 受太阳 + 五颗行星引力 + 玩家实时推力 |
| 推力 | 实时持续推力：按住即烧，方向 = 拖动方向，强度 = 拖动距离；松手停机。**无燃料限制**（先跑通核心，燃料后加） |
| 积分 | 半隐式欧拉 + 固定子步（`SUBSTEP = 0.0045` 游戏秒），单帧子步上限 900 |
| 开局保护 | 前 60 帧不判行星碰撞（避免初始相位踩雷） |

## 7. 氦闪膨胀模型

- 壳半径 `shellR(t) = SUN_R + ∫ growRate(t) dt`，从第 0 秒开始胀。
- 基础生长率 `BASE_GROW`：让壳在 ~17 秒追上 1 AU 处地球（约 4 单位/秒）。
- 耀斑脉冲：8–20s 间触发 2–3 次，每次脉冲 `growRate` 临时 ×4 持续 1 秒再回落，触发前 0.3 秒全屏红边预警。
- 终局加速：20s 后 `growRate` 随时间二次增长，壳冲向大爆发。
- 壳膨胀速度 `shellV(t) = growRate(t)`，用于动态胜利判定。

## 8. 数值真源

### 8.1 尺度

| 常量 | 值 | 说明 |
|---|---|---|
| `AU` | 100 | 1 天文单位 |
| `SUN_R` | 10 | 太阳半径（视觉放大） |
| `EARTH_R` | 3.4 | 地球半径（视觉放大） |
| `G_SUN` | 11000 | 太阳 GM，1 AU 圆轨道速度 = 10.49 单位/秒 |
| `ESCAPE_R` | 4200 (42 AU) | 胜利距离门槛（冥王星外） |

### 8.2 行星（沿用原 bodies.js，五颗全留）

| 行星 | 半径 | 轨道 | `gm` | 影响球 `capR` |
|---|---|---|---|---|
| 水星 | 2.0 | 0.39 AU | 3 | 18 |
| 金星 | 3.2 | 0.72 AU | 8 | 26 |
| 火星 | 2.4 | 1.52 AU | 5 | 22 |
| 木星 | 9.0 | 5.20 AU | 500 | 45 |
| 土星 | 7.6 | 9.54 AU | 380 | 40 |

内行星 `gm` 压到不显著扰动地球公转的量级；捕获/弹弓风险与机会交给木星土星。

### 8.3 玩家推力

| 常量 | 值 | 说明 |
|---|---|---|
| `THRUST_ACC` | 7.0 | 满推力加速度（配合能量管理，间歇推+脉冲乘波 90 秒可达 42 AU） |
| `AIM_DEAD` | 12 px | 拖动死区 |
| `AIM_FULL` | 0.25 | 达满推所需拖动距离（屏幕短边比例） |

**无燃料机制**（先跑通核心算法，燃料后加）。

### 8.4 氦闪节奏

| 常量 | 值 | 说明 |
|---|---|---|
| `ROUND_TIME` | 30 秒 | 一局时长 |
| `BASE_GROW` | 4.0 单位/秒 | 壳基础生长率 |
| `PULSE_TIMES` | [10, 16] 秒 | 耀斑脉冲触发时刻（2 次） |
| `PULSE_GAIN` | 4× | 脉冲时生长率倍数 |
| `PULSE_DUR` | 1.0 秒 | 脉冲持续时长 |
| `PULSE_WARN` | 0.3 秒 | 脉冲前红边预警时长 |

### 8.5 真实单位换算（HUD 用）

| 常量 | 值 |
|---|---|
| `REAL_SEC_PER_GAME_SEC` | 5.26×10⁵（游戏 1 秒 ≈ 真实 6.09 天） |
| `KMS_PER_UNIT` | ≈ 2.844 |
| `YEARS_PER_GAME_SEC` | 1/60 |

互锁校验：1 AU 圆轨道速度 × KMS_PER_UNIT = 29.8 km/s，1 AU 转一圈 = 60 游戏秒 = 1 年。

## 9. 胜负判定

| 条件 | 结果 |
|---|---|
| 距日 < `SUN_R + EARTH_R` | 撞太阳失败 |
| 距(行星) < 行星半径 + `EARTH_R` | 撞行星失败 |
| 距(行星) < `capR` 且相对速度 < `√(2·gm/dist)` | 被引力捕获失败 |
| 距日 < `shellR`（当前壳半径） | **被氦闪壳吞没失败** |
| `t ≥ ROUND_TIME` 仍飞行 | **时间耗尽失败**（30 秒内未达到逃逸能量） |
| 距日 > `shellR + 安全余量` 且 速度 > `shellV` | **逃逸成功** |

## 10. 场景与渲染

| 项 | 做法 |
|---|---|
| 引擎 | Three.js（内联 `three.min.js` 约 600KB） |
| 太阳 | 程序化贴图（Canvas 生成）+ 加色光晕壳；氦闪时 scale 膨胀 + 白闪 |
| 地球 | 复用 base64 earth/clouds 贴图 + 大气壳 |
| 五行星 | 复用 base64 mercury/venus/mars/jupiter/saturn 贴图；土星环 ring geometry（不参与碰撞） |
| 星空天球 | 程序化银河贴图 |
| HUD | 左上倒计时大字（<10s 红脉冲 + 整秒滴答音）；右上逃逸比 + 距日 + 速度；危险时全屏红边脉冲；进入影响球预警提示；耀斑脉冲触发时全屏白闪 |
| 音效 | 程序化 WebAudio（首次触摸解锁）：点火隆隆声（噪声+低通，音量随推力）+ 耀斑爆音 + 倒计时滴答 + 胜利/失败音 |

**砍掉**：序章剧情层、56 道发动机光柱、月球、海啸/风暴/地下城、轨道预测虚线、双档相机、预定量点火、自研 WebGL 引擎。

`node tests/headless_escape.js` —— 在 Node 沙箱里跑玩法内核：

| 组 | 断言 |

## 14. 风险与取舍

| 风险 | 取舍 |
|---|---|
| 真实尺度不可玩 | 放大天体半径与行星引力，只保证单位换算真实 |
| 单向引力不守恒 | 接受。玩法要的是可预测（弹弓才有意义） |
| 30 秒推到 20 AU 物理紧 | 动态胜利条件（速度 > 壳速即赢）而非固定距离，给操作空间 |
| 五行星全留包体大（3.1MB） | 接受。用户要真贴图与弹弓，包体换玩法丰富度 |
| 弹弓学习曲线 | 影响球靠近时预警提示 + HUD 显示相对速度/逃逸阈值，降低踩雷 |
| `file://` CORS | 贴图全部 base64 内联，three.min.js 内联，双击即开零 CORS |
