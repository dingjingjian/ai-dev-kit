# 流浪地球 · 逃出太阳系 —— 设计与数值真源

> 本文件是玩法的**设计与数值唯一真源**：三段式结构、物理模型、数值表、判定规则与验收标准都记在这里。
> 改数值先改本文，再改 `assets/bodies.js` / `assets/game.js` / `assets/story.js`；面向玩家的说明见 [`README.md`](README.md)。

---

## 1. 定位

`#vibegame`。核心体验一句话：**刹车时代看过场，逃逸时代亲手把地球推出太阳系——在近日点点火、借木星弹弓、躲过氦闪，飞出去。**

与同题材的 `moon-landing-3d` / `solar-system-3d` / `earth-3d` 划清界限：那三个是"看与懂"，本项目是"玩与赢"。素材与引擎复用，价值取向不同。

## 2. 三段式结构（剧情唯一真源在 `story.js`）

```
序章 · 刹车时代（约 42 年，不可操作，点击推进 / 可跳过）
  氦闪预警 → 飞船派/地球派之争 → 万台发动机点火
  → 月球被推离地球轨道（海啸）→ 停止自转 → 迁入地下城
        ↓ 交还操控
第一章 · 逃逸时代（可操作）
  绕日 15 圈，一圈圈把轨道推大
  第 10 圈：叛乱 → 处决 → 太阳氦闪爆发（太阳膨胀吞没水星金星）
        ↓
终局：距日 > 20 AU 即胜利
```

- 序章 7 幕（含交还操控的转场幕），每幕带 `year` 起止与场景指令（自转速率 / 发动机亮度 / 城市灯光 / 海啸 / 风暴 / 太阳异常 / 相机档位 / 月球状态）。
- 叛乱 3 幕：前两幕**冻结物理**，氦闪幕解冻并允许操作——太阳在数秒内膨胀到 9.5 倍（≈ 1.0 AU），玩家要靠推力自救，离日太近即被吞没。
- 重开不重播序章（重开成本低是设计的一部分）。

## 3. 操控与相机

### 3.1 拖出箭头 · 预定量点火

- 在屏幕任意处按下并拖动：**方向 = 点火方向，长度 = 点火量**。松手执行，发动机烧完预定的 Δv 自动停机（`game.commitBurn`）。
- 拖动时**不消耗燃料**，实时画出点火后的预测轨道（橙色虚线）——"规划 → 执行 → 观察"的回合节奏。
- 单次点火 Δv 上限 `DV_MAX = 3.0` 游戏单位（≈ 8.5 km/s）；死区 12 px，拖过屏幕短边 30% 达满。

### 3.2 双档自动切换

| 档 | target | 距离 | 时机 |
|----|--------|------|------|
| **远景**（默认） | 太阳 | 覆盖当前轨道远日点（`max(320, apoapsis×2.4)`） | 平时——轨道怎么变一目了然 |
| **近景** | 地球 | 54 | 点火执行中及结束后 1.4 s |

- **瞄准期间相机冻结**，否则锚在地球上的箭头会跟着漂。
- 滚轮 / 双指：额外缩放系数（0.5–2.2×）。
- 相机方位固定俯视（不随玩家旋转），因此屏幕方向到世界方向是**常量映射**：屏幕右 → +X，屏幕下 → +Z。
- 地球出画时在屏幕边缘画准星 + 方向箭头（远景区地球常常只有几个像素甚至出画）。

## 4. 物理模型

| 项 | 做法 |
|----|------|
| 运动平面 | 共面（XZ 平面），太阳静止于原点 |
| 太阳 | 引力 `a = −G_sun · p / |p|³` |
| 行星 | 圆轨道匀速公转，位置与速度解析给出；**不受地球影响**（单向引力，保证可预测） |
| 地球 | 受太阳 + 五颗行星引力 + 玩家推力 |
| 推力 | 预定量点火（`commitBurn`）优先于持续推力（`setThrust`，自检兼容路径）；两者共用同一燃料账 |
| 燃料 | 按速度增量扣：`fuel -= dv / FUEL_DV`，满燃料可提供 19 单位/秒的总 Δv |
| 积分 | 半隐式欧拉 + 固定子步（`SUBSTEP = 0.0045` 游戏秒），单帧子步上限 900 |
| 开局保护 | 前 90 帧不判行星碰撞 |

## 5. 数值真源

### 5.1 尺度（`bodies.js`）

| 常量 | 值 | 说明 |
|------|----|------|
| `AU` | 100 单位 | 1 天文单位 |
| `SUN_R` | 10 | 太阳半径（视觉放大） |
| `EARTH_R` | 3.4 | 地球半径（视觉放大） |
| `G_SUN` | 11000 | 太阳 GM，使 1 AU 处圆轨道速度 = 10.49 单位/秒 |
| `ESCAPE_R` | 2000（20 AU） | 胜利线 |
| `PROXIMA_POS` | [2400, 0, 0] | 比邻星方向 |

### 5.2 行星（`bodies.js`）

| 行星 | 半径 | 轨道 | `gm` | 影响球 `capR` |
|------|------|------|------|--------------|
| 水星 | 2.0 | 0.39 AU | 3 | 18 |
| 金星 | 3.2 | 0.72 AU | 8 | 26 |
| 火星 | 2.4 | 1.52 AU | 5 | 22 |
| **木星** | 9.0 | 5.20 AU | **500** | **45** |
| 土星 | 7.6 | 9.54 AU | 380 | 40 |

内行星 `gm` 压到不显著扰动地球公转的量级（自检钉住"不操作时轨道稳定"）；捕获风险交给木星 / 土星。

### 5.3 玩家推力与逃逸经济学（`bodies.js` / `game.js`）

| 常量 | 值 | 说明 |
|------|----|------|
| `THRUST_ACC` | 3.6 单位/秒² | 满推力加速度 |
| `FUEL_DV` | 19.0 单位/秒 | 满燃料总速度增量（≈ 54 km/s） |
| `DV_MAX` | 3.0 单位/秒（`app.js`） | 单次点火上限 → 满燃料约 6 次点火机会 |
| `OBERTH_GAIN` | 0.55（`game.js`） | 近日点效率加成上限：`eff = 1 + 0.55 × peri`，实测近日点点火多换 52% 速度 |
| `LAP_TOTAL` | 15 | 绕日圈数（叙事框架 + HUD 进度） |
| `FLASH_LAP` | 10 | 第几圈触发叛乱与氦闪 |

**奥伯特效应的游戏化**：近日点窗口强度 `peri = max(0, cosθ) × (0.45 + 0.55·min(1, e/0.5))`（θ 为真近点角）。同样 1 单位燃料，在近日点换来 1.525 单位速度、远日点只换 1.000——自检有断言。这是"什么时候点火"的策略核心。

### 5.4 真实单位换算（`game.js`）

| 常量 | 值 |
|------|----|
| `REAL_SEC_PER_GAME_SEC` | 5.26×10⁵（游戏 1 秒 ≈ 真实 6.09 天） |
| `KMS_PER_UNIT` | ≈ 2.844 |
| `YEARS_PER_GAME_SEC` | 1/60（60 游戏秒 = 1 年） |

互锁校验：`V_CIRC × KMS_PER_UNIT = 29.8 km/s`，1 AU 转一圈 = 60 游戏秒 = 1 年。

## 6. 轨道解算与呈现（`orbit.js` + 2D 叠加层）

- `orbit.elements(pos, vel, gm)`：由位置速度解算半长轴 / 偏心率 / 半通径 / 近日点方向 / 真近点角 / 周期 / 逃逸速度。**纯函数**，无头自检直接调用。
- 2D 叠加层（`#fx` canvas，`renderer.project` 投影）画：
  - 地球当前轨道（实线冷蓝）与**点火预测轨道**（虚线暖橙）；
  - 近日点标记（e > 0.03 才画；进入点火窗口变橙并脉冲）；
  - 行星影响球（靠近 4.5× 影响球内才画，进入变橙红虚线）；
  - 地球准星 / 出画边缘指示器；推力箭头。
- 近圆轨道（e < 1e-4）近日点方向退化为径向，HUD 按 e 阈值隐藏标记（物理上近圆轨道处处等价）。
- 3D 轨道环（`bodies.js`）只在远景显示——近景下它们是横穿屏幕的色带。

## 7. 胜负判定（`game.js` 的 `check()`）

| 条件 | 结果 |
|------|------|
| `r_sun < SUN_R + EARTH_R` | 撞毁 · 坠入太阳 |
| `dist(行星) < 行星半径 + EARTH_R` | 撞毁 · 撞击该行星 |
| `dist(行星) < capR` 且 `v_rel < √(2·gm/dist)` | 被引力捕获 |
| `st.flashR > 0` 且 `r_sun < flashR + EARTH_R` | **被氦闪吞没** |
| `r_sun > ESCAPE_R` | **成功 · 飞出太阳系** |

`st.flashR` 由剧情层每帧写入（太阳膨胀半径），物理内核只读判定——职责边界与行星位置一致。

## 8. 渲染与场景

| 项 | 做法 |
|----|------|
| 引擎 | 手写 WebGL（`engine.js`），相机随动光；星空天球 + 深空底色 |
| 地球 | 贴图球 + 云壳 + 加色大气壳；**表面 56 道发动机光柱**（斐波那契球面分布，挂在地球局部坐标系下随自转），亮度 = 剧情亮度 × (常亮 0.28 + 点火 0.72) |
| 序章表现 | 自转速率由剧情驱动渐停；城市灯光随"迁入地下城"熄灭（贴图色乘 0.5–1.0）；海啸 = 云层增厚；风暴 = 大气壳增强；太阳异常 = 光晕增亮 |
| 月球 | 序章第 4 幕被推离：远离 + 淡出 + 尾焰锥体，之后退场 |
| 太阳氦闪 | 太阳三壳整体 scale 至 9.5×（≈ 1.0 AU），水星金星被吞（mesh 与轨道环隐藏）；白闪 + 爆音 |
| HUD | 真实单位（AU / km/s / 年）；逃逸比 = 当前速度 ÷ 当地逃逸速度，≥ 1.00 高亮 |

## 10. 参数真源与约定

1. **尺度、行星参数、推力参数**只在 `bodies.js` 的 `M3D.WORLD`；其余文件一律引用。
2. **判定规则与物理积分**只在 `game.js`；`app.js` 不做数值判断。
3. **剧情幕表与场景指令**只在 `story.js`；`app.js` 只执行不定义。
4. **屏幕方向 → 世界方向**映射与相机方位耦合（见 §3.2）；若允许转视角必须同步改。
5. **HUD 显示真实单位**（AU / km/s / 年），游戏单位只存在于内部计算。
6. **脚本一律相对路径**；**贴图全部内联**（新增贴图必须有对应 `*-data.js`）。
7. `project(worldPos数组, out)` 收的是**数组**不是三个标量——第二次踩这个坑就该抽封装了（`app.js` 的 `proj(x,z)` 就是）。

## 12. 自检（34 项）

`node tests/headless_wandering.js` —— 在 Node 沙箱里**真的跑一遍玩法内核**：

| 组 | 断言 |
|----|------|
| 工程 | 15 个脚本顶层可求值；`buildWorld` / `createGame` / `orientUp` / `orbit.elements` / `createStory` 导出齐全；序章 7 幕、叛乱 3 幕 |
| 常量 | 1 单位/秒 ≈ 2.844 km/s；60 游戏秒 ≈ 1 年 |
| 玩法 | 不操作时稳定绕日；顺向点火逃逸；逆向减速坠日；低速进木星影响球被捕获；高速掠过安全；燃料耗尽推力归零 |
| 轨道 | 圆轨道 e≈0、a≈1 AU、周期≈60 秒；超逃逸速度 → 双曲线；圆轨道顺向点火 → 点火点成近日点 |
| 新机制 | 10 年 ≈ 10 圈（圈数累计）；**奥伯特效应**（近日点 +1.525 vs 远日点 +1.000）；`commitBurn` 按量点火并自动停机；燃料按 Δv 扣减；氦闪吞没判定 |

## 13. 风险与取舍

| 风险 | 取舍 |
|------|------|
| 真实尺度不可玩 | 放大天体半径与行星引力，只保证**单位换算**真实；README 如实说明 |
| 单向引力不守恒 | 接受。玩法要的是**可预测**（轨道预测线才有意义） |
| 剧情杀（第 10 圈氦闪） | 氦闪幕解冻并允许操作，膨胀有数秒过程，离日不太近即可存活；正常玩家此时轨道已远大于 1 AU |
| 序章 45 秒不可操作 | 每幕可点击推进、可整段跳过；重开不重播 |
| 燃料预算紧张（6 次点火） | 刻意的：逼玩家用近日点窗口与引力弹弓，而不是无脑满推 |
| 与原著的差异 | 事件与顺序忠于小说设定；时间尺度（42 年 → 45 秒）与数值为可玩性压缩 |
