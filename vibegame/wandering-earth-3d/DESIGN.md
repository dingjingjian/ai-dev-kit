# 流浪地球 · 逃出太阳系 —— 设计与数值真源

> 本文件是玩法的**设计与数值唯一真源**：物理模型、数值表、判定规则、里程碑与验收标准都记在这里。
> 改数值先改本文，再改 `assets/bodies.js` / `assets/game.js`；面向玩家的说明见 [`README.md`](README.md)。

---

## 1. 定位

`#vibegame`。核心体验一句话：**用有限的行星发动机燃料，把地球从 1 AU 推着穿过太阳系，靠速度躲开行星的引力陷阱，飞出去。**

爽点来自三处：
1. **引力弹弓**：贴着木星掠过、速度刚好高于逃逸阈值——免费得到一大截速度；
2. **临界紧张**：警告条上"相对速度 15.7 / 逃逸阈值 14.1 km/s"擦着过；
3. **一次失误就归零**：没有血条、没有复活，撞了或被抓住就是失败，重开成本低。

与同题材的 `moon-landing-3d` / `solar-system-3d` / `earth-3d` 划清界限：那三个是"看与懂"，本项目是"玩与赢"。素材与引擎复用，价值取向不同。

## 2. 玩法循环

```
开局（地球在 1 AU 圆轨道，燃料 100%）
   ↓ 滑动屏幕 → 行星发动机点火（有限燃料）
穿越太阳系（太阳引力 + 五颗行星引力实时作用）
   ↓
   ├─ 撞上太阳 / 行星         → 任务失败（撞毁）
   ├─ 进入行星影响球且速度不足 → 任务失败（被引力吸走）
   └─ 距日 > 20 AU            → 任务成功（飞出太阳系）
```

重新开始 = 一键复位（`game.reset()`），不设关卡与进度存档。

## 3. 操控与相机映射

- **相机固定方位俯视**（不随玩家旋转），只允许滚轮 / 双指缩放。这是刻意选择：滑动要用来操控地球，若同时用于转视角会互相打架。
- 因为方位固定，屏幕方向到世界方向的映射是**常量**：

| 屏幕 | 世界（XZ 平面） |
|------|----------------|
| 向右滑 | +X |
| 向下滑 | +Z |
| 向左滑 | −X |
| 向上滑 | −Z |

- **推力大小**与滑动距离成正比（死区 10 px，满推力约需滑过屏幕短边的 22%）。
- **滑一段后按住不动**保持当前推力方向与强度（松手即停）——避免必须持续划动，移动端手感更好。
- 相机平滑跟随地球（时间常数 ≈ 1/6 s），避免逐帧硬切造成抖动。

## 4. 物理模型

| 项 | 做法 |
|----|------|
| 运动平面 | 共面圆轨道（XZ 平面），不做轨道倾角与偏心率 |
| 太阳 | 静止于原点，引力 `a = −G_sun · p / |p|³` |
| 行星 | 各自按圆轨道匀速公转，位置与速度解析给出；**不受地球影响**（单向引力，保证可预测性） |
| 地球 | 受太阳 + 五颗行星的引力 + 玩家推力 |
| 推力 | `a += thrustDir · THRUST_ACC · mag`，同时按 `FUEL_BURN` 扣燃料 |
| 积分 | 半隐式欧拉 + 固定子步（`SUBSTEP = 0.0045` 游戏秒），单帧子步上限 900 |
| 开局保护 | 前 90 帧不判行星碰撞（避免初始相位踩雷给出"莫名失败"） |

子步必须小的原因：木星影响球半径 45 单位，而地球掠过时相对速度可达 5 单位/秒——单子步位移 0.0225 单位，远小于影响球，判定不会"穿过去"。若把 `SUBSTEP` 放大到 0.05 以上，会出现高速掠过却不触发捕获的漏判。

## 5. 数值真源

### 5.1 尺度（`bodies.js`）

| 常量 | 值 | 说明 |
|------|----|------|
| `AU` | 100 单位 | 1 天文单位 |
| `SUN_R` | 10 | 太阳半径（视觉放大；真实 0.00465 AU） |
| `EARTH_R` | 3.4 | 地球半径（视觉放大；真实 4.3×10⁻⁵ AU） |
| `G_SUN` | 11000 | 太阳 GM，使 1 AU 处圆轨道速度 = 10.49 单位/秒 |
| `V_CIRC` | √(G_SUN/AU) ≈ 10.49 | 1 AU 圆轨道速度 |
| `ESCAPE_R` | 2000（20 AU） | 胜利线 |
| `PROXIMA_POS` | [2400, 0, 0] | 比邻星方向（胜利指向） |

### 5.2 行星（`bodies.js`）

| 行星 | 半径 | 轨道 | `gm` | 影响球 `capR` | 说明 |
|------|------|------|------|--------------|------|
| 水星 | 2.0 | 0.39 AU | 3 | 18 | 内圈干扰 |
| 金星 | 3.2 | 0.72 AU | 8 | 26 | 内圈干扰 |
| 火星 | 2.4 | 1.52 AU | 5 | 22 | 逃逸路上第一道坎 |
| **木星** | 9.0 | 5.20 AU | **500** | **45** | 主威胁；逃逸轨道必经，也是最佳弹弓 |
| 土星 | 7.6 | 9.54 AU | 380 | 40 | 外侧挑战 |

`gm` 取值原则（改这块务必先读）：**既要让"低速掠过被吸走"，又不能强到干扰地球在 1 AU 的正常公转**。
内行星若 `gm` 过大（曾取 120 / 300 / 200），会在近距交会时把地球轨道拽偏，最严重时开局几十秒就坠入太阳——自检里的"不操作时稳定在地球轨道附近"就是为了钉住这条。

### 5.3 玩家推力（`bodies.js`）

| 常量 | 值 | 说明 |
|------|----|------|
| `THRUST_ACC` | 3.6 单位/秒² | 满推力加速度（约为 1 AU 处太阳引力的 3.3 倍） |
| `FUEL_DV` | 19.0 单位/秒 | 燃料可提供的总速度增量（约为圆轨道速度的 1.8 倍） |
| `FUEL_BURN` | 3.4 /秒 | 燃料消耗速率 → 满推力可持续约 5.6 游戏秒 |

设计意图：满推力一轮烧完刚好能把圆轨道推成逃逸轨道（逃逸需要 Δv ≈ 4.34 单位/秒），**但余量不多**——所以不能一路狂喷，必须规划点火时机与方向。

### 5.4 真实单位换算（`game.js`）

| 常量 | 值 | 说明 |
|------|----|------|
| `REAL_SEC_PER_GAME_SEC` | 5.26×10⁵ | 游戏 1 秒 ≈ 真实 6.09 天 |
| `KMS_PER_UNIT` | ≈ 2.844 | 1 单位/秒 ≈ 2.844 km/s |
| `YEARS_PER_GAME_SEC` | 1/60 | 60 游戏秒 = 1 年 |

这三条互锁：`V_CIRC × KMS_PER_UNIT = 29.8 km/s`（真实地球公转速度），`1 AU 转一圈 = 60 游戏秒 = 1 年`。自检有对应断言，改动任一常量都会被抓出来。

## 6. 胜负判定（`game.js` 的 `check()`）

| 条件 | 结果 |
|------|------|
| `r_sun < SUN_R + EARTH_R` | 撞毁 · 坠入太阳 |
| `dist(行星) < 行星半径 + EARTH_R` | 撞毁 · 撞击该行星 |
| `dist(行星) < capR` **且** `v_rel < √(2·gm/dist)` | 被引力吸走 · 成为该行星的卫星 |
| `r_sun > ESCAPE_R` | 成功 · 飞出太阳系 |

**为什么用"相对速度 vs 逃逸速度"而不是"进了影响球就死"**：这是整个玩法的支点。同一条接近轨迹，速度够就是弹弓、不够就是墓碑；玩家能通过实时警告条（相对速度 / 逃逸阈值）判断该加速还是绕开，失败可归因、可学习。

## 7. 渲染与场景

| 项 | 做法 |
|----|------|
| 天体光照 | 走相机随动光（`useSun: false`），任何机位都不背光，保证所有行星始终可辨；太阳用 `glow = 1` 自发光 |
| 地球 | 贴图球 + 云壳 + 加色大气壳，随速度方向自转 |
| 行星 | 贴图球（土星带环）；贴图来自 `solar-system-3d`，内联 data URI |
| 轨道圈 | 半透明加色圆环，标出各行星轨道与地球原轨道（帮助判断是否已脱离） |
| 比邻星 | 远处加色亮点，给出胜利方向的空间参照 |
| 推力尾焰 | 沿推力反方向的加色锥体，紧贴地球背面，透明度随推力强度变化 |
| 月球 | 程序化贴图球（零资源文件），**仅出现在开场剧情**：绕地公转，行星发动机启动后逐渐远离地球并淡出，呼应"把月球留在原地，地球独自上路" |
| 开场剧情 | 进入游戏前的过场（app.js `prologue` 状态机，不改物理内核）：自转暂停 → 行星发动机点火（白闪 + 尾焰粒子 + 音效）→ 月球离场，结束后交还滑屏操控；点击任意处可推进、右上角可跳过 |
| 背景 | 星空（天球，只旋转不平移）+ 深空底色 |

## 9. 参数真源与约定

1. **尺度、行星参数、推力参数**只在 `bodies.js` 的 `M3D.WORLD`；`game.js` / `app.js` 一律引用，不复制数值。
2. **判定规则与物理积分**只在 `game.js`；`app.js` 不做数值判断（只做渲染与输入）。
3. **屏幕方向 → 世界方向**的映射写在 `app.js` 的操控段，且与相机方位（固定俯视）耦合——若要允许转视角，必须同步改这里的映射，否则滑动方向会与直觉不符。
4. **HUD 显示真实单位**（AU / km/s / 年），游戏单位只存在于内部计算。
5. **脚本一律相对路径**，禁止硬编码绝对路径（`TRACKS.md` 维护约定第 4 条）。
6. **贴图全部内联**：任何新增贴图都要有对应 `*-data.js`，否则 `file://` 直开会被画布污染拦下。

## 11. 自检

`node tests/headless_wandering.js` —— 在 Node 沙箱里**真的跑一遍玩法内核**，共 16 项：

| 组 | 断言 |
|----|------|
| 工程 | 13 个脚本顶层可求值；`buildWorld` / `createGame` / `orientUp` 导出齐全 |
| 常量 | 1 单位/秒 ≈ 2.844 km/s；60 游戏秒 ≈ 1 年 |
| 玩法 | 不操作时稳定绕日（10 年后仍在 1.1 AU 附近）；顺向点火能爬到逃逸能量并最终 `escaped`；逆向减速会坠入太阳；**低速进木星影响球 → 被捕获**；**高速掠过同一影响球 → 安全通过**；燃料会耗尽且耗尽后推力归零 |

改物理或数值后先跑自检——它对"手感参数被改坏"的敏感度远高于肉眼试玩。

## 12. 风险与取舍

| 风险 | 取舍 |
|------|------|
| 真实尺度不可玩 | 放大天体半径与行星引力，只保证**单位换算**真实；放大项在 README 如实说明 |
| 放大行星引力会干扰地球公转 | 内行星 `gm` 压到不显著扰动的量级，捕获风险交给木星 / 土星；自检钉住"不操作时的轨道稳定性" |
| 单向引力不守恒 | 接受。玩法要的是**可预测**（行星轨迹固定，玩家可规划），而非严格 N 体 |
| 滑动既操控又转视角会打架 | 相机固定方位、只手势缩放；映射写在 `app.js` 并有本文明示 |
| 燃料太少会劝退 | 燃料预算刚好够一次逃逸（1.8× 圆轨道速度），留出"贴木星弹弓"的省油打法空间 |
| 与《流浪地球》原著不符 | 本项目只取"行星发动机推动地球"的意象，不做剧情复刻；README 明示这一点，避免被当成原著还原 |
