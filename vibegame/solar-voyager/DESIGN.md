# 星航者 · 太阳系漫游 — 设计文档

> 本文档记录项目整体思路、玩法设计、数值设定、视觉方向与待优化清单，供后续迭代参考。
> 最后更新：2026-08-31（v0.5 太阳系完整化 + 节奏复检）

---

## 1. 项目概览

- **定位**：小红书 VibeCoding 大赛 `#vibegame` 参赛作品，以「小工具」形式上传挂载
- **形态**：手机端优先的 H5 单页游戏，离线运行、不联网、无构建步骤
- **核心体验**：基地运营 + 火箭设计 + 太空探索 三段循环的策略游戏
- **灵感参考**：群星（Stellaris）+ 坎巴拉太空计划（KSP），压缩为手机端轻量可玩版本
- **入口**：`index.html`（根目录，内联样式）+ `src/` 下 5 个外置经典脚本
- **新版覆盖范围**：13 个天体（地球 + 8 行星 + 矮行星冥王星 + 月球/木卫二/土卫六 + 小行星带）、15 项科技、终点 = 冥王星

### 1.1 代码结构（v0.4）

原来全部逻辑挤在单个 `src/main.js`（47 KB），已拆分为按职责分层的 5 个文件，靠全局 `SV` 命名空间协作，**加载顺序即依赖顺序**：

| 文件 | 职责 | 依赖 |
|------|------|------|
| `src/data.js` | 静态配置、火箭解算、存档、派生状态 | 无 |
| `src/vfx.js` | 全部 Canvas 绘制（星云/星球/火箭/粒子/场景） | `data.js` |
| `src/ui.js` | DOM 渲染、数字滚动、涟漪、弹窗 | `data.js` / `vfx.js` |
| `src/flight.js` | 飞行小游戏（关卡生成、物理、HUD、音效） | `data.js` / `vfx.js` |
| `src/game.js` | 主循环、回合经济、任务成就、引导、事件绑定 | 全部 |

拆分原因：单文件已难以定位问题，且绘制层与逻辑层互相污染；分层后视觉改动只碰 `vfx.js`，数值改动只碰 `data.js`。

## 2. 核心玩法循环

```
基地运营（产资源/攀科技/触发事件）
      ↓
火箭设计（装配/算推重比/航程/护盾）
      ↓
发射探索（选目标→操控飞行→拾取补给）
      ↓
建立新基地（解锁新资源加成）
      ↓
回到基地（更强）→ 推进更远星球
```

**四层目标感**：

1. **任务链**（12 个）给出下一步该做什么
2. **成就**（12 个）提供可选的自我挑战
3. **事件**（12 种）让每回合有变数
4. **结局**：抵达冥王星触发终局画面

胜利感来源：科技树推进 + 基地从地球扩张到冥王星 + 解锁更远航线 + 档案页累积的远征日志。

## 3. 三阶段详解

### 3.1 基地运营

- 顶部资源条：金属 / 燃料 / 科研，数值变化时**滚动到新值**并弹出飘字 `+N / −N`
- 人力分配：共 4 人起（居住舱 +2 上限），拖动岗位条分配到 采矿 / 科研 / 精炼 三岗；改一岗时其余按当前比例自动重摊，超出上限的人力闲置
- 基地设施：4 种建筑，消耗金属建造
- 科技树：打开**图状科技地图**（Canvas 节点 + 贝塞尔依赖边），可解锁
- 下一回合：产出资源、回合数 +1；**从第 3 回合起有 32% 概率触发随机事件**
- 顶栏基地名可点击：切换主基地
- 场景画面：天空渐变 + 三层视差山脊 / 云带 + 弧形地表 / 云顶 + 按设施绘制的建筑 + 浮尘 + 暗角
  - **气态 / 冰巨星**没有地表，基地是浮空站：脚下改为翻涌的云海（带亮边的云顶 + 远云带），天空更黑、太阳更小、星星更密

### 3.2 火箭设计

- **多件装配**（v0.4 最大改动）：舱体决定挂载位与护盾，燃料罐可叠加、引擎可并联

  | 舱体 | 质量 | 挂载位（罐/引擎） | 护盾 |
  |------|------|------------------|------|
  | 基础舱 | 4 | 1 / 1 | 0 |
  | 加强舱 | 6 | 2 / 2 | 1 |
  | 重型舱 | 9 | 3 / 3 | 2 |

- 零件库受科技树解锁限制（锁定项灰显）
- 实时计算：总质量 / 推力 / 推重比 / 燃料 / 航程 / 护盾，并列出**不可起飞的具体原因**
- 保存设计（按航程自动命名「近地者 / 拓荒者 / 远行者 / 深空号 + 序号」），可删除 / 选用
- Canvas 预览：**逐件滑入的装配动画**（引擎→罐→舱→仪器，各延迟 0.07s）+ 金属质感 + 尾焰粒子
- 换更小舱体时自动截断超出挂载位的零件

### 3.3 太空探索

- 选已保存火箭 + 选目标星球（未解锁航线灰显，星球标注危险等级 0–3）
- 发射判定：能起飞、基地燃料够装满火箭、航程 ≥ 目标距离
- 通过后进入竖屏操控小游戏：
  - 火箭持续上升，左右拖动控制水平位置
  - **护盾**由舱体提供，撞击扣 1 层并获 1.3s 无敌闪烁；无护盾时一次撞击即失败
  - 障碍分三类：岩石、**引力井**（横向拉扯）、**碎片带**（留一个缺口需穿过去）
  - 拾取物：**燃料罐**（回 14% 燃料）、**加速环**（1.6s 内速度 ×1.75）、**数据晶体**（需装科学仪，结算换科研点）
  - 到达目标星球 = 成功；撞击耗尽护盾 / 燃料耗尽 = 失败
- 成功结算：可建基地的星球建立/补给基地；不可建基地的（小行星带）给一次性金属；数据晶体 ×8 科研；剩余燃料回收 50%；零损伤额外标记
- 失败结算：回收 `质量 × 50%` 金属
- 到访新星球弹**星球知识卡**（描述文本 + 资源加成），并提示是否切换主基地
- 首次抵达土卫六触发结局画面

## 4. 视觉设计方向

**风格：深空摄影质感**（仿 NASA / 星空摄影）

- **星云背景**：多层径向渐变，离屏 canvas 预渲染并按尺寸缓存
- **多层星点**：远/中/近三层视差 + 大亮星带十字光芒 + 闪烁
- **行星表面纹理**：离屏预渲染，按 `pl.kind` 分流
  - 地球：蓝绿陆地斑块 + 漂移云带 + 极冠
  - 月球 / 水星：灰白 + 陨石坑（暗斑 + 亮边）
  - 火星：红褐斑 + 极冠 + 水手号峡谷
  - 金星：Y 形硫酸云拉丝 + 极区暗涡
  - 木卫二：冰壳裂纹（linea，锈红色交叉细线）
  - 土卫六：橙色雾霾 + 亮赤道带 + 甲烷湖暗斑
  - 冥王星：斑驳地形 + 心形亮冰原（Tombaugh Regio）
  - 气态巨行星（木星 / 土星）：横向条带 + 大红斑 / 北极六边形 + 白色椭圆风暴
  - 冰巨星（天王星 / 海王星）：极淡冷色条带 + 大暗斑 / 高速白云
  - 纹理生成宽度取 `4R`、特征在 `x` 与 `x+2R` 重复，横向滚动**无缝循环**＝自转
  - 统一加大气边缘光、终止线阴影
- **土星环**：按 `pl.ring` 标志位绘制，目前仅真土星有；土卫六不再有错挂的环
- **小行星带不画球**：走专用 `drawBeltField`——倾斜椭圆尘带（角动量守恒感的视觉）+ 46 块三层深度的碎石（公转 / 自转 / 竖直抖动都不同步，避免像一条完美椭圆）。`drawPlanet` 见到 `kind === 'belt'` 直接转调它。
- **太阳**：日冕光晕 + 表面黑子 + 镜头光斑十字
- **火箭**：金属圆柱渐变（暗-亮-暗反光）+ 发光舷窗 + 接缝 + 尾焰粒子；按零件逐件绘制以支持装配动画
- **粒子系统**：`V.PS` 统一的 emit / burst / update / draw，用于尾焰、爆炸、拾取
- **UI**：玻璃拟态（backdrop-filter）+ 内发光 + 深空配色 + 等宽数字 + 面板淡入 + 按钮涟漪
- **机库 / 基地场景**：桁架、聚光灯、透视地面网格、按设施类型分别绘制的 4 种建筑

**配色变量**（见 index.html `:root`）
- 背景 `#03040a`，玻璃 `rgba(18,26,54,.55)`
- 强调：金 `#ffd66b`、青 `#7fd0ff`、紫 `#b98cff`、暖橙 `#ff9b5c`

## 5. 数据与数值设定

### 5.1 资源与人力
- 基础资源：金属 / 燃料 / 科研 / **口粮**（全局共享池，由基地回合产出）
- **稀有资源**：钛晶 / 氦三 / 冰核 —— **基地产不出，只能靠成功飞抵对应星球带回**
- 人力：总 `5 + 居住舱 × 3`，分采矿 / 科研 / 精炼 / **农业**（v0.5 起点 5、上限更宽；见 §5.14）
- 初始资源：金属 34 / 燃料 8 / 科研 0 / 口粮 12 / 稀有资源各 0

#### 稀有资源（v0.5 核心机制）
| id | 名称 | 产地 | 首访带回 | 之后每次 |
|----|------|------|---------|---------|
| ti | 钛晶 | 月球 · 水星 · 小行星带 | 月球 20 / 水星 34 / 带 40 | 月球 10 / 水星 18 / 带 20 |
| he | 氦三 | 金星 · 火星 · 木星 · 土星 · 天王星 | 金星 32 / 火星 20 / 木星 26 / 土星 30 / 天王星 38 | 金星 16 / 火星 10 / 木星 14 / 土星 16 / 天王星 20 |
| ice | 冰核 | 木卫二 · 土卫六 · 海王星 · 冥王星 | 木卫二 18 / 土卫六 32 / 海王星 34 / 冥王星 44 | 木卫二 10 / 土卫六 16 / 海王星 18 / 冥王星 24 |

规则：
1. 只有**成功抵达**才结算带回量，飞行失败颗粒无收（只回收残骸金属）
2. 首次抵达某星球按 `first` 结算并标记「首次勘探」，此后每次按 `per` 结算「例行采样」
3. 基地不产出稀有资源，也不参与回合结算 —— 顶栏单列一行，与基础资源区分
4. 中后期科技节点强制消耗稀有资源，因此「蹲在地球刷基地」推不动科技树
5. 首次抵达某星球同时给一次性科研奖励 `18 + dist × 0.28`（独立于稀有资源），给「出去飞」一条换科研的路

#### 不变量（稀有资源产地冗余）
本项目曾两次踩坑：玩家把主基地搬到某稀有资源产地后，该产地不再是合法飞行目标，若此时其余产地都还没解锁，这种资源就彻底采不到。**地球基地永远存在**，所以这不构成硬死锁，但会让自动玩家连续二十几回合无事可做。

为了避免再次发生，每次新增 / 修改稀有资源产地时，必须保证：
1. 至少还有别的产地（`最终产地数 ≥ 2`）
2. 站在「孤立产地」期间的累计需求 ≤ 一趟首访所得（确保有缓冲）

实测这条断言加在 `tests/simulate.js [1b]`，自动玩家端到端空转测试加在 `tests/playthrough.js`，两道关都守住。

#### 为什么需要它（修复的设计缺陷）
v0.4 的科技树只吃科研点，而科研点靠堆研究所就能刷满，于是存在一条不出门的通关路径：
`堆研究所 → 刷科研 → 点满科技 → 造火箭`。200 回合推演下，玩家能囤到近 2 万科研点，
全程 0 次发射。加入稀有资源门禁后，同样的推演**停在 4/13 项科技**，第一个卡点是
「中推力引擎」（需钛晶 4），必须飞月球才过得去。

### 5.2 产出公式（每回合，当前基地）
```
岗位位   mining   = 1 + 采矿场数
         research = 1 + 研究所数
         refine   = 已解锁「化学燃料」? 1 + 精炼厂数 : 0

金属   = pop.mining   × 岗位位.mining   × 2   × 星球.mod.metal
科研   = pop.research × 岗位位.research × 1.5 × 星球.mod.research
燃料   = pop.refine   × 岗位位.refine   × 1.8 × 星球.mod.fuel
口粮   = pop.farming  × 岗位位.farming  × 2   × 星球.mod.food
```
稀有资源不在此公式内 —— 它只从远征结算进入。

#### 口粮结算顺序（每回合）
```
需求     = 在岗人数 × 0.5
供给     = 库存口粮 + 本回合口粮产出
短缺判定 = 供给 < 需求
库存     = max(0, 供给 − 需求)
非口粮产出 ×= 短缺 ? 0.5 : 1      ← 口粮产出本身不打折，否则会死亡螺旋
```

#### 口粮能养活多少人（各星球自给所需的农业人力占比）
```
农民占比 = 0.5 / (岗位位.farming × 2 × 星球.mod.food)
```
| 水培舱 | 岗位位 | 地球 | 火星 | 月球/金星 | 水星 | 木卫二/土卫六 |
|-------|-------|------|------|----------|------|--------------|
| 1 | 2 | 12.5% | 15.6% | 25% | 31.3% | 10.4% |
| 2 | 3 | 8.3% | 10.4% | 16.7% | 20.8% | 6.9% |
| 3 | 4 | 6.3% | 7.8% | 12.5% | 15.6% | 5.2% |

农民数不能超过农业岗位位，所以人口涨到一定规模**必然**要新建水培舱。
同样 20 人：地球 2 座水培舱 / 2 个农民（10% 人力），水星 3 座 / 4 个农民（20% 人力）。

精炼系数 1.8 与采矿 2 / 科研 1.5 对等。发射按整箱燃料容量扣费（重型火箭约 390），
精炼若按 1 计算，一次长途远征要干等三十多回合。

```
地球 → 月球 → 钛晶 → t4/t5/t6 → 金星·火星 → 氦三 → t7 → 小行星带
     → t8/t9/t10 → 木星·土星 → 氦三 → t13 → 天王星·海王星
     → 木卫二·土卫六 → 冰核 → t11/t12/t14 → 冥王星
```

#### 三次稀有资源死锁与修复（不可再犯）
本项目踩过三次同一类陷阱：玩家把主基地搬到某稀有资源产地后，该产地不再是合法飞行目标（`renderLaunch` 里的 `if (pl.id === s.base) return;`），而该稀有资源的其他产地此刻都还没解锁。

- **第一次（v0.5 早期）**：氦三只有火星(t6) + 金星(t7)，而 t7 本身要 8 氦三。**金星提前到 t6**。
- **第二次（v0.5 中期）**：钛晶只有月球(t1) + 小行星带(t7) + 水星(t7)，t7 要氦三。**水星提前到 t6**，同时把 t6 钛晶需求从 10 降到 6，使得「在 t6 解锁前」这段窗口的累计需求（t4+t5+t6 = 14）≤ 一趟月球首访（20）。
- **第三次防护**：`tests/simulate.js [1b]` 把上述不变量写成断言，加新天体 / 改稀有资源时如果再踩同样的模式，CI 立刻失败。

#### t12 离子推进为什么挂在 t11 之后而不是 t13
v0.5 早期 t13 挂在 t12 之后，仿真发现土卫六 → 天王星之间连续 20+ 回合无事可做（t12 推力 +18% 不开任何新航线）。把 t13 提前挂在 t11 之后、t12 保留为可选支线，让「冲冥王星」与「点满科技」成为两种玩法，而不是被一条链锁死。

### 5.5 火箭计算
```
干质量   = 舱体 + Σ燃料罐 + Σ引擎 + Σ载荷      （燃料不计入干质量，是消耗品）
推力     = Σ engine.thrust × (已解锁 t12 ? 1.18 : 1)
推重比   = 推力 / 干质量
平均燃效 = Σ engine.eff / 引擎数                （多引擎并联取平均）
过载     = max(0, ceil(推重比 / 舱体.maxTwr) - 1)
航程     = 48 × (燃料 / 干质量)^0.8 × 平均燃效 × 载荷加成 × 过载惩罚
             载荷加成：科学仪 ×1.15、导航阵列 ×1.30、t11 低温超导 ×1.25
             过载惩罚：(1 - 0.35)^过载级数
飞行时长 = 12 + 航段距离 × 0.085               （秒）
全程消耗 = 燃料 × (航段距离 / 航程)            ← 飞满航程正好烧光，面板即实际
起飞消耗 = 干质量 × 1.5 × (已解锁 t11 ? 0.88 : 1)
上升速度 = 42 + 推重比 × 11                    (px/s)
护盾     = 舱体.shield + (装甲板 ? 1 : 0) - 过载
造价     = Σ 各零件造价                        （保存设计时一次付清，之后每次只烧燃料）
```

可起飞判定：有引擎、有燃料罐、推重比 ≥ 1.2、燃料 ≥ 起飞消耗、燃料不超舱体容量；
无护盾且过载时判定结构解体。

### 5.5b 航线机动门槛
每条航线按危险度要求最低推重比 —— 推重比不只是「能不能起飞」，更是「躲不躲得开」：

```
最低推重比 = 1.2 + (危险度 - 1) × 0.9     →  危险度 1：1.2 ／ 2：2.1 ／ 3：3.0
```

这是大推力引擎存在的理由。省油的小引擎能把航程做到 470+，
但挂上装甲板和货舱后推重比只剩 2.26，去不了木卫二和土卫六。

### 5.13 设计空间复检（v0.5）
改造前先跑了诊断，问题是：902 种组合里 93% 都能飞，
但**面板航程与飞行消耗是两套模型**（最大偏差 21 倍）、**零件严格单调递增无取舍**、
**仪器槽只有一个选项**。每个距离的最优解基本是同一个。

改造后同一套脚本复检：

| 指标 | 改造前 | 改造后 |
|------|-------|-------|
| 可拼组合数 | 902 | **17007**（18.9 倍） |
| 可飞比例 | 93% | 87%（约束真的在起作用） |
| 面板航程与实际消耗的偏差 | 最大 21 倍 / 3637 例 | **0 例** |
| 载荷选项 | 1 个（科学仪） | 6 个互斥 |
| 「省钱/飞最远/最抗撞」选出同一种火箭的航线 | 高度收敛 | **0 / 7 条** |

引擎不再有「无脑最优」。重型舱 + 3 大罐，只换引擎：

| 引擎 | 推重比 | 航程 | 造价 | 能飞土卫六（危险 3） |
|------|-------|------|------|------------|
| 小×3 | 2.72 | **473** | 159 | ✗ 推重比不足 |
| 小×2 + 中 | 3.80 | 424 | 173 | ✓ |
| 大×2 + 中 | 9.30 | 261 | 267 | ✓ |
| 大×3 | 10.82 | 228 | **300** | ✓ |

航程最高的去不了，去得了的最贵 —— 中间那一档才是玩家要自己找的答案。

### 5.14 人口：是整条经济真正的总闸门

v0.5 早期人口上限 = 4 + hab × 2 = 6 人。`tests/balance-sweep.js` 在 24 组参数组合里跑下来发现：人口被居住舱锁死后，科研产出恒定在 6~13 点/回合，而科技树总成本 1620 点 —— 结果是 **84% 的回合玩家无事可做**，只能点下一回合等科研。这不是调参能解决的，是结构性瓶颈。

`SV.POP_BASE = 5, SV.HAB_POP = 3`（扫描从 5 / +3 起最好）后：
- 新基地人口上限 5 + 3 = **8 人**（原 6）
- 通关 117 → 69 回合
- 最长空转 26 → **10 回合**

口粮边界分析（`tests/analyze-pop.js`）仍成立 —— 真正卡住规模的是居住舱的指数造价：

| 目标人口 | 居住舱金属 | 水培舱金属 | 合计 | 农民占比（地球） |
|---------|-----------|-----------|------|---------|
| 12 | 0 | 0 | 0 | 9% |
| 20 | 1881 | 43 | 1924 | 10% |
| 28 | 11130 | 43 | 11173 | 10.7% |

BUILD_STEP（1.55）和科研系数（1.5）保持不变 —— 改这两条会破坏「抑制无脑堆设施」和
「采矿 2 / 科研 1.5 / 精炼 1.8 的相对关系」这两条既有设计意图，且对空转的改善远不如
改人口闸门。

#### 「出去飞换科研」机制（首访科研奖励）
即便人口放宽、后期空转压到 10 回合左右，科技门控期间（两个新航线之间的空档）
仍有 10~20 回合的等待。给首次抵达星球加一笔一次性科研 `18 + dist × 0.28`，让
「等科研」的玩家永远有「去新地方换科研」这条路。

也正是这条机制让自动玩家不再需要永远「点下一回合」：每飞一颗新星球就有事可做，
相当于把「科研等待」分摊到了「探索」这条主动行为上。

### 5.8 飞行小游戏
```
障碍组数   = clamp(round(航段距离 / 13) + 星球危险, 5, 20)
组内类型   = 15% 引力井 / 25% 碎片带（留 96~150px 缺口）/ 60% 岩石 1~2 块
拾取       = 每 4 组一个燃料罐 / 每 6 组一个加速环 / 装科学仪时每 5 组一个数据晶体
目标时长   = 12 + 航段距离 × 0.085   (秒)
实际耗率   = 基础耗率 × (总里程 / 上升速度) / 目标时长   ← 与时长对齐，远航不会必然耗尽
加速环     = 1.6s 内速度 ×1.75
燃料罐     = 回满油量的 14%
护盾       = 舱体提供，撞击 -1 并获 1.3s 无敌；归零即解体
成功/失败  = 抵达目标星球 / 护盾耗尽或燃料耗尽
```

关卡用**可复现的种子随机**（LCG，`U.seed`）生成，同一局内分布稳定。

## 6. 技术约束（小红书小工具合规）

详见 `.skill/references/`，要点：
- `index.html` 在 zip 根目录，脚本**外置**（禁止内联 script / 行内事件）

- Canvas 2D / Pointer Events / localStorage / alert·confirm 可用
- 安全区：`var(--safe-area-inset-*, env(safe-area-inset-*, 0px))` + `viewport-fit=cover`
- 触摸/鼠标统一用 Pointer Events
- 体积 < 2MB（当前 **49 KB**）
