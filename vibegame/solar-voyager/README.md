# 星航者 · 太阳系漫游（solar-voyager）

> 小红书 VibeCoding 大赛参赛作品 · `#vibegame` 互动游戏赛道

一款用 AI vibe coding 打造的太阳系探索策略小游戏。从地球的一座小型基地起步，运营资源、攀科技树、设计并装配火箭，一趟趟飞向月球、火星、木卫二，直到把人类的坐标推到土卫六。打开即玩，手机也能飞。

## 玩法

三段循环：

1. **基地运营** —— 分配人力到采矿 / 科研 / 精炼 / 农业，建造设施，解锁科技树，每回合产出资源并可能触发随机事件
2. **火箭设计** —— 选舱体（决定挂载位与护盾）、叠加燃料罐、并联引擎、加装科学仪，实时算出质量 / 推力 / 推重比 / 航程
3. **发射探索** —— 选目标星球出航，进入竖屏操控小游戏：拖动摇控方向，躲岩石与引力井，穿碎片带的缺口，捡燃料罐与加速环，靠护盾硬抗撞击

抵达新星球会解锁一张**星球知识卡**，并可在其上建立新基地获得资源加成、缩短后续航段。全程有 11 个任务引导、11 个成就可选挑战，抵达土卫六触发结局。

**稀有资源**是推进科技树的硬门槛：钛晶（月球 / 水星 / 小行星带）、氦三（火星 / 金星）、冰核（木卫二 / 土卫六）基地里产不出，只有成功飞抵对应星球才能带回。想点满科技树，就必须一趟趟飞出去。

**口粮**是人口的账单：每回合按在岗人数扣除，收成靠农业岗与水培舱。喂不饱就全基地减产。各星球的适宜度差很多——地球 ×1，火星 ×0.8，月球与金星 ×0.5，水星只有 ×0.4。把主基地往前线搬之前，先算算那地方养不养得起这么多人。

进度自动存本地，关掉再打开可「继续远征」。

## 技术路线
- `index.html` + `src/` 下 6 个外置经典脚本，无构建步骤，作为小红书「小工具」上传挂载
- 渲染：Canvas 2D（星云、星球、火箭、粒子全部程序化绘制，无外部图片素材）
- 音频：Web Audio 实时合成，无音频文件。音效 11 种；BGM 由和声进行 + 五条音色层实时生成，随场景无缝切换
- 红线：离线运行不联网、手机触屏可玩、无控制台报错、不依赖任何外链

## 目录约定
```
index.html          # 入口（内联样式 + HUD 结构，脚本外置）
src/data.js         # 静态配置、火箭解算、存档
src/vfx.js          # Canvas 绘制与粒子系统
src/ui.js           # DOM 渲染与反馈动效
src/flight.js       # 飞行小游戏 + 音效（AudioContext 由 BGM 共用）
src/bgm.js          # 程序化 BGM：调度器、和声进行、音色层
src/game.js         # 主循环、回合经济、任务成就、引导
tools/              # 本地开发工具（不进提交包）
  make-icon.js      # 纯 Node 应用图标生成器（自写 SDF + PNG 编码）
dist/               # 提交用的 zip 包
docs/               # 素材与截图
  icon/             # 图标素材（1024 / 多尺寸 / maskable / 矢量 favicon / 预览）
DESIGN.md           # 设计文档（数值与结构详情）
tests/              # 无头校验脚本，不进提交包
```

## 校验

无浏览器 / 无构建步骤，直接用 node 跑：

```bash
node tests/simulate.js    # 数值与依赖图：门禁不成环、远征趟数、反例推演
node tests/smoke-dom.js   # jsdom 载入真实页面：DOM 渲染、点击门禁、结算链路
node tests/bgm-audio.js   # BGM 合成：用 AudioContext 桩真跑每个场景，查音高/参数/定时器
```

## 打包
```bash
node tools/build-zip.js   # 自动收 index.html + src/ 下全部脚本
# 需要 index.html 在 zip 根目录，src/ 随行
# 当前包：dist/solar-voyager.zip（约 82 KB，上限 2 MB）
```
