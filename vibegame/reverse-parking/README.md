# 倒车入库模拟 · reverse-parking

> **分类**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

第一人称视角的倒车入库模拟。玩家坐在驾驶座，靠三面后视镜与后窗判断车身姿态，
用滑动控制方向盘与油门，把车倒进库位并停正——核心体验是「真实驾考的紧张感 +
可重复练习的关卡递进」。

## 打开方式

双击 `index.html` 即可运行（推荐 Chrome / Edge）。资源在 `assets/`，需与
`index.html` 保持同级目录；首次加载 three.js 约 600 KB，之后离线可用。

## 玩法要点

- **控制**：左指滑动控制方向盘角度，右指滑动控制油门 / 刹车，按钮切换 R / N / D 挡。
- **视角**：挂 R 挡自动切后窗，三面后视镜（左 / 右 / 车内）高亮放大；俯视小地图
  默认关闭，可在设置中开启作为新手辅助。
- **关卡**：主线 7 关 + 挑战 1 关，线性解锁，另有自由练习模式；每关按压线、停正度、
  居中度、修正次数评 1–3 星。
- **音效**：倒车雷达与提示音全部由 WebAudio 现场合成，零音频文件。

完整玩法、物理模型、评分公式与关卡数据见 [`DESIGN.md`](DESIGN.md)（设计唯一真源）。

## 目录结构

```
reverse-parking/
├── index.html      入口（HUD / 菜单 / 结算弹窗结构）
├── main.js         全部逻辑：物理 / 视图 / 输入 / 判定 / 音效 / UI
├── DESIGN.md       设计真源：物理模型、关卡、评分、风险点
├── assets/         three.js 等运行期资源
└── _shots/         开发期截图（不入库）
```

## 技术栈

零构建、零外部依赖：`index.html` + `main.js` + 本地 `three.min.js`。
兼容基线 Android 8.1 出场 Chrome / WebView 61（ES2017）。

## 验证

当前项目**无自动验证**。玩法核心是实时物理与手感，需人工试玩判定（车辆运动学、
压线检测与评分逻辑的正确性靠实际倒库体验确认），故未配置 `tests/`；改动物理参数
或关卡数据后请手工回归。
