# 倒车入库模拟 · 设计文档

> 状态：设计完成，待落地。本文为项目设计唯一真源，落地实现须遵循。

## 概述

一款第一人称视角的倒车入库模拟小游戏。玩家坐在驾驶座，通过三面后视镜与后窗视角判断车身姿态，用滑动控制方向盘与油门，将车倒入库位并停正。核心体验是「真实驾考的紧张感 + 可重复练习的关卡递进」。

## 1. 核心循环

```
起步位 → 挂倒挡 → 控制方向/速度倒车 → 观察车身姿态修正 → 入库停正 → 评分
```

## 2. 视角与呈现

- **主相机**：驾驶座位置，看向前挡风玻璃（车头方向）
- **三面后视镜**：左 / 右 / 车内，各一个低分辨率 RenderTarget 小窗（256×128），黑色塑料框边模拟真实镜面
- **后窗视角**：挂 R 挡自动切到后挡风玻璃方向（看库线车位标杆），或手动"回头看"按钮切换；挂 D 或再按按钮切回前视
- **挂 R 挡时三面后视镜高亮/放大**（倒车时的主信息源）
- **俯视辅助小地图**：挡风玻璃下方半透明小窗，显示车身矩形+朝向、库位、库线、障碍、倒车预测轨迹虚线。**可开关，默认关**（沉浸感优先，新手可开）

## 3. 控制方式

滑动控制（手机友好，桌面也可用）：

- **左指滑** → 方向盘角度：`steerInput = clamp(touchX / halfW, -1, 1)`，`δ = steerInput · δ_max`
- **右指滑** → 纵向：上滑油门 `throttle = clamp(touchY / halfH, 0, 1)`，下滑刹车 `brake = clamp(-touchY / halfH, 0, 1)`
- **挡位 R / N / D** 切换按钮

回正逻辑（做成开关）：
- 自动回正开（默认）：无方向输入时 δ 以 3 rad/s 趋近 0
- 自动回正关：δ 保持，玩家手动回正（更真实更难）

## 4. 车辆物理模型

### 4.1 状态量（后轴中心为参考点）

- `(x, y)` 后轴中心位置
- `θ` 车身朝向（弧度）
- `v` 速度（正前进 / 负倒车）
- `δ` 前轮转角（弧度，正为右转）

### 4.2 自行车模型运动学方程

```
dx/dt = v·cos(θ)
dy/dt = v·sin(θ)
dθ/dt = (v / L)·tan(δ)
```

### 4.3 参数标定

| 参数 | 值 | 说明 |
|---|---|---|
| 轴距 L | 2.6m | |
| 车长 / 车宽 | 4.5m / 1.8m | |
| 前轮最大转角 δ_max | ±35° (±0.611 rad) | |
| 方向盘最大角 | ±540° (1.5 圈) | 传动比 ≈ 15.4 |
| 最大速度 v_max | 5 m/s (18 km/h) | 倒库不需要快 |
| 油门加速度 | 2 m/s² | |
| 刹车减速度 | 5 m/s² | |
| 怠速阻力 | v·0.5 | 松油门发动机制动 |

最小转弯半径：`R_min = L / tan(δ_max) = 2.6 / tan(35°) ≈ 3.71m`（后轴中心）；前轴中心 ≈ 4.52m。前外角扫掠半径更大，是倒库压线主因，判定重点查四角。

### 4.4 挡位与速度

```
挡位 D → targetV = throttle · v_max
挡位 R → targetV = -throttle · v_max
挡位 N → targetV = 0（自由滑行+阻力）
```

### 4.5 每帧积分（欧拉，dt=1/60s 足用，倒库低速无需 RK4）

```
v += (targetV - v) · accelRate · dt
x += v · cos(θ) · dt
y += v · sin(θ) · dt
θ += (v / L) · tan(δ) · dt
v = clamp(v, -v_max, v_max)
```

### 4.6 四角位置（压线检测用）

```
前轴中心 = (x + L·cosθ, y + L·sinθ)
前左 = 前轴中心 + (-W/2·sinθ, +W/2·cosθ)
前右 = 前轴中心 + (+W/2·sinθ, -W/2·cosθ)
后左 = (x - W/2·sinθ, y + W/2·cosθ)
后右 = (x + W/2·sinθ, y - W/2·cosθ)
```

### 4.7 阿克曼升级（可选）

```
δ_L = atan(L·tanδ / (L - (W/2)·tanδ))
δ_R = atan(L·tanδ / (L + (W/2)·tanδ))
```

左右前轮转角不同，前轮轨迹更真实。倒库场景自行车模型够用，阿克曼主要影响前轮扫掠细节，需要时再上。

### 4.8 倒库几何校验

起步位距库口 7–9m > R_min 3.71m，几何上可倒入，参数自洽。

## 5. 关卡设计

### 5.1 关卡序列（主线 7 关 + 挑战 1 关，线性解锁 + 自由练习模式）

| 关 | 名称 | 库位 | 起步位 | 限时 | 教学点 / 难点 |
|---|---|---|---|---|---|
| 1 | 直线倒车 | 3.0m×5m 正后方 | 正对库口 | 无 | 学挂 R、控速、看后视镜、停车 |
| 2 | 右倒库 | 2.5m×5m | 库左前控制线 | 60s | 右镜见库角打方向、回正时机 |
| 3 | 左倒库 | 2.5m×5m | 库右前控制线 | 60s | 左镜判断，镜像第 2 关 |
| 4 | 侧方停车 | 6m×2.2m 路右侧 | 前车旁平行 | 90s | 前后车距紧，多次修正 |
| 5 | 斜角入库 | 2.5m×5m，斜 45° | 道路上 | 60s | 车身朝向与库有夹角，判断更难 |
| 6 | 限时挑战 | 同第 2 关 | 同第 2 关 | 30s | 考熟练度 |
| 7 | 窄库精停 | 2.1m×5m | 库左前 | 60s | 仅留 0.15m 余量，考精度 |
| 挑战 | 移库 | A→B 相邻库 | A 库内 | 120s | 二进二倒，经典驾考移库，不挡主线 |

### 5.2 难度递进维度（同时叠加）

1. 库宽递减：3.0 → 2.5 → 2.1m
2. 起步偏移递增：正对 → 偏左 → 偏右远
3. 障碍递增：无 → 前后车 → 限时
4. 操作复杂度递增：直倒 → 单次打方向 → 多次修正 → 二进二倒
5. 视野挑战递增：教学关开小地图 → 中段默认关 → 后段可加夜雨（可选扩展）

### 5.3 辅助开关（玩家可调，不影响解锁）

- 俯视小地图（默认关，新手开）
- 方向盘自动回正（默认开）
- 倒车预测轨迹线（后视镜里画预计轨迹，类似 360 影像，默认开）
- 教学文字提示（前 3 关默认开，之后默认关）

### 5.4 星级评定（每关 1–3 星）

- ⭐ 完成入库（满足完成条件，total ≥ 50）
- ⭐⭐ + 停正 < 5° + 居中 < 20cm
- ⭐⭐⭐ + 停正 < 2° + 居中 < 10cm + 用时 < 限时 70% + 无压线

### 5.5 解锁规则

前一关获 1 星解锁下一关；练习模式全开放；挑战模式通关主线 7 关后解锁。

### 5.6 关卡数据结构（每关一个 JSON）

```json
{
  "id": 2,
  "name": "右倒库",
  "start": { "x": 0, "y": 9, "theta": 0 },
  "bay":   { "x": 1.5, "y": 0, "w": 2.5, "h": 5, "theta": 0 },
  "obstacles": [],
  "timeLimit": 60,
  "targetScore": 90
}
```

## 6. 判定与评分

### 6.1 压线检测

车身四角 + 四边与库线做线段相交判定：

```
segIntersect(p1p2, p3p4):
  d1 = cross(p4-p3, p1-p3); d2 = cross(p4-p3, p2-p3)
  d3 = cross(p2-p1, p3-p1); d4 = cross(p2-p1, p4-p1)
  return (d1·d2 < 0) && (d3·d4 < 0)
```

车身四边逐一与每条库线测试，任一相交 → 压线。

**压线分级**（做成开关，默认如下）：
- 库口线压线：常见，扣分不否决（每次 -5 分）
- 库底 / 边线 / 障碍：一票否决，立即失败

### 6.2 停正度

```
停正角 = |normalize(θ - θ_bay)|    // 归一到 [-π,π] 取绝对值
```

< 2° 满分 / 2–5° 良好 / 5–10° 及格 / > 10° 不及格

### 6.3 居中度

```
车身中心 = 后轴中心 + (L/2)·(cosθ, sinθ)
横向偏移 = |车身中心到库位中心在库宽方向投影|
```

< 10cm 满分 / 10–20cm 良好 / 20–30cm 及格 / > 30cm 不及格

### 6.4 完成条件（全满足才算入库）

- |v| < 0.05 m/s
- 车身四角全在库位矩形内
- 未压库底 / 边线、未碰障碍

### 6.5 修正次数

方向反转且 |Δδ| > 5° 计一次（贴近"揉库"手感）；挡位 R↔D 切换不计（移库需要）。

### 6.6 评分公式（各项归一化 0–100）

```
score_stop   = 停正 <2°→100, 2–10°线性→0
score_center = 居中 <10cm→100, 10–30cm线性→0
score_time   = 用时 <70%限时→100, 70–100%线性→0
score_modify = 修正 0次→100, 1–5次线性→60, >5次→0

total = 0.35·stop + 0.25·center + 0.20·time + 0.20·modify
```

停正权重最大（倒库核心）。库口压线每次 -5 分；库底 / 边线 / 障碍一票否决 total=0。

### 6.7 失败条件

- 压库底 / 边线 / 障碍 → 立即失败，提示"压线/碰撞，重试"
- 超时 → 失败，提示"超时"
- 车出场景边界 → 失败

### 6.8 实时反馈（游戏中持续）

- 压线闪红 + 震动
- 雷达距离（四点实时）
- 小地图倒车预测轨迹
- **不实时显示分数**（避免分心，结算时给）

## 7. UI / 音效 / 反馈层

### 7.1 车内 HUD

- 挡位 R/N/D（大字居中下部）
- 速度表（km/h）
- 方向盘角度条（左红右绿，中心 0）
- 倒车雷达四点距离（前/后/左/右最近距离，数字 + 颜色渐变）
- 关卡名 + 倒计时（右上）
- 暂停按钮（右上）

### 7.2 后视镜布局

- 左后视镜：左上角；右后视镜：右上角；车内后视镜：顶部中央
- 三路 RenderTarget 256×128，黑色塑料框边
- 挂 R 挡时三镜高亮 / 放大

### 7.3 倒车雷达（WebAudio 方波合成）

| 距离 | 声 |
|---|---|
| > 1m | 静音 |
| 0.5–1m | 慢滴 1 Hz |
| 0.3–0.5m | 中滴 3 Hz |
| 0.1–0.3m | 快滴 8 Hz |
| < 0.1m | 长鸣（将碰撞）|

### 7.4 音效（WebAudio 现场合成，零音频文件）

- 发动机：低频锯齿波，频率随 |v| 升（怠速 60Hz → 5m/s 120Hz）
- 打方向：短促滤波白噪
- 挂挡：方波咔嗒包络
- 压线：下降两音 + 屏幕闪红 + 震动
- 入库成功：上升琶音 C-E-G
- 评分弹窗：柔和提示音

### 7.5 评分弹窗

- 半透明遮罩 + 星级逐颗点亮动画
- 分项：压线次数 / 停正度(°) / 居中(cm) / 用时 / 修正次数 → 总分
- 按钮：重试 / 下一关 / 回菜单
- 新纪录高亮

### 7.6 主菜单 + 关卡选择

- 菜单：开始 / 练习 / 挑战 / 设置（辅助开关 + 音量）
- 关卡卡片网格：关名、已获星级、锁定状态
- 背景：3D 车辆缓慢旋转或俯视库场景动画

### 7.7 视觉风格

写实风：真实车模 + 沥青地面 + 白库线 + 黄标杆。车模用简单几何 + 贴图即可，沉浸感优先。

### 7.8 移动端适配

- 滑动控制区：左半屏方向 / 右半屏油门
- 后视镜小窗竖屏下可折叠
- 竖横屏自适应

## 8. 技术栈与风险点

### 8.1 技术栈

- Three.js 单文件 HTML（符合仓库零依赖单文件调性，可挂小红书小工具）
- 后视镜用 RenderTarget，低分辨率三路性能 OK
- 音效 WebAudio 现场合成，零音频文件
- 兼容基线：Android 8.1 Chrome/WebView 61（ES2017），新 API 做能力检测

### 8.2 风险点

- 后视镜三路 RenderTarget 每帧渲染，桌面 OK，移动端要实测帧率
- 车内视角看不见库线是核心难点，靠「后视镜 + 雷达 + 可开关小地图」三重保障
- 滑动控制"松开保持方向 vs 自动回正"做成开关，照顾不同习惯
- Three.js 体积大，单文件打包后较大，需评估是否可接受或用 CDN
