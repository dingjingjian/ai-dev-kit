# 国风拼豆坊 · 设定文档

## 一、项目概述
- **是什么**：基于拼豆（Perler Bead）钉板填色玩法，在国风纹样上逐格填豆，拼成图案即过关的网页小游戏。
- **形态**：纯前端零依赖，脚本外置（`index.html` + `main.js`），浏览器直接打开即可运行，离线可用，移动端优先。
- **当前版本**：v2 重构版。保留核心「拼豆」玩法，全面重绘视觉与图案库；图案稿合并为 `patterns.py` 单一真源，开发期新增 `check.py` 体检工具。

## 三、技术栈与硬约束
- 渲染：Canvas 2D（拟真拼豆、钉板、熨烫动画）+ DOM/CSS（UI 外壳）。
- 音效：Web Audio 程序化合成，零音频文件。
- 图案数据：以 ASCII 像素稿形式程序化生成，保证边缘清晰、颜色可控。
- 兼容老 WebView：无 `padStart`、无 flex gap 依赖、`padding-bottom` 撑正方形、Pointer Events + Touch/Mouse 双监听。
- **色卡硬约束**：任意两色的 RGB 欧氏距离 ≥ 60（逐格填豆靠颜色分辨，太近认不出；改色后必须跑 `python _dev/check.py pal` 复验）。
- **画圆硬约束**：像素圆环一律用 `G.ring2`（两圆相减），不用 `ring()`。
- **小红书小工具规范**：脚本外置经典脚本、无内联 `on*=`、无外部资源、无下载/剪贴板/传感器等能力、zip 根为 `index.html`、体积 ≤2MB（`build_zip.py` 打包前强制校验）。
- 存档：`localStorage` 的 `pbg_records` 记录每个已完图纸的最佳成绩 `{用时, 星级, 步数}`（自动兼容旧版 `pbg_completed` 数组）；全量存档键见「七点七」。

### 画圆的约定（`G.ring2`）
小尺寸像素圆极易被削平或变尖，统一用**两圆相减**而非 `ring()`：

```python
g.ring2(cx, cy, r_out, r_in, c_out, c_in=None)   # 先填外圆 c_out，再用内圆覆盖
```

三个理由：
1. **外沿形状由 `r_out` 精确决定**，圆才是圆的。`ring()` 用「中心半径 r + 环宽 w」描述，改半径时容易把外沿一起带偏。
2. 环带不会在某些行整行消失——两个实心圆相减在任何行都至少留下一格。
3. `c_in` 省略时**保留内圆原有像素**（纯相减），适合在已画好的图案上加一圈边线；给出则用该色填满内圆。

半径差建议 **≥ 1.0**。差 < 1 时某些行可能一个环带格子都没有，金边断成虚线。

圆心必须取在**格线交点**（如 13×13 取 6.5）或半格点，使 dx/dy 同时为整数，否则上下左右不对称。

验收用 `python _dev/check.py 铜钱` 看行宽序列与「上下等宽」判定。

## 六、玩法机制
- **棋盘**：根据图案难度，尺寸为 13×13 / 17×17 / 21×21 / 25×25。
- **填豆**：选择色珠 → 点按或拖动连续填豆；橡皮可清除。
- **模式**（两个，底栏「更多」菜单内切换）：
  - 临摹：钉板淡底显示参照图，顶栏缩略图清晰。
  - 挑战：钉板不画参照，顶栏缩略图虚化（只留轮廓不给答案），凭记忆或「提示」推进。
  - 曾用过「自由」模式，但它实际只是「挑战 − 提示」（target 照常加载、完成照样庆祝），名不副实，已移除。
- **完成度**：实时计算正确格数 ÷ 目标非空格数，顶栏右侧圆环进度。
- **计时/步数/失误**：用于三星评价。
- **提示**（计一次失误参考，与中秋版一致）：一次高亮**一整批**格子，按优先级取第一类非空集合：
  1. 图案外的多余豆 → 提示「用橡皮擦掉」；
  2. 当前选中色还可放的位置（一次全指出）；
  3. 当前选中色放错的位置；
  4. 当前色没问题、但其他色放错的位置；
  5. 当前色已全对 → 剩余待拼位置（属于其他颜色）。

  全部为空则提示「已经完美啦」。高亮为脉动光环 + 外扩波 + 内部辉光 + 四角准星，自带 rAF 重绘，3.2 秒后自动收起（`stopHint()`）；完成时/清空时/切图时都会清掉，避免两个 rAF 打架。
- **底栏（6 个）**：图纸 / 画笔 / 橡皮 / 提示 / 清空 / 更多。
  - 「图纸」= 回首页图纸库选图；「更多」= 底部上浮菜单（模式切换 / 我的画廊 / 音效 / 背景音乐 / 玩法说明）。
  - 清空为二次确认：按钮转红并轻微抖动、文案变「再点确认」，3 秒无操作自动取消。
- **顶栏（纯展示，无任何可点按钮）**：左起参照缩略图 → 图纸名与「分类 · 尺寸 · 豆数 · 色数」→ 右侧进度环 + 计时/星级。
  - 用色数并入顶栏元信息，色板区不放任何标题文字，保持纯珠子网格。
  - 顶部零按钮是为了避免与宿主 App（小红书等）自带的返回/关闭控件冲突或误触。
  - 参照缩略图纯展示、无交互：显示状态完全由模式决定（`syncThumb()` 切 `.masked`），不再提供手动开关。
- **独立进度**：每幅图纸各自保存棋盘、已用时、步数、失误（`pbg_progress`，棋盘压缩为字符串）。切走再回来自动恢复，首页卡片显示「已拼 N%」；清空或拼成后自动清掉该图进度。
- **换图统一在首页**：拼豆台不提供图案横条，换图一律走底栏「图纸」回首页选。
- **色珠布局**：`flex-wrap` 换行网格（非横向滚动），每行约 6 颗、最多两行，移动端所有色珠均可直接点选；单颗 38px，右上角带「已放/需放」计数。
- **已移除**：物料清单面板（用色数量已直接显示在每颗色珠的计数徽章上）、底部典故信息条（典故只在首页图纸卡片展示）。
- **启动首页 = 图纸库（两个视图切换）**：
  - `#homeView` 为 fixed 全屏遮罩，打开即见；`#playView` 常驻文档流（保证 stage 尺寸有效）。
  - 首页头部：品牌印章 + 「国风拼豆坊 / 对图填豆 · 熨烫成画」+ 已完成数统计。
  - 顶部按分类筛选：全部 / 入门 / 进阶 / 精工 / 传世。
  - 每张图纸卡展示：缩略图、名称、分类 / 棋盘尺寸 / 豆子总数 / 用色数、典故文案。
  - 已完成的图纸显示星级徽章与上次用时；当前正在拼的图纸有描金描边。
  - 点击卡片进入拼豆台（重新计时并返回首页时刷新成绩）。
  - 行为约定：`selectPattern()` 只加载数据不启动计时；`openPattern()` 才重置计时并切到拼豆台。
- **画廊**：完成的图案收入本地画廊，可回看或重玩。
- **过关**：完成 100% 触发「熨烫融合」动画 → 盖「成」字印章 → 落花/金粉粒子 → 结算弹窗。

## 七、视觉设计升级
- **背景**：宣纸噪点纹理 + 描金角饰 + 缓慢漂浮的金色微尘。
- **钉板**：仿木质外框 + 方孔钉板 + 立柱阴影/高光。
- **拼豆**：短塑料管/空心圆柱质感，正视图为「外圈圆环 + 中心圆孔」：
  - 孔径约占外径 57%，露出钉柱暖灰色，孔壁下侧受光、上侧背光。
  - 哑光塑料：上下轻微线性渐变，外缘压暗表示管壁厚度，无球面隆起。
  - 高光极小且只落在环面上，避免像糖果/药丸。
- **熨烫融合**：完成后珠子从带孔圆环压扁扩散、孔洞闭合、颜色对比降低、表面变平，最终熔成连续色片；同时叠加整片柔和光泽。
- **棋盘内外边距**：画布 = `cell×n + pad×2`，`pad=max(12, cell×0.42)`，钉板面从 `pad-6` 起，因此最外圈拼豆完整落在板面内，不会压到木框；坐标换算统一加 `pad` 偏移（绘制、提示圈、点击命中都算）。
- **UI**：SVG 图标替代 emoji；描金流光标题；进度环；图案卡片带缩略图与星级。
- **动效**：选色珠弹跳、完成时熨烫融合（孔洞收缩/边缘外扩/光晕增强）、印章落下、花瓣飘落。

## 七点五、宿主 App 安全区适配
- CSS 变量：`--safe-top` / `--safe-bottom` / `--safe-l` / `--safe-r`，默认跟随系统 `env(safe-area-inset-*)`。
- 当检测到宿主 App（如小红书小工具，顶部自带返回/关闭按钮）时，`<body>` 加 `.in-app` 类：
  - `--safe-top` 额外 +40px，`--safe-l` = 48px，`--safe-r` = 92px。
  - 受影响区域：顶栏、下拉菜单、首页头部、分类 tabs、图纸网格的左右内边距与顶部留白。
- 触发方式：**仅当 URL 带 `?inapp=1`** 时给 `body` 加 `.in-app`；也可手动加 class。**不做 UA 嗅探**（打包校验强制拒绝 UA 判定，见 `build_zip.py`）。

## 七点六、音效系统
- **实现方式**：Web Audio API 实时合成，**不引入任何外部音频文件**，保持零依赖、离线可用。
- **音频总线**：`master(0.85)` → `sfxBus(0.95)` / `bgmBus(0.55)`。
- **音色（全部程序化合成）**：
  - `pluck` 古筝拨弦：三角波主体 + 二倍泛音，低通随时间收敛模拟弦振衰减。
  - `mallet` 木鱼/梆子：带通噪声瞬态 + 下滑三角波共鸣，用于放豆。
  - `bell` 编钟/铃：基频叠加 2.0 / 2.76 / 5.4 非谐泛音 + 长衰减，用于提示与通关。
  - `sweep` 带通噪声扫频：用于擦除与熨烫。
- **音效清单**：选色（古筝双击）／放豆（木鱼，音高四选一随机，55ms 节流避免拖动糊成一片）／擦除（噪声下扫）／提示（双铃上行）／清空（噪声下扫 + 低音）／熨烫（1.5s 噪声上扫）／通关（G-A-C-D-E 五声编钟琶音 + 低音铺底）／按钮点击（轻拨弦）。
- **背景音乐**：C 宫五声音阶（宫商角徵羽，跨两个八度）随机游走，每 1.0~1.8s 一个拨弦音，随机叠加低八度衬底与高音点缀；音量压得很低（实际约 0.06），只作氛围底噪。
- **开关与持久化**：底栏「更多」菜单内两项——「音效」（总开关）、「背景音乐」（单独开关），状态存入 `localStorage` 的 `pbg_audio` = `{s:1|0, b:1|0}`。
- **移动端解锁**：`AudioContext` 必须在用户手势内创建/恢复。`init()` 里对 `pointerdown / touchstart / keydown` 各绑一次 `once` 监听触发 `SFX.unlock()`，解锁成功后才启动背景音乐。

## 七点七、本地存档键
| 键 | 内容 |
|----|------|
| `pbg_records` | 已拼成图纸最佳成绩 `{id:{t,s,m}}`（自动兼容旧版 `pbg_completed` 数组） |
| `pbg_progress` | 进行中图纸独立进度 `{id:{g,t,m,k}}`（g 为压缩棋盘） |
| `pbg_audio` | 音效/BGM 开关 `{s,b}` |

> 前缀 `pbg_`（Perler Bead Game），与中秋版 `pma_` 完全隔离，同一设备装两版互不覆盖。

## 八、扩展指引
- 新增图案：`patterns.py` 写图案函数 + 追加 `ALL` 条目 → `python _dev/patterns.py` → `python _dev/check.py <名>` 验行宽 → `python _dev/build.py` → `python _dev/build_zip.py`。画圆一律用 `ring2`。
- 改色卡：同步改 `patterns.py` 的 `PAL` 与 `build.py` 的 `PALETTE`（两处必须一致），然后 `python _dev/check.py pal` 确认任意两色 RGB 距离 ≥ 60。
- 评分阈值、熨烫时长、音色参数均在 `build.py` 的 `JS_TEMPLATE` 中调整。
- 改完务必跑 `cd _dev && node smoke_test.js` 确认拼图闭环未被破坏。
