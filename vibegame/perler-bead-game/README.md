# 拼豆游戏 - Perler Bead Game

> **赛道**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

国风拼豆填色网页小游戏：按编号逐格填豆，拼成即过关。纯前端单文件，零依赖。

## 打开方式

双击 `index.html`，或由源码重新构建（见下）。

## 玩法

- 选定图案后按色号逐格填豆
- 拼完即过关，可继续挑战下一张
- 国风纹样图案库

## 工程约定

| 项 | 说明 |
|----|------|
| 唯一真源 | `_dev/build.py`，**不要直接改 `index.html` / `main.js`** |
| 构建产物 | `index.html` + `main.js` |
| 打包 | `_dev/build_zip.py`，校验并打包为小红书小工具 zip |
| 设定 | [`设定文档.md`](设定文档.md) |

## 赛道判定

有明确过关条件与逐关推进的反馈，"再来一张"的驱动力来自玩法而非产出 → `#vibegame`。同为拼豆题材的 `perler-bead-designer` 产出的是图纸（工具闭环），两者不同赛道。
