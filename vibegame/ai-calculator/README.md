# AI 计算器 - AI Calculator

> **分类**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

一台会故意算错的计算器。它给出的结果约 50% 概率是错的，你得自己判断、验算，答对得分。外滩大会全民黑客松 · AI Coding 大赛参赛作品。

## 打开方式

双击 `index.html`。零依赖（HTML + 本地 `assets/`），打开即玩；手机 / 电脑浏览器均可。

## 玩法

- 像普通计算器一样输入算式，点 `=`
- 屏幕显示的结果约 50% 概率是错的——常见陷阱：个位数错位、小数点错位、末位微调、数字对调
- 判断「正确 / 错误」：判断正确 +10 分，连击有加成；判断错误 -5 分，连击中断
- 实时统计：分数、最高分、准确率、轮次、连击
- 帮助面板说明规则与常见错误类型
- 支持键盘：数字 / 运算符直接输入，`C` = 正确、`X` = 错误、回车 = 下一题
