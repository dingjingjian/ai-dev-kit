# AI 计算器 - AI Calculator

> **赛道**：`#vibegame` 互动游戏　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

一台会故意算错的计算器。它给出的结果不一定对，你得自己判断、验算，答对得分。

## 打开方式

双击 `index.html`。零依赖单文件，打开即玩。

## 玩法

- 计算器随机产生计算错误
- 判断它算得对不对，答对得分
- 连对有加成，实时战绩反馈
- 越算越快，练的是心算与验算能力
