# Word 转 Markdown - Word to MD

> **赛道**：`#vibetool` 实用工具　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

浏览器端 `.docx` → Markdown 转换工具，本地解析，文件不上传服务器。

## 打开方式

双击 `word-to-md.html`，在页面中选择或拖入 `.docx` 文件。

## 功能特性

- 浏览器本地解析 `.docx`，文档不出本机
- 输出 Markdown 文本，支持复制到剪贴板
- 支持下载 `.md` 文件
