# 心情日记 · 小红书笔记文案

## 标题候选

- 每天一种颜色，画出一整年的心情
- 不写日记只点颜色，半年后看热力图哭了
- 心情热力图：打工人的情绪 GitHub

## 正文

每天下班点一下今天的心情，六种颜色一键选——

😆 兴奋 → 橙
😊 开心 → 绿
😌 平静 → 蓝
😐 一般 → 黄
😟 难过 → 紫
😡 愤怒 → 红

不写一个字，半年后打开看热力图，哪天开心哪天崩，一目了然。

像 GitHub 的提交热力图，但记录的不是代码，是你的情绪。

**功能：**
- 六种心情一键记录
- GitHub 式热力图回看半年
- 连续好心情天数 + 本月好心情率
- 点任意格子可改历史
- 四套主题跟随系统切换
- 数据全存本机，可导出备份

**不记具体事件**——只回答一个问题：今天心情怎么样。

点开就能用，零依赖离线可用。
