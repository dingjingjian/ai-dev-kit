# 设计风格图鉴 · UI/UX Style Gallery

> **分类**：`#vibetool` 实用工具　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

移动端优先的 UI/UX 设计风格速查图鉴：收录 67 种主流设计风格（编号 1–68，含跳号缺 54），按通用 / 落地页 / 仪表板 / 现代四类分组。每种风格提供纯 CSS 迷你示例卡片，详情页含中文介绍、AI 提示词（一键复制）、配色方案与适用场景。纯前端零依赖，离线可用，已适配小红书小工具容器。

参考：[UI/UX Pro Max](https://tool.anysome.cn/uiux/index.html)（67 种风格全量站），本作按相同编号与分组，为每种手写移动端 CSS 迷你 demo。

## 打开方式

双击 `index.html`，或打包后上传小红书小工具。

## 功能

- **列表页**：四类分组，每张卡片上半部为该风格的纯 CSS 迷你示例，下半部为名称 + 一句话特征。
- **详情页**：风格介绍、AI 提示词（可一键复制到剪贴板）、主色 / 辅助色色块、适用 / 不适用场景。
- **路由**：hash 路由（`#/` 列表、`#/s/<id>` 详情），适配小红书容器无跳转限制。
- **返回原位**：从详情返回列表时回到离开时的滚动位置与分类，不用从头再翻。
- **移动端优先**：竖屏单列、大字号、安全区适配、触摸友好。

## 工程约定

| 项 | 说明 |
|----|------|
| 源码 | `index.html`（内联 CSS）+ `main.js`（数据 + 渲染逻辑，经典脚本） |
| demo 实现 | 每个 demo 根节点须撑满 `.demo-body`（`width/height:100%`）；内部尺寸统一用 `em`，基准字号由 `.demo-body` 控制（卡片 11px / 详情页 16px），同一套 demo 在两处自动等比缩放 |
| 自检 | `_dev/shot_check.py`，截图列表页与 4 张详情页，并断言每个 demo 撑满预览区、hero 高度符合预期 |
| 打包 | `_dev/build_zip.py`，前置校验 + 打包 zip（产物 `uiux-style-gallery.zip`） |
| 体积 | 远小于 2MB 建议值 |
| 改动顺序 | 一律直接改根目录 `index.html` / `main.js`，重跑 `build_zip.py` 刷新 `dist/` 与 zip，不要手改 `dist/` |

## 构建命令

python _dev/build_zip.py    # 前置校验 + 打包 zip

## 小红书小工具适配

- 脚本外置 `main.js`，无内联 `<script>`、无内联事件、无 `eval`。
- 无任何 http(s) 外部资源引用，离线可用。
- 安全区用 `var(--safe-area-inset-*, env(...))` 组合适配刘海屏。
- 不使用 UA 判定宿主，不使用 WebSocket/Worker/geolocation/clipboard 等禁用能力。
- 复制 AI 提示词：容器禁用剪贴板 API（`navigator.clipboard` / `execCommand` 均不可用），改为点按提示词选中文本后引导用户长按手动复制。
