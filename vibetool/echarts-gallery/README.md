# 图表图鉴 · Charts Gallery

> **分类**：`#vibetool` 实用工具　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

移动端优先的图表速查图鉴：收录 30 种常用图表，按基础统计图 / 数据可视化进阶 / 层级与关系 / 多维与组合四类分组。每种图表提供真实渲染的缩略卡片，详情页含大图演示、中文介绍、主题配色、AI 提示词（一键复制）与适用场景。内置 5 套主题（含一套暗色），在「主题配色」块内点选即可整站换色。纯前端离线可用，已适配小红书小工具容器。

参考：[vibetool/uiux-style-gallery](../uiux-style-gallery/)（设计风格图鉴），本作沿用其框架与工程约定，把纯 CSS demo 替换为真实数据图表。

## 打开方式

双击 `index.html`，或打包后上传小红书小工具。

## 功能

- **列表页**：四类分组，每张卡片上半部为该图表的真实渲染缩略图（浅色衬底 + 细网格、留白由 CSS 控制），下半部为名称 + 一句话作用。
- **分类筛选**：顶部分类 tab 用短名（全部 / 基础 / 进阶 / 层级 / 组合）+ 自动换行；窄屏不再横向滚动，5 个分类任何时候都点得到（分组标题仍显示全名）。
- **详情页**：大图演示（300px）、图表介绍、主题配色、AI 提示词（英文、技术无关，只描述内容与风格，可一键选中复制）、适用 / 不适用场景。
- **主题切换**：详情页「主题配色」块内直接点选（不弹窗），5 套主题（晴空蓝 / 深海青 / 墨玉紫 / 暮光橙 / 暗夜石墨）切换后页面色调与全部 30 张图表同步换色；选择写入 `localStorage`（键 `cg_theme`），容器禁用存储时静默回退默认主题。
- **路由**：hash 路由（`#/` 列表、`#/c/<id>` 详情），适配小红书容器无跳转限制。
- **返回原位**：从详情返回列表时回到离开时的滚动位置与分类，不用从头再翻。
- **移动端优先**：竖屏单列、大字号、安全区适配、触摸友好。

## 主题

- **入口**：详情页「主题配色」块内的主题卡片，直接点选立即生效（页面色调 + 全部图表 + 色板一起换），无弹窗、无需刷新；当前主题高亮打勾。
- **5 套主题**：晴空蓝（默认）/ 深海青 / 墨玉紫 / 暮光橙 / 暗夜石墨（`dark:true`，整套切到深色页面 token）。
- **加一套主题**：在 `main.js` 的 `THEMES` 里追加一项即可 —— 5 个色环色（各自带 `deep` / `light` / 中文名 `n`）+ 需要覆盖的 `ui` 字段，其余 token 自动继承 `UI_LIGHT`（或 `UI_DARK`）。**不用改任何图表数据**，换色在渲染时统一映射。
- **持久化**：选择写入 `localStorage['cg_theme']`，下次打开自动恢复。

## 工程约定

| 项 | 说明 |
|----|------|
| 源码 | `index.html`（内联 CSS）+ `main.js`（图表数据 + 渲染逻辑，经典脚本）+ `echarts.min.js`（本地外置，约 1MB） |
| 图表实现 | 每个图表提供 `option(mode)` 函数，`mode="thumb"` 返回缩略配置（卡片预览区 152px），`mode="full"` 返回完整配置（详情页 hero 300px） |
| 配色 | `main.js` 顶部 `C` 是**角色基色**真源（`c0`~`c4` / `deep` / `grid` / `text` / `link` …，不是最终颜色）；柱/极坐标柱用 `barGrad`（竖向渐变）、条形用 `hGrad`（横向渐变）、面积用 `areaGrad`（上实下透） |
| 主题 | `THEMES`（5 套）＝ 色环 `ramp` + 页面 token `ui`；`ramp` 顺序固定为【主色 / 绿 / 黄橙 / 红粉 / 辅色】，`ui` 覆盖 `index.html` 的 CSS 变量。渲染前 `chartOption()` 先 `recolor()` 把基色映射为当前主题色，再写入顶层 `opt.color`（供饼图 / 圆环 / 漏斗 / 旭日 / 矩形树 / 河流 / 桑基 / 关系图等未显式指定颜色的系列取色），深色主题最后由 `themeChrome()` 补坐标轴 / 图例 / 图注文字色 |
| 取色起点 | `chart._rot = 序号 % 5`：同主题下各图从色环不同起点取色，避免 30 个详情页张张同色；仪表盘（低中高）与 K 线（涨跌）的颜色含语义，固定在起点 0（见 `SEMANTIC_CHARTS`） |
| AI 提示词 | 30 条 `prompt` 为**英文、技术无关**：只写「要表达的内容 + 视觉风格 + 何时不适用」，不点名图表库、不写 API 与配置项，技术方案交给 AI 自选（句式参照 [`uiux-style-gallery`](../uiux-style-gallery/) 的 `prompt`）；用 `\n` 分行在 `<pre>` 里排版，复制即可直接喂给 AI |
| 缩略图取舍 | thumb 关闭坐标轴文字与图例，保留结构辨识元素（树 / 桑基 / 关系图 / 矩形树保留 9px 小标签），并放大半径与点径；预览衬底与留白由 `.demo` / `.chart-pad` / `.preview-bg` 控制 |
| 间距基线 | Chrome <84 无 flex gap（基线 Chrome 61），分组标题中英文、色块、场景列等间距一律用子项 `margin`；顶栏 tab 用短名 + `flex-wrap` 换行（不依赖横向滚动），见 `index.html` 顶部「Flex 间距基线」块 |
| 实例管理 | `activeCharts` 数组跟踪当前页所有 echarts 实例，路由切换前 `disposeCharts()` 全部销毁，避免内存泄漏 |
| 渲染时机 | `requestAnimationFrame` 内 init，确保 DOM 已布局获得真实尺寸；`window.resize` 时统一 `resize()` |
| 打包 | `_dev/build_zip.py`，前置校验 + 打包 zip（产物 `echarts-gallery.zip`，含 `index.html` / `main.js` / `echarts.min.js`） |
| 体积 | zip 约 1.05MB（echarts.min.js 占大头），低于 2MB 建议值 |
| 改动顺序 | 一律直接改根目录 `index.html` / `main.js`，重跑 `build_zip.py` 刷新 `dist/` 与 zip，不要手改 `dist/` |

## 小红书小工具适配

- 脚本外置 `echarts.min.js` + `main.js`，无内联 `<script>`、无内联事件、无 `eval`。
- 无任何 http(s) 外部资源引用，echarts 本地加载，离线可用。
- 安全区用 `var(--safe-area-inset-*, env(...))` 组合适配刘海屏。
- 主题偏好存 `localStorage`（键 `cg_theme`），读写均 try/catch 包裹：容器禁用存储时静默回退默认主题，不影响功能。
- 不使用 UA 判定宿主，不使用 WebSocket/Worker/geolocation/clipboard 等禁用能力。
- 复制 AI 提示词：容器禁用剪贴板 API（`navigator.clipboard` / `execCommand` 均不可用），改为点按提示词选中文本后引导用户长按手动复制。
