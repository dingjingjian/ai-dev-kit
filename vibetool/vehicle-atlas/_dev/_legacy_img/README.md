# 改版前的配图归档（具体型号版）

本目录存放的是图鉴**改版前**的素材。当时条目是「具体型号」（丰田卡罗拉、空客 A380、MSC Irina……），
配图按 `car-01` / `plane-03` / `ship-cargo-05` / `cover-car` 这类 id 命名。

改版后条目改为「交通工具类型」（畜力车、家用汽车、集装箱船、空间站……），
id 换成 `ground-01` / `water-07` / `sky-06` / `space-01` / `cover-ground` 等，
这批图已不被 `main.js` 引用，也不参与打包（`_dev/build_zip.py` 只收被引用的配图）。

保留原因：其中若干通用造型仍可作新配图的参考；确认无用后整目录删除即可，不影响任何构建脚本。

- `*.webp`：改版前成品图（条目图 640×360、分类封面 960×540）
- `raw/`：改版前未压缩的原始 PNG
