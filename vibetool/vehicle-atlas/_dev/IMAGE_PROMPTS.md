# 配图施工图 · 全球交通工具图鉴

> 本文件由 `_dev/gen_image_prompts.py` 从 `main.js` **自动生成**，请勿手改；改数据请改 `main.js` 后重跑脚本。

图片生成 agent 按本清单产出配图即可，页面无需任何改动：文件名对上就自动显示，对不上则继续显示占位块。

## 1. 交付规格

| 项 | 要求 |
| --- | --- |
| 存放位置 | `assets/img/`（相对 zip 根目录） |
| 文件命名 | `<base>.webp`，base 见下方表格（如 `car-01.webp` / `cover-car.webp`） |
| 条目图尺寸 | 640 × 360（16:9 横构图） |
| 分类封面尺寸 | 960 × 540（16:9 横构图） |
| 格式 | WebP（页面另有 jpg / png 后缀回退，但 WebP 体积最优） |
| 单张体积 | 条目图 ≤ 45 KB，分类封面 ≤ 90 KB |
| 全部图片合计 | ≤ 1.8 MB（小工具 zip 建议不超过 2 MB，图片是主要体积来源） |
| 构图安全区 | 卡片按约 2.2:1 裁切显示，主体须**水平居中、垂直居中**，上下各留 ≥20% 余量 |
| 禁止 | 画面内出现文字 / 字母 / logo / 水印 / 人物；使用外部素材（版权风险） |

转化命令（若生成工具只出 PNG/JPG）：

```python
from PIL import Image
img = Image.open("raw.png").convert("RGB").resize((640, 360))
img.save("assets/img/car-01.webp", "WEBP", quality=78, method=6)
```

## 2. 统一风格串（每张图都要带上）

```text
Clean editorial vehicle encyclopedia illustration, photorealistic 3D product render, three-quarter front view, soft even studio lighting, plain uncluttered light-gray gradient background, subtle contact shadow under the subject, subject centered and fully visible with about 20% empty margin on all sides, no people, no text, no letters, no logo, no watermark, landscape 16:9
```

**完整提示词 = 统一风格串 + 空格 + 下表「主体」**，逐张拼接即可。
