# 像素画编辑器 - Pixel Art Editor

> **赛道**：`#vibetool` 实用工具　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

浏览器端像素画绘制工具，零依赖单文件 HTML，打开即用，不上传任何数据。

## 打开方式

双击 `index.html`（或拖入浏览器）。无需安装、无需联网。

## 功能特性

- 画布尺寸 16×16 至 256×256
- 多种画笔与填充工具，支持取色
- 图层、撤销 / 重做
- 导入图片作为底稿
- 导出 PNG、导出 SVG，也可直接复制 SVG 代码
