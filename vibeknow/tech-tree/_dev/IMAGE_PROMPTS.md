## 1. 交付规格

## 只配两处，科技树节点不配图

科技树的节点是**紧凑小卡**（名称 + 年代 + 连线），塞图会挤掉连线空间、也看不清，
所以配图只出现在两个位置：

1. **详情页**大图：`assets/img/<科技 id>.webp`；
2. **图鉴视图**的卡片与时代封面：`assets/img/<科技 id>.webp` 与 `assets/img/cover-<时代 key>.webp`。

## 构图（最容易被忽略、也最影响观感）

页面用 `object-fit: cover` 裁切，源图上下两条会被丢掉：

- 条目图进图鉴卡片：显示框约 **2.39:1**，源图**上下各丢 12.7%**
- 时代封面：显示框约 **3.44:1**，源图**上下各丢 24%**

因此：

- 主体必须**水平居中**；
- 主体**高度不超过画面的 55%**，即上下各留 **≥22% 纯背景**；
- 时代封面务必把**一排主体压在画面中带**，上下留足空白，别让立着的火箭、船桅、望远镜顶到边缘；
- 画布外沿再留 3% 安全边，避免压缩时被裁。

## 画面内容

- 每条 `subject` 已经指定了模式，二选一，不要混：**博物馆器物实拍**（影棚光）或**极简 3D 概念图**
  （用于语言、哲学、互联网、人工智能这类没有单一实物的条目）。
- 背景统一为**干净的浅灰影棚背景**，实体下方带柔和接触阴影；不要真实场景、地标、天空、海面或建筑。
- 视角统一为**清晰的三分之四视角或正侧视**，主体完整入画、不被画框切断。
- 画面中**不得出现可读的现代文字、字母、数字、logo 与水印**。例外：泥板、算筹、钱币、针灸铜人、
  铅字盘这类条目，本身画的就是带铭文的器物，允许出现**不可辨识的古文字刻痕**，不允许出现清晰的现代字。
- 不使用任何外部素材（版权风险）。

## 生成后处理

若生成工具只输出 PNG / JPG，先落到 `_dev/raw_img/<base>.png`，再执行：

```bash
python _dev/process_images.py
```

该脚本会按清单里的尺寸缩放、按体积预算自动调质量，输出到 `assets/img/<base>.webp`。

## 2. 统一风格串（每张图都要带上）

```text
Clean editorial encyclopedia image of a single subject, either a photorealistic museum artifact photograph or a clean minimalist 3D conceptual rendering, clear three-quarter or side view, soft even studio lighting, seamless plain light-gray background, subtle soft contact shadow, the subject is fully inside the frame and horizontally centered, occupying only the middle half of the frame height, wide empty background above and below, muted restrained color palette, no readable modern text, no letters, no numerals, no logos, no brand marks, no watermarks, landscape 16:9
```

**完整提示词 = 统一风格串 + 空格 + 下表「主体 / 画面」**，逐张拼接即可。
