# 函数可视化 - Function Visualization

> **赛道**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

初高中数学函数图像绘制工具：输入表达式，立刻看到曲线，还能看对称轴等特征。

## 打开方式

双击 `index.html`（逻辑在 `main.js`，两者需保持同级目录）。

## 功能

- 输入函数表达式，浏览器端绘制图像
- 坐标系与网格
- 对称轴等特征展示
