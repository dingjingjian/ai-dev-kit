# 3D 火箭发射 - Rocket Launch 3D

> **赛道**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

3D 火箭发射模拟：从倒计时到入轨，可看整体演示，也可拆开看箭体结构。

## 打开方式

双击 `index.html`。

## 模式与内容

- **展示模式**：完整发射流程，含实时遥测与倒计时
- **拆解模式**：分级箭体结构展示

## 工程约定

| 脚本 | 用途 |
|------|------|
| `build.mjs` | 构建 |
| `pack.mjs` | 打包为小红书小工具 zip |
| `verify-minitool.mjs` | 产物校验 |

脚本一律使用相对路径，禁止硬编码绝对路径（参考根目录 `TRACKS.md` 维护约定）。
