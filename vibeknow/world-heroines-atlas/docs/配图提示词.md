「世界女英雄图鉴」女英雄卡片配图：**22 张**，一张对应一位女英雄。
本文既是给生图模型的提示词包，也是给落位者的验收标准——**先读第三节「硬约束」和第五节「落位契约」，再动笔出图**。

### 缺图不是障碍

`img` 指向的文件不存在或加载失败时，卡片会**自动回退到程序化占位**：曙光渐变 + 星点 + 一轮暖橙金圆盘 + 一行小字「配图待生成」以及该图位的文件名。
也就是说：**22 张可以分批补，一张不做也能上线**。这一点是硬要求，不要为了"必须凑齐 22 张"而降低单张质量。

## 三、硬约束

1. **横向安全边**：出图按 3:1 出，但上机按 2.8:1 ~ 3.1:1 裁切。主体必须居中，**左右各留约 10%、上下各留约 12%** 的空白余量，人物头部、旗帜、兵器等不要贴边。
2. **暖橙金是唯一主光源**。卡片周围是深紫红曙光底，出现冷蓝天空、强白色逆光或摄影棚打光都会与界面脱节。
3. **色调统一**：全部走深紫红 + 暖白 + 暖橙金。允许少量环境色（赭石、青铜、墨绿），但整体要压暗、低饱和。一张冷蓝调的图混进去就会破功。
4. **无文字**：不得出现任何文字、印章、题款、水印、签名板。姓名与故事由界面里的 HTML 文字承担，图上再写字必然和界面字打架。
5. **不混搭文化与时代**：这是最容易翻车的项。中国条目不要出现和服/韩服，埃及条目不要出现希腊柱式，日本条目不要出现神社鸟居，俄国条目不要出现苏联镰刀锤（叶卡捷琳娜是沙俄非苏联），美国内战条目不要出现现代军装。逐条对照第四节「红线」验收。
6. **人物要庄重不猎奇**：涉及原住民与非洲题材时，按「古老、庄严、有力量」处理，不做野蛮化、奇观化、漫画化的描绘。
7. **不出现宗教偶像面部特写的争议**：埃及法老条目取「仪式感、侧面、远景」最稳，避免正面巨脸。

## 五、落位契约

1. 文件名严格按 `<slug>.webp`，slug 与 `heroines.js` 的 `slug` 字段一致。
2. 放图即生效：文件丢进 `assets/illus/`，`app.js` 启动时预检通过即显示，无需改代码。
3. 缺图或加载失败自动回退到程序化占位，不出现空白块、不改动卡片尺寸。
4. 22 张可分批补，不必等齐了再上线。
