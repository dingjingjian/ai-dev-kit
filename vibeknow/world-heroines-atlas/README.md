# 世界女英雄图鉴 · WORLD HEROINES ATLAS

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

3D 地球上点亮全球 28 位真实历史女英雄的标记，转动地球、点开光点，读她们的故事。曙光暖色调，复用姊妹项目 `vibeknow/moon-myths` 的标记点+卡片+分享骨架。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录。

## 交互

- 拖动旋转地球，滚轮 / 双指缩放
- 地球表面有 28 个发光标记，标记随地球自转；标记在屏幕上尺寸恒定（约 18px，选中约 22px），小屏 / 宽屏 / 拉近拉远都一致，靠近地球轮廓时淡出
- **标记按大洲取色**（与底部筛选条的提示点同色）：东亚红 / 南亚橙 / 中东金 / 欧洲蓝 / 非洲绿 / 美洲紫 / 大洋洲青
- **每个可见标记都挂名牌**（国别·姓名，前有大洲色圆点）：名牌**全量显示、允许相互重叠**，不因挤不下而隐藏；选中的名牌层级最高，被卡片压住属正常遮挡
- 点击标记 → 地球停转、飞到该标记正面、底部展开女英雄卡片
- 卡片含国别·地域、姓名、**年代·身份**、配图、故事、关键词标签、经纬度
- 底部区域筛选（全部 / 东亚 / 南亚 / 中东 / 欧洲 / 非洲 / 美洲 / 大洋洲）：单排胶囊、溢出一屏时两端渐隐、横向滚动 + `scroll-snap` 吸附（同 `vibeknow/solar-system-3d` 的 dock 交互）
- **光照取真实北京时间**：太阳直射点经度 = 15°×(20 − 北京小时)，纬度按日期取太阳赤纬，于是北极的极昼／极夜、晨昏线的季节倾斜都对得上今天
- 右上设置：顶部显示"此刻"（北京时间 / 直射点），下面为自动旋转 / 星空 / 云层 / 标签开关，重置 / 俯视视角

## 配图

女英雄卡片上有 28 个配图位（`assets/illus/<slug>.webp`，1080×360，约 3:1，单张 ≤90KB）。

- **图未生成时**：卡片显示程序化占位（曙光渐变 + 朝阳圆盘 + 文件名），不空着、也不改卡片尺寸，因此**可以分批补图**。
- **放图即生效**：路径写在 `assets/heroines.js` 的 `img` 字段，文件按约定命名丢进 `assets/illus/` 即可，无需改代码。
- **提示词**：28 条统一风格前缀 + 逐条画面主体 + 红线 + 转换命令，见 [`docs/配图提示词.md`](docs/配图提示词.md)。

## 视觉

曙光暖色调：深紫红底（`#1a0a14`）+ 暖白文字（`#f4e4c1`）+ 暖橙金强调（`#e8a04a`）。标题用衬线体（宋体感），故事正文用衬线体，UI 用无衬线。

地表标记形制参考 `vibeknow/moon-myths`（实心点 + 光晕 + 描边 + 细环四层），配色按大洲取色（东亚红/南亚橙/中东金/欧洲蓝/非洲绿/美洲紫/大洋洲青）。

## 技术栈

复用 `vibeknow/earth-3d` 的 Three.js 渲染框架（地球贴图、程序化星空、云层、大气辉光、手势控制），改造为「地图标注 + 点击展开」交互形态。单文件零依赖（除 three.min.js），兼容 Android 8.1 Chrome/WebView 61 基线。

配图走「数据声明路径 + 预检 + 程序化占位」：`heroines.js` 的 `img` 字段声明图位，`app.js` 启动时逐张预检，加载失败或 2.6 秒未就绪即回退到 CSS 占位，因此配图缺失不影响功能与布局（做法与 `vibeknow/world-food-3d` 一致）。

光照不引入任何天文库：直射点、太阳赤纬都是十几行三角函数，见 `app.js` 的 `astroUpdate()`。北京时间取 `Date` 的 UTC 值 +8 小时，**不依赖设备时区**。
