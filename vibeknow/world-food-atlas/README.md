# 世界美食图鉴 · WORLD FOOD ATLAS

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

3D 地球上点亮全球 36 道代表性美食的标记，转动地球、点开光点，读它的来历、食材与风味；左上「清单」按钮可直接摊开全部 36 道，按大洲分列翻检。暖琥珀 + 奶油白的现代美食杂志风（深夜厨房的一盏暖灯），复用姊妹项目 `vibeknow/world-heroines-atlas` 的 3D 地球+标记点+卡片+地域筛选+分享骨架，配图与数据复用 `vibeknow/world-food-3d`。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录。

## 交互

- 拖动旋转地球，滚轮 / 双指缩放
- 地球表面有 35 个发光标记，标记随地球自转；标记在屏幕上尺寸恒定（约 18px，选中约 22px），小屏 / 宽屏 / 拉近拉远都一致，靠近地球轮廓时淡出
- **标记按大洲取色**（与底部筛选条的提示点同色）：亚洲红 / 欧洲蓝 / 非洲绿 / 北美紫 / 南美橙 / 大洋洲青
- **每个可见标记都挂名牌**（产地·菜名，前有大洲色圆点）：挤不下时按"更正面者优先"让位（被挤掉的隐藏，不移动、不乱飘），被卡片挡住的位置不排
- 点击标记 → 地球停转、飞到该标记正面、底部展开美食卡片
- 卡片含产地·大洲、菜名、**味型·热量**、配图、介绍、**食材**、风味标签、经纬度
- 底部地域筛选（全部 / 亚洲 / 欧洲 / 非洲 / 北美 / 南美 / 大洋洲）：单排胶囊、溢出一屏时两端渐隐、横向滚动 + `scroll-snap` 吸附（同 `vibeknow/solar-system-3d` 的 dock 交互）
- **左上「清单」按钮 → 36 道完整菜单**：按大洲分列（顺序同底部筛选条，组内保持数据原序，每组标题带该洲道数），每行含配图缩略图、菜名、产地与味型·热量；点任意一行即收起清单 → 地球飞到该标记正面 → 展开卡片（与直接点标记完全同一条路径）。当前地域筛选生效时，名单中非本洲项同步变暗、选中项描金高亮；`Esc` 或右上 `×` 关闭
- **光照取真实北京时间**：太阳直射点经度 = 15°×(20 − 北京小时)，纬度按日期取太阳赤纬，于是北极的极昼／极夜、晨昏线的季节倾斜都对得上今天
- 右上设置：顶部显示"此刻"（北京时间 / 直射点），下面为自动旋转 / 星空 / 云层 / 标签开关，重置 / 俯视视角
- 卡片底部「分享到小红书」：合成 1080×1440 海报（菜名 + 产地 + 味型热量 + 配图 + 介绍 + 食材 + 标签 + 经纬度），调用 `window.xhs.miniTool` 发笔记

## 配图

菜品卡片上有 36 个配图位（`assets/foods/<slug>.webp`，512×512，主体居中留白），复用 `vibeknow/world-food-3d` 已生成的菜品图。

- **图未生成时**：卡片显示程序化占位（暖橙渐变 + 火候圆盘 + 文件名），不空着、也不改卡片尺寸，因此**可以分批补图**。
- **放图即生效**：路径写在 `assets/foods.js` 的 `img` 字段，文件按约定命名丢进 `assets/foods/` 即可，无需改代码。

## 视觉

现代美食杂志风：焦糖黑底（`#16100a`）+ 奶油白文字（`#f5ebd8`）+ 蜜金强调（`#e8a33d`），面板是暖褐烟熏玻璃（`rgba(38,29,19,.84)`），地球配一圈蜜金色大气辉光。底色的暖是「低明度、低彩度」的暖（只在黑里透一点褐），真正的暖留给强调色、地球辉光与菜品照片。标题用衬线体（宋体感），介绍正文用衬线体，UI 用无衬线。

六大洲色按「香料盘」取色：六个色同一明度带（L 53%~64%）、饱和度收敛，只靠色相区分（亚洲红 `#e2604a` / 欧洲蓝 `#6c9bd2` / 非洲绿 `#86ab5c` / 北美紫 `#b07cc6` / 南美橙 `#eaa34e` / 大洋洲青 `#46b0a4`），成组出现时不打架。色值唯一真源在 `assets/foods.js` 的 `REGIONS[].color`。

与 `vibeknow/world-heroines-atlas`（深紫红曙光调）和 `vibeknow/world-food-3d`（中式老馆木铜朱墨）三套配色实质差异化，复用同一交互骨架但不构成换皮：卡片内容字段不同（女英雄是年代·身份+故事+标签；美食是味型·热量+介绍+食材+标签），数据维度不同（女英雄 7 大洲含东亚/南亚/中东细分；美食 6 大洲），视觉定调不同。

地表标记形制参考 `vibeknow/moon-myths`（实心点 + 光晕 + 描边 + 细环四层），配色按大洲取色。

## 技术栈

复用 `vibeknow/earth-3d` 的 Three.js 渲染框架（地球贴图、程序化星空、云层、大气辉光、手势控制），改造为「地图标注 + 点击展开」交互形态。单文件零依赖（除 three.min.js），兼容 Android 8.1 Chrome/WebView 61 基线。

配图走「数据声明路径 + 预检 + 程序化占位」：`foods.js` 的 `img` 字段声明图位，`app.js` 启动时逐张预检，加载失败或 2.6 秒未就绪即回退到 CSS 占位，因此配图缺失不影响功能与布局。

光照不引入任何天文库：直射点、太阳赤纬都是十几行三角函数，见 `app.js` 的 `astroUpdate()`。北京时间取 `Date` 的 UTC 值 +8 小时，**不依赖设备时区**。
