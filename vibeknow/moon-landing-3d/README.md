# 3D 登月全程 - Moon Landing 3D

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

以「口袋火箭」同款 UI 与自研 WebGL 引擎打造的登月全过程科普应用：按中国载人登月真实的 **长征十号双箭发射 + 环月交会对接** 架构呈现——先发射揽月着陆器驻留环月轨道，数日后再发射梦舟载人飞船，二者环月对接后，航天员转入着陆器动力下降，稳稳落在月面。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录（贴图以内联 data URI 提供，`file://` 直接打开即可运行，无需联网）。

## 三种模式

- **展示**：长征十号静态陈列，拖动旋转视角。
- **拆解**：箭体在独立展示空间中逐级铺开，点击标签查看各舱段说明（逃逸塔、梦舟飞船、揽月着陆器、二级、芯一级、助推芯……）。
- **登月**：完整任务流程，含倒计时、实时遥测、阶段字幕与长按加速。

## 登月流程（双箭发射 → 环月对接 → 月面着陆）

**第一次发射 · 揽月着陆器**

| 阶段 | 内容 |
|------|------|
| 发射上升 | 三芯并联点火、程序转弯、最大动压（无逃逸塔，本次不载人） |
| 级间分离 | 两枚 5 m 助推芯分离 → 芯一级分离 → 氢氧上面级点火 → 整流罩分离（露出着陆器） |
| 停泊轨道 | 着陆器入近地轨道 |
| 地月转移 | 上面级二次点火（TLI）奔月，船箭分离，着陆器沿转移轨道飞向月球 |
| 近月制动 | 着陆器发动机反推减速（LOI），被月球引力捕获 |
| 环月就位 | 着陆器驻留环月轨道，静候飞船 |

**第二次发射 · 梦舟载人飞船**（数日后）

| 阶段 | 内容 |
|------|------|
| 发射上升 | 三芯并联点火、程序转弯、最大动压、逃逸塔分离（本次载人，无整流罩） |
| 级间分离 | 助推芯分离 → 芯一级分离 → 氢氧上面级点火 |
| 停泊轨道 | 飞船入近地轨道，太阳翼展开 |
| 地月转移 | 上面级二次点火奔月，船箭分离，飞船飞向月球 |
| 近月制动 | 飞船发动机反推减速，被月球引力捕获，进入环月轨道 |
| 交会对接 | 飞船靠近驻留着陆器，环月轨道交会对接，航天员转入着陆器 |

**着陆下降**

| 阶段 | 内容 |
|------|------|
| 船器分离 | 揽月着陆器（载 2 名航天员）与梦舟飞船分离 |
| 动力下降 | 下降发动机反推制动，展开着陆腿，扬起月尘 |
| 月面软着陆 | 稳稳触地，地球悬于漆黑月空 |

## 关于「双箭发射」架构

本应用按中国载人登月的真实方案呈现：**长征十号双箭发射**——一枚发射揽月着陆器、一枚发射梦舟载人飞船，二者在环月轨道交会对接后，航天员转入着陆器落月；飞船则驻留环月轨道等待返回。为便于同框观赏，地月距离做了压缩（真实约 60 倍地球半径，此处压缩至约 12 倍），遥测数值仍按真实公里 / 米每秒显示；两次发射之间的数天间隔在时间轴上压缩为一次黑场过渡。箭体构型与舱段划分为科普示意，不代表工程实态。

> 工程实现见 `assets/mission.js` 的两段式任务时序：第一次发射结束有着陆器「驻留」（`parked`，独立于主体每帧定位）；段间过渡复原共用箭体、把飞船 / 逃逸塔 / 太阳翼整体下移 `SHIP_OFFSET` 构成载人构型；第二次发射经交会（`rendezvous`）收敛环月角后对接（`docking`），着陆器接合到飞船下方，再船器分离、动力下降。无头自检见 `tests/headless_two_segment.js`（`node tests/headless_two_segment.js`）。

## 素材与工程

| 项 | 说明 |
|----|------|
| 引擎 | 复用手写 WebGL 引擎（`engine.js`），新增「通用贴图天体」着色分支渲染月球 |
| 月面贴图 | 取自同目录 `../solar-system-3d/assets/moon.jpg`（NASA 影像），内联为 `assets/moon-data.js` |
| 地球 / 云层 | 复用「口袋火箭」内联贴图 `earth-data.js` / `clouds-data.js` |
| 音效 | 程序化 Web Audio 合成（`audio.js`），零音频资源；新增着陆触地闷响 |

脚本一律使用相对路径，禁止硬编码绝对路径（参考根目录 `TRACKS.md` 维护约定）。

## 分类判定

没有分数也没有关卡，用户是来看「怎么去月球、每一步发生了什么」，带走的是对登月流程与器箭构成的认知 → `#vibeknow`。与 `rocket-launch-3d`、`moon-3d` 同属该题材的不同呈现。
