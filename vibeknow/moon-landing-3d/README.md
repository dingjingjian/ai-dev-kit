# 3D 登月全程 - Moon Landing 3D

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

以「口袋火箭」同款 UI 与自研 WebGL 引擎打造的登月全过程科普应用：按中国载人登月真实的 **长征十号双箭发射 + 环月交会对接** 架构呈现——先发射揽月着陆器驻留环月轨道，数日后再发射梦舟载人飞船，二者环月对接后，航天员转入着陆器动力下降，稳稳落在月面。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录（贴图以内联 data URI 提供，`file://` 直接打开即可运行，无需联网）。

## 三种模式

展示 / 拆解两种模式下，底部可在**两枚长征十号**之间切换（同一支箭的两种发射构型）：

- **① 第一次发射 · 揽月着陆器**：助推×2 + 芯一级 + 芯二级 + 整流罩（罩内为揽月着陆器）；无飞船 / 逃逸塔 / 太阳翼。
- **② 第二次发射 · 梦舟载人飞船**：助推×2 + 芯一级 + 芯二级 + 整流罩（罩内为梦舟飞船：返回舱 + 服务舱）+ 逃逸塔（坐在罩顶）；无着陆器。

| 模式 | 说明 |
|------|------|
| **展示** | 当前构型静态陈列（默认第一次发射构型），拖动旋转视角 |
| **拆解** | 当前构型在独立展示空间中逐级铺开，点击标签查看各部件说明——构型①有整流罩 / 揽月着陆器，构型②有整流罩 / 梦舟返回舱 / 服务舱 / 逃逸塔（太阳翼按发射构型收拢，入轨后才展开） |
| **登月** | 完整任务流程，含倒计时、实时遥测、阶段字幕与长按加速；构型由任务流程自动切换（第一发 → 第二发），故此处隐藏构型切换器 |

## 登月流程（双箭发射 → 环月对接 → 月面着陆）

**第一次发射 · 揽月着陆器**

| 阶段 | 内容 |
|------|------|
| 发射上升 | 三芯并联点火、程序转弯、最大动压（无逃逸塔，本次不载人） |
| 级间分离 | 两枚 5 m 助推器分离 → 芯一级分离 → 芯二级（液氧煤油）点火 → 整流罩分离（露出着陆器） |
| 停泊轨道 | 着陆器入近地轨道 |
| 地月转移 | 芯二级二次点火（TLI）奔月，船箭分离，着陆器沿转移轨道飞向月球 |
| 近月制动 | 着陆器发动机反推减速（LOI），被月球引力捕获 |
| 环月就位 | 着陆器驻留环月轨道，静候飞船 |

**第二次发射 · 梦舟载人飞船**（数日后）

| 阶段 | 内容 |
|------|------|
| 发射上升 | 三芯并联点火、程序转弯、最大动压、逃逸塔分离、整流罩分离（本次载人：逃逸塔 + 整流罩，罩内为梦舟飞船） |
| 级间分离 | 助推器分离 → 芯一级分离 → 芯二级（液氧煤油）点火 |
| 停泊轨道 | 飞船入近地轨道，太阳翼展开 |
| 地月转移 | 芯二级二次点火奔月，船箭分离，飞船飞向月球 |
| 近月制动 | 飞船发动机反推减速，被月球引力捕获，进入环月轨道 |
| 交会对接 | 飞船靠近驻留着陆器，环月轨道交会对接，航天员转入着陆器 |

**着陆下降**

| 阶段 | 内容 |
|------|------|
| 着陆器与飞船分离 | 揽月着陆器（载 2 名航天员）脱离梦舟飞船，转入落月飞行 |
| 动力下降 | 下降发动机反推制动，展开着陆腿，扬起月尘 |
| 月面软着陆 | 稳稳触地，地球悬于漆黑月空 |

## 关于「双箭发射」架构

本应用按中国载人登月的真实方案呈现：**长征十号双箭发射**——一枚发射揽月着陆器、一枚发射梦舟载人飞船，二者在环月轨道交会对接后，航天员转入着陆器落月；飞船则驻留环月轨道等待返回。为便于同框观赏，地月距离做了压缩（真实约 60 倍地球半径，此处压缩至约 12 倍），遥测数值仍按真实公里 / 米每秒显示；两次发射之间的数天间隔在时间轴上压缩为一次黑场过渡。箭体构型与部段划分为科普示意，不代表工程实态。

> 工程实现见 `assets/mission.js` 的两段式任务时序：第一次发射结束有着陆器「驻留」（`parked`，独立于主体每帧定位）；段间过渡复原共用箭体、按载人构型换上「罩内梦舟 + 罩顶逃逸塔」；第二次发射经交会（`rendezvous`）沿环月轨道从后方追近驻留着陆器（终态角差 = `DOCK_GAP` 换算出的环月角，飞船始终在着陆器后方，接近轨迹不穿越对方），对接帧对齐姿态后着陆器原位重定基、接合到飞船前方（对接机构在飞船头部），再着陆器与飞船分离（梦舟整体作为刚体缓速漂离、驻留环月轨道，不散架也不淡出）、动力下降、着陆末段、月面软着陆。地月转移按真实过程呈现：近地点切向加速（芯二级二次点火，高度基本不变）后关机、沿椭圆滑行，速度在段末与转移段起点严格衔接；环月 / 交会 / 着陆段的镜头始终锁定飞行器本体（取景目标不再经月心插值），月面镜头以月面法线为 up；重新观看时 `reset()` 会连同高度 / 速度一并清零，因此倒计时阶段发射台正常显示。无头自检见 `tests/headless_two_segment.js`（`node tests/headless_two_segment.js`）。
>
> 时序与几何的几个约定（改这块前务必先读）：
> 1. 活动栈质心不写死常量——入轨 / 船箭分离时用 `centroidOf()` 现场求值并做两级重定基（原点平移到新活动体质心 + 部件 `baseY` 同步回退），模型改动后自动跟随。
> 2. 入轨 MET 由上升段实际取得（`state.metInsert`），随后在停泊轨道段平滑推进到 `MET_TLI`；环月段持续推进到本段终点。MET 应全程单调（自检含该项）。
> 3. 停泊轨道环与箭体共用「视觉半径」`R_ORB_VIS`（含高度增益），遥测仍显示真实轨道高度；两者不要各写一套。
> 4. `approach` 是真实相位；`docking` / `landerSep` / `landing` 只是字幕事件（`PHASES` 中保留其文案），`state.phase` 不会取这些值。
> 5. 两枚火箭的构型（部件可见性）只由 `applyConfig(seg)` 一处决定，展示 / 拆解 / 登月三条路径共用；展示 / 拆解通过 `mission.setVariant(1|2)` 切换，`mission.reset()` 始终复位到构型①，由 app 层在复位后再套用目标构型。两次发射的几何基准完全相同（都带整流罩），因此不再需要"飞船整体下移"这类偏移常量。
>
> 6. 整流罩分离字幕按构型区分（`captionFor` 返回 `fairingSepLander` / `fairingSepShip`）。

## 构型核对（与真实长征十号对照）

模型已按公开资料核对过，**仍未落实的简化**一并列出，避免被误当成真实工程状态：

| 项 | 真实长征十号（公开资料） | 本应用 |
|----|--------------------------|--------|
| 级数 | **三级半**：助推器、芯一级、芯二级、芯三级（另配逃逸塔与整流罩） | 合并为两级（芯一级 + 芯二级），地月转移归到芯二级 |
| 起飞级动力 | 芯一级 5 m、**7 台 YF-100K**；两枚助推器各 **7 台**，起飞共 **21 台**（约 2678 t） | 已一致（21 个喷管，1 台居中 + 6 台环绕） |
| 芯二级 | 5 m、**2 台 YF-100M（液氧煤油，真空推力 146 t 级）** | 已一致（2 台，液氧煤油） |
| 芯三级 | 上面级，承担地月转移 | 未建模（TLI 画在芯二级上） |
| 整流罩 | 全新研制，**直径与高度均为 5 m**；载人构型做"船罩联合振动试验" | 有罩，罩内为揽月着陆器 / 梦舟飞船；外廓按略鼓示意 |
| 逃逸塔 | 载人构型为「**逃逸塔 + 整流罩**」，塔位于罩顶 | 已一致（塔坐罩顶，MET 120 s 分离） |
| 载荷 | 揽月着陆器；梦舟飞船（返回舱 + 服务舱 + 太阳翼） | 一致（示意比例；太阳翼发射时收拢、入轨后展开） |

资料来源：长征十号总体设计（三级半构型、箭体组成、各级动力配置，百度百科）；整流罩分离试验报道"高度和直径均为 5 米"（中国运载火箭技术研究院，2024-11）；芯一级 7 台 + 两枚助推各 7 台共 21 台（多家媒体报道一致）；三级发动机整机长程试车（2022-06）。

## 素材与工程

| 项 | 说明 |
|----|------|
| 引擎 | 复用手写 WebGL 引擎（`engine.js`），新增「通用贴图天体」着色分支渲染月球 |
| 月面贴图 | 取自同目录 `../solar-system-3d/assets/moon.jpg`（NASA 影像），内联为 `assets/moon-data.js` |
| 地球 / 云层 | 复用「口袋火箭」内联贴图 `earth-data.js` / `clouds-data.js` |
| 音效 | 程序化 Web Audio 合成（`audio.js`），零音频资源；新增着陆触地闷响 |

脚本一律使用相对路径，禁止硬编码绝对路径（参考根目录 `TRACKS.md` 维护约定）。

## 分类判定

没有分数也没有关卡，用户是来看「怎么去月球、每一步发生了什么」，带走的是对登月流程与器箭构成的认知 → `#vibeknow`。与 `rocket-launch-3d`、`moon-3d` 同属该题材的不同呈现。
