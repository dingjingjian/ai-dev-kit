# 路线横幅与背景配图需求

本文是「侏罗纪公园 · 游览导航」中 **路线横幅 ×4、公园大门、丛林背景、木纹纹理** 的出图规格。
这些图共同营造侏罗纪公园的视觉氛围，缺图时均有 CSS 兜底，功能与排版不受影响。

## 一、图位总览

| 编号 | 图位 | 数量 | 规格 | 路径 | 落地位置 |
|------|------|------|------|------|----------|
| ② | 公园大门 | 1 | 16:9 横幅 | `assets/tex/gate.webp` | 大门过渡页背景 |
| ③ | 丛林背景 | 1 | 16:9 横幅 | `assets/tex/jungle.webp` | 路线选择页顶部 hero 区 |
| ④ | 路线横幅 | 4 | 16:9 横幅 | `assets/tex/route-<key>.webp` | 路线卡片背景 |
| ⑤ | 木纹纹理 | 1 | 512×512 可平铺 | `assets/tex/wood.webp` | 大门与控制栏木纹 |

key 为 `predator` / `giants` / `time` / `bizarre`。

## 二、硬性约束

1. **单张横幅 ≤ 200KB，木纹 ≤ 60KB**。本项目零依赖离线，体积敏感。
2. **无文字、无水印、无品牌标识、无现代建筑、无人物正脸**。
3. **色调统一**。低饱和、自然光、浅景深，与公园森林绿/铜/米白三色系协调。
4. **木纹须可平铺**（横竖接缝连续）。生图模型默认不给无缝，须在提示词写明并在出图后人工检查。

## 三、② 公园大门（`assets/tex/gate.webp`）

大门过渡页的背景图，在两扇 CSS 木门打开后透出。

- **尺寸**：1600×900（16:9），WebP 质量 80
- **画面**：侏罗纪公园铸铁大门内景，门内是茂密蕨类丛林与远处恐龙轮廓剪影，
  暖黄探照灯自上方漫射，雾气弥漫，有纵深感
- **要点**：画面中央须留暗部——CSS 的三角 logo 与标题会压在中央，
  太亮或太杂会干扰文字可读性
- **色调**：深森林绿底 + 暖黄灯光 + 铜色门框
- **缺图回退**：CSS 径向渐变（丛林绿 → 暗绿）+ 两扇 CSS 画的木门 + 火炬动画

**提示词要点**：
> 侏罗纪公园大门内景，16:9 横幅，铸铁大门向两侧敞开，门内茂密蕨类丛林，
> 远处恐龙轮廓剪影，暖黄探照灯光柱自上方斜下，雾气弥漫，纵深感强，
> 画面中央偏暗供压字，深森林绿与暖黄铜色调，低饱和自然光，浅景深，
> 无文字、无水印、无人物。

## 四、③ 丛林背景（`assets/tex/jungle.webp`）

路线选择页顶部 hero 区的背景图，压在公园标题与火炬之下。

- **尺寸**：1600×900（16:9），WebP 质量 80
- **画面**：侏罗纪丛林远景，高大蕨类与苏铁层层叠叠，林间透光柱，
  雾气弥漫，底部渐暗过渡到路线列表
- **要点**：画面上部留暗部供标题压字，下部渐暗
- **色调**：深森林绿 + 林间暖光
- **缺图回退**：CSS 径向渐变（丛林绿 → 暗绿）+ 底部暗化遮罩

**提示词要点**：
> 侏罗纪丛林远景，16:9 横幅，高大蕨类与苏铁层层叠叠，
> 林间透暖光柱，雾气弥漫，上部偏暗供压字，下部渐暗，
> 深森林绿调，低饱和自然光，浅景深，无文字、无水印、无人物。

## 五、④ 路线横幅 ×4

路线选择页中每条路线卡片的背景图，压在路线名称与描述之下。

- **尺寸**：1200×400（3:1），WebP 质量 80
- **铺法**：`background-size:cover`，卡片高约 120–160px，上下会有裁切
- **要点**：画面须有该路线的主题氛围；左侧可偏暗（路线名压在左上）
- **缺图回退**：路线主题色渐变（`--rc-dark → --rc-mid`）

### 01 `route-predator` · 掠食者之旅

- **主题色**：火焰红橙 `#e0453a` / `#f06449`，暗底 `#2a0e06`
- **画面**：暗红夜色中，掠食恐龙的眼睛特写或利齿剪影，火光摇曳
- **提示词**：掠食恐龙夜间猎食氛围，暗红底色，火光摇曳，利齿或眼睛剪影，
  紧张压迫感，左侧偏暗供压字，无文字

### 02 `route-giants` · 巨兽之旅

- **主题色**：深森林绿 `#6b9a4a` / `#8ab860`，暗底 `#08150f`
- **画面**：蜥脚巨龙长颈高举过树冠的剪影，仰视视角，雾气中巨影幢幢
- **提示词**：蜥脚类巨龙仰视剪影，深森林绿底色，长颈高耸过树冠，
  雾气中巨影幢幢，震撼感，左侧偏暗供压字，无文字

### 03 `route-time` · 时空之旅

- **主题色**：青铜蓝绿 `#4a9ab0` / `#6ab8d0`，暗底 `#0a1520`
- **画面**：地质年代螺旋或地层剖面，从古老到年轻渐变，化石嵌在岩层中
- **提示词**：地质地层剖面或年代螺旋，青铜蓝绿底色，化石嵌在岩层中，
  从古老到年轻渐变，通史感，左侧偏暗供压字，无文字

### 04 `route-bizarre` · 奇异物种之旅

- **主题色**：暗紫琥珀 `#c080d0` / `#d8a0e0`，暗底 `#180a20`
- **画面**：怪异恐龙剪影群——帆背、厚颅、四翼、镰爪，暗紫雾气中若隐若现
- **提示词**：形态怪异的恐龙剪影群，暗紫底色，帆背厚颅四翼镰爪各异，
  雾气中若隐若现，怪诞感，左侧偏暗供压字，无文字

## 六、⑤ 木纹纹理（`assets/tex/wood.webp`）

大门两扇木门与游览车控制栏的木纹贴图。

- **尺寸**：512×512，WebP 质量 80，可平铺
- **画面**：深胡桃木直纹，带轻微结疤，无高光、无漆面反光
- **色调**：暗木棕 `#3d1f12` 系
- **缺图回退**：CSS 纯色渐变（`--wood-7 → --wood-9`）

**提示词要点**：
> 深胡桃木直纹纹理，512×512 可平铺，暗棕色调，细直木纹带轻微结疤，
> 无高光、无漆面反光，画面左右上下接缝完全衔接。

## 七、缺图回退

所有图片未生成时均有 CSS 兜底：
- 大门 → CSS 渐变 + CSS 画的两扇木门 + 火炬动画
- 丛林 → CSS 径向渐变 + 暗化遮罩
- 路线横幅 → 路线主题色渐变
- 木纹 → CSS 纯色渐变

故可分批生成，不必齐了再上线。
