## 二、统一参照（重要）

这几张图**不要写成"侏罗纪主题的公园大门"这种泛化描述**——那样出来的是"某个丛林公园的
铁门"，缺的就是那个辨识度。提示词里**直接点名 1993 年电影《侏罗纪公园》**：

> 参照 **1993 年电影《侏罗纪公园》（Jurassic Park, 1993）** 中那座标志性的公园大门／标志，
> 复刻其造型语言（不是复刻某一帧照片）。

出图时按下面这几条"电影的识别锚点"逐条压——**右列是首版实际画错的地方，必须写进提示词**：

| 锚点 | 要什么 | **不要什么**（首版就错在这） |
|------|--------|------------------------------|
| **三角徽标** | 门楣正中**骨白实心三角 + 黑色恐龙骨架剪影**，全片最强识别物，**不能省** | 首版**完全没有**这个徽标，门缝只挂了个圆形花饰 |
| **石柱** | 两座**光面方形石柱**，柱身横向砌缝、柱顶外挑石帽 | 首版画成了带**十字凸肩**的柱子，像牌坊／城门 |
| **石楣** | 两柱间**平直厚重的矩形石横梁** | 首版是**石拱**（圆弧拱顶），电影大门没有拱 |
| **铁艺门** | 双开竖栅栏铁门，**纯竖条 + 上下两道横梁 + 顶端尖饰** | 首版栅栏里加了**圆形花饰**，太花 |
| **门口光** | 柱顶／门楣两端各一盏**暖黄泛光灯**，在雾里打出光柱 | 首版只有门后一片强光，柱上灯不明显 |
| **色调** | **阴郁的深森林绿雾气**打底，暖光只作局部 | 首版门后**金黄过曝**，像天门，丢掉了阴森的压迫感 |
| **环境** | 门前泥土路，两侧蕨类密林，浓雾 | 无 |

> ⚠️ **允许出现的"文字"只有徽标本身**：若模型能在石楣上压出 `JURASSIC PARK`
> 弧线字更好；压不准就**只留三角徽标**，别硬凑。其它任何文字、水印、logo、人物一律不要。

## 三、⑥ 公园 logo `logo.webp`

压在首页大门图上方，取代原来 CSS 画的三角。**这一张是补齐"侏罗纪公园 logo"的关键图**。

- **尺寸**：宽 800px 左右，透明底，保留上下留白
- **画面**：经典构图——**骨白色实心三角**（底边水平、顶尖朝上），三角内是
  **黑色恐龙骨架剪影**（侧视，肋骨架 + 长尾 + 小头，剪影占三角内部约 2/3 高）
- **要点**：扁平矢量感、边缘干净、只有白与黑两色；
  **不要外框、不要背景色块、不要渐变**
- **色调**：纯白三角 + 纯黑剪影，便于叠在任何底的图上
- **缺图回退**：整块 logo 隐藏，只留文字标题

**提示词要点**（照抄可用）：
> 参照 1993 年电影《侏罗纪公园》的经典三角标志：透明背景，正立等边三角形，
> 三角为纯白实心，三角形内是黑色的恐龙骨架剪影（侧视全身，头骨、脊柱、肋骨、
> 长尾与后肢清晰可辨，骨架占三角内部约三分之二），
> 极简扁平矢量风格，构图居中对称，边缘锐利，无描边、无外框、无背景、无渐变、
> 无任何文字、无水印。

**常见问题**：

| 症状 | 原因 | 怎么改 |
|------|------|--------|
| 三角出来是灰的/带渐变 | 加了"金属质感""立体" | 只留"纯白实心 + 黑色剪影"两个色 |
| 骨架糊成一团 | 分辨率低或剪影太满 | 骨架缩到三角内约 2/3，要求"头骨与肋骨可辨" |
| 出了 `JURASSIC PARK` 英文 | 模型自动补字 | 明确写"无任何文字"；中文站名由页面承担 |
| 背景是白/黑块 | 没给透明底 | 强调"透明背景 alpha channel"，导出 PNG 后再转 WebP |
| 模型以商标为由拒图 | 直接点名品牌名 | 改成"经典公园标志：白色三角内嵌黑色恐龙骨架剪影"，不谈片名，造型不变 |


## 四、⑦⑧ 大门两张（**必须同机位同光位，一组出**）

这两张承担"开车到门口 → 门开了 → 进园"的整个开场。
**造型一律按第二节的电影识别锚点来**，尤其门楣正中那个三角恐龙骨架标志不能省。

- **⑦ `gate-front.webp`**：车停在门外的视角，**大门关闭**。落地两处：
  首页顶部 hero（按 `center 50%` 裁切，故上部要暗）+ 大门页第一帧
- **⑧ `gate-open.webp`**：**完全相同的机位与光照**，但**大门已向两侧敞开**，
  门内是雾气中的园区土路与恐龙剪影，暖黄探照灯照着门口

两张之间代码只做**交叉淡化 + 轻微推近**（各约 5 秒），所以：

1. 石柱、门楣、道路、远景必须**对得上**，否则淡入时画面会跳
2. ⑦ 的门闩/门框位置要与 ⑧ 打开后的空门洞重合
3. 两张都不要出现文字、水印、人物、现代车辆

**⑦ 提示词要点**（照抄可用）：
> 参照 1993 年电影《侏罗纪公园》里那座标志性公园大门，正面平视全景，16:9，
> 两座**光面方形巨石柱**（柱身横向砌缝、风化苔痕、柱顶外挑方形石帽），
> 两柱之间横跨**平直厚重的矩形石横梁**，
> **横梁正中嵌着标志：骨白实心正三角，三角内是黑色恐龙骨架剪影**，
> 两扇**竖栅栏铁艺大门紧闭**（纯竖铁条 + 上下两道横梁 + 顶端尖饰 + 锈迹），
> 柱顶与门楣两端各有一盏**暖黄泛光灯**，在浓雾中打出光柱，
> 门前泥土路自画面底部通向大门，两侧蕨类密林，
> **阴郁的深森林绿雾气**为底、暖光只用于门口局部，
> 低饱和自然光，浅景深，画面上部偏暗，
> **不要拱形门洞、不要圆形花饰、不要十字凸肩的柱子、不要整片金黄过曝**，
> 无文字、无水印、无人物、无现代车辆。

**⑧ 提示词要点**（照抄可用）：
> 与上一张**完全相同的机位、构图、石柱造型与光照**，同一座电影《侏罗纪公园》的大门，

### ⑩⑪ 竖屏版（手机适配，可选但强烈建议）

**为什么要另出一版**：横版是 16:9，而手机竖屏约 9:19.5。横图在竖屏里按 `contain` 显示，
只能占屏幕中间一条，上下会留出大片信箱边（约 70% 的屏幕）。出一对竖版图，大门就能铺满整屏。

| 编号 | 图位 | 规格 | 路径 |
|------|------|------|------|
| ⑩ | 大门正面·竖版 | 1080×1920（9:16） | `assets/tex/gate-front-portrait.webp` |
| ⑪ | 大门开启·竖版 | 1080×1920（9:16） | `assets/tex/gate-open-portrait.webp` |

- 文件名**必须**与上表完全一致，代码已按此路径挂好（`@media (orientation:portrait)` 分支）
- 若生图模型支持自定义比例，**用 1080×2160（1:2）会比 9:16 更满**，上下几乎无信箱边
- 竖版图缺失时该层 404，自动回退到横版 —— 可以先只出这一对，不影响运行

**竖构图要点**（横版那套锚点全部沿用，只改机位与留白）：

| 位置 | 放什么 | 为什么 |
|------|--------|--------|
