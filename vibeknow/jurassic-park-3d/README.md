# 侏罗纪公园 · 游览导航

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

一个侏罗纪公园游览导航 app。**选择游览路线 → 经典大门开启 → 巡逻车按路线行进 → 巡逻日志**，
致敬 1993 年经典电影《侏罗纪公园》。园内 30 只恐龙按 4 条主题路线组织，
也可自选路线自由编排；巡逻车行进时地球组件实时标注化石发现地。

> 本项目参照 [`world-food-3d`](../world-food-3d/) 的技术框架构建，底层逻辑从「菜单点菜」改为「园区游览 app」。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录。

## 交互

### 路线选择页（主界面）

- **版式同 `world-food-3d` 菜单页**：通栏 hero 固定在顶不随滚动走，路线列表区自己滚动
- 顶部 hero：**一张大门正面图铺满** + 公园 logo 图 + 文字标题，只叠一层暗化保可读；
  页面不画任何 CSS/SVG 装饰（火炬、警戒带、CSS 三角 logo 已全部移除）
- 图位：背景 `gate-front.webp`（缺图回退 `jungle.webp`），logo `logo.webp`（缺图整块隐藏）
- 5 张导览牌卡片：4 条预设路线 + 1 张「自选路线」（黄黑警戒带）
- 每张有编号铭牌（TAB-01…）、路线名、标签、描述、恐龙数/年代数/发现国数/刺激度
- 卡片背景为路线横幅图，缺图依次回退木纹 → 主题色渐变
- 点预设路线卡 → 进入经典大门页；点自选路线卡 → 进入自选路线页

### 自选路线页

- **我的路线**：按加入顺序列出，带序号、色点、年代，可 ↑ ↓ 调序、× 移除
- **恐龙名录**：30 只按 5 个年代分组，每行缩略图 + 名字 + 发现地 + 体长 + 威胁
- 底栏：随机一条（抽 8 只按年代排序）、清空、开始游览
- 路线存 localStorage，下次进园还在

### 经典大门页（致敬电影）

- **两帧 AI 出图交叉淡化 + 一路推近**：① 大门关闭（`gate-front.webp`）→
  ② 大门敞开、正对园内（`gate-open.webp`），开门过程全在两张图里，页面不做任何 CSS 绘制
- 两帧**共用同一条缩放曲线与同一条缓动**（`scale 1 → 1.5`，只有 `opacity` 不同），
  交叉期间逐帧缩放完全一致 —— 读起来是持续驶向大门，不会出现"一进一退"
- **竖屏优先用竖版图**：`@media (orientation:portrait)` 把
  `gate-front-portrait.webp` / `gate-open-portrait.webp` 置于背景层首位，
  竖版缺图该层 404，自动落到横版 —— 纯 CSS 兜底，不碰 JS
- 约 7.1s 后切进游览页；字幕依次淡入：欢迎语（1.1s）→ "When Dinosaurs Ruled the Earth"（1.6s）
  → 路线名（2.1s），**在屏上停留约 5s** 才随整场一起淡出（6.2s 起）
- 图层用 `contain` + 一层**模糊铺底**：竖屏也不会裁掉石柱，留白处由虚化的同一张图填满
- 两帧须同机位同光位；缺图时都回退到旧图 `gate.webp`

### 游览页（巡逻车视角）

- 顶栏只留一行：路线名 · 年代 · 第 X / N 站（左右两侧的车牌与进度已移除）
- 地球定位组件嵌在顶栏下方：标出路线上全部恐龙的化石发现地，
  当前这只高亮脉动，其余路线成员压暗作上下文
- 恐龙图做成**园区监控画面**：`filter` 压成绿灰调 + 扫描线 + 缓慢下扫的光带 + 暗角，
  角上是 `REC` 红点、`CAM 0X` 与走动的时间码
- 画面是**正方形**（恐龙图本身就是 1:1 方图），边长 `24vh`、**宽高同值**、限幅 `88–190px`：
  方图正好填满方框，屏幕矮时整块等比变小，**绝不裁掉恐龙头与脚**；
  `background-size` 一律用 `contain` 兜底 —— 万一画框被 flex 挤成非方形，
  也只会在两侧留深色边（读作监视器内框），不会重新裁图
- **地球高度固定 `--globem:218`，不为任何页面让步**；「一屏不翻页」由
  **画面边长可压缩**（`24vh`，flex 让位）+ 卡片紧凑化（出处与活体数据并作一行）保证
- 图片下是一张**恐龙档案卡**（最大宽 540px），卡内文字**一律左对齐**、信息分层：
  - 卡头：恐龙名（左）+ 围栏编号徽章 `PADDOCK-01`（右）
  - 次行：左「年代 · 发现国 · 产地」、右「体长 X 米 ｜ 威胁 X/5」（并作一行）
  - 介绍（限 3 行）→ 末行：特征胶囊 `traits` + 食性标签 `tags`（同排）
- **版式与 `world-food-3d` 的菜品页一致**：顶栏 `52` → 地球条带 `--globem:218` →
  内容区 → 底部操作栏；`.wrap` 最大宽 `820`
- 底栏只留三枚按钮：上一只 / 下一站 / 结束返程
  （原来的进度文字已删 —— 顶栏面包屑里已有「第 X / N 站」，重复）
- 地球槽右上角两枚小按钮：左＝**分享这只恐龙**（把原图直发笔记，见 §笔记分享；只在容器注入了
  端能力、且这只恐龙的原图确实加载成功时出现），右＝背景音乐开关
- 最后一站时「下一站」变为「巡逻总结」

### 巡逻日志（总结页）

- 路线名 + 恐龙数/年代数/化石发现国数
- **一句自然简报**：本次停靠几站、几只有名的合计体长、最长与最短是谁
  （原来「以某维最突出 / 某维最克制」的定评句与「体型合计」条形模块已删除）
- **六维特征雷达图**（体型/威胁/速度/智力/防御/稀有，本次均值，峰值维度标红）
- 恐龙档案：每只一行（色点 · 名称 · 发现地 · 该只最突出的两维）
- 底栏：再游一次 / **分享** / 返回选择路线（分享＝把总结画成一张同款样式的卡片发笔记，见 §笔记分享）

### 地球组件

- 拖动地球可转动、滚轮/双指缩放
- 游览时以当前这只的朝向为基准轻微摆头，化石发现地始终留在视野中央
- 仅在游览页显示（CSS `body.mode-tour .globe-slot{display:block}`）

## 数据

- 内置 **30 种恐龙**，覆盖 **5 个地质年代**、**11 个国家**
- 数据文件：`assets/dinos.js`，每条记录字段：
  `name / country / city / lat / lon / era / intro / traits / tags / stats / length / color / img`
- `stats` 为六维特征分值 `[体型, 威胁, 速度, 智力, 防御, 稀有]`，各 0–5 整数，口径是该物种的代表性个体，
  供游览总结页的特征图谱使用。**六维顺序不可变**（`app.js` 的 `STATS_DIMS` 与之一一对应）
- `length` 为成年个体代表体长的估算值（米），供巡逻日志的简报使用
- 离线零依赖：`img` 缺失或加载失败时，用该条记录的 `color` 色卡代替恐龙图，

## 背景音乐

地球槽（地图）右上角一枚黄铜小牌，**落在顶栏之下**——顶栏不为它留右侧空白，标题保持真居中。音源是**藏在包内 `.js` 里的 base64 音频**：

| 项 | 说明 |
|------|------|
| 数据 | `assets/audio/bgm.js`（`window.JP3D_BGM`，由 `tools/make-bgm.mjs` 生成）；源曲目 `assets/audio/bgm.mp3` 是构建输入，**不进 zip** |
| 曲目 | `Theme from Jurassic Park` · 取 **64s→197s** 这段 133s 乐句 · 56kbps 单声道 22.05kHz（910 KB） |
| 选点 | 由 `tools/analyze-bgm.mjs` 选出（判据：织体相似 + 接缝处最安静；这首没有重复段，波形相关仅 0.058） |
| 起播 | **用户第一次点按之后**才出声（容器 autoplay 策略要求手势），之后全程循环 |
| 循环 | 整段即乐句，首尾 **4s 交叠淡化** —— 接缝落在乐句自己的首尾，不是把「曲头」和「曲尾裁断处」硬接在一起 |
| 开关外观 | 出声中＝压铸黄铜小牌 + 音符；静音＝转暗 + 斜杠音符。两枚图标是内联 SVG，随 `.on` 换显，不依赖图片 |
| 开关状态 | 没存过记录＝偏好开启；用户手动关掉才记成静音（`localStorage` 键 `jp3d.bgm`），关掉后下次进园仍是静音 |
| 缺数据 | 开关整块隐藏（`html.has-bgm` 挂不上），五页流程与从前完全一样 |
| 切后台 | `visibilitychange` 停声 + 挂起音频上下文，回前台自动续上 |
| 位置 | 地球槽（地图）右上角、顶栏之下：`top:calc(var(--dishbar) + var(--sattop) + var(--bgmgap))`。`--bgmgap` 默认 `12px`（开关顶边在地球槽顶边之下多少），**要挪位置就改这一个数** |

容器**纯本地、不联网**，上传白名单不含任何音频扩展名，CSP 又禁 `data:` / `blob:` 媒体源 ——
所以只有「base64 藏进 .js + Web Audio 解码播放」这一条路（全程不产生任何 URL）。
源曲目是 320kbps，帧级裁剪只能留 26 秒，所以用 `tools/analyze-bgm.mjs` 选乐句、
`tools/make-bgm.mjs` 截段 + 重编码到 56kbps，把整段 133s 塞进
「单条 base64 解码后 ≤ 1 MiB」的门禁里（实测 0.888 MiB）。

> ⚠️ **版权**：这条音轨是电影配乐，来源是素材站下载，不构成商用授权 ——
> 上线前必须换曲或取得授权，见 `docs/背景音乐需求.md` §6。
>
> 演示模式（`?demo`）不显示音乐开关；且演示全程无用户手势，BGM 也不会自动起播 ——
> 宣传片里的配乐请在后期混音时加。

## 笔记分享

容器里没有名为「分享」的 API，只有 §3.3 的 **POSTNOTE**（唤起 App 的笔记发布页并带上内容与媒体；
`mediaInfo` 必填，且图片 / 视频 / 实况三种资源至少传一种）。两处入口：

| 入口 | 位置 | 媒体 | 笔记正文 |
|------|------|------|----------|
| **分享这只恐龙** | 游览页右上角（地球槽右上角、音乐开关左侧的小图标按钮） | **该恐龙的原图原文件**（`assets/dinos/*.webp`，逐字节，不重绘） | 该恐龙的介绍 + 一段紧凑资料 |
| **分享游览总结** | 总结页底栏中间 | Canvas 现画的总结卡片（**版式与配色照总结页复刻**） | 游览简报 + 一行统计 |

### 详情页分享（恐龙原图）

```
XHR ./assets/dinos/<slug>.webp → FileReader.readAsDataURL → data:image/webp;base64,…
  → writeTempFile({ data }) 换成本地 filePath → postNote({ pageType:'photo_publish', … })
```

| 项 | 说明 |
|------|------|
| 为什么不用 canvas | `drawImage` 在 `file://` 来源下会把画布标记成被污染、`toDataURL` 抛 `SecurityError`；而且重绘等于重编码，分享出去的就不是原图了。XHR + FileReader 拿到的是**逐字节原图**，格式仍是 webp |
| 显隐条件 | 只在游览页、**且该恐龙原图确实加载成功**（复用游览页大图那份 `IMG_OK` 预检，不另开探测）、且容器注入了端能力时出现。没图就不给按钮，与「缺图回退色卡」同一口径，不做占位分享 |
| 标题 | `恐龙名 · 发现国`（限 20 字） |
| 正文 | 该恐龙 `intro`（介绍）+「年代·发现国·产地 / 体长·威胁 / 六维 / 特征」，截到 1000 字内 |
| 换一只刷新 | 每次 `showTourDino()` 与恐龙图加载回调都会重算显隐，逐只各自判断 |

### 总结页分享（同款卡片）

`drawSummaryCard()` 用 Canvas 2D 画一张 **1080×1440** 的卡片，**版式与配色照总结页复刻**：
丛林径向渐变底 + 上下两条仪表台 + 火焰橙分段标题带点线 + 六维特征图谱 + 恐龙档案行，
导出 `image/jpeg` q=0.92（约 210 KB；同样内容的 PNG 约 1.8 MB，压不动）。

> 卡片**只用图元与文字绘制，不 `drawImage` 任何图片** —— 同上，避免 `file://` 下画布被污染。
> 恐龙档案超过 8 只时列前 7 只 + 一行「… 另有 N 只未列出」，保证不溢出到底栏。

两处都走同一套能力检测：拿不到 `window.xhs.miniTool.postNote` 就整块隐藏
（桌面直接打开 `index.html`、`?demo` 录屏都不会出现）。客户端没有 `writeTempFile` 时，
直接把完整 `data:uri` 交给 `postNote`（§3.3 允许 base64 或本地路径）。
**`postNote` 成功只代表发布页被唤起并由用户点了发布，不代表过审** —— 所以只当"已唤起"提示，
不据此做任何强一致的状态变更。

## 兼容性（Chrome 61 回退层）

最低基线是 **Android 8.1 出场 Chrome / WebView 61**。做法是「基线层 + 能力检测后的增强层」，
不为旧内核另起一套页面：

| 能力 | 基线（Chrome 61 可用） | 增强（检测后启用） |
|------|----------------------|------------------|
| Flex `gap` | 子项 `margin-left` | `.supports-flex-gap` 下换 `gap` 并清 margin |
| `clamp()` | `--hero-h` 固定值 + 按视口高的媒体查询分档 | 不引入 |
| `env(safe-area-inset-*)` | `--sat / --sattop / --sab` 取容器注入的 `--safe-area-inset-*`（PC 模拟器就是靠注入它模拟安全区），无注入则 `0 / 8px / 0` | `@supports` 块里退成 `var(--safe-area-inset-*, env(safe-area-inset-*, 0px))` —— 模拟器认注入变量、真机认 `env()` |
| `:focus` | `:focus` 描边基线 | 不用 `:focus-visible` |
| WebGL 3D | 地球槽内挂 `.globe-down`，路线/大门/游览/总结照常 | 完整地球 |
| `localStorage` | `try/catch` 包住，读写失败则自选路线只活在本次会话 | 自选路线跨会话保留 |
| 大门切换 | 两张图 `opacity` + `transform:scale` 交叉淡化，Chrome 61 原生可用 | 不引入 |
| 多行截断 | 介绍文字用 `-webkit-line-clamp`（Chrome 61 支持）限行 | 不引入 |
| 背景音乐 | `AudioContext` + `decodeAudioData` + `GainNode` 包络（Chrome 61 原生）；手势后才起播 | 没有 `AudioContext` / 解码失败则开关隐藏，不引入第三方音频库 |

**3D 不可用不再是全屏报错**：地球只是标化石发现地的组件，它挂了就只在槽内降级，
底下的路线选择、自选路线、大门动画、巡逻车游览、巡逻日志一条不少。

## 与 earth-3d 的关系

复用 earth-3d 的：WebGL 渲染器、星空天球、地球贴图与云层、`ll2v` 经纬→球面坐标、相机手势。

改造为化石发现地定位组件：画布由全屏改为面板内尺寸，相机改写为"对准化石发现地"而非自由浏览，
标记点由 30 个常显改为"路线成员全显 + 当前这只高亮脉动 + 其余压暗"，发现地标签只保留当前一处。

## 与 world-food-3d 的关系

参照 `world-food-3d` 的技术框架（多页结构、地球定位组件、Chrome 61 兼容层、零依赖离线单文件），
底层逻辑从「菜单点菜」改为「园区游览 app」：

- 菜单页 → 路线选择页（4 条主题路线，原按大洲的菜品列表）
- 菜品页 → 经典大门页（两帧大门图交叉淡化，原无此页）
- 品鉴页 → 游览页（巡逻车视角按路线行进，原逐道上菜）
- 风味总结 → 巡逻日志（六维特征图谱 + 体型合计，原口味图谱 + 热量合计）
- 新增：自选路线页（原项目没有的自由编排线）
- 点单 + 上菜 → 选路线 + 开始游览（原逐个加入点单再统一上菜）

数据字段对应：`foods`→`dinos`、`continent`→`era`、`taste`→`stats`、`kcal`→`length`、`ingredients`→`traits`。

## 分类判定

没有任务、没有输赢，用户点开是为了"选一条路线，坐巡逻车穿行史前世界，看看各种恐龙的化石在哪儿出土"，
也可以自己排一条线，
看完脑子里多一份对古生物与地球史的认知 → `#vibeknow`。地球是标注化石发现地的组件，3D 是手段而非目的，故不归 `#vibeart`。
