# assets/tex/ —— 场景与横幅图位（待出图）

本目录放除帆船图之外的全部图片。路径已在 `index.html` 的 CSS 与 `app.js` 里挂好，
**只需按文件名落位，不用改代码**。
规格、识别锚点、**逐张可照抄的提示词**见 [`../../docs/场景与横幅配图需求.md`](../../docs/场景与横幅配图需求.md)。

**本目录为空是正常的**：每张图缺失时都有下一级回退（见下表），五页流程照常。

## 待补齐文件清单

| 文件名 | 内容 | 规格 | 缺图回退 |
|--------|------|------|----------|
| `logo.webp` | 航海徽标（罗盘玫瑰 + 白色三桅帆船剪影） | 宽约 800px，**透明底** | 徽标块隐藏，只剩文字标题 |
| `port-docked.webp` | 港口停泊（帆收起、船靠岸），首页 hero + 出港页第一帧 | 1600×900 | 退到 `harbor.webp` |
| `port-sail.webp` | 扬帆出港（帆张满、船离岸），出港页第二帧，**与上一张同机位** | 1600×900 | 退到 `harbor.webp` |
| `harbor.webp` | 旧港兜底（任意 17 世纪欧洲港口远景） | 1600×900 | 纯主题渐变底 |
| `chart.webp` | 海图纸纹（羊皮纸 + 淡经纬网，**低对比**） | 800×800，可平铺 | 卡片底纹退纯渐变 |
| `route-merchant.webp` | 商船航路横幅（琥珀金） | 1200×400 | 退海图纸纹 → 主题渐变 |
| `route-warship.webp` | 战舰航路横幅（炮铜红） | 1200×400 | 同上 |
| `route-explorer.webp` | 探险航路横幅（深海青） | 1200×400 | 同上 |
| `route-lineage.webp` | 风帆谱系横幅（海绿） | 1200×400 | 同上 |
| `route-custom.webp` | 自选航路横幅（羊皮纸橙） | 1200×400 | 同上 |
| `port-docked-portrait.webp` | 港口停泊·竖版（竖屏优先使用） | 1080×1920（1:2 更满） | 自动退横版 |
| `port-sail-portrait.webp` | 扬帆出港·竖版（竖屏优先使用） | 1080×1920（1:2 更满） | 自动退横版 |

单张 ≤ 200KB（徽标 ≤ 60KB）。`port-docked` 与 `port-sail` 必须**同机位同光位**，
否则出港页的交叉淡化会跳。
