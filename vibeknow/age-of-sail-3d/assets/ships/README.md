# assets/ships/ —— 帆船图位（已出图）

本目录放 **30 张帆船图**，文件名与 `assets/ships.js` 里每条记录的 `img` 字段一一对应。
✅ 30 张全部出齐（512×512 WebP，全套约 1.07 MB，单张 28–44 KB）。
规格、统一风格前缀、**逐条可照抄的提示词**见 [`../../docs/帆船图片素材需求.md`](../../docs/帆船图片素材需求.md)。

- 规格：**512×512（1:1 方图）**、WebP 质量 80、单张 ≤ 80KB、全套 ≤ 2.5MB
- 主体居中、四周留约 12% 空白；3/4 侧前方视角；桅顶与吃水线都要在画面内
- 无文字、无人物、无水印、无现代船只

**本目录为空是正常的**：`img` 缺失或加载失败时，页面自动回退到该船的 `color` 色卡，
五页流程照常。图片可以分批补，`img` 一到位就生效，不用改代码。
