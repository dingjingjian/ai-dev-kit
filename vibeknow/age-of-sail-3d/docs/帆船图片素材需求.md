## 二、① 帆船图 ×30

### 统一风格前缀（每条提示词都加在开头）

> 古典帆船复原图，船舶模型册 / 海洋博物馆展板质感，
> 3/4 侧前方视角（船首略朝画面左前方），整艘船完整入画（桅顶、帆、吃水线与一小片海面倒影都在画面内），
> 主体居中、四周留出约 12% 空白，帆已张满、绳索与滑轮清晰可辨，
> 船体结构准确（桅数、帆装、炮门数量与位置严格按描述），
> 平静海面、低饱和自然光、柔和天光、浅景深，
> 无人物、无手、无文字、无水印、无品牌标识、无比例尺人形、无现代船只。

### 构图要求（决定能否用）

- 画框是**正方形**（航海页 `.voyage-frame` 边长 `24vh`、88–190px），所以出 **1:1 方图**。
- **不要正俯视或正仰视**（桅杆会透视变形），3/4 侧前方或正侧视最稳。
- 桅顶与吃水线**都要留在画面内**，上下各留约 12% 余量——船图会被 `contain` 放进方框，裁掉桅顶最难看。
- 海面占画面下缘 1/5 左右即可，**不要**画成大浪或风暴（图鉴要"静"）。

### 27–30 日/朝四艘：可照抄提示词

这四艘**不是中式硬帆船**：27/28/29 是**和船**（平底、水押首、戸立尾、单桅一枚帆、靠**橹**推进），30 是**朝鲜板船**。

### 21–23 印度洋三艘：原型锚定版（可照抄提示词）

上一轮这三张的问题是：21 画成了**欧洲三桅横帆船**，22/23 画成了「**欧式全帆装盖伦 + 硬加一排桨**」，
和地中海 10 加莱塞、大西洋 17 盖伦撞脸；23 的「两排桨孔」「红海暖色海面」也没兑现。
根因是描述里写的是「三桅混合帆」「两桅方帆」这类**欧洲帆装词**——模型只会照着画盖伦。
下面这版把型号钉到**有文献原型的印度洋船型**上，逐条写死**桨 / 桅 / 帆 / 炮**，整段照抄即可。

## 三、硬约束

1. **单图不超过 80KB，全套 30 张不超过 2.5MB**。本项目是零依赖离线单文件工具，
   引入图片就是引入了体积，须按此上限控制。建议 **512×512、WebP 质量 80**。
2. **无文字、无人物、无水印、无品牌标识、无比例尺人形**。
   出现船名铭牌、人名、港口招牌或现代比例人，都会立刻破坏"博物馆船模册"的调性。
3. **色调统一**：低饱和、自然光、浅景深，暖木色船体 + 冷色海面，才能与页面的
   深海蓝 / 黄铜金 / 羊皮纸三色对得上；一张高饱和"海盗大片"风混进来就会破功。
4. **帆装必须逐条核对**：这是本套图最容易被模型画错的地方。

| 易错点 | 正确做法 |
|--------|----------|
| 全部画成"一张大横帆的通用帆船" | 三角帆（07/12/19/20）与横帆（01/05/06）在画面上必须明显不同 |
| 抢风船做成方帆 | 拉蒂纳 / 卡拉维尔 / 双桅三角帆船 / 独桅三角帆船一律**纵帆（三角帆）** |
| 把加莱类画成普通帆船 | 必须有**成排桨孔与入水桨叶**（08/10/11/22/23） |
| 战列舰只画一层炮门 | 06 必须**三层炮甲板、三排炮门**；05 才是单排 |
| 中国帆船（24–26）做成西洋船 | 一律**硬帆（竹肋撑开、帆面有明显横向分节）+ 高翘船尾**，索具少、横桁短 |
| 日本/朝鲜船（27–30）做成西洋船 | 一律**和船 / 板船船型**：**单桅一面布质方帆**（30 为两桅）、**两舷成排木橹入水**；**没有船首斜桅 / 顶帆 / 后桅 / 舷侧炮列 / 白色水线带 / 船首雕像**（硬帆只属 24–26） |
| 和船画成欧式船体 | 船首必须**水押**（尖喙状前伸）、船尾必须**竖直平截的户立**、平底浅吃水；28/29 甲板上要有**箱形总矢仓**，30 要有**龟背木顶盖 + 铁尖刺** |
| 印度洋 21/22/23 画成欧洲船 | 21 必须**两桅、每桅一张大三角帆**（不是三桅横帆船）；22/23 必须**成排木桨入水 + 舷墙旋回炮**，且**不能有欧洲式全帆装方帆与多层炮门**；照抄「21–23 原型锚定版」 |
| 画面四角出现模糊小字 / 签名 / 版权字样 | 生成残留，**一律重出**；提示词里写死「无签名、无角落小字」，交付前把四角与底边放大 6–8 倍自检 |
| 帆船停在台风里 | 海面平静、微澜即可，图鉴要"静" |

## 四、落位契约

### 目录约定

```
assets/
├── ships/          帆船图（30 张，<slug>.webp）
└── tex/            纹理与横幅（舰队横幅、港口两帧、海图纸纹、徽标）
```

### 代码契约

`assets/ships.js` 每条记录的 `img` 字段已写好路径：

```js
{name:'卡拉维尔帆船',cls:'small',country:'葡萄牙',yard:'拉各斯',lat:37.10,lon:-8.67,family:'atlantic',year:'1450',color:'#b08a5a',img:'./assets/ships/caravel.webp',
  ...}
```

### 缺图必须能跑

`img` 缺失或加载失败时，一律回退到该条记录的 `color` 色卡（径向渐变色盘），
**因此图片可以分批补、不必等 30 张齐了再上线**。这一点是硬要求，不要写成"必须有图"。

### 换图

只需**覆盖同名文件**，页面按文件名探测，无需改代码。
