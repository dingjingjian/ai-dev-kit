## 二、统一参照（重要）

这几张不要写成"某个古代港口"这种泛化描述，那样出来的就是"随便一座码头"。
提示词里直接点名 **16–17 世纪大航海时代（Age of Sail）的欧洲贸易港**，
按下面这份"识别锚点"逐条压：

| 锚点 | 要什么 | 不要什么 |
|------|--------|----------|
| **船** | 木造三桅帆船：方帆 + 三角帆混挂、绳索密布、船首斜桅 | 现代游艇、蒸汽船、钢铁船体、独木舟 |
| **码头** | 湿漉漉的石砌码头 / 木栈桥 + 系缆桩 + 成堆的木箱与酒桶与麻袋 | 集装箱、塔吊、柏油马路、汽车 |
| **桅杆林** | 远景密排的桅杆与横桁，港口的"森林感" | 只有一艘孤零零的船 |
| **建筑** | 山墙砖石仓库、钟楼、红瓦屋顶、酒馆招牌**无字** | 玻璃幕墙、现代高楼 |
| **色调** | 黎明或黄昏的暖金光 + 冷蓝海面，低饱和、不起雾过曝 | 高饱和卡通、正午死白强光 |
| **画面上部** | 天空**偏暗**（首页 hero 会 `cover` 裁切并压字） | 上部一片惨白 |

> ⚠️ **不要任何文字**：港口招牌、船名、旗帜上的字样一律不要。页面自己承担所有文案。
> 旗帜可以有颜色与纹样，但必须是无字的色块。

## 三、② 航海徽标 `logo.webp`

压在首页港口图上方，是"大航海时代 · 帆船图鉴"的视觉标识。

- **尺寸**：宽 800px 左右，透明底，保留上下留白
- **画面**：正圆细线外环（双线，黄铜金 `#b0894a`）→ 环内一枚**八角罗盘玫瑰**（同色金）→
  正中叠加**白色三桅帆船正侧剪影**（船首朝左，桅杆与横帆轮廓清晰可辨）
- **要点**：扁平矢量感、边缘干净、只有金色与白色两色；
  **不要外框色块、不要背景、不要渐变、不要立体金属质感**
- **缺图回退**：整块徽标隐藏，只留文字标题

**提示词**（照抄可用）：

> 透明背景大航海时代主题徽标：正圆细线双环外框，环内为八角罗盘玫瑰（航海罗盘星芒），
> 罗盘正中叠加一艘白色三桅帆船正侧剪影（船首朝左，桅杆、方帆与三角帆、船首斜桅轮廓清晰），
> 黄铜金色（#b0894a）线条配纯白帆船剪影，
> 极简扁平矢量风格，构图居中对称，边缘锐利，
> 无描边色块、无背景、无渐变、无立体质感、无任何文字、无水印。

**常见问题**：

| 症状 | 原因 | 怎么改 |
|------|------|--------|
| 徽标是灰的/带渐变 | 加了"金属质感""立体" | 只留"黄铜金线条 + 纯白剪影"两个色 |
| 帆船糊成一团 | 分辨率低或船太满 | 要求"桅杆与横帆轮廓可辨"，船缩到环内约 2/3 |
| 出了 `VOYAGE` 之类英文 | 模型自动补字 | 明确写"无任何文字" |
| 背景是白/黑块 | 没给透明底 | 强调"透明背景 alpha channel"，导出 PNG 后转 WebP |
| 罗盘方了 | 没说外框形状 | 明确"正圆细线双环" |

### ⑧⑨ 竖屏版（**唯一在用**，移动端优先）

竖版两帧就是出港页的**两个关键帧**，代码只挂竖版一套（不切横版），横屏由 `cover` 裁上下。

- 文件名**必须**与上表完全一致：`port-docked-portrait.webp` / `port-sail-portrait.webp`
- 建议 **1080×2160（1:2）**：手机 9:19.5 屏上 `contain` 后只剩上下各约 3% 的信箱边
- 缺图该层 404，自动落 `harbor.webp` 兜底

> ⚠️ **第一版失败案例（2026-09）**：两帧**前后没有关系** —— ⑧ 是"沿码头看船的侧后视角"、⑨ 是"正对船尾的越肩视角"，
> 港口建筑、地平线高度、船在画面里的大小全都不一样，7 秒交叉淡化时像换了个地方。
> 根因：两帧**分别独立生成**，提示词只写了"完全相同机位"这类形容词，没给**可核对的锁定项**。
> 第二版改成：**先出 ⑧，再用 ⑧ 图生图出 ⑨**，并给出镜头参数、锁定清单与差分清单。

**竖构图要点**（横版那套锚点全部沿用，只改机位与留白）：

| 位置 | 放什么 | 为什么 |
|------|--------|--------|
| 画面上 10% | 天空 / 桅杆顶端 / 云，**不放关键元素** | 手机状态栏、刘海会压住这里 |
| 画面 30%–62% | **帆船主体**（船身与张满的帆），中上偏左（与下面的锁定表一致） | 视觉中心，且避开顶部与底部 |
| 画面 62%–88% | 码头前沿与水面 | **字幕就压在这块**，须暗、须空 |
| 画面左右 8% | 水面 / 建筑留白 | 保证船首尾完整不被裁 |

**机位与画面锁定（两帧共用的硬参数，写进提示词、也用来核对）**：

| 项 | 锁定值 |
|----|--------|
| 机位 | 站在**码头末端**、人眼高度（约 1.5 m），**平视**，不俯不仰 |
| 镜头 | 35 mm 等效、无畸变，竖构图 9:16 |
| 地平线 | 落在画面 **44%** 高度处，上下留白对称 |
| 主体位 | 帆船在画面**中上偏左**、**船首朝画面右前方**（出港方向），桅顶不顶边 |
| 前景 | 画面下三分之一：湿石码头前沿 + 一列**系缆木桩**（左右各露一部分）+ 木箱酒桶 |
| 远景 | 山墙仓库轮廓 + 一座钟楼 + 木桅杆林，**逐帧位置不变** |
| 光 | 黄昏暖金光，太阳在**画面左上**，光源方位与色温逐帧不变；冷蓝海面 |
| 空档 | 船与码头之间留一片水面，⑨ 里船驶进这片水面 |

**⑧ 港口停泊（提示词）**：

> 竖构图 9:16，17 世纪欧洲木帆船港湾，厚涂油画质感，平视机位、相机高度约人眼 1.5 米，
> 远景地平线在画面 44% 高度，镜头 35mm 无畸变；
> 一艘三桅木造帆船位于画面中上偏左、**船首朝画面右前方**、**帆已收起卷在横桁上**、缆绳系在码头木桩上，桅顶不顶边；
> 画面下三分之一是湿漉漉的石砌码头前沿、一列系缆木桩（左右各露一部分）、堆放木箱与酒桶；
> 左右两侧留出水面与山墙仓库，远景是一座钟楼与密排木桅杆；太阳在画面左上、黄昏暖金光 + 冷蓝海面；
> 低饱和自然光、浅景深，**画面上部天空偏暗**；
> 无文字、无水印、无人物、无现代船只、无任何 19 世纪以后的构件。

**⑨ 扬帆出港（提示词）—— 拿 ⑧ 做图生图，不要重新生成**：

> 与输入图**完全相同的机位、镜头、地平线高度、码头轮廓、系缆桩位置、远景建筑与钟楼、太阳方位与色温**；
> 只做四处改动：① 帆从"卷在横桁上"改成"**全部张满鼓风**"；
> ② 缆绳已解、收回船上，**系缆桩空着**；
> ③ 船身**驶离泊位约一个船宽**、进入船与码头之间那片水面，船首仍朝画面右前方；
> ④ 平静水面留下**散开的尾迹**；
> 其余一切（码头石缝、木箱数量与位置、云、光斑）保持不变。
> 无文字、无水印、无人物、无现代船只。

> **出图顺序**：⑧ 定稿 → 用 ⑧ 做图生图（img2img，强度 0.35–0.5）出 ⑨ → 只改上面那四处。
> **交付前叠图自查**：把两帧叠在一起快速切换，**码头前沿线、系缆桩、钟楼、地平线**这四处必须重合；
> 有一处错位就重出 ⑨ —— 交叉淡化跳不跳，全看这四处。
> **退路**：若模型始终压不齐，就把出港页改成"**单帧 ⑧ + 缓慢推近**" —— 去掉 `.depart-shot.open`
> 与 `.depart-bg.open` 两层，并把 `shotClosed` 的透明度改成**全程为 1**（只留推近，不再淡出），
> 宁可不换帧，也不要跳帧。

## 五、⑥ 海图纸纹 `chart.webp`

- **落地**：航路卡片与控制栏的底纹（`background-size:190px auto; background-repeat:repeat`）
- **画面**：泛黄羊皮纸质感，**极淡**的经纬网与海岸线，角落一个模糊的罗盘玫瑰水印，纸面有轻微污渍与折痕
- **关键**：**对比度要低**。这层上面还要压文字与暗化渐变，纹样太抢会把卡片读成"贴纸"。
  整张图的明度波动控制在 ±8% 以内，噪点与污渍不要有锐利边缘
- **可平铺**：四边需能无缝拼接；做不到无缝就做成"看不出接缝"的低对比纹理
- **缺图回退**：卡片底纹退到纯主题渐变

**提示词**（照抄可用）：

> 无色相偏向的泛黄羊皮纸纹理，极低对比度：纸面纤维与轻微污渍、淡淡折痕，
> 极浅的经纬网格线与零星海岸线轮廓，角落一枚模糊的罗盘玫瑰水印，
> 整体明度均匀、无锐利边缘、无强阴影、无文字，
> 可无缝平铺的纹理贴图，俯视平铺，无透视。
