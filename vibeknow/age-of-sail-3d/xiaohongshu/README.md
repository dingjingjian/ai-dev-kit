# xiaohongshu/ — 小红书参赛与宣传素材

本目录存放「大航海时代 · 帆船图鉴」的小红书 vibecoding 大赛参赛 / 宣传素材。
**这些素材不进入小工具 zip**——zip 仅含 `index.html` + `assets/`（由 `pack.mjs` 产出）。

## 目录内容

- `笔记文案.md` —— 参赛笔记的标题 + 正文 + 话题标签，直接照抄或微调即可发布。

## 封面 / 海报建议

- **首图优先用工具内实机截图**：航海页（海图图鉴画面 + 地球标注建造地）信息量最高；
  次选出港页的 `assets/tex/port-sail-portrait.webp`（扬帆离港）或首页 hero 轮播图作氛围封面。
- **截图方式**：浏览器打开 `index.html`，进「航海页」后用系统截图；竖版 9:16 最适配小红书信息流。
- 如需 AI 出图封面，风格前缀与硬约束见 `docs/场景与横幅配图需求.md`。

## 发布步骤

1. 取仓库打包产物 `age-of-sail-3d.zip`（zip 根即 `index.html`），上传为小红书小工具；
2. 新建笔记，挂载该小工具；
3. 复制 `笔记文案.md` 的标题 / 正文，带 `#小红书vibecoding大赛` + `#vibeknow` 发布。

> 赛事背景、赛道划分与奖励金额以仓库根目录 `小红书vibecoding大赛-官方启动文案.md` 为唯一真源，本文不另行维护副本。
