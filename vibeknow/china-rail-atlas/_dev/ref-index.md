# 参考照片索引（生图参考）

照片以 Wikimedia Commons 为主（可溯源、可自由使用的授权）；
个别条目使用**用户提供**或官方站点图，来源与许可在表中逐张标注。
全部照片仅作生图造型参考，不随项目分发。每个条目 1–3 张，
落盘于 `_dev/ref/<条目id>-NN.jpg`。

「外观要点」是看图提炼的关键特征，生成插画时应写进提示词或据此校对。

> 分类封面（`cover-*`）**不指定参考照片**：现版封面画的是铁路物件聚成的一景
>（动轮与连杆、车厢门与皮箱、麻袋与木箱、站台雨棚与站台灯……），
> 组景描述见 `main.js` 的 `COVER_SUBJECTS`，按文字要点生图即可。
> 表中 `cover-pax` / `cover-station` 两行是旧版「多件并排」封面留下的备用照片，现已停用。
