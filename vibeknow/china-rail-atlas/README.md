# 中国铁路发展图鉴 · China Rail Atlas

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

一部中国铁路的图鉴：从龙号机车到复兴号、从 22 型绿皮车到 25T 型空调车、从敞车棚车到长大货物车，再到哈尔滨站到上海虹桥站。收录 **50 个具体型号 / 车站 + 4 张分类封面 = 54 张图**，按 **火车头 / 客运车厢 / 货运车厢 / 著名车站** 四类分组，类内从早到晚排列，串成一条中国铁路的发展线索。纯前端零依赖、离线可用，已适配小红书小工具容器。

**收录口径**：写**具体型号**（如「东风4型内燃机车」「25G 型客车」「C70 型敞车」「北京站」），不写泛泛的「电力机车」「客车」。每个条目描述的是一台可指认的实车 / 一座可指认的站房，造型识别点（轮式、车体轮廓、车窗排布、涂装色带、受电弓数量、站房屋顶）都写进配图要点，让生出来的图一眼能认出型号。

## 打开方式

双击 `index.html`，或打包后上传小红书小工具（`node ../../tools/build.mjs --pack`）。

## 功能

- **列表页**：四类分组，每组顶部为分类封面图，下面为该类的条目卡片（配图 + 年代 + 中文名 + 英文名 + 一句话特点）。
- **分类筛选**：顶栏 tab 用 2 字短名（全部 / 机车 / 客车 / 货车 / 车站），窄屏单行放下。
- **年代线索**：卡片与详情页标注**问世年代**，一眼看出这台车 / 这座站在铁路史中的位置。
- **详情页**：配图大图、分类与年代徽标、介绍、关键参数、亮点清单、配图文件路径。
- **配图占位**：图片未就位时显示虚线占位块，补图不需要改一行代码——把 `<base>.webp` 放进 `assets/img/` 即自动覆盖。
- **路由**：hash 路由（`#/` 列表、`#/v/<id>` 详情），适配容器无跳转限制。
- **分享到小红书**：详情页一枚按钮，分享图是 Canvas 现场合成的竖版分享卡（顶部通栏配图 + 深绿底文字区，版式对齐 nobel-atlas），正文按「【名称】分类 · 类型 + 介绍 + 年代 + 关键参数 + 落款 + 话题」组织，一键唤起 App 的笔记发布页。只有容器里拿得到 `postNote` 时才出现。
- **返回原位**：从详情返回列表时回到离开时的滚动位置与分类。
- **移动端优先**：竖屏单列（窄屏以上两列）、大字号、安全区适配、触摸友好。

## 分享到小红书（详情页）

tagline 下方一枚「分享到小红书」按钮：**图文是 Canvas 现场合成的竖版分享卡，正文按「【名称】分类 · 类型 + 介绍 + 年代 + 关键参数 + 落款 + 话题」组织**。只有容器里拿得到 `postNote` 时才建出来。

| 项 | 说明 |
|------|------|
| 触发 | 详情页按钮，由用户手势触发（容器要求） |
| 分享卡 | Canvas 合成的 1080×1440 竖版（3:4）：顶部通栏铺详情页**已经加载好的那张原图**（cover 裁切 + 下缘渐隐），下方深绿底文字区放「分类 · 类型 / 年代 / 名称 / 一句话亮点 / 正文（最多三行）/ 关键参数（最多两行）/ 标签胶囊」，页脚品牌——版式对齐 nobel-atlas，文字全部落在纯底色上，不与配图交叠 |
| 为什么不用 XHR 取原字节 | 本仓 skill 的 `device-capabilities.md` §4/§7 把网络请求 API 列为**不可用行为**并进了扫描清单（连标识符都不许出现，打包守卫会 grep），所以分享图改走 Canvas 现场合成——代价是重编码一次（1080×1440 的 JPEG 0.92，data:uri 后在几百 KB 量级），换来一行被禁 API 都不用。容器里页面与图同源，画布不会被污染 |
| 落文件 | 有 `writeTempFile` 就先把 `data:uri` 换成临时 `filePath` 再交给 `postNote`；没有则直接把完整 `data:uri` 传进 `mediaInfo`（`jsbridge-api.md` 允许 base64） |
| 参数 | `pageType:"photo_publish"` · `title` ≤20（`<条目名> · <分类短名>`，直接裁尾）· `content` ≤1000 · `mediaInfo.image_resources[0].url`（两处上限都主动裁剪） |
| 能力检测 | 拿不到 `postNote` 就整块隐藏（桌面直接开 `index.html` 不出现、测试里也是这条断言）；**不做 UA / 机型判断** |
| 原图未就位 | 按钮压暗且不可点（lazy 加载晚于渲染，图片 `load` 后自动转可用；后缀回退链在换下一个后缀时不误判成失败） |
| 结果语义 | `postNote` 成功只代表**发布页被唤起**、用户点了发布，**不代表过审** —— 所以只提示「已唤起」，不据此改任何状态 |

## 参考照片与配图流水线

- **参考照片已就位**：51 个条目已在 `ref/` 落盘 1–3 张照片（共 134 张，多数来源 Wikimedia Commons、可溯源；CRH2 的 2 张为用户提供），逐张来源与许可见 [`tools/ref-index.md`](tools/ref-index.md)。
- **外观要点已提炼**：每个条目的造型识别点写在 `tools/ref_notes.json`，并汇总进 [`tools/ref-index.md`](tools/ref-index.md) 的「外观要点」列，供生图时写进提示词或校对。
- **配图施工图**：逐张的「风格串 + 主体描述 + 完整提示词 + 参考照片」由 [`tools/gen_image_prompts.py`](tools/gen_image_prompts.py) 从 `main.js` 派生到 [`tools/IMAGE_PROMPTS.md`](tools/IMAGE_PROMPTS.md)。改条目数据改 `main.js`，重跑脚本即可同步。
- **风格分两层**：条目图（50 张）是**图鉴式插画**（正侧视 / 正立面、浅暖白底、信息优先）；分类封面（4 张）是**写实棚拍静物小品**（同一片浅暖白底、氛围优先）——封面把该类别的铁路物件**聚成一景**（一景一图，不是一排摆件）：动轮与连杆 + 煤堆铁锹 / 车厢门 + 皮箱与搪瓷缸 / 敞车侧板 + 麻袋木箱 / 站台雨棚 + 站台灯木椅行李车。**不画具体车型**：封面显示框约 3.4:1 塞不下整车，硬塞只会把车厢压短，而认型号本来就是条目图的活。四张共用一套配方（同底色、同光位、同正交视角、同样的主件 + 陪衬结构），所以看起来是一个系列。风格串与组景描述都在 `main.js`（`IMG_STYLE_COVER*` / `COVER_SUBJECTS`），要求在 [`tools/image-spec.md`](tools/image-spec.md)。
- **生图后处理**：生成图落到 `.work/raw_img/<base>.png`（或 jpg），跑 `python tools/process_images.py` 自动缩放 + 转 WebP + 压体积到预算（条目图 ≤45 KB、封面 ≤90 KB、合计 ≤2 MB），输出到 `assets/img/`。

> 4 个分类封面是**铁路物件聚成的静物小品**（不画具体车型，也不指定参考照片，组景描述见 `main.js` 的 `COVER_SUBJECTS`）；CRH2 的参考照片由用户提供，K18 漏斗车在 Commons 无库存照、按文字要点生图。其余无库存型号（G60→GHK 系列、P64→P70、D26→DQ45）已在 ref-index 注明近似来源。

## 目录结构

```
china-rail-atlas/
├── index.html              # 单文件图鉴（列表 + 详情 + 占位块）
├── main.js                 # 数据真源：CATS / ITEMS / 四条风格串（IMG_STYLE / _ARCH / _COVER / _COVER_ARCH）
├── assets/img/             # 生成的 .webp 落位处（含 README 说明）
├── tools/                  ← 构建 / 打包脚本
└── tests/                  ← 验证 / 冒烟脚本
    ├── image-spec.md       # 配图交付要求（唯一真源）
    ├── gen_image_prompts.py
    ├── gen_ref_index.py
    ├── fetch_refs.py       # 参考照片抓取（Wikimedia Commons）
    ├── process_images.py   # 原图 → WebP 压图

    ├── ref/                # 132 张参考照片 + _meta.json（不随站点分发）
    ├── shot_check.py       # 渲染自检（含分享链路：注入桥桩验 postNote）
    ├── ref_notes.json      # 逐条外观要点
    ├── ref-index.md        # 参考照片索引
    └── IMAGE_PROMPTS.md    # 配图施工图
```
