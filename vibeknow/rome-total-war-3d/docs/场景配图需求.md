## 二、② 图鉴 logo（军牌式）

**显示环境**：`height:82px`、`width:auto`、`background-size:contain`、居中靠下，
上面压着标题「罗马军团图鉴」与小字「SPQR · LEGIONVM CODEX」；实际显示约 **123×82px**。

**这一张是「军牌」，不是抠空的图形**（2026-09-22 改）：logo 以一枚**带底板的军牌**出现——
底板、描边、徽章三层一起画进图里，**不要求透明底**。
原来的「透明底 WebP」要求已经取消：出图模型交上来的「透明底」实际是白底/棋盘底，
文件里没有 alpha 通道，压在 hero 上就是一块生白块，比有底还难看。既然底色跑不掉，就把它做成**有意为之**。

- **画幅 512×340**（约 3:2），**满幅出图**，四角**直角**；不要圆角、不要投影、不要外发光
  ——页面会给这一块加两层 `drop-shadow`，自带投影会叠成双影。
- **底板**：**深色石质**——近 `#1b1512`–`#2a211a` 的暗棕石 / 玄武岩，带极细的磨石纹理；
  明度要和页面 hero 上那层暗化渐变同一档，**不能有亮色边**（现在那版是纯白底，就是这个问题）。
- **描边**：**暗金细线**（`#c9a13b`，1–2px 即可；可在四角收一个细小的内折角）。
  这是「军牌」的识别特征，也是它和「一块底色」的区别；不要双线、不要繁复花纹。
- **徽章**：一枚居中的**罗马军团鹰旗（aquila）**——站立的鹰立在旗杆顶端，下方月桂环。
  金色 `#c9a13b` + 大理石白 `#f3ede1` 双色，扁平带轻微浮雕感。
- **只出图形，不出文字**。SPQR 这几个字母由页面自己的文字层负责，
  交给生图模型写字母几乎必错，不要赌。
- 实际只显示 123×82px，**细节一律删掉**：鹰的羽毛层次保留三层就够，多了会糊成一团。
- 徽章在牌面里**居中**，四周留 10–12% 内边距，别顶到描边上。

> 提示词要点：罗马军团鹰旗徽章，深色石质军牌底板，暗金细描边，单只立鹰站于旗杆顶端、
> 下方月桂环，金色与大理石白双色，扁平带轻微浮雕感，徽章居中、四周留内边距，
> 无文字无字母无水印，直角方形画幅

## 三、⑨ 过渡画面 ×9（「即将检阅」页的主素材）

**这一页是什么**：选完阵营点进检阅之间，整整 7.1 秒的一屏——一帧画面 + 缓慢推近，
画面上压着「阵营名 / 拉丁名 / 即将检阅 · N 队」三行字幕。**它按你选中的阵营换图**，
是这一页唯一随阵营变化的东西，所以「九张之间画面统一、彼此又认得出来」比单张多漂亮更重要。

**显示环境**：

- `.gate-shot` 用 **`background-size:cover` 铺满整屏**（2026-09-22 由 contain 改过来）：
  横屏竖屏都**不留上下横边**，代价是竖屏会**裁掉左右两侧**——
  所以**入口/门必须落在画面正中**，裁掉的只能是两边的余景。
  裁切量：竖屏（约 9:19）在 16:9 源图上只保留横向中间约 30%，主体必须在这个区间里。
- 字幕压在下三分之一：**画面下三分之一留出干净的暗部**，别在那儿放主体或高亮。
- 九张之间**同一机位、同一光位**（夕阳左后方逆光、门洞内最深）——换阵营时是硬切，
  机位或光位一变就会跳。
- **九张的「主体位置」也要对齐**（同机位只是前提，位置还得落到同一个坐标上）：
  **入口（门洞 / 闸口）中心落在画面中线 ±1%**、**入口整扇高度占画面 55%±3%**、
  **地平线统一在画面高度 62%±3%**、相机高度与焦距九张一致。
  换阵营是一次硬切，位置差 3% 以上就看得出来「门跳了一下」；允许变的只有建筑形制、材质与色调。
- ⑨ 缺图时页面退到**该阵营横幅（⑧）**，不会开天窗。
  旧的「通用凯旋门」兜底已整组退役（八、），画面链只剩这两层。

**内容**：该阵营的**进入地标**——军营正门 / 城门 / 关隘 / 港闸之类，正面中轴视角、
入口整扇完整可见，远处带一点该阵营的营区或队列纵深；前景可以放一两个旗号或兵士剪影，
**人不要大、不要正对镜头**。

> 提示词要点（每张替换方括号内容）：
> 古代军营地标远景，[画面内容]，正对入口的中轴视角，入口在画面正中、整扇完整可见，
> 入口中心落在画面中线（偏差不超过画面宽度 1%），入口整扇高度约占画面 55%，
> 地平线统一在画面高度 62%，相机高度与焦距固定、九张构图位置一致，
> 低饱和暗调，浅景深，[阵营色调]，夕阳左后方逆光、入口洞内最深，地面有长投影，
> 画面下三分之一留出干净的暗部，无文字无水印无人物特写无现代物件，
> 整屏横构图 16:9，源图 1600×900

## 四、⑦ 大理石纹理 `marble.webp`

**显示环境**：`background-size:190px auto`、`repeat`，作为阵营卡片、控制栏的底纹层。

- **必须可无缝平铺**。生成后先自己拼 2×2 看接缝，接缝明显就换一张——
  平铺纹理最容易翻车的就是这一条。
- 512×512，米白 / 暖灰的卡拉拉大理石，纹路细浅、对比低。
  它是**背景中的背景**，纹路太抢会把卡片文字吃掉。
- 整体偏暗更好：页面上叠在上面的是一层 84% 的暗化渐变，纹路只透出一点点。

> 提示词要点：白色卡拉拉大理石纹理，细浅灰色脉络，低对比，柔光，
> 无缝平铺纹理，无接缝无方向性无污渍，正方形

## 五、⑧ 阵营横幅 ×9

**显示环境**：阵营卡片的底图，`cover` 铺满。卡片最宽 820px、高约 160–180px；
手机上约 420×170。图上压着一条横向暗化渐变：

```
linear-gradient(90deg, rgba(8,7,6,.84) 0%, rgba(8,7,6,.48) 60%, rgba(8,7,6,.20) 100%)
```

即**左侧最暗、右侧最亮**，而卡名、拉丁名、简介文字都在**左侧**。
所以构图铁律：**视觉焦点放在画面中间偏右（约 55–75% 区间）**，左侧留出干净的暗部给文字。

**但它同时又是首页 hero 的轮播图**（八大军团各一张，8s 一格纯 CSS 交叉淡化）：
hero 是窄而矮的通栏，用 `cover` 会**左右各裁掉约 1/4**（只保留中间约 23%–77% 的横向区间）。
焦点再往右压（进入 80% 以后）在卡片上好看，在 hero 里会被裁掉——这就是为什么焦点收在中间偏右。

- 尺寸 1600×600，**低饱和、暗调**，不要人脸特写、不要文字、不要旗帜上的字母。
- 每张按阵营色调走（见 [`兵种图片素材需求.md`](兵种图片素材需求.md) 三·3 的阵营色调表），

- 建议尺度是"远景 + 剪影"：远处的城、山、林，前景放一两个士兵或旗号的剪影，
  人不要大、不要正对镜头。

## 六、硬约束

1. **体积**：logo ≤40KB，大理石 ≤60KB，阵营横幅各 ≤120KB；
   **过渡画面各 ≤110KB、⑨ 全套 ≤0.9MB**；**场景图全套不超过 2.7MB**。
2. **无文字、无水印、无品牌标识**。logo 是唯一带底板的图（军牌式，见 二、），
   但也**只出图形、不出文字**——字母交给页面文字层。
3. **年代不穿帮**：不出现马镫、全身板甲、十字弓、火器、现代建筑与电线。
   **也不许出现任何现代物件**（相机、镜头、三脚架、绳索护栏……）——
   旧的通用凯旋门那几张就是栽在这条上（见 八、）。
4. **⑨ 九张之间必须同机位、同光位**（夕阳左后方逆光、入口洞内最深），
   并且**主体位置对齐**（入口居中 ±1%、入口占高 55%±3%、地平线 62%±3%，见 三、）。
   换阵营时这一页是一次硬切，机位、光位或位置一变就会跳。
5. **大理石必须能无缝平铺**，阵营横幅焦点必须落在画面中部（约 55–75%，见 五、）。

## 七、落位契约

```
assets/tex/logo.webp
assets/tex/marble.webp               可平铺大理石
assets/tex/faction-<key>.webp        阵营横幅 ×9（key 见上表；同时作首页 hero 轮播 ×8）
```

文件名与 `index.html` 里的 `url()` **逐一对应**，不要改拼写。
`faction-<key>.webp` 的 `<key>` 必须等于 `units.js` 中 `FACTIONS[].key`，
自选军团用 `custom`——写错 key 会静默回退到大理石，看不出报错。

落位后校验：

```bash
node tools/check_data.js      # 含图位齐全检查 + 退役图位防回归

```
