> 两处只要各出一张；原 ④ `gate-open`（横）与竖版第二帧**已取消**。

## 二、② 图鉴 logo

**显示环境**：`height:82px`、`width:auto`、`background-size:contain`、居中靠下，
上面压着标题「罗马军团图鉴」与小字「SPQR · LEGIONVM CODEX」。

- 必须是**透明底 WebP**，不能带白底或方角背景——它压在有图的 hero 上。
- **只出图形，不出文字**。SPQR 这几个字母由页面自己的文字层负责，
  交给生图模型写字母几乎必错，不要赌。
- 图形控制在**一个能认出来的符号**：罗马军团鹰旗（aquila）——一只站立的鹰立在旗杆顶端，
  下方桂冠环，可加一对交叉的短剑或一面盾形轮廓做底。
- 实际只显示约 123×82px，**细节一律删掉**。鹰的羽毛层次保留三层就够，多了会糊成一团。
- 单色或双色（金 `#c9a13b` + 大理石白 `#f3ede1`）最稳；页面会给它加深色投影。

> 提示词要点：罗马军团鹰旗徽章，单只立鹰站于旗杆顶端，下方月桂环，金色与大理石白双色，
> 极简徽章设计，透明背景，无文字，扁平带轻微浮雕感，边缘干净

## 三、③ 凯旋门单帧（横版）

**视频缺失时的兜底画面**：一帧 + 7 秒缓推（`scale(1) → scale(1.5)`）。
只有一帧，所以**不再有「两帧必须同机位」这件事**；但这一帧要和过渡视频的首帧同一道门、同一光位。

### ③ `gate-front.webp` —— 门在外面

- 正对凯旋门的**正面视角**，三开间拱门（中间大、两侧小）完整入画，门洞是暗的深景。
- 相机在军道上、视平线略低于门基，门占画面高度约 70%，左右留出街道与建筑剪影。
- 光位固定为**左侧逆光**（过渡视频的首帧也按这个来）：夕阳从左后方来，
  立面左侧亮、门洞内最深，地面有长投影。
- 构图**左右对称、门居中**：这一页只有它一个画面主体，画偏了没有第二帧来补救。

> 提示词要点：
> 古罗马凯旋门，三开间拱门，石灰华大理石立面，正面视角，相机在军道正中，
> 夕阳左后方逆光，立面左侧受光、门洞内深邃，地面长投影，
> 写实历史插画质感，低饱和，浅景深，无文字无铭文无人物特写无现代物件，
> 门完整可见，尚未穿行，门洞是暗的深景

## 四、⑤ 凯旋门竖版单帧（可选）

**显示环境**：`orientation:portrait` 时优先加载，`.gate-shot` 用 `contain`，
门必须**完整可见、不裁立柱**。竖版缺失时纯 CSS 自动落回横版（该层 404 即跳过），不影响功能。

- 尺寸 900×1400（约 9:14），与 ③ **同机位同光位**——可以视为把横版重新竖构图，
  但门的位置、比例、光照方向必须一致。
- 竖构图里门占画面高度约 55%，上下留出天空与军道，避免顶天立地。
- **只有一帧**，不需要「穿行」的第二张。

> 提示词要点：与 ③ 完全相同的前缀，追加「竖幅构图，9:14，凯旋门完整入画，
> 上方留天空，下方留军道纵深」

## 五、⑥ 兜底内景 `gate.webp`

- 只用在前五张全缺时的最底层，横版 1600×900 即可。
- 内容随意一些：凯旋门内景、军道、或罗马广场的柱廊。**暗调**，因为它上面还可能压别的层。
- 这一张可以最后补，也可以直接不做——没有它，页面退到纯色渐变，仍然完整可用。

## 六、⑦ 大理石纹理 `marble.webp`

**显示环境**：`background-size:190px auto`、`repeat`，作为阵营卡片、控制栏的底纹层。

- **必须可无缝平铺**。生成后先自己拼 2×2 看接缝，接缝明显就换一张——
  平铺纹理最容易翻车的就是这一条。
- 512×512，米白 / 暖灰的卡拉拉大理石，纹路细浅、对比低。
  它是**背景中的背景**，纹路太抢会把卡片文字吃掉。
- 整体偏暗更好：页面上叠在上面的是一层 84% 的暗化渐变，纹路只透出一点点。

> 提示词要点：白色卡拉拉大理石纹理，细浅灰色脉络，低对比，柔光，
> 无缝平铺纹理，无接缝无方向性无污渍，正方形

## 七、⑧ 阵营横幅 ×9

**显示环境**：阵营卡片的底图，`cover` 铺满。卡片最宽 820px、高约 160–180px；
手机上约 420×170。图上压着一条横向暗化渐变：

```
linear-gradient(90deg, rgba(8,7,6,.84) 0%, rgba(8,7,6,.48) 60%, rgba(8,7,6,.20) 100%)
```

即**左侧最暗、右侧最亮**，而卡名、拉丁名、简介文字都在**左侧**。
所以构图铁律：**视觉焦点放在画面中间偏右（约 55–75% 区间）**，左侧留出干净的暗部给文字。

**但它同时又是首页 hero 的轮播图**（八大军团各一张，8s 一格纯 CSS 交叉淡化）：
hero 是窄而矮的通栏，用 `cover` 会**左右各裁掉约 1/4**（只保留中间约 23%–77% 的横向区间）。
焦点再往右压（进入 80% 以后）在卡片上好看，在 hero 里会被裁掉——这就是为什么焦点收在中间偏右。

- 尺寸 1600×600，**低饱和、暗调**，不要人脸特写、不要文字、不要旗帜上的字母。
- 每张按阵营色调走（见 [`兵种图片素材需求.md`](兵种图片素材需求.md) 三·3 的阵营色调表），
  与切换阵营时整页换装的主题色对得上。
- 建议尺度是"远景 + 剪影"：远处的城、山、林，前景放一两个士兵或旗号的剪影，
  人不要大、不要正对镜头。

## 八、硬约束

1. **体积**：logo ≤40KB，凯旋门横/竖各 ≤180KB，兜底 ≤150KB，大理石 ≤60KB，
   阵营横幅各 ≤120KB；**场景图全套不超过 1.8MB**。
2. **无文字、无水印、无品牌标识**，logo 除外但 logo 也只出图形（见第二节）。
3. **年代不穿帮**：不出现马镫、全身板甲、十字弓、火器、现代建筑与电线。
4. **③ 与过渡视频首帧必须同门同光位**——图片兜底只此一帧，它和视频之间是一次硬切，
   门换了、光位变了就会跳；竖版 ⑤ 与 ③ 也要同机位同光位。
5. **大理石必须能无缝平铺**，阵营横幅焦点必须落在画面中部（约 55–75%，见 §七）。

## 九、落位契约

```
assets/tex/logo.webp
assets/tex/gate-front.webp           横版 · 单帧（视频缺失时缓推）
assets/tex/gate-front-portrait.webp  竖版 · 单帧（可选，竖屏优先）
assets/tex/gate.webp                 兜底内景
assets/tex/marble.webp               可平铺大理石
assets/tex/faction-<key>.webp        阵营横幅 ×9（key 见上表；同时作首页 hero 轮播 ×8）
```

文件名与 `index.html` 里的 `url()` **逐一对应**，不要改拼写。
`faction-<key>.webp` 的 `<key>` 必须等于 `units.js` 中 `FACTIONS[].key`，
自选军团用 `custom`——写错 key 会静默回退到大理石，看不出报错。

落位后校验：

```bash
node tools/check_data.js      # 含图位齐全检查
python tools/smoke_test.py    # 五页流程无头冒烟
```
