# 兵种图片素材需求

本文列出「罗马军团图鉴 · 兵种志」中 48 张兵种图的图位、构图模板、逐条主体描述与提示词要点。
出图前请先读「二、显示环境」「三、统一风格」「五、硬约束」——这三节决定图能不能直接落位。

> logo、凯旋门、阵营横幅、大理石纹理**不在这里**，另见 [`场景配图需求.md`](场景配图需求.md)。
> 背景音乐另见 [`背景音乐需求.md`](背景音乐需求.md)。
> 生成顺序、后处理与体积核对见 [`素材生成说明.md`](素材生成说明.md)。

## 一、图位总览

| 编号 | 图位 | 数量 | 规格 | 落地位置 | 缺图时 |
|------|------|------|--------|----------|--------|
| ① | 兵种图 · 写实 | 48 | 1:1 方图 512×512，WebP | `assets/units/<id>.webp`，检阅页默认风格 | 回退 `units.js` 里的 `color` 色卡 |
| ①′ | 兵种图 · 兵牌 | 48 | 1:1 方图 512×512，WebP | `assets/units/card/<id>.webp`，检阅页切「兵牌」时用 | 同上（退回色卡） |

**两套是各自独立出图的**：写实走 §三 3.1/3.2 + §3.4 取景 + 每条各写的地景；
兵牌走 §三 3.5/3.6 + §3.8 半身取景 + §3.7 的固定暗底。
主体描述（§四）**两套共用**，差别只有「风格前缀 + 取景 + 背景」。
提示词由 `tools/gen_prompts.py` 一次生成，每条兵种给 4 段（写实 EN/CN + 兵牌 EN/CN）。

**优先级**：①（写实）决定观感跃迁，必须做；①′（兵牌）是可选增强——代码里已有「写实 / 兵牌」切换开关，
出了就能切、缺了就退色卡。两套都可以分批补，缺哪张就退哪张的色卡，页面照常跑。

## 二、显示环境（决定构图，务必先看）

检阅页的画框是**正方形**，边长随视口高度收缩：`24vh`，钳在 **88–190px** 之间（`index.html` 的 `.tour-frame`）。
图片以 `background-size:contain` 铺进去，所以：

- **方图正好填满方框**，不会被上下裁掉头脚——这是刻意选 1:1 的原因，不要出横图或竖图。
- **实际显示只有 88–190px**，细节会被吃掉。构图必须「少即是多」：
  一个主体、一件能认出来的武器、一块能认出来的盾，其余全部交给背景虚化。
- 画面四周留 **10–12% 空白余量**，别把人物顶到边——画框本身还有一圈金色描边与暗角，
  贴边会被暗角压掉一截。
- 图上会叠一层固定滤镜 `saturate(.82) contrast(1.10) brightness(.96) sepia(.10)`，
  出图时**不要再压饱和度**，否则成品会灰掉。宁可出得稍亮一点。
- **两套图（写实 / 兵牌）在同一个方框里显示**，所以兵牌那套也别做成横版卡片：
  它的差别在**画风、光照与取景**（见 §3.5 / §3.8），不在画幅。
- 兵牌的画风锚点是**《罗马 2：全面战争》原版兵牌**（写实古典半身像、低对比暗调）。
  原版是**竖版矩形**卡，本项目画框是方的，所以只借它的**半身取景与画风**——
  画幅仍是 1:1 方图，**不要出竖版**，也不要把原版的界面（边框纹样 / 血条 / 等级圆点）画进图里。

## 三、统一风格

### 3.1 风格前缀（每条提示词都加在开头）

> 古代军事历史插画，博物馆展板级的写实插画质感，
> 单人主体、3/4 侧身视角、姿态自然沉稳、不做夸张透视与英雄光效，
> 装备与服饰按考古复原绘制，金属有使用痕迹，布料有织物质感，
> 环境为同期地景并做浅景深虚化，自然光、侧逆光，
> 无文字、无铭牌、无水印、无品牌标识、无现代物件、无旗帜上的字母。

### 3.2 英文风格前缀（出图模型吃英文时用这一条，与上条等价）

> historically accurate ancient military illustration, museum exhibition plate quality,
> single figure, three-quarter view, calm natural stance, no heroic lighting,
> archaeologically reconstructed armour and clothing, worn metal, woven fabric texture,
> shallow depth of field with period landscape background, natural side-back light,
> no text, no watermark, no logo, no modern objects, no legible letters

### 3.4 构图模板（每条都指定 A / B / C）

| 模板 | 用于 | 构图 |
|------|------|------|
| **A** | 步兵 / 长矛兵 / 轻步兵 / 远程 | 单人 3/4 侧身，**膝以上入画**，头顶到膝约占画面高度 78%，武器完整可见 |
| **B** | 骑兵 / 弓骑兵 | 骑者与坐骑**整体入画**，马蹄到骑者头顶约占高度 82%，马头朝画面左侧 |
| **C** | 战象 / 战车 / 战犬 | 以兽或车为主体占画面宽度 85%；战象取**象头与前半身 + 象轿**的近景，不画全躯（画全躯在 88px 下会成一团） |

### 3.5 兵牌风格前缀（`assets/units/card/<id>.webp` 用，与 3.1 / 3.2 互斥）

画风锚点是**《罗马 2：全面战争》原版兵牌**：写实古典半身像、低对比暗调渲染，
造型语言取自古希腊红绘 / 黑绘陶瓶与古罗马石刻浮雕，偏**厚重油画质感**，
**不是纯线稿、不是卡通色块概括、不是强描边**。

| | 说明 |
|---|---|
| ✅ 画风锚点 | 《罗马 2》**原版**兵牌：写实古典半身像、低对比暗调、软光柔和过渡、厚重油画质感 |
| ❌ 不要画成 | Bullgod「牛神」MOD 那类玩家手绘兵牌：干净线稿、强明暗对比、锐利硬边（同题材的另一种流行画法，不是本项目参照） |

> 古罗马兵种单位卡插画，写实古典半身像，造型语言取自古希腊红绘陶瓶与古罗马石刻浮雕，
> 厚重油画质感，笔触收敛，不做线稿描边、不做卡通色块概括、不做锐利硬边，
> 单人主体居中、正面或微侧站立，姿态沉静肃穆、不做夸张动态与英雄光效，
> 头盔、甲胄、盾与主武器的识别特征都要完整交代，
> 软化均匀的散射光，明暗过渡柔和、对比度低、轮廓柔和，
> 整体暗沉低饱和，土褐、暗红、灰黑为主，
> 装备与服饰按考古复原绘制，金属有使用痕迹，布料有织物质感，
> 无文字、无铭牌、无水印、无品牌标识、无边框、无界面元素、无现代物件、无旗帜上的字母。

### 3.6 兵牌英文风格前缀（出图模型吃英文时用这一条，与上条等价）

> roman-era unit card illustration, realistic painted half-body portrait in the classical-antiquity tradition,
> forms and drapery referencing ancient Greek red-figure / black-figure pottery and Roman stone relief,
> thick oil-painting feel with restrained brushwork, no line-art outlines, no flat cartoon colour blocking, no hard edges,
> single figure centred, front-facing or slightly turned, calm austere stance, no exaggerated action, no heroic lighting,
> helmet, armour, shield and main weapon all clearly readable,
> soft diffused light with gentle tonal transitions, low contrast, soft contours,
> overall dark and desaturated: earth brown, dark red, grey-black,
> archaeologically reconstructed armour and clothing, worn metal, woven fabric texture,
> no text, no watermark, no logo, no border, no UI elements, no modern objects, no legible letters

### 3.7 兵牌背景（**替换** §四 表格里每条兵种的「背景」列）

兵牌要在一眼之内认出兵种，所以**不画地景**，只留一层**模糊的暗色纯色底**：

> CN：模糊的暗色纯色底（深土褐 / 暗红 / 灰黑之间的柔和渐变，随阵营色调微调），中央略亮、四周柔和暗角，无地景无天空无建筑无器物无投影，背景完全退到人物之后
>
> EN：blurred plain dark backdrop, a soft gradient of deep earth-brown, dark red or grey-black tinted by the faction palette, soft centre light with gentle vignette, no landscape, no sky, no architecture, no props, no cast shadow, background fully receding behind the figure

### 3.8 兵牌构图模板（**替换** §3.4 的 A/B/C 取景；主体描述仍用 §四 表格）

原版兵牌是**半身像**，不是全身立绘。所以兵牌那套把 §3.4 的取景统一收近一档：

| 模板 | 用于 | 兵牌构图 |
|------|------|----------|
| **A** | 步兵 / 长矛兵 / 轻步兵 / 远程 | 半身近景（胸肩到腰），人物占画面高度约 85%；头盔、甲胄、盾与主武器完整可辨，武器斜置或竖置，不做夸张动态 |

## 五、硬约束

1. **写实：单图 ≤70KB、全套 48 张 ≤2.6MB**；**兵牌：单图 ≤55KB、全套 48 张 ≤2.0MB**
   （单位卡色块大、细节少，同档质量能压得更小）。建议 512×512、WebP 质量 78–82。
   本项目是零依赖离线单文件工具，图片体积就是包的体积。
2. **无文字、无铭牌、无水印、无品牌标识、无现代物件**。
   盾面上不要出现可读的字母或数字——盾牌在小尺寸下本就糊，出现字母反而像贴图错误。
3. **年代不能穿帮**。以下元素一律不得出现：马镫、高桥马鞍、板甲（全身铁甲）、
   十字弓、火器、鞋子上的现代缝线。马镫是最常见的失误，骑兵一律画无镫控马。
4. **色调统一**。48 张必须是同一套光位与同一档饱和度：写实是侧逆光 + 自然光 + 低饱和，
   兵牌是软化均匀散射光 + 低对比 + 暗沉低饱和。一张高对比"游戏立绘"混进来就会破功。
5. **构图服从模板**。每表已指定 A / B / C，别让模型自由取景；尤其战象不要画全躯。
   写实走 §3.4（膝以上 / 整体入画 / 兽车占宽），兵牌走 §3.8（**半身近景**，腿以下不出画）。
6. **兵牌画风不许跑偏**。两套是各自独立出图的，兵牌那一套必须**整批同一风格**：
   写实古典半身像 + 厚重油画质感 + 低对比暗调（§3.5）。
   出现线稿描边、平涂色块、强明暗对比、亮白底、图内边框或任何界面元素（血条 / 等级圆点 / 金框），
   都算不合格——本项目卡片的金色边框由页面 CSS 负责画，图里一律不出。
   高卢 / 日耳曼这两个阵营最容易跟写实那批混出（2026-09-22 已实际发生一次），建议单独盯一遍。

## 六、落位契约

### 目录与命名

```
assets/units/<id>.webp         写实兵种图 ×48，文件名即 units.js 里的 id（见第四节各表）
assets/units/card/<id>.webp    兵牌兵种图 ×48，同一个 id（路径由 app.js 派生，不写进数据）
assets/tex/                    场景图（见 场景配图需求.md）
assets/audio/bgm.js            base64 音频（见 背景音乐需求.md）
```

**文件名必须与 `units.js` 的 `id` 完全一致**，含连字符。改文件名就要改 `img` 字段，两边一起动。

### 缺图回退

`assets/app.js` 在图片 404 时会退回该兵种的 `color` 色卡（径向渐变），页面照常跑完。
所以**可以分批补图**：先把 48 张里最要紧的做了，剩下的留空也能交付。

### 落位后校验

```bash
node tools/check_data.js      # 数据三方契约（units.js / index.html / app.js）
python tools/smoke_test.py    # 无头冒烟：五页流程 + 缺图回退 + 自选军团分支
```
