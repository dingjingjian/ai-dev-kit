# 凯旋门过渡视频需求

「即将检阅」这一页的过渡主体由**两帧图交叉淡化**改为**一段视频**。本文给的是技术规格与镜头要求，
提示词你自己写，写完按 [`素材生成说明.md`](素材生成说明.md) 的批次表推进即可。

> 兵种图 ×48 见 [`兵种图片素材需求.md`](兵种图片素材需求.md)，场景图见 [`场景配图需求.md`](场景配图需求.md)，
> BGM 见 [`背景音乐需求.md`](背景音乐需求.md)，落位与体积核对见 [`素材生成说明.md`](素材生成说明.md)。

## 一、图位

| 编号 | 图位 | 数量 | 规格 | 落地位置 | 缺视频时 |
|------|------|------|--------|----------|----------|
| ⑨ | 凯旋门穿行视频 | 1 | 1280×720 · 16:9 · H.264 mp4 | 检阅前的过渡页整屏 | 退回 ③④ 两帧图交叉淡化，再退 ⑥，再退纯色 |

**这一改带来的连带变化**：

- ③④ 两帧图（`gate-front` / `gate-open`）**从主素材降为兜底**——视频到位后，它们只在视频播不动时登场。
  `gate-front` 仍然要出，因为它还是首页 hero 的底图。
- ⑤ 竖版两帧**可以不做了**：视频用 `object-fit:cover` 铺满，竖屏只裁左右两侧，不需要另外一版竖构图。
- 优先级不变：视频是「首页之后第一眼」的一半，建议排在兵种图之前做。

## 二、显示环境（决定构图，务必先看）

- 整屏铺满（`object-fit:cover`），底下压着一张模糊铺底图，字幕层压在视频之上。
  **横屏几乎不裁**；**竖屏会左右各裁掉约三分之一**，所以门必须落在画面正中。
- 字幕节奏：阵营名在约 **29%** 处淡入，整段字幕在结束前 **0.9s** 淡出。
  页面按视频实际时长自动换算（钳在 3.2–9.0s），所以**时长不用卡死 7 秒**，6–8 秒都合适。
- 视频**静音播放**（页面另有 BGM）。出片带不带音轨都行，`prep_video.py` 会去掉。
- 视频结束即进检阅页。末帧最好比首帧亮一些——接着要跳到浅色的检阅页，末帧太暗会有一次硬跳。

## 三、规格

| 项 | 要求 |
|----|------|
| 时长 | **6–8 秒**（推荐 7s）。短于 4s 字幕读不完，长于 9s 会被页面强制截断 |
| 分辨率 | **1280×720**（16:9）。不够就由 `prep_video.py` 裁到 16:9；不要给竖版 |
| 容器 / 编码 | **mp4 + H.264**，yuv420p，main profile，`faststart`（moov 前置，起播不等待） |
| 帧率 | 24–30fps，脚本统一到 30fps |
| 体积 | **≤1.2 MB**（建议 600KB–1MB）。这是零依赖离线单文件工具，包体就是一切 |
| 落位文件名 | `assets/video/gate.mp4`，**只有这一个名字** |

## 四、镜头与内容

**镜头（一句话）**：相机从军道上正对凯旋门，匀速略加速地推进，穿过中门，落到门后远去的军道上。

- **单镜头、单向、连续推进**。不要切镜头，不要闪白，不要叠化、缩放转场之类的"特效"——
  它就只有 7 秒，任何一次剪辑都会读成卡顿。
- **首帧要能接住首页 hero**：同一道门、同一个光位（夕阳左后方逆光、门洞内最深）。
  首页到过渡页是一次硬切，门换了、光位变了就会跳。
- **末帧略亮**：出洞那一刻有天光，正好接住检阅页。
- **门始终在画面正中**，竖屏才不会被裁掉。
- 不要出现：可读的文字与铭文、水印、现代物件、马镫、明显的人脸特写。
  字幕层是页面自己画的，视频里写字必然与它打架。

## 五、硬约束

1. **体积 ≤1.2 MB**，压不进预算就换镜头（减少高频纹理与噪点），不要靠降低分辨率绕过——720p 是整屏播放的底线。
2. **不切镜头、不加转场特效**。
3. **无文字、无水印、无可读铭文**。
4. **与 ③④ 同一道门、同一光位**（若 ③④ 还没出，就按 [`场景配图需求.md`](场景配图需求.md) 三、的光位来）。
5. **门在画面正中**——竖屏真的会裁掉两侧。

## 六、落位

```bash
python tools/prep_video.py --src 原片.mp4 --dry      # 先看时长/尺寸
python tools/prep_video.py --src 原片.mp4            # 转码落位（自动压进预算）
python tools/prep_video.py --src 原片.mp4 --dur 7    # 原片太长时只取前 7 秒
node tools/check_assets.js                            # 核对体积
```

脚本依次做：裁 16:9 → 缩到 1280×720 → 去音轨 → H.264 重编码（crf 30 起，压不进就 32/34/36，
再不行降到 960×540 重来）→ `faststart`。压不进预算会**明确报错**，不会写出超重的 mp4。

```
assets/video/gate.mp4    过渡视频（唯一文件名）
```

## 七、兜底链路

视频缺 → ③④ 两帧图交叉淡化 → ⑥ 兜底内景 → 纯色渐变。四层都不会白屏；
前三层全缺时页面照常跑完，只是过渡页是一块深色底加字幕。
