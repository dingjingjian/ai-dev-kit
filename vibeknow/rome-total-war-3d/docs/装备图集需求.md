# 装备图集需求

检阅页右列「装备拆解」用的 52 件装备小图。名单**唯一真源是 [`assets/gear.js`](../assets/gear.js) 的 `GEAR`**
（本文件逐条给它配提示词；脚本 `tools/gen_prompts.py` 读的就是这里的表）。

> 兵种图 ×96 见 [`兵种图片素材需求.md`](兵种图片素材需求.md)，场景图 ×14 见 [`场景配图需求.md`](场景配图需求.md)，
> 过渡视频见 [`过渡视频需求.md`](过渡视频需求.md)，BGM 见 [`背景音乐需求.md`](背景音乐需求.md)。
> 生成顺序、后处理、落位与体积核对见 [`素材生成说明.md`](素材生成说明.md)。

## 一、图位总览

| 编号 | 图位 | 数量 | 规格 | 落地位置 | 缺图时 |
|------|------|------|--------|----------|--------|
| ⑪ | 装备图 | 52 | **1:1 方图 128×128，透明底 WebP** | 检阅页右列「装备拆解」的图标位 | 退成槽位名文字（头部 / 盾 / 主武器…），页面照常跑 |

**预算**：单张 **≤8KB**，全套 **≤0.60MB**（52 × 8KB ≈ 416KB）。
零依赖单文件工具里，图的体积就是包的体积；这一套是**唯一的可选项**——缺了照样能看懂兵种。

## 二、显示环境（决定构图，务必先看）

图标位在页面里只有 **28×28px**（`background-size:contain`），旁边的装备名才是主信息。

- **只画一件东西，居中，占画面 80% 左右**。不要画手、不要画人、不要画地台与投影。
- **透明底**（必须）：图标压在深色底与羊皮纸底两种主题上都可能出现，白底会出现方块。
- **轮廓优先**：在 28px 下能认出来的只有剪影与一两个特征。萨里沙长矛的关键是"很长"，
  罗马大盾的关键是"弧面矩形"，投石带的关键是"一根带子中间有兜"。
- **正视角或 3/4 视角**，不要俯视——俯视会让长兵器在方框里缩成一团。
- 金属件用**暖金 / 青铜色**（页面主色 `#c9a13b`），皮革与木头用暗棕，布面用麻白；
  与页面主题一致，不要鲜红、亮蓝这类跳出配色的颜色。

## 三、统一风格

### 3.1 风格前缀（每条加在开头）

> 古代军事装备图鉴插画，单件物件居中，博物馆展板级的写实绘制，
> 轻微做旧与使用痕迹，柔和均匀的光、无强投影、无地台，
> 透明背景，无文字、无铭牌、无水印、无品牌标识、无现代物件。

### 3.2 英文风格前缀（出图模型吃英文时用这一条，与上条等价）

> ancient military equipment illustration, single object centred, museum plate quality,
> slight weathering and wear, soft even light, no cast shadow, no base, no scenery,
> transparent background, no text, no watermark, no logo, no modern objects

### 3.3 逐件通用后缀

> 画幅：方形 1:1，主体占画面高约 80%，四周留出少量空白

### 3.4 英文通用后缀（与 3.3 等价）

> Format: square 1:1, subject fills about 80% of the frame height, transparent background

## 五、硬约束

1. **透明底**，不能带白底或方角背景——图标压在深色底与浅色底上都会出现。
2. **单张 ≤8KB，全套 ≤0.60MB**。建议 128×128、WebP 质量 80–85；透明底用 `alpha_q 100`。
3. **无文字、无水印、无品牌标识、无现代物件**。
4. **年代不穿帮**：**不得出现马镫**（马具图尤其容易画错）、不得出现火器与板甲。
5. **一图一物**。不要把"短剑 + 盾"画在一张里——页面是按槽位一件一件排的，多画就是重复。

## 六、落位契约

```
assets/gear/<id>.webp     装备图 ×52，文件名即 assets/gear.js 里 GEAR 的键
```

⚠️ **武器图必须无马镫**：`horse` / `light-horse` / `armoured-horse` / `chariot` 这四张
最容易画上马镫——罗马共和国时期没有马镫，这一条是全套装备图里最常见的失误。

落位：

```bash
python tools/gen_prompts.py                              # 出图前：生成提示词（含这 52 条）
python tools/prep_units.py --kind gear --src <原图目录>   # 出图后：裁方 → 缩 128 → 转 sRGB → 压 WebP → 落位
node tools/check_assets.js                               # 核对体积与方图
```
