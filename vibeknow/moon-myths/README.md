# 寰宇月话 · 全球月亮神话 - Moon Myths

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

3D 地球上点亮全球各文明的月亮神话标记，转动地球、点开光点，听一段段关于月亮的古老故事。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录。

## 交互

- 拖动旋转地球，滚轮 / 双指缩放
- 地球表面有 14 个发光标记，标记随地球自转；标记在屏幕上尺寸恒定（约 18px，选中约 22px），
  小屏 / 宽屏 / 拉近拉远都一致，靠近地球轮廓时淡出
- **标记按大洲取色**（与底部筛选条的提示点同色）：东亚红 / 南亚橙 / 中东金 / 欧洲蓝 / 非洲绿 / 美洲紫 / 大洋洲青
- **每个可见标记都挂名牌**（文明·神话名，前有大洲色圆点）：挤不下时按"更正面者优先"让位，
  被卡片挡住的位置不排
- 点击标记 → 地球停转、飞到该标记正面（视线下压，让标记与名牌露在卡片上方）、底部展开神话卡片
- 卡片含文明名、神话名、配图、故事、关键词标签、经纬度
- 底部区域筛选（全部 / 东亚 / 南亚 / 中东 / 欧洲 / 非洲 / 美洲 / 大洋洲）：每项前有对应大洲颜色的提示点；非该区域标记压暗，地球转至该区域并停转。底栏与姊妹项目 `vibeknow/solar-system-3d` 的 dock 同一套交互与样式：单排胶囊、溢出一屏时两端渐隐、横向滚动 + `scroll-snap` 吸附，手机上不换行成两排
- **光照与月相取真实北京时间**：太阳直射点经度 = 15°×(20 − 北京小时)，纬度按日期取太阳赤纬，
  于是北极的极昼／极夜、晨昏线的季节倾斜都对得上今天；月球按真实的月相摆位（相位差 + 赤纬），
  盈亏、时刻、被照亮的比例是真的，夜半球由随盈亏变亮的月光补光
- 地球旁有绕行公转的月球（`assets/moon.jpg` 贴图，复用 earth-3d 的地月系统）
- 右上设置：顶部显示"此刻"（北京时间 / 月相 / 直射点），下面为自动旋转 / 星空 / 云层 / 月亮 / 标签开关，重置 / 俯视视角

## 配图

神话卡片上有 14 个配图位（`assets/illus/<slug>.webp`，1080×360，约 3:1，单张 ≤90KB）。

- **图未生成时**：卡片显示程序化占位（夜空渐变 + 月相圆盘 + 文件名），不空着、也不改卡片尺寸，因此**可以分批补图**。
- **放图即生效**：路径写在 `assets/myths.js` 的 `img` 字段，文件按约定命名丢进 `assets/illus/` 即可，无需改代码。
- **提示词**：14 条统一风格前缀 + 逐条画面主体 + 红线 + 转换命令，见 [`docs/配图提示词.md`](docs/配图提示词.md)。

## 视觉

国风夜空配色：深靛蓝底 + 月白文字 + 暖金强调。标题用衬线体（宋体感），故事正文用衬线体，UI 用无衬线。

地表标记形制参考 `vibeknow/rome-total-war-3d`（实心点 + 光晕 + 细环三层），
配色改成按大洲取色；另加一圈细暗线描边，专为雪原、沙漠这类亮地表定形。
全部走 alpha 混合、材质 `toneMapped:false`（原因与尺寸标定写在 `assets/app.js` 标记点一节的开头注释里）。

夜空贴图收尾做一次 `blur(2.5px)`：Canvas2D 的渐变是逐像素抖动（dither）着色的，天球把它放大 2~5 倍后
会在银河和星云上糊出一片横竖对齐的「白色网格」——模糊一次把逐纹素的抖动平均掉即可消除，
成因、误判过程与接缝处理写在 `app.js` 的 `starfieldTex()` 末尾。

## 技术栈

复用 `vibeknow/earth-3d` 的 Three.js 渲染框架（地球贴图、程序化星空、云层、大气辉光、手势控制），改造为「地图标注 + 点击展开」交互形态。单文件零依赖（除 three.min.js），兼容 Android 8.1 Chrome/WebView 61 基线。

配图走「数据声明路径 + 预检 + 程序化占位」：`myths.js` 的 `img` 字段声明图位，`app.js` 启动时逐张预检，加载失败或 2.6 秒未就绪即回退到 CSS 占位，因此配图缺失不影响功能与布局（做法与 `vibeknow/world-food-3d` 一致）。

光照与月相不引入任何天文库：直射点、太阳赤纬、月相（朔望月 + 一个已知朔时刻当历元）都是十几行三角函数，
见 `app.js` 的 `astroUpdate()`。北京时间取 `Date` 的 UTC 值 +8 小时，**不依赖设备时区** ——
人在纽约打开，看到的也是此刻北京的昼夜与月相。
