## 二、① 菜品图 ×36

### 统一风格前缀（每条提示词都加在开头）

> 中式老馆餐厅菜品摄影，白瓷盘或木托盛装，深色木桌背景，暖黄灯光侧照，
> 45 度俯拍，低饱和、暖色调、浅景深，画面干净，无人物、无手、无文字、无水印、无品牌标识。

### 构图要求（决定能否用）

菜品卡上的图是**圆形裁切**，因此主体必须居中、四周留出约 12% 的空白余量，
否则圆边会切掉菜品轮廓。不要出俯视正投影（会显得扁平），45 度俯拍最稳。

菜单列表项复用同一张原图（CSS 等比裁切），**无需另出缩略图**。

## 三、硬约束

1. **无缝与可平铺是硬要求**。② 要贴到一个球的内壁，③④⑤ 要被 CSS 平铺。
   生图模型默认不给无缝，必须在提示词里明确写「画面左右两边内容完全衔接，可无缝横向循环」，
   出图后仍需人工检查接缝；平铺纹理则要横竖都接得上。
2. **单图不超过 60KB，全套不超过 3MB**。本项目原本是零依赖离线单文件工具，
   引入图片就是引入了体积，需按此上限控制。菜品图建议 512×512、WebP 质量 80。
3. **无文字、无人物、无手、无水印、无品牌标识**。菜品图里出现餐具品牌或餐巾印字都会很扎眼。
4. **色调统一**。全部走深背景 + 暖黄光 + 低饱和，才能与木、铜、宣纸三色对得上；
   一张冷色调的图混进去就会破功。
5. **地域菜要核对主体**。模型很容易把「冬阴功」画成「椰奶鸡汤」、把「英吉拉」画成普通薄饼，
   逐条对照上表验收。

## 四、② 至 ⑧ 各图位说明

### ② 餐厅背景（`assets/tex/room-360.jpg`）

中式老馆室内夜景：暗枣木护墙板与木格花窗，暖黄灯笼漫射光，墙上淡墨山水挂轴，
角落木桌与青瓷，无人物。等距圆柱投影全景，左右两边必须完全衔接。

**需重点提示**：绝大多数生图模型不输出真正的等距圆柱投影，直接贴到球面会有明显形变。
两条退路：

- 使用专门支持 360 度全景输出的模型或能力，并在提示词中写明等距圆柱；
- 放弃天空球，改为在球体之后放一块大平面贴 16:9 室内图。形变小得多，
  代价是视角转到侧面时会露空。

**在当前实现下，本条优先级可以往后放**。第 1 步已用纯 CSS 的暖光渐晕与暗角垫出了室内感，
即使不做这张图也不会退回"太空"的观感。

### ③ 木牌木纹（`assets/tex/wood-sign.webp`）

深枣木，细直木纹带轻微结疤，无高光、无漆面反光。512×512 可平铺。
用于招牌底与菜单面板外框。

### ④ 宣纸纹理（`assets/tex/paper.webp`）

米黄宣纸，横向细帘纹，云絮状纤维，无污渍无折痕。512×512 可平铺。
用于菜品卡、设置抽屉、菜单内页。

### ⑤ 桌沿木纹（`assets/tex/wood-desk.webp`）

深胡桃木横纹，方向需与纸签托盘一致。512×512 可平铺，或 2048×256 长条。

### ⑥ 朱印章（`assets/props/seal.png`）

阴刻篆书印章，正方形，纯朱红，透明底，256×256。
内容建议「寰宇小馆」或单字「食」。

**需注意**：生图模型写篆书几乎必然出错，会用像篆书但不是字的形状糊过去。
更可靠的做法是用篆体字库渲染，或采用 CC0 授权的现成印章素材再做调色。
当前实现用 CSS 画的朱红方章，效果已经可接受，这张图属可选优化。

### ⑦ 老馆内景横幅（`assets/tex/top-banner.webp`）

**用途**：菜单页 `.menu-hero` —— 顶栏招牌之下、菜单标题之上的一幅通栏横幅。
**整幅完整显示**（不裁不拉），观感相当于墙上挂的一幅横匾：铜线描边、深木衬边、投影。

**规格**：
- 尺寸 **750×220**。这个比例是**承重**的：`.menu-hero` 按它开槽
  （`aspect-ratio:750/220` + `background-size:100% 100%`），换图必须同比例，否则会被拉伸
- 格式 **WebP**，有损压缩，**50KB 以内**
- 构图须**自足**：不再有「左右可裁」的余量，四面都可能顶到边框，主体不要贴边

**布局**：横幅宽取「菜单列宽 / 820px / 34vh 折算宽」三者最小后居中 ——
手机通栏（390 宽 → 高 114），桌面与标题页签同宽（820 → 高 241），
矮视口由 34vh（横屏另按 14vh）兜住，保证下方菜单列表始终可见。

**内容与风格**：
- 中式老馆内景氛围：木梁屋檐、红灯笼、铜器、宣纸卷轴等元素
- 暖色调，与馆内五色定调一致（枣木 `#3d1f12` / 铜 `#b0894a` / 宣纸 `#f7eedd` / 朱 `#a52a1f`）
- 暗调摄影或工笔插画风格，上部偏暗（顶栏落在其上沿，承接得住），中下部有灯笼/牌匾等可视元素
- 不要出现清晰文字（避免与招牌"寰宇小馆"争抢视觉）

**生图提示词参考**：
> Chinese old tavern interior, wooden beams and red lanterns hanging from ceiling, brass utensils, warm candlelight glow, dark moody atmosphere, top half darker, bottom half warm glow with lanterns and wooden signboard, color palette of dark wood brown brass gold and vermillion red, no text, cinematic lighting, webp

**缺图回退**：图片未生成时 `url()` 404，横幅只显示深木底色与铜线边框，功能与布局不受影响。

### ⑧ 缺图占位（`assets/foods/_placeholder.jpg`）

1:1 方图。可以是一张极简的白瓷空盘，也可以不出——
现有实现缺图时会自动回退到 `foods.js` 里每道菜的 `color` 色卡，观感并不突兀。

## 五、落位契约

### 目录约定

```
assets/
├── foods/          菜品图（36 张 + 可选占位图）
├── tex/            纹理与横幅（木牌、桌沿、宣纸、老馆内景横幅、餐厅背景）
└── props/          透明底道具（朱印章）
```

### 代码契约

`assets/foods.js` 每条记录新增 `img` 字段：

```js
{name:'北京烤鸭', country:'中国', city:'北京', lat:39.9, lon:116.5, continent:'asia',
 color:'#8b3a1f', img:'./assets/foods/beijing-kaoya.jpg', ...}
```

纹理与道具则直接写进 `index.html` 的 CSS，不经过数据层。

### 缺图必须能跑

`img` 缺失或加载失败时，一律回退到现有的 `color` 色卡方案，因此图片可以分批补、
不必等 35 张齐了再上线。这一点是硬要求，不要写成"必须有图"。

## 六、尚未接入

当前代码侧还没有读取这些图片的入口——`index.html` 已把图位的路径与规格写在

这一步安排在改造的第 2 至第 3 步，与"竹签名牌菜签"「餐厅背景与灯光」一并完成。
