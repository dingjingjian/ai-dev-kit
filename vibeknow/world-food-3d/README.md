# 世界美食大百科 - World Food 3D

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

复用 [`earth-3d`](../earth-3d/) 的 3D 地球框架，把世界各地的代表性美食以发光红点的形式钉在地球上。转地球、点红点，便能看到这道菜的来历、做法与风味。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录。

## 交互

- 拖动旋转地球，滚轮 / 双指缩放
- 点击地球上的**发光红点** → 弹出该美食的详情卡片（菜名、国家·城市、介绍、关键食材、风味标签）
- 底部 dock 按**大洲**筛选：全部 / 亚洲 / 欧洲 / 非洲 / 北美 / 南美 / 大洋洲
- 右上角设置：自动旋转、城市标签、星空、云层、连线高亮、重置 / 俯视视角

## 数据

- 内置 **35 道美食**，覆盖 **6 大洲**、**20+ 个国家**
- 数据文件：`assets/foods.js`，每条记录字段：`name / country / city / lat / lon / continent / intro / ingredients / tags / color`
- 离线零依赖：详情用程序化色卡代替图片，无需联网

## 与 earth-3d 的关系

复用 earth-3d 的：WebGL 渲染器、星空天球、地球贴图与云层、`ll2v` 经纬→球面坐标、相机手势、标签投影与防重叠布局。

移除：四季成因、地月系统、地球内部剖切、经纬网格、月相指示器。

新增：美食数据集、球面发光标记点、raycaster 点击拾取、悬停高亮、详情卡片、大洲过滤、脉冲动画。

## 分类判定

没有任务、没有输赢，用户点开是为了"看看世界各地的人都在吃什么、怎么吃"，看完脑子里多一份对他人饮食文化的认知 → `#vibeknow`。地球是承载美食位置的容器，3D 是手段而非目的，故不归 `#vibeart`。
