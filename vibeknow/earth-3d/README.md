# 3D 地球科普 - Earth 3D

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

WebGL 渲染的 3D 地球，把课本上的地理概念变成能转、能看、能对照的立体模型。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录。

## 知识点

- 昼夜交替
- 四季成因
- 月相成因（地月系统）
- 地球内部结构
- 经纬网格

## 月相模式

底部切到「月相」：俯视地月系统，阳光自屏幕左侧平行照亮，月球绕地球公转。

- 月球任何时刻都只有朝向太阳的一半被照亮，绕地公转时这半面相对地球不断改变朝向 → 月相
- 轨道上标出新月 / 蛾眉月 / 上弦月 / 盈凸月 / 满月 / 亏凸月 / 下弦月 / 残月 八个相位
- 左上角指示器实时画出「站在地球上看到的月亮」圆面形状，并给出相位名与月龄（朔望月 29.53 天）
- 「轨道线」「云层」开关在设置面板内，与其它模式共用
