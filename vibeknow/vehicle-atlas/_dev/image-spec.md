# 配图生产要求（唯一真源）

本文件是配图交付要求的**唯一真源**：`_dev/gen_image_prompts.py` 会把它整段嵌入
`_dev/IMAGE_PROMPTS.md` 的「1. 交付规格」，README 与 `assets/img/README.md` 只做指引、不重复细则。
改要求请改本文件，然后重跑 `python _dev/gen_image_prompts.py`。

## 交付清单

| 项 | 要求 |
| --- | --- |
| 存放位置 | `assets/img/`（相对项目根目录） |
| 文件命名 | `<base>.webp`，base 见逐张清单（如 `ground-01.webp`、`cover-ground.webp`） |
| 条目图尺寸 | 640 × 360（16:9 横构图） |
| 分类封面尺寸 | 960 × 540（16:9 横构图） |
| 格式 | WebP（页面另有 jpg / png 后缀回退，但 WebP 体积最优） |
| 单张体积 | 条目图 ≤ 45 KB，分类封面 ≤ 90 KB |
| 全部图片合计 | ≤ 1.8 MB（小工具 zip 建议不超过 2 MB，图片是主要体积来源） |

## 构图（最容易被忽略、也最影响观感）

页面用 `object-fit: cover` 裁切，源图上下两条会被丢掉：

- 条目图进列表卡片：显示框约 **2.39:1**，源图**上下各丢 12.7%**
- 分类封面：显示框约 **3.44:1**，源图**上下各丢 24%**

因此：

- 主体必须**水平居中**；
- 主体**高度不超过画面的 55%**，即上下各留 **≥22% 纯背景**；
- 分类封面务必把**一排主体压在画面中带**，上下留足空白，不要让桅杆 / 烟囱 / 头锥顶到边缘；
- 画布外沿再留 3% 安全边，避免压缩时被裁。

## 画面内容

- **只画该类交通工具的典型样貌**；生图提示词里给出的具体型号**仅用于提高造型准确度**，画面中不得出现任何品牌名、型号字样、文字、字母、logo、水印、国旗、编号与人物。
- 背景统一为**干净的浅灰渐变影棚背景**，主体下方带柔和接触阴影；不要真实场景、地标、天空、海面或建筑。
- 视角统一为**清晰的三分之四视角或正侧视**，主体完整入画、不被画框切断。
- 不使用任何外部素材（版权风险）。

## 生成后处理

若生成工具只输出 PNG / JPG，先落到 `_dev/raw_img/<base>.png`，再执行：

```bash
python _dev/process_images.py
```

该脚本会按清单里的尺寸缩放、按体积预算自动调质量，输出到 `assets/img/<base>.webp`。
