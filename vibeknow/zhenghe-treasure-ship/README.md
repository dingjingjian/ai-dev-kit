# 郑和宝船 - Zheng He Treasure Ship

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

以 Blender 建模、离线 H5 呈现的明代郑和宝船科普小工具：按《明史·郑和传》与《瀛涯胜览》的记载还原**九桅十二帆**的宝船形制，立体展示船体结构、桅帆制度与七下西洋的航行脉络。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录（模型与贴图以内联数据提供，`file://` 直接打开即可运行，无需联网）。

## 三种模式

| 模式 | 说明 |
|------|------|
| **展示** | 宝船整体陈列，拖动旋转、双指缩放，观察九桅十二帆的全貌 |
| **拆解** | 船体主要部件在独立展示空间中铺开，点击标签查看各部件说明 |
| **航行** | 七下西洋的航线叙事：船队编队、季风与针路 |

## 形制要点

模型的形制由一张参数表（`assets/ship-params.js`）唯一确定，HTML 与 Blender 两侧读同一份数据。

| 要点 | 落实 |
|------|------|
| 尺度 | 严守记载的**长宽比 2.4667**（44.4 × 18 丈），绝对米数不写进界面 |
| 九桅十二帆 | 后桅群 5 桅（尾桅双帆）+ 前桅群 4 桅（主桅三帆）＝ 9 桅 12 帆 |
| 福船线型 | 尖底、方首方尾、首尾上翘的龙骨弧线、近乎垂直的舷侧 |
| 水密隔舱 | 13 道舱壁，随船体线型收放 |
| 大舵 | 舵叶下缘低于龙骨——福船大舵可升降的形制特征 |
| 双色船体 | 水线分界，深赭舷侧 + 米白船底，舷侧两排舷孔（**示意性涂装**） |
| 上层建筑 | 舵楼（三层收进）、中舱、首楼 |

> 涂装与舷孔属示意性艺术处理，史料未载；尺度亦按记载折算，仅示意比例。详见 `docs/史料考证.md`。

## 史料依据

| 项 | 记载 | 出处 |
|----|------|------|
| 尺度 | 长四十四丈四尺、阔十八丈 | 《明史·郑和传》 |
| 桅帆 | 九桅、十二帆 | 《瀛涯胜览》 |
| 船型 | 福船：尖底、方首、方尾、设水密隔舱 | 龙江船厂遗址出土舵杆等实物 |

> 明代营造尺取值与「四十四丈四尺」的实际米数在学界有争议（约 44 丈 → 124～140 m 不等），本应用按**示意比例**建模，不宣称工程实态。详见 `docs/史料考证.md`。

## 自检

三层，各管一段，互不替代。分工与断言清单见 [`tests/README.md`](tests/README.md)。

```bash
# 几何层：无头建模 + 19 项几何审计 + 导出 GLB
blender --background --factory-startup --python blender/headless_check.py

# 参数层：25 项参数自洽
node tests/params_test.js

# 产物层：构建 + 21 项合规校验
node build.mjs && node verify-minitool.mjs dist
```

## 打包（小红书小工具）

按 [`.skill/minitool-zip-builder`](../../.skill/minitool-zip-builder/SKILL.md) 规范打包为可上传的离线 zip：

| 脚本 | 用途 |
|------|------|
| `build.mjs` | 构建 `dist/`（`index.html` 置于根 + `assets/`，仅复制允许类型） |
| `verify-minitool.mjs` | 逐条对照规范校验 `dist/` |
| `pack.mjs` | 压缩 `dist/` 的「内容」为 `zhenghe-treasure-ship.zip` |

```bash
node build.mjs && node verify-minitool.mjs dist && node pack.mjs
```
