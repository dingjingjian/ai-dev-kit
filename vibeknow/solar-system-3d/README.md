# 太阳系 3D - Solar System 3D

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

WebGL 渲染的太阳系，行星按轨道运行，可点击任意天体追踪观察。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录。

## 知识点与交互

- 八大行星完整轨道运行与相对尺度
- 土星环、天王星环
- 行星贴图来自 NASA 影像（经 npm `solar-system` 包由 jsdelivr 获取，存于 `assets/`）
- 点击任意天体追踪，锁定视角跟随；底部 dock 可直接切换，也支持在 dock 上左右滑动翻页
- 彩蛋：月球不在 dock 中，点击场景里的月球即可锁定追踪
- 时间流速调节、俯视 / 重置视角、轨道线 / 标签 / 星空开关
