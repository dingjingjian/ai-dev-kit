# 场景配图需求

本文件列出 `cat-globe-3d` 除猫咪品种图外的场景配图需求。风格统一遵循 [`生图规范.md`](生图规范.md)（治愈系 Q 版可爱卡通插画），不要另立新风格。

## 图位总览

| 图位 | 路径 | 尺寸 | 状态 |
|------|------|------|------|
| 首页 hero 横幅 | `assets/tex/hero.webp` | 1200 × 480 | **唯一必需图位**，已出图且已接线（见「接线状态」） |
| 飞行页 | — | — | **零配图**，全部程序化生成 |
| 基因解析页 | — | — | **零配图**，雷达图/条形图为内联 SVG |

即：整个项目**只有 hero 一个需要生图的场景图位**，其余都是 CSS / Canvas / Three.js 现场绘制。

## hero 横幅（首页顶部背景图）

### 在页面中的呈现方式（出图前必读，提示词就是按这些事实写的）

代码事实（`index.html`）：

- 容器 `.hero`：高 **196px**、左右外边距 14px、圆角 28px、`overflow:hidden`；内容左对齐 + 底对齐，内边距 `18px 20px`
- 图片 `.hero-img`：`position:absolute; inset:0; width:100%; height:100%` + **`object-fit:cover`**，即整张铺满并**居中裁切**；同时 **`opacity:.6`**，叠在 `.hero` 自身的奶油粉渐变（`#ffe8f0 → #fff3e5 → #e6f8f1`）之上
- 压在图上的叠层（出图时必须避开）：
  - **左下角**：白色标题「世界猫咪图鉴」（23px 圆体、带白色 text-shadow）+ 副标题「心动哪只，就飞去见哪只」
  - **右上角**：猫爪水印（140×140、粉色半透明、旋转 12°、自右上角向外偏 16px）
  - **中偏右上**：`radial-gradient(circle at 70% 26%, rgba(255,255,255,.6), transparent 62%)` 的白色柔光罩，会盖在图上

### 安全区（重要元素必须落在这里）

`object-fit:cover` 的裁切量取决于视口宽高比（页面无 `max-width`，容器 `position:absolute; inset:0` 占满窗口）：

| 视口 | hero 容器 | 裁切结果 | 可见范围 |
|------|-----------|----------|----------|
| 手机 375px | 347 × 196 | 左右各裁 ≈15% | 水平 15%–85%、垂直满高 |
| 手机 414px | 386 × 196 | 左右各裁 ≈11% | 水平 11%–89%、垂直满高 |
| 桌面 1280px | 1252 × 196 | 上下各裁 ≈30% | 水平满宽、垂直 30%–70% |

→ **取交集：所有主体必须放进「水平 15%–85% × 垂直 30%–70%」的中央横带，四边留白。**

手机是主战场（裁左右），桌面端还会再砍掉上下各 30%——五只猫与地图轮廓都要压在这条横带里，否则手机上左右两只猫会被切掉、桌面上整幅地图的上下会被切掉。

### 因为 `opacity:.6`，出图要「比看起来更饱和」

图片以 60% 不透明度叠加在奶油粉渐变上，实际显示会被明显冲淡、发灰。因此：

- 线条与色块**不要用浅色**（浅粉/浅黄叠上渐变后会糊成一片），用规范里中等明度的马卡龙色
- 背景保持**纯奶油白 `#FFF7F3`**，**不要**画满屏天空渐变或海水，否则与页面底色脱节

### 内容与提示词

- **内容**：奶油白底手绘世界地图，五只 Q 版小猫分别坐在对应大洲上（亚洲·日本短尾猫 / 欧洲·英国短毛猫 / 美洲·缅因猫 / 非洲·埃及猫 / 大洋洲·澳洲雾猫），**以粉色爱心为节点的虚线航线**把它们连成一张旅行手账
- **不要画小飞机**：航线节点与飞行体统一用**爱心**（飞行页的飞行体也已经是爱心，见下节），保持同一套隐喻
- **提示词**：

  ```
  Q版可爱卡通插画，奶油白背景上的手绘世界地图，各大洲用圆润的马卡龙色系色块呈现（薄荷绿、蜜桃橘、奶油黄、淡粉），奶油浅蓝色海洋，五只Q版小猫分别坐在亚洲、欧洲、美洲、非洲、大洋洲的色块大陆上，小猫圆润大头小身、大眼睛带高光、粉嫩腮红，粉色爱心串成的虚线航线连接各洲，柔和深棕描边，平涂上色，治愈旅行手账风，横版构图，所有主体集中在画面中央横带（垂直30%-70%、水平15%-85%），左下角与右上角留白，1200x480
  ```

- **负面提示词**：照片，写实，3D渲染，真实卫星影像，阴暗，高对比，细节繁杂，文字，水印，logo，甜点，马卡龙，蛋糕，饼干，食物

  > 「马卡龙 / 甜点 / 蛋糕 / 饼干 / 食物」是必加项：上一版把提示词里的「马卡龙色块大陆」理解成了马卡龙**甜点**，出成一排猫咪坐在马卡龙上、完全没有世界地图与大洲。改成「马卡龙色**系**色块」并显式排除甜点后重出。

- **构图注意**：左下角 1/3 与右上角必须留浅色留白（分别压标题与猫爪水印），不要在高对比内容；中偏右上还有一层白色柔光罩，也别放主体

### 接线状态（已完成）

`index.html` 里预留了 `<img class="hero-img" id="heroImg" alt="">`，`assets/app.js` 的 `start()` 中已补上赋值：

```js
setImg(Q('heroImg'), './assets/tex/hero.webp', function(){});
```

即 hero 现在与猫咪图一样，**覆盖同名文件刷新即生效**；文件缺失或路径错误时 `setImg` 的失败回调不做处理，图片保持为空，页面自动回退到 `.hero` 的 CSS 渐变 + 猫爪水印。

### 当前出图实测（2026-09-16）

对当前 `assets/tex/hero.webp` 做过像素级核对：

| 项 | 实测 | 结论 |
|----|------|------|
| 尺寸 / 格式 | 1200 × 480 WebP | 合规 |
| 背景色 | 四角 `#FFF7F3`（左下/右下/右上精确命中，左上 `#FEF8F3` 差 1 阶）；中部有一层很淡的暖色柔光（约 `#FFFDED`，与底色差 6 阶以内） | 合规（属奶油白范围内的柔光，不是色块） |
| 航线节点 | 粉色虚线 + **爱心**串连 | 已按新提示词落实 |
| 主体外接框 | 水平 **14.8%–84.8%**、垂直 **32.5%–70.4%**（要求 15–85 / 30–70） | 擦边达标（三边在界内，左边界差 0.2%、下边界差 0.4%，即 2 像素级） |
| 世界地图 / 大洲 | **仍没有**——五只猫坐在五个马卡龙色花朵形色块上，无地图轮廓、无大洲形状 | **不符合** |

→ 唯一未达标项是「没有世界地图」。连续两版出图都收敛成「一排小猫 + 马卡龙色色块 + 爱心虚线」，模型没有执行"世界地图 + 五只猫坐在大洲上"这个组合。若继续按原提示词重投大概率还是这个结果，建议改用下面两种策略之一：

1. **强化地图为第一主体**：把地图提到提示词最前并写实一点，例如「一幅完整的卡通世界地图占据整个画面，能清晰分辨亚洲、欧洲、非洲、美洲、大洋洲的轮廓与相对位置，陆地用马卡龙色系色块、海洋用奶油浅蓝，五只 Q 版小猫分别坐在对应大陆上，粉色爱心虚线航线连接它们……」——把"地图"从背景变成主角
2. **降低为象征构图**：接受当前「色块岛屿 + 猫 + 爱心航线」的思路（更像手账贴纸，也更符合可爱风），但把五个色块画成**可辨认的大洲剪影**（亚洲/欧洲/美洲/非洲/大洋洲），并在文档里把要求从"世界地图"改为"五片大洲元素色块"

另注：当前图里五只猫是通用配色（橘虎斑/白猫/三花），**认不出是日本短尾猫、英国短毛猫、缅因猫、埃及猫、澳洲雾猫**这五只指定品种。在 1200×480 且页面按 60% 透明度显示时影响很小，故未列为必改项。

## 飞行页（零配图，不需要生图）

飞行页**不需要任何图片**，全部程序化生成，不要再为它出图：

| 元素 | 实现 |
|------|------|
| 地球 / 云层 | base64 内联的真实贴图（`assets/earth-tex.js`，复用 earth-3d 的 `earth.jpg` + `clouds.png`） |
| 星空天球 | `app.js` 里 Canvas 绘制的天蓝 → 奶油粉渐变 + 520 个随机星点 |
| 大气 | 粉色半透明 BackSide 球壳 |
| 出发地标记 | 薄荷绿小球（`SphereGeometry`） |
| 目的地标记 | **粉色爱心 Sprite**（`heartTex()` Canvas 绘制，带脉动光晕） |
| **飞行体（「正在飞行的我」）** | **粉色爱心 Sprite**（`makeHeartMarker()` → `heartTex()` Canvas 绘制） |
| 航线 | 粉色大圆航线 `THREE.Line`（slerp 采样 72 点） |
| 光晕 | 径向渐变 Canvas 贴图 + `AdditiveBlending` |
| 舷窗暗角 | `.cockpit-frame` 的 CSS 内阴影 |

**结论：不需要生成飞机图片。** 飞行体已从飞机改为爱心（"我带着一颗心飞去见它"），爱心、航线、光晕、星空全部是 Canvas / Three.js 现场绘制；换成图片只会增加体积、引入 `file://` 下的跨域与加载失败风险。

> 命名与图标已全部统一为爱心：`app.js` 中函数为 `makeHeartMarker()`、航线对象字段为 `routeObjs.heart`，航线 HUD 用 `💗`；`index.html` 的「再飞一次」按钮图标也是 `💗`。**全项目已无任何飞机元素，因此不存在"需要生成飞机图片"的需求。**

## 缺图回退

- hero 文件缺失或加载失败时，`setImg` 的失败回调不处理，图片保持为空，页面回退为 CSS 奶油粉渐变 + 猫爪水印（`#ffe8f0 → #fff3e5 → #e6f8f1`），标题文字正常显示
- 飞行页的天空渐变、星空天球、航线、爱心标记、舷窗暗角全部由 CSS / Canvas 程序化生成，**不存在缺图问题**

## 可选增强：可爱风地球贴图（默认不启用）

飞行页的地球使用真实卫星贴图（复用 earth-3d 的 `earth.jpg`），保留真实地理质感，这是项目「飞遍全球」的科普内核。若追求视觉极致统一，可另出一张卡通地球：

- **规格**：等距圆柱投影（equirectangular），宽高比严格 2:1（建议 2048 × 1024），**左右边缘必须无缝衔接**（经度 180° 处接得上）
- **风格**：马卡龙色系色块大陆 + 奶油浅蓝海洋，海岸线圆润简化，柔和暖棕描边，不要写实纹理与卫星影像
- **提示词**：

  ```
  Q版可爱卡通插画风格的等距圆柱投影世界地图贴图，马卡龙色系色块大陆（薄荷绿、蜜桃橘、奶油黄、淡粉），奶油浅蓝色海洋，圆润简化海岸线与岛屿，柔和深棕描边，平涂上色，无文字无国界，平铺无缝，2048x1024
  ```

- **取舍**：会削弱「真实地理」的科普感，建议作为可选皮肤而非默认替换
- **替换方式**：把出图转成 base64 data URI，覆盖 `assets/earth-tex.js` 中的 `EARTH_TEX_URI`（该文件由贴图生成，**勿手动编辑**）。云层 `CLOUDS_TEX_URI` 同理，可保留真实云层或换纯色柔光层
