# 场景配图需求

本文件列出 `cat-globe-3d` 除猫咪品种图外的场景配图需求。风格统一遵循 [`生图规范.md`](生图规范.md)（治愈系 Q 版可爱卡通插画），不要另立新风格。

## hero 横幅

- **路径**：`assets/tex/hero.webp`
- **尺寸**：横版 1200 × 480 px（页面按 196px 高、`object-fit:cover` 圆角裁切，两端与顶部可能被裁掉，**重要元素集中在画面中间 70%**）
- **内容**：奶油白底手绘世界地图，五只 Q 版小猫分别坐在对应大洲上（亚洲·日本短尾猫 / 欧洲·英国短毛猫 / 美洲·缅因猫 / 非洲·埃及猫 / 大洋洲·澳洲雾猫），粉色虚线航线与小飞机图标把它们连成一张旅行手账
- **风格**：与 24 张猫咪图同一套 Q 版可爱插画风（奶油白底、马卡龙色块大陆、柔和暖棕描边、平涂上色）
- **提示词**：

  ```
  Q版可爱卡通插画，奶油白背景上的手绘世界地图，各大洲用圆润的马卡龙色块呈现（薄荷绿、蜜桃橘、奶油黄、淡粉），浅蓝色海洋，五只Q版小猫分别坐在亚洲、欧洲、美洲、非洲、大洋洲上，小猫圆润大头小身、大眼睛带高光、粉嫩腮红，粉色虚线航线连接各洲并配小飞机图标，柔和深棕描边，平涂上色，治愈旅行手账风，横版构图，留白充足，1200x480
  ```

- **负面提示词**：照片，写实，3D渲染，真实卫星影像，阴暗，高对比，细节繁杂，文字，水印，logo
- **构图注意**：页面左侧压着标题「世界猫咪图鉴」与副标题，**左下角 1/3 请留浅色留白**，不要放置高对比内容；猫爪水印会叠在右上角，右上角也尽量清爽

## 缺图回退

- hero 缺图时，页面回退为 CSS 奶油粉渐变 + 猫爪水印（`#ffe8f0 → #fff3e5 → #e6f8f1`），标题文字正常显示
- 飞行页的天空渐变、星空天球、航线、爱心标记、舷窗暗角全部由 CSS / Canvas 程序化生成，**不需要配图**

## 可选增强：可爱风地球贴图（默认不启用）

飞行页的地球使用真实卫星贴图（复用 earth-3d 的 `earth.jpg`），保留真实地理质感，这是项目「飞遍全球」的科普内核。若追求视觉极致统一，可另出一张卡通地球：

- **规格**：等距圆柱投影（equirectangular），宽高比严格 2:1（建议 2048 × 1024），**左右边缘必须无缝衔接**（经度 180° 处接得上）
- **风格**：马卡龙色块大陆 + 奶油浅蓝海洋，海岸线圆润简化，柔和暖棕描边，不要写实纹理与卫星影像
- **提示词**：

  ```
  Q版可爱卡通插画风格的等距圆柱投影世界地图贴图，马卡龙色块大陆（薄荷绿、蜜桃橘、奶油黄、淡粉），奶油浅蓝色海洋，圆润简化海岸线与岛屿，柔和深棕描边，平涂上色，无文字无国界，平铺无缝，2048x1024
  ```

- **取舍**：会削弱「真实地理」的科普感，建议作为可选皮肤而非默认替换
- **替换方式**：把出图转成 base64 data URI，覆盖 `assets/earth-tex.js` 中的 `EARTH_TEX_URI`（该文件由贴图生成，**勿手动编辑**）。云层 `CLOUDS_TEX_URI` 同理，可保留真实云层或换纯色柔光层

## 复用资源（已就位，无需生成）

- `assets/three.min.js` — Three.js 本地副本（渲染引擎）
- `assets/flexgap.js` — Flex gap 能力检测
- `assets/earth-tex.js` — 真实地球与云层贴图（复用 earth-3d 的 `earth.jpg` + `clouds.png`），base64 data URI 内联，规避 `file://` 协议下 WebGL 拒绝跨域图片的限制。由贴图文件生成，勿手动编辑
