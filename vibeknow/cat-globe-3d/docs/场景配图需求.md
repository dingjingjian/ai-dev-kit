# 场景配图需求

本文件列出 `cat-globe-3d` 除猫咪品种图外的场景配图需求。

## hero 横幅

- **路径**：`assets/tex/hero.webp`
- **尺寸**：横版，建议 1200 × 480 px（页面会裁切适配）
- **内容**：世界地图暖色调手绘风，几只不同品种的猫咪剪影散布在各大陆上，飞机航线虚线连接
- **风格**：暖米白底 + 柔和橙红强调，手绘/扁平插画风（非写实）
- **提示词**：暖色调手绘世界地图，米白底，各大洲用柔和色块，几只猫咪剪影坐在不同大陆上，虚线航线与飞机图标连接，温馨治愈旅行手账风，横版构图，留白充足

## 缺图回退

- hero 缺图时，页面回退到 CSS 渐变背景（`#f6dacd → #f4e4d8`），标题文字正常显示
- 其余场景（飞行页天空、地球贴图）均由 Three.js 程序化生成或复用 `earth.jpg`/`clouds.png`，无需额外配图

## 复用资源（已就位，无需生成）

- `assets/three.min.js` — Three.js 本地副本（渲染引擎）
- `assets/flexgap.js` — Flex gap 能力检测
- `assets/earth-tex.js` — 真实地球与云层贴图（复用 earth-3d 的 earth.jpg + clouds.png），base64 data URI 内联，规避 `file://` 协议下 WebGL 跨域限制。由贴图文件生成，勿手动编辑
