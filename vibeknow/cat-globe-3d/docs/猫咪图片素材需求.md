# 猫咪图片素材需求

本文件是 `cat-globe-3d` 的出图权威文档。共需 **24 张猫咪品种图**，交由生图模型生成后覆盖同名文件即可，页面按文件名探测加载。

## 通用规格

- **尺寸**：512 × 512 px，方图
- **格式**：WebP（优先）/ PNG（兜底）
- **背景**：纯浅灰 `#ECECEC`，柔和无缝
- **光**：柔和自然光，无明显方向阴影
- **风格**：写实摄影，非卡通非插画
- **主体**：品种特征清晰可辨，居中，占画面 60–75%
- **命名**：与 `assets/cats.js` 的 `img` 字段路径一一对应，slug 见下表

## 提取提示词

每条猫数据的 `prompt` 字段已包含完整提示词，格式统一为：

> 一只[品种]，[毛色/花纹]，[特征1]，[特征2]，[姿态]，写实摄影，纯浅灰背景，柔和自然光，512x512方图

可用脚本批量提取：

```js
CATS.forEach(c => console.log(c.img, '→', c.prompt));
```

## 缺图回退

页面加载图片失败时，猫咪卡片缩略位显示虚线圆占位符，不影响布局与心动功能。生成图片后覆盖同名文件即自动生效，无需改代码。
