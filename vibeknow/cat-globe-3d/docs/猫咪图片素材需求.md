# 猫咪图片素材需求

本文件是 `cat-globe-3d` 的 **24 张猫咪品种图清单**（图位与品种特征要点）。风格规范以 [`生图规范.md`](生图规范.md) 为准：治愈系 Q 版可爱卡通插画。

出图后覆盖同名文件即可，页面按文件名探测加载，无需改代码。

## 通用规格

- **尺寸**：512 × 512 px，方图
- **格式**：WebP（优先，质量 80–85）/ PNG（兜底）
- **背景**：纯色奶油白 `#FFF7F3`（与页面底色一致，可无缝贴进白色卡片）
- **风格**：Q 版可爱卡通插画 —— 圆润大头小身、大眼睛带高光、粉嫩腮红、柔和深棕描边、平涂上色。**不要写实摄影**
- **构图**：主体居中，占画面 60–75%，四周留白；裁成方形后不变形
- **命名**：与 `assets/cats.js` 的 `img` 字段路径一一对应，slug 见下表

## 提示词

提示词已写入 `assets/cats.js` 每条数据的 `prompt` 字段，**已含统一风格锚点，可整条复制直接投喂生图模型**。格式为：

> 一只[品种]，[毛色/花纹]，[标志特征]，[姿态]，[眼色]，Q版可爱卡通插画，圆润大头小身，大眼睛带高光，粉嫩腮红，柔和深棕描边，平涂上色，纯色奶油白背景，柔和顶光无硬阴影，512x512方图

负面提示词、出图参数、配色与自检清单见 [`生图规范.md`](生图规范.md)。

## 交付自检

- [ ] 24 张是否同一批、同一风格后缀出图（放在一起像一套作品）
- [ ] 是否都有粉嫩腮红 + 带高光的大眼睛
- [ ] 背景是否纯色奶油白（贴进白卡片无边框感）
- [ ] 文件名是否与上表 slug 完全一致
- [ ] 覆盖到 `assets/cats/` 后刷新页面是否自动生效

## 缺图回退

页面加载图片失败时，猫咪卡片缩略位显示**呼吸跳动的粉色猫爪占位**（纯 CSS 内联 SVG，无需图片资源），不影响布局与心动功能。生成图片后覆盖同名文件即自动生效，无需改代码。
