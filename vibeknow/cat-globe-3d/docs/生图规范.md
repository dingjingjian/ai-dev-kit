# 生图规范（可爱插画风）

本文件是 `cat-globe-3d` 全部视觉素材的**风格唯一真源**。所有图位（24 张猫咪图、hero 横幅，以及可选装饰图）都必须遵循本规范，避免各图与页面 UI 风格割裂。

页面 UI 走的是「奶油粉底 + 草莓牛奶粉主色 + 大圆角贴纸卡」的治愈可爱风，图片必须与同一套色彩语言对齐。

## 1. 风格定位

**治愈系 Q 版卡通插画**：圆润、软萌、粉嫩、带手账贴纸感。

> 一句话锚点：**「Q版可爱卡通插画，圆润大头小身，大眼睛带高光，粉嫩腮红，柔和深棕描边，平涂上色」**

## 2. 必备风格关键词

| 维度 | 关键词 | 说明 |
|------|--------|------|
| 画风 | Q版可爱卡通插画、圆润造型、手绘感 | **不要**写实摄影、不要 3D 渲染 |
| 比例 | 圆润大头小身，头身比约 2:1 | 萌感来源 |
| 五官 | 大眼睛带高光、粉嫩腮红 | 每只猫都要有 |
| 线条 | 柔和深棕描边 `#5A453F`、圆头线条 | 比纯黑描边柔和 |
| 上色 | 平涂 + 少量柔和渐变 | 不要写实毛发纹理 |
| 背景 | 纯色奶油白 `#FFF7F3` | 与页面底色一致，贴进白卡片不突兀 |
| 光影 | 柔和顶光、无硬阴影 | 不要强对比、不要摄影棚布光 |
| 构图 | 主体居中，占画面 60–75%，四周留白 | 卡片按 1:1 方形裁切 |

## 3. 统一提示词结构

每条提示词 = **主体描述** + **风格锚点后缀**

- 主体描述：`一只[品种]，[毛色/花纹]，[标志特征]，[姿态]，[眼色]`
- 风格锚点后缀（原样复制，不要改写）：

```
，Q版可爱卡通插画，圆润大头小身，大眼睛带高光，粉嫩腮红，柔和深棕描边，平涂上色，纯色奶油白背景，柔和顶光无硬阴影，512x512方图
```

完整示例（可直接使用）：

```
一只英国短毛猫，蓝灰色短毛，圆脸圆眼圆身，正面端坐如茶壶，铜色圆眼，Q版可爱卡通插画，圆润大头小身，大眼睛带高光，粉嫩腮红，柔和深棕描边，平涂上色，纯色奶油白背景，柔和顶光无硬阴影，512x512方图
```

## 4. 负面提示词（Negative Prompt）

每条都加，防止模型往写实方向跑：

```
照片，写实，真实毛发纹理，摄影，3D渲染，CG，阴暗，高对比，复杂背景，文字，水印，签名，多余肢体，畸变，人类，多只猫
```

## 5. 出图参数

| 项 | 值 |
|----|----|
| 尺寸 | 512 × 512 |
| 比例 | 1:1 |
| 输出格式 | WebP（优先，质量 80–85）/ PNG（兜底） |
| 命名 | 与 `assets/cats.js` 的 `img` 字段一一对应（slug） |
| 出图批次 | 建议每批 ≤ 4 张，同一批使用**完全相同**的风格后缀与负面词，保证 24 张像同一套作品 |

## 6. 配色（与 UI 设计 token 对齐）

| 用途 | 色值 |
|------|------|
| 背景 | `#FFF7F3` 奶油白 |
| 主色（点缀、心形、腮红） | `#FF8FAE` 草莓牛奶粉 |
| 辅助点缀 | `#FFB489` 蜜桃 / `#8AD6BD` 薄荷 / `#FFD489` 奶油黄 |
| 描边 | `#5A453F` 暖棕 |
| 深色文字感 | `#5A453F` 暖棕 |

各品种的毛色以其真实品种特征为准（如英国短毛猫蓝灰、孟买猫纯黑、斯芬克斯猫麂皮色）；上表的粉色系用于**背景、腮红、点缀**，不要拿它覆盖品种毛色。

## 7. 图位清单

| 图位 | 数量 | 规格 | 需求文档 |
|------|------|------|----------|
| 猫咪品种图 | 24 | 512 × 512 | `docs/猫咪图片素材需求.md` |
| hero 横幅 | 1 | 1200 × 480 | `docs/场景配图需求.md` |
| 装饰素材 | 0 | — | 见下方说明，不需要生图 |

**装饰元素全部程序化生成，不占图位**：猫爪水印、心动爱心、loading 跳动猫爪是 CSS 内联 SVG（`:root` 的 `--paw`）；飞行页的航线、爱心标记、星空天球是 Three.js Canvas 绘制。换成图片只会增加体积、引入加载失败与跨域风险，不要替换。

## 8. 出图与替换流程

1. 从 `assets/cats.js` 的 `prompt` 字段取提示词（已含风格锚点，整条复制即可）；或按第 3 节模板自行拼装
2. 加上第 4 节负面提示词，按第 5 节参数出图
3. 按 slug 命名，覆盖到对应目录：猫咪图 → `assets/cats/<slug>.webp`；hero → `assets/tex/hero.webp`
4. 刷新页面即生效，**无需改任何代码**（加载失败时自动回退占位）
5. `node pack.mjs` 重新打包分发

批量导出全部提示词：

```js
CATS.forEach(c => console.log(c.name, '→', c.prompt));
```

## 9. 交付自检清单

- [ ] 风格是 Q 版卡通插画（不是写实摄影）
- [ ] 有粉嫩腮红 + 带高光的大眼睛
- [ ] 描边是柔和暖棕（不是纯黑细线）
- [ ] 背景是纯色奶油白（不是浅灰、不是场景、不是渐变）
- [ ] 主体居中且占画面 60–75%，裁成方形后不变形
- [ ] 品种特征可辨（能认出是哪只猫，不是通用小猫）
- [ ] 24 张放在一起看像同一套作品
- [ ] 文件名与 `cats.js` 的 slug 完全一致
