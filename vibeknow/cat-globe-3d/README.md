# 为了小猫我飞遍全球 · 世界猫咪图鉴

> `#vibeknow` 人文知识。参照 `jurassic-park-3d` 的多页框架与 Three.js 地球组件，将交互从「园区游览 app」重构为「世界猫咪图鉴 → 心动 → 飞去见小猫 → 爱猫基因解析」。核心创新：地区切换用**飞机第一视角沿地球表面飞行动画**，而非地球转动定位相机。

零构建、双击即开的离线前端项目。所有主视觉图片预留占位，提示词见 `docs/`，交生图模型生成后覆盖同名文件即可。

## 交互流程

三页流转，由 `body.className` 切 `mode-xxx` 控制：

```
图鉴页 ──心动 N 只──→ 见小猫模式 ──逐只飞行切换──→ 爱猫基因解析
  ↑                                                        │
  └─────────────── 回到图鉴 ←──────────────────────────────┘
```

### 1. 图鉴页（首页 · mode-atlas）

- hero 横幅 + 世界猫咪图鉴
- 按 5 大洲分组：亚洲 / 欧洲 / 美洲 / 非洲 / 大洋洲
- 每只猫卡片：图 + 名字 + 原产国·城市 + 特征胶囊 + 心动按钮（♥/♡）
- 底部操作栏：[基因解析] [去见 N 只心动小猫]（心动 ≥ 1 才启用）
- 心动状态存 localStorage（键 `catglobe.hearts`），跨刷新保留

### 2. 见小猫模式（mode-fly）

- **飞机第一视角飞行动画**：Three.js 渲染地球，相机贴近地表沿大圆航线（球面线性插值 slerp）飞行
- 起飞 → 巡航 → 降落三阶段，相机高度随 `sin(πt)` 变化，穿过云层时有云从眼前掠过
- 相机朝向航线前方略低位置，视野里下半是地表、上半是天空，叠加舷窗暗角增强第一视角
- 到达后相机环绕目标点上方缓慢转动，弹出小猫卡片（图 + 介绍 + 特征）
- 操作栏：[上一只] [N/总] [下一只] [基因解析]，支持 ←/→ 键盘切换
- 不支持 WebGL 时降级为平铺展示小猫

### 3. 爱猫基因解析（mode-gene）

基于心动的猫咪生成专属报告：

- **爱猫人格**：根据六维均值与偏好模式生成自然语言描述
- **基因图谱**：六维雷达图（毛量/亲人/活跃/独立/颜值/稀有），内联 SVG 零依赖
- **地区基因构成**：心动猫咪的大洲分布条形图
- **特征基因构成**：出现频次最高的 8 个特征条形图
- **心动猫咪列表**：缩略图网格

## 数据

`assets/cats.js` 含 24 只世界猫咪，覆盖 5 大洲。每条字段：

```js
{name:'英国短毛猫',country:'英国',city:'伦敦',lat:51.50,lon:-0.12,region:'europe',
 intro:'...',          // 50-80 字介绍
 traits:['五圆','蓝灰','淡定'],  // 特征胶囊
 tags:['短毛','明星','古典'],
 stats:[4,3,2,4,5,1],   // 六维 [毛量,亲人,活跃,独立,颜值,稀有] 各 0-5，顺序不可变
 color:'#9db4c4',      // 无图回退色
 img:'./assets/cats/british-shorthair.webp',
 prompt:'...'}         // 生图提示词
```

常量 `REGION_LABEL` / `REGION_ORDER` / `STATS_DIMS` 顺序固定不可变。

## 素材

| 图位 | 路径 | 规格 | 说明 |
|------|------|------|------|
| 猫咪品种图 ×24 | `assets/cats/<slug>.webp` | 512×512 方图 | 提示词在 `cats.js` 的 `prompt` 字段，详见 `docs/猫咪图片素材需求.md` |
| hero 横幅 | `assets/tex/hero.webp` | 1200×480 | 详见 `docs/场景配图需求.md` |
| 地球/云层贴图 | `assets/earth-tex.js` | base64 内联 | 真实地形贴图（复用 earth-3d 的 earth.jpg/clouds.png），base64 内联规避 `file://` WebGL CORS |

缺图时逐级回退：猫咪卡片显示虚线圆占位，hero 回退 CSS 渐变。生成图片后覆盖同名文件即生效，无需改代码。

**关于地球纹理**：复用 earth-3d 的真实地球贴图（earth.jpg + clouds.png），转为 base64 data URI 内联到 `assets/earth-tex.js`（约 1MB），规避 `file://` 协议下 WebGL 拒绝跨域图片的 CORS 限制。`assets/earth-tex.js` 由贴图文件生成，勿手动编辑。

## 兼容性

- 最低基线：Android 8.1 出场 Chrome/WebView 61（ES2017）
- Flex gap：`flexgap.js` 能力检测，不支持时回退 margin 布局
- WebGL：三层检测（webgl2 → webgl → 降级平铺），不支持时飞行页显示提示并直接展示小猫
- localStorage：try/catch 包裹，失败静默降级为本次会话
- CSS：基线层 + `@supports`/行为检测增强，不维护两套样式

## 打包

```bash
node pack.mjs
```

产出 `cat-globe-3d.zip`（zip 根即 `index.html`），可直接分发。

## 与 jurassic-park-3d 的关系

参照其多页框架、地球组件结构、兼容性策略与打包脚本，但**交互逻辑真正重构**：

| 维度 | jurassic-park-3d | cat-globe-3d |
|------|------------------|--------------|
| 主题 | 恐龙园区游览 | 世界猫咪图鉴 |
| 首页 | 路线选择卡 | 猫咪图鉴网格（按地区分组） |
| 选择机制 | 选路线/自选恐龙 | 心动猫咪（localStorage） |
| 地区切换 | 地球转动定位相机到化石地 | **飞机第一视角沿大圆航线飞行** |
| 终页 | 巡逻日志（雷达图+简报） | 爱猫基因解析（雷达图+基因构成+人格） |
| 数据 | 30 恐龙 / 5 年代 / 11 国 | 24 猫咪 / 5 大洲 / 15 国 |
| 六维 | 体型/威胁/速度/智力/防御/稀有 | 毛量/亲人/活跃/独立/颜值/稀有 |
