# 诺奖图鉴 · NOBEL ATLAS

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

3D 地球上点亮**两种光点**：**成果**（30 项已经走进日常的诺奖成果）与**人物**（32 位诺奖得主）。底部「成果 / 人物」一键切换维度，转动地球、点开光点，成果读「它解决了什么问题、今天用在哪」，人物读「他做了什么、留下了什么」。左上「名录」按钮可直接摊开当前维度的全部条目，按分类分列翻检。深夜蓝 + 奖章金（诺贝尔之夜的配色），复用姊妹项目 `vibeknow/world-food-atlas` 的 3D 地球+标记点+卡片+分类筛选+清单+分享骨架。

内容方向对应小红书活动 **#不硬核诺奖指南** 的子话题 **#生活中的诺奖**，活动材料原文归档见 [`xiaohongshu/活动要求.md`](xiaohongshu/活动要求.md)。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录。

> 每人的卡片第二行是「奖项年份 + 生卒年」，正文讲他/她怎么走到那一步，落点行是「留下了什么」。

## 交互

- 拖动旋转地球，滚轮 / 双指缩放
- 地球表面有 30 / 32 个发光标记，标记随地球自转；标记在屏幕上尺寸恒定（约 18px，选中约 22px），小屏 / 宽屏 / 拉近拉远都一致，靠近地球轮廓时淡出
- **标记按分类取色**（与底部筛选条的提示点同色）
- **每个可见标记都挂名牌**（地点·名称，前有分类色圆点）：地名在球面上挤成一处的——成果维度的美国东北部 7 项（石溪 / 默里山 / 霍姆德尔 / 纽约 / 约克镇高地 / 费城 / 普林斯顿）、伦敦 3 项（青霉素 / CT / 光纤通信），人物维度的「纽约 + 哈特福德」——名牌不再互相挤掉，而是**在光点上下叠成一列外挂**（上方放得下就挂上方，否则挂下方），每条用一条极细的引线连回自己的光点；挤压 3 项以上的地方，列首旁挂一个数字徽标（如 `7项`）说明这一处压着几项。判定全在屏幕空间做，拉远拉近、转到侧面都跟着走；名牌本身可点，密集处照样点得准；点光点则统一落到该处的列首那一条（同一个判定球里点中谁并无意义）
- 点击标记 → 地球停转、飞到该标记正面、底部展开卡片
- **底部「成果 / 人物」切换维度**：换维度即换一整套分类与条目，标记点、名牌、筛选条、名录、清单标题与单位（项 / 位）全部同步重建，选中态与相机回到该维度的默认位置（成果对德国维尔茨堡的 X 射线，人物对中国宁波的屠呦呦）
- 卡片含「分类 · 地点」、名称、**奖项胶囊**、配图、正文、**落点行**（成果＝今天用在哪；人物＝留下了什么）、关键词标签、经纬度
- 底部分类筛选：单排胶囊、溢出一屏时两端渐隐、横向滚动 + `scroll-snap` 吸附（同 `vibeknow/solar-system-3d` 的 dock 交互）
- **左上「名录」按钮 → 当前维度完整名录**：按分类分列（顺序同底部筛选条，组内保持数据原序，每组标题带该组条数），每行含配图缩略图、名称、地点与该条的奖项年份；点任意一行即收起名录 → 地球飞到该标记正面 → 展开卡片（与直接点标记完全同一条路径）。当前分类筛选生效时，名录中非本类项同步变暗、选中项描金高亮；`Esc` 或右上 `×` 关闭
- **光照取真实北京时间**：太阳直射点经度 = 15°×(20 − 北京小时)，纬度按日期取太阳赤纬，于是北极的极昼／极夜、晨昏线的季节倾斜都对得上今天
- 右上设置：顶部显示"此刻"（北京时间 / 直射点），下面为自动旋转 / 星空 / 云层 / 标签开关，重置 / 俯视视角，以及本次的「关于」说明
- 卡片底部「分享到小红书」：合成 1080×1440 海报（名称 + 分类地点 + 奖项 + 正文 + 落点 + 标签 + 经纬度），调用 `window.xhs.miniTool` 发笔记，正文尾注品牌与 `#不硬核诺奖指南 #生活中的诺奖`

## 配图

条目卡片上有 62 个配图位（成果 30 + 人物 32，`assets/illus/<slug>.webp`，512×512，主体居中留白，slug 见 `assets/data.js` 的 `slug` 字段）。

- **图未生成时**：卡片显示程序化占位（深夜蓝底 + 奖章圆盘 + 文件名），不空着、也不改卡片尺寸，因此**可以分批补图**。此时控制台会有对应图片的 404，属预期（预检失败即回退占位）。
- **放图即生效**：路径写在 `assets/data.js` 的 `img` 字段，文件按约定命名丢进 `assets/illus/` 即可，无需改代码。

## 视觉

深夜蓝 + 奖章金：深靛蓝底（`#070b16`，斯德哥尔摩市政厅蓝厅的夜色）+ 象牙白文字（`#eaf0fa`）+ 奖章金强调（`#d9b26a`），面板是冷调玻璃（`rgba(16,24,42,.86)`），地球配一圈奖章金的边缘辉光。标题用衬线体（宋体感），正文用衬线体，UI 用无衬线。

六大分类色同一明度带、饱和度收敛，只靠色相区分（医红 `#e2604a` / 数码蓝 `#6c9bd2` / 通信青 `#46b0a4` / 食绿 `#86ab5c` / 家用紫 `#b07cc6` / 能源橙 `#eaa34e`），成组出现时不打架。色值唯一真源在 `assets/data.js` 的 `CATS[].color`。

与 `vibeknow/world-food-atlas`（焦糖黑暖琥珀）、`vibeknow/world-heroines-atlas`（深紫红曙光）三套配色实质差异化；复用同一交互骨架但不构成换皮：本项目多了一层**维度切换**（成果 / 人物两套分类与两套坐标语义），卡片字段也不同（奖项胶囊 + 落点行，而非味型热量 + 食材）。

地表标记形制参考 `vibeknow/moon-myths`（实心点 + 光晕 + 描边 + 细环四层），配色按分类取色。

## 技术栈

复用 `vibeknow/world-food-atlas` → `vibeknow/earth-3d` 的 Three.js 渲染框架（地球贴图、程序化星空、云层、大气辉光、手势控制），改造为「地图标注 + 点击展开 + 双维度」交互形态。单文件零依赖（除 three.min.js），兼容 Android 8.1 Chrome/WebView 61 基线。

配图走「数据声明路径 + 预检 + 程序化占位」：`data.js` 的 `img` 字段声明图位，`app.js` 启动时逐张预检，加载失败或 2.6 秒未就绪即回退到 CSS 占位，因此配图缺失不影响功能与布局。切换维度时对新维度重跑一次预检。

光照不引入任何天文库：直射点、太阳赤纬都是十几行三角函数，见 `app.js` 的 `astroUpdate()`。北京时间取 `Date` 的 UTC 值 +8 小时，**不依赖设备时区**。

## 数据口径

- 奖项年份、得主、奖项类别按官方公布整理，逐条校对；人物生卒年与出生地取公开资料。
- 成果的「诞生地」指该获奖研究的发生地（实验室 / 城市），人物的经纬度取出生地，两者不混用。
- 和平奖中收录的是历史性的个人与机构（施韦泽、红十字国际委员会、特蕾莎修女、无国界医生、国际原子能机构），不涉及当代政治议题。
- 不收录有明确争议或仍在演变的当代案例。

没有任务、没有输赢，用户点开是为了"看看那些改变世界的发现怎么走进日常生活、那些追问了一辈子的人是怎么想的"，看完脑子里多一份对科学与人类处境的认知 → `#vibeknow`。
