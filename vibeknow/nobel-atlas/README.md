# 诺奖图鉴 · NOBEL ATLAS

> **分类**：`#vibeknow` 人文知识　·　分类索引见根目录 [`TRACKS.md`](../../TRACKS.md)

3D 地球上点亮**两种光点**：**成果**（50 项已经走进日常的诺奖成果）与**人物**（50 位对应人物，与成果一一对应）。卡片顶部「成果 / 人物」一键切换维度——切过去会直接落到当前条目的配对方（如 X 射线 ↔ 伦琴）。转动地球、点开光点，成果读「它解决了什么问题、今天用在哪」，人物读「他做了什么、留下了什么」。左上「名录」按钮可直接摊开当前维度的全部条目，按分类分列翻检。深夜蓝 + 奖章金（诺贝尔之夜的配色），复用姊妹项目 `vibeknow/world-food-atlas` 的 3D 地球+标记点+卡片+分类筛选+清单+分享骨架。

内容方向对应小红书活动 **#不硬核诺奖指南** 的子话题 **#生活中的诺奖**，活动材料原文归档见 [`xiaohongshu/活动要求.md`](xiaohongshu/活动要求.md)。

## 打开方式

双击 `index.html`。资源在 `assets/`，需与 `index.html` 保持同级目录。

## 交互

- **开场视角固定在中国上空**：一点开镜头就对准 35°N / 105°E（`app.js` 的 `aimHome()` / `CAM_HOME`），看到的是中国所在的这一面；这一面是白天还是夜里交给真实光照去决定，夜面另有城市灯光。若开了「自动旋转」，地球自转会带着这块地方挪走，此时以光照为准
- 拖动旋转地球，滚轮 / 双指缩放
- 地球表面有 50 / 50 个发光标记（两个维度一一对应），标记随地球自转；标记在屏幕上尺寸恒定（光点约 15px，选中约 19px），小屏 / 宽屏 / 拉近拉远都一致，靠近地球轮廓时淡出
- **标记按分类取色**（与底部筛选条的提示点同色）；外圈是虚线环，缓慢自转（选中态转快一倍），相位随序号错开
- **名牌密度全按缩放走**：**默认视角一条名牌都不挂**，只留光点，方便一眼看清分布；而且要拉近到 **1.5 倍**（`z = fitR()/radius` ≥ `LABEL_Z_MIN`，`app.js`）才开始从 0 逐条出现，额度 ≈ 系数 × `(z-1.5)^1.3`：手机拉近 1.7× 出 3 条、2.2× 出 16 条，拉到最近等于不限量。选中项与「筛了某一类」（**该类的条目有几条就放几条**，见 `curCatN`）不受这条门槛限制
- **成簇判定距离也随缩放收紧**：宽屏 30→14px、窄屏 22→11px，拉近后本可分开的点会自动散开、各挂各的名牌
- **额度优先给看得见的地方**：屏幕外的标记不挂名牌；被顶部品牌 / 左右按钮 / 底部筛选条 / 已展开卡片挡住的位置降级到候选末尾，额度不够就先不给它——视线范围内的名牌先出现
- **名牌文案一律完整**：宽屏窄屏都写全「地点·名称」，不缩写、不加省略号；密度只靠额度与成簇外挂控制
- **没成簇的单条名牌也有一串备选位**（`TAG_LADDER`）：默认位置被旁边的名牌挤掉、或压到标题带 / 筛选条 / 展开的卡片底下时，沿纵向逐格上下让位（引线自动牵回自己的光点），不会因为「旁边正好有名牌」就整条不挂——那是「点看得见、却认不出是谁」的最难用情况
- **窄屏兜底**：每列最多 2 行（宽屏 3 行），超出列上限的成员由列首「N 项」徽标代表
- 地名在球面上挤成一处的——如美国东北部 6 项（石溪 / 默里山 / 霍姆德尔 / 纽约 / 费城 / 普林斯顿）、伦敦 3 项（青霉素 / CT / 光纤通信）——名牌不再互相挤掉，而是**在光点上下叠成一列外挂**（上方放得下就挂上方，否则挂下方），每条用一条极细的引线连回自己的光点；挤压 3 项以上的地方，列首旁挂一个数字徽标（如 `7项`）说明这一处压着几项。判定全在屏幕空间做，拉远拉近、转到侧面都跟着走；名牌本身可点，密集处照样点得准；点光点则统一落到该处的列首那一条（同一个判定球里点中谁并无意义）
- 拖拽灵敏度随缩放自适应：拉得越近，同样的手指滑动转过的角度越小
- 点击标记 → 地球停转、飞到该标记正面、底部展开卡片
- **卡片顶部「成果 / 人物」切换维度**：换维度即换一整套分类与条目，标记点、名牌、筛选条、名录、清单标题与单位（项 / 位）全部同步重建；**从卡片内切换会落到当前条目的配对方**（如 X 射线 ↔ 伦琴），卡片不关、内容顺势换过去，无配对时退回该维度开场落点
- 卡片含「分类 · 地点」、名称、**奖项胶囊**、配图（人物用其成果的图）、正文、**落点行**（成果＝今天用在哪；人物＝留下了什么）、关键词标签、经纬度
- 底部分类筛选：单排胶囊、溢出一屏时两端渐隐、横向滚动 + `scroll-snap` 吸附（同 `vibeknow/solar-system-3d` 的 dock 交互）；**点某一类 = 定位到这一类**（`frameCat()`）：镜头对准该类条目的球面质心（不是 `data.js` 里给筛选条用的手写粗方位），并按该类最外围条目的角距离 + 命中「标记可见度」两个下限反解视距，把整类框进画面——在放大视角下会先把镜头拉远再对过去，不会出现「转过去却什么都找不到」；距离夹在 `0.3×fitR() ~ fitR()`（整球视角）之间，跨度大到绕到球背面的分类退回整球视角，背面的条目只能转动地球再看。点「全部」只撤掉筛选、不动镜头
- **左上「名录」按钮 → 当前维度完整名录**：顶部自带「成果 / 人物」切换器（与卡片顶部同一套，切换时清单原地刷新、选中态两处同步），`Esc` 或右上 `×` 关闭；按分类分列（顺序同底部筛选条，组内保持数据原序，每组标题带该组条数），分类头吸顶、左右通铺不留缝，每行含配图缩略图、名称、地点与该条的奖项年份；点任意一行即收起名录 → 地球飞到该标记正面 → 展开卡片（与直接点标记完全同一条路径）。当前分类筛选生效时，名录中非本类项同步变暗、选中项描金高亮；`Esc` 或右上 `×` 关闭
- **夜面有城市灯光**：地表之上单贴一层加色混合的灯光球壳（`assets/earth-night.jpg`），只在该点背向太阳时出现——`smoothstep(0.08,-0.26,法线·太阳方向)` 让灯光在晨昏线附近柔和亮起，白昼那半边一条不亮。太阳方向是世界空间的量（`astroUpdate()` 每帧写进 `uSun`），球壳挂在内层自转组里，所以灯光随地球自转一起走；在设置里可以关掉
- **光照取真实北京时间**：太阳直射点经度 = 15°×(20 − 北京小时)，纬度按日期取太阳赤纬，于是北极的极昼／极夜、晨昏线的季节倾斜都对得上今天
- 右上设置：顶部显示"此刻"（北京时间 / 直射点），下面为自动旋转 / 星空 / 云层 / 城市灯光 / 标签开关，重置（回到开场朝向，即中国上空）/ 俯视视角，以及本次的「关于」说明
- 卡片底部「分享到小红书」：合成 1080×1440 海报（名称 + 分类地点 + 奖项 + 正文 + 落点 + 标签 + 经纬度），调用 `window.xhs.miniTool` 发笔记，正文尾注品牌与 `#不硬核诺奖指南 #生活中的诺奖`

## 配图

**只给成果维度出图：50 张**（`assets/illus/<成果 slug>.webp`）。规格：**横向 2:1**，建议 720×360（显示端卡片配图区约 2:1，cover 铺满），主体居中、四周留白，单张 ≤ 60 KB、合计 ≤ 2.5 MB（WebP）。slug 见 `assets/data.js` 各成果条目的 `slug` 字段——也就是全部 50 条成果的 slug。

**人物维度不出图**：每位人物与一件成果一一对应（`pair` 字段），其配图在运行时按 pair **复用对应成果的图**（`app.js` 的 `itemImg()`）。因此人物卡片、名录缩略图、分享海报上的图都是那张成果图，调整配对关系不需要重出图。

- **图未生成时**：卡片显示程序化占位（深夜蓝底 + 奖章圆盘 + 实际使用的文件名），不空着、也不改卡片尺寸，因此**可以分批补图**。此时控制台会有对应图片的 404，属预期（预检失败即回退占位）。
- **放图即生效**：成果条目的路径写在 `assets/data.js` 的 `img` 字段，文件按 `<成果 slug>.webp` 丢进 `assets/illus/` 即可，无需改代码；人物条目不用写 `img`。
- 50 张成果配图已全部就位（`assets/illus/`），slug 与 50 条成果一一对应；缺图时仍会回退到上面的程序化占位。

## 视觉

深夜蓝 + 奖章金：深靛蓝底（`#070b16`，斯德哥尔摩市政厅蓝厅的夜色）+ 象牙白文字（`#eaf0fa`）+ 奖章金强调（`#d9b26a`），面板是冷调玻璃（`rgba(16,24,42,.86)`），地球配一圈奖章金的边缘辉光。标题用衬线体（宋体感），正文用衬线体，UI 用无衬线。

六大奖项分类色同一明度带、饱和度收敛，只靠色相区分（物理蓝 `#6c9bd2` / 化学绿 `#86ab5c` / 医学红 `#e2604a` / 文学紫 `#b07cc6` / 和平橙 `#eaa34e` / 经济青 `#46b0a4`），两个维度同奖同色，成组出现时不打架。色值唯一真源在 `assets/data.js` 的 `CATS[].color`。

与 `vibeknow/world-food-atlas`（焦糖黑暖琥珀）、`vibeknow/world-heroines-atlas`（深紫红曙光）三套配色实质差异化；复用同一交互骨架但不构成换皮：本项目多了一层**维度切换**（成果 / 人物两套分类与两套坐标语义），卡片字段也不同（奖项胶囊 + 落点行，而非味型热量 + 食材）。

地表标记形制参考 `vibeknow/moon-myths`（实心点 + 光晕 + 描边 + 细环四层），配色按分类取色。

顶部标题带压一层与页面底色同源的竖向渐变底衬（`.top::before`，顶端最实、往下淡出）：地球拉近后亮面地形 / 云层会顶到标题后面，纯白字压上去读不清；底衬在深色空处与底色重合看不出、在亮地形上就是一块渐隐的暗底。标题文字除原有金色辉光外另加一道极近的深色描边，让字形边缘在亮地形上也咬得住。

## 技术栈

复用 `vibeknow/world-food-atlas` → `vibeknow/earth-3d` 的 Three.js 渲染框架（地球贴图、程序化星空、云层、大气辉光、手势控制），改造为「地图标注 + 点击展开 + 双维度」交互形态。单文件零依赖（除 three.min.js），兼容 Android 8.1 Chrome/WebView 61 基线。

配图走「数据声明路径 + 预检 + 程序化占位」：`data.js` 的 `img` 字段声明图位，`app.js` 启动时逐张预检，加载失败或 2.6 秒未就绪即回退到 CSS 占位，因此配图缺失不影响功能与布局。切换维度时对新维度重跑一次预检。

光照不引入任何天文库：直射点、太阳赤纬都是十几行三角函数，见 `app.js` 的 `astroUpdate()`。北京时间取 `Date` 的 UTC 值 +8 小时，**不依赖设备时区**。

夜面城市灯光不引入任何依赖：一张 2048×1024 的灯光贴图 + 一个二十来行的 `ShaderMaterial`（世界空间法线与太阳方向点乘决定显隐，加色混合叠在地表上），见 `app.js` 的 `nightMat` / `nightMesh`。贴图按「显示值」做成暖金色，`ShaderMaterial` 又是原始取样、不做 sRGB 解码，所以它不参与本文件里那套 `convertSRGBToLinear()` 的色彩管理。

## 数据口径

- 奖项年份、得主、奖项类别按官方公布整理，逐条校对；人物生卒年与出生地取公开资料。
- 成果的「诞生地」指该获奖研究的发生地（实验室 / 城市），人物的经纬度取出生地，两者不混用。
- 和平奖中收录的是历史性的个人（亨利·杜南、布劳格、乔迪·威廉姆斯、勒内·卡森），不涉及当代政治议题。
- 不收录有明确争议或仍在演变的当代案例。

## 分类判定

没有任务、没有输赢，用户点开是为了"看看那些改变世界的发现怎么走进日常生活、那些追问了一辈子的人是怎么想的"，看完脑子里多一份对科学与人类处境的认知 → `#vibeknow`。
