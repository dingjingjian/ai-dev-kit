# 国风拼豆小游戏 · 设定文档

## 一、项目概述
- **是什么**：基于拼豆（Perler Bead）钉板填色玩法，照着国风纹样在 21×21 钉板上填豆，拼出图案即过关的网页小游戏。
- **来源**：以 `perler-bead-designer`（48 色拼豆设计器）为基底衍生，将"自由设计"改为"对纹闯关"。
- **形态**：纯前端单文件、零依赖，浏览器直接打开即可运行，**移动端优先，不单独适配 PC**。

## 二、文件结构
```
国风拼豆小游戏/
├── 国风拼豆小游戏.html                ← 游戏本体（单文件 HTML+CSS+JS）
├── 国风拼豆小游戏.html.bak.YYYYMMDD  ← 初版安全备份（可回滚）
└── 设定文档.md                       ← 本文件
```
**运行方式**：双击或用浏览器打开 `国风拼豆小游戏.html` 即可，无需安装、无需联网。

## 三、技术栈
- 纯前端单文件，零外部依赖。
- 渲染：Canvas 2D 负责钉板与拼豆的 3D 效果；DOM + CSS 负责 UI 外壳。
- 目标图案生成：先用离屏 canvas 以国风色绘制纹样，再逐像素量化到国风色卡，得到"目标网格"（每格一个色号或空）。

## 五、游戏机制
- **钉板**：N×N = 21×21；每格可放一颗拼豆（圆形 3D 渲染：径向渐变 + 中心孔洞 + 高光）。
- **玩法**：选国风色 → 点按 / 拖动连续填豆 → 对照"参照纹样"拼出目标图案。
- **完成度**：正确格数 ÷ 目标非空格数，实时进度条；达到 100% 自动盖「成」字印章庆祝，并记录用时。
- **交互工具**：画笔 / 橡皮 / 显示参考答案（淡淡底色提示）/ 校验答案（红圈标出待修正）/ 清空 / 示范（一键完成看效果）。
- **画廊**：9 个国风图案横向切换，每个带难度星级（★）。

## 七、UI 设计基调
- **配色**：暗木纹底（`--bg-*`）+ 米纸色钉板（`--paper`）+ 朱砂红（主行动色 `--red`）+ 描金（点缀 / 进度 / 印章 `--gold`）；并细化出 `--red-deep / --gold-soft / --gold-deep / --paper-warm / --border-gold / --shadow-soft / --shadow-deep / --ease` 等设计变量。
- **字体**：楷体 / 宋体栈（`KaiTi` / `STKaiti` / `KaiTi SC` / `楷体` / `Songti SC` / `SimSun` …）。
- **装饰**：回纹 / 云纹角饰、印章式 logo、宣纸质感背景、描金分隔线。
- **动效**：hover / active 微过渡（印章轻转、卡片上浮、按钮描金高亮）；移动端触控热区 ≥ 40px。
- **布局**：移动端单列（顶栏 / 图案条 / 钉板舞台 / 色珠串 / 工具条），`100dvh` 满屏不滚动，安全区 `env(safe-area-inset-*)` 适配；图案条与色珠串横向滚动；工具条固定底部，触控热区 ≥ 44px；**不考虑 PC 布局**。
