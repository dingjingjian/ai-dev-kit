# 拼豆设计工具 - Perler Bead Designer

浏览器端拼豆图案设计工具，严格遵循拼豆行业颜色标准，功能完全适配拼豆制作专业流程。

## 功能特性

### 拼豆色卡
- 50 色行业标准配色，按色系分组（白色/黄/橙/红/粉/紫/蓝/绿/棕/灰黑色系）
- 每种颜色标注中文色名和色值
- 支持自定义取色器

### 钉板系统
- **4 种钉板形状**：正方形、圆形、心形、六边形
- **5 种钉板尺寸**：14×14、20×20、29×29、40×40、58×58
- 自动识别有效钉位，非钉位区域不可放置拼豆

### 绘制工具
- 放置拼豆 / 移除拼豆 / 填充 / 取色
- 对称绘制模式（水平镜像），适合制作对称图案
- 水平镜像、垂直镜像、顺时针旋转 90°
- 撤销 / 重做（最多 50 步）

### 拼豆渲染
- 圆形拼豆 3D 渲染效果（渐变 + 中心孔洞 + 高光）
- 熨烫效果预览（模拟成品融合效果）
- 可切换方形/圆形显示样式

### 用料统计
- 实时统计各颜色拼豆用量，按数量降序排列
- 自动计算成品尺寸（5mm/颗，熨烫后约 5.5mm/颗）

### 导入与导出
- 导入图片并量化到拼豆色卡
- 导出 PNG 高清图（10 倍放大）
- 导出 SVG 矢量图
- 导出拼豆图纸（含颜色标注、用量统计、行列编号）

### 移动端适配
- ≤768px：底部工具栏 + 滑出式色卡面板 + 滑出式功能面板
- ≤1024px：可弹出右侧面板
- 完整触摸绘制支持

## 使用方法

直接在浏览器中打开 `index.html` 即可使用，无需安装任何依赖。

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| B | 放置拼豆 |
| E | 移除拼豆 |
| G | 填充 |
| I | 取色 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| +/- | 缩放画布 |
| 0 | 适配画布 |

## 技术栈

- 纯前端单文件应用（HTML + CSS + JavaScript）
- Canvas 2D API 渲染
- 零外部依赖
