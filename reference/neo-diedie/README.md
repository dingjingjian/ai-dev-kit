## 亮点拆解

1. **情绪场景化包装**：把「叠玛尼堆」这一户外疗愈行为搬进屏幕，背景是春日溪畔、草地、流水、白云，直接营造「吹吹风，叠叠石头」的情绪氛围。
2. **进度外化**：左上角「我的小石塔 06 块」把游玩进度变成可量化、可截图分享的小成就，适合作为每日打卡/轻社交素材。
3. **日记体文案**：底部「今天，在这里歇了一会儿。吹吹风，叠叠石头。」用第一人称日记口吻降低工具感，增强陪伴感与情绪共鸣。
4. **场景切换**：顶部「春日溪畔」暗示存在多套户外场景（溪畔、山顶、林间等），可持续解锁，延长新鲜感。
5. **文化符号借力**：#玛尼堆 自带祈福、平衡、户外文化意象；配合 #小红书外人节 #赛博户外，把数字解压与户外生活方式结合，话题组合清晰。
6. **跨界定位**：标签同时打 #小工具 和 #小工具游戏，说明交互偏轻、玩法偏休闲，可作为「工具 + 游戏」中间态的参考。

## 与自研项目对照

- **同赛道样本**：与 `vibetool/` 的情绪化小工具、解压类小工具同频；相比 `vibegame/` 的竞技/街机，叠叠更偏「低压力陪伴 + 情绪产出」，和 perler-city（拼豆城市）的慢节奏创作有相通之处。
- **可借鉴**：户外场景插画化、进度卡片式 UI、日记体收尾文案、可截图分享的成果页设计；若做类似玩法，可重点拆解石头放置的物理/平衡判定、倾倒反馈、不同形状石头的生成规则。
- **待拆解问题**：石头是否受重力/碰撞影响（物理平衡 vs 纯点击堆叠）、失败条件、是否有音效/震动、场景解锁机制、能否保存/分享最终石塔。
