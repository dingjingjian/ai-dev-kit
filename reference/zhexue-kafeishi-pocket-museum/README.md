## 简介

「把博物馆展品缩小到手机里」的 3D 展品浏览器：首件展品为 T-72B3 主战坦克，可 360° 旋转、放大观察细节、从不同角度查看车体结构，像在博物馆里绕着展品慢慢看。系列化运营，按「第 N 件展品」持续更新。

## 亮点

- **3D 交互完备**：360° 旋转 / 缩放 / 自转开关 / 复位 / 展签（展品说明卡），移动端手势操作完整。
- **部件标注导览**：左侧编号列表（1 炮口、2 炮塔、3 车体、4 反应装甲、5 履带、6 车尾、7 负重轮），点选聚焦对应结构——教育价值的关键设计。
- **半透明分解视图**：截图上部可见线框/网格状的顶部分解层，疑似「结构透视/分层展示」效果，比普通 3D 模型展示更进一步。
- **系列化内容运营**：「掌上博物馆 · 第01件展品」连载形式 + 评论区征集下一件展品，天然的持续更新钩子。
- **版权规范**：界面底部标注「CC BY 4.0 · XM@哲学咖啡师」，模型授权来源清晰。
- **叙事立意**：「博物馆展品数字化，会让更多人获得知识」，从知识普惠角度立意而非炫技。

## 笔记原文摘录

> 如果坦克可以放进口袋里，会是什么感觉？
> 掌上博物馆 · 第01件展品。今天把一辆 T-72 坦克"搬"进了小红书小工具#掌上博物馆。
> 这次不是看一张坦克照片，而是可以直接在手机里：🔄 360°旋转 🔍 放大观察细节 👀 从不同角度查看车体结构 📱 像在博物馆里绕着展品慢慢看。
