## 简介

竖屏像素风「自动飞升」攀高游戏：角色自动向上升，玩家只负责左右控制踩平台借力，比谁飞得更高；带高度计（当前/最高）、血量（爱心）、区域分层（地面城区等）。

## 亮点

- **单手双区操控**：底部左右两侧「按住左侧 / 按住右侧」触区，竖屏单手即可玩，操作极简。
- **自动飞升 + 左右微操**：纵向进度自动化，玩家只管横向落点——把 Doodle Jump 类玩法压缩到「一个维度」的决策，门槛极低。
- **即时数值反馈**：右上角实时「高度 96m / 最高 496m / 地面城区」——当前值 + 最佳值 + 区域名三件套，攀比欲直接拉满。
- **像素叙事分层**：黄昏城市剪影背景随高度分层（地面城区等），高度本身成为视觉叙事；标题「中国人能飞🪽」玩梗自带传播性。
- **社交裂变文案**：「看谁飞的更高哈哈哈」+ @多位好友，直接把攀比做成传播钩子。
