## 简介

把阿波罗任务的真实安全规则做成了游戏：月球车不能开到宇航员走不回登月舱的距离之外。氧气 240 秒是任务时钟，电量随速度平方消耗，地面上一圈虚线实时标出「此刻还能走回去」的极限——圈越缩越小，电池在圈外耗尽即失败。

## 亮点

- 真实航天规则 → 核心机制：步行返回线是天然的风险/收益可视化，无需教程
- 收益结构克制而清晰：7 个采样点越远分越高（最远「创世岩」100 分），剩余氧气与电量计入结算奖励，「贪不贪自己掂量」
- 状态可视化即玩法：虚线圈随氧气收缩，风险直接画在地面上
- 完全离线零资源：地形/贴图代码生成，鼓/贝斯/琶音全靠振荡器现场合成，开车有电机声、越线有警报
- 发布文案带「一整局视频没剪」增强可信度，含「最佳成绩 105」留存钩子
