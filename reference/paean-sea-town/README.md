## 简介

在安静的海面上造属于自己的小镇：轻点水面铺码头平台，点屋顶把房子叠高，点墙面横向延伸，逐步长出一座地中海风的海上小镇。

## 亮点

- 三种点击语义极简建造：水面铺码头 / 点屋顶叠高 / 点墙面延伸，零教学成本
- 等距视角 + 柔和低饱和配色 + 水面倒影，治愈系氛围拉满（首屏即成片）
- 评论区晒图互动闭环：「晒晒你的海上小镇」把玩家产出变成社区内容
- 「自在城镇」「岛屿制造人叠高高」自创话题标签做轻品牌化
