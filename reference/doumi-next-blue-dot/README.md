## 笔记原文摘录

> 通关条件不是飞得最远，是找到一颗有海的星球。《下一个蓝点》，从家门口的草地飞到宇宙的边缘。
> 一局 60–90 秒，只有点、按住、滑三个手势：
> ① 拼飞船，配平重心，刷个漆
> ② 按住蓄能，松手落进绿区
> ③ 滑着躲飞鸟、客机、雷暴、流星
> ④ 按住靠近木星，松手，被引力甩出去（真·引力弹弓）
> ⑤ 星图二选一：补给站、遗迹、黑洞、伽马暴
> ⑥ 沿宇宙网的金色丝线往外飘
> 六个阶段六种玩法，手势还是那三个，一次都没多。
> 尺子从「米」起跳，一路跳到百万光年。过卡门线时屏幕上只有一句：「从这里开始，天空不再是天空。」
> 整包一百来 KB，零图片零音频，61 张天体卡也是参数现画的。
> 越接近光速，返航时地球流逝的年数越多。它不参与玩法，纯粹因为它是真的，就想放进去。
> 结局那颗星叫 TOI-700 d，101.4 光年外，宜居指数 0.93。它真的在那儿。

## 亮点拆解

1. **三手势六阶段**：点 / 按住 / 滑三个手势贯穿六个玩法阶段（拼装蓄能 → 躲避 → 引力弹弓 → 星图分支 → 宇宙网巡航）——操作集合极小、玩法密度极高，「一次都没多」是刻意的设计纪律。
2. **尺度叙事**：尺度尺 HUD 从 m → km → 万 km → AU → ly → kly → Mly → Gly 连续跳格，把不可感的宇宙尺度做成可感的进度条；「过卡门线」用一句文案切换场景心境。
3. **真科学作彩蛋不作机制**：时间膨胀（近光速返航地球流逝年数）明确「不参与玩法」；结局星 TOI-700 d（101.4 ly，宜居指数 0.93）是真实系外行星——科普价值与情感落点都来自真实性。
4. **极端轻量化**：整包约 100 KB、零图片零音频，61 张天体卡全部参数化实时绘制——与零构建单文件 HTML 路线完全同构，工程上可直接对标。
5. **通关条件反套路**：不比飞得远，比「找到一颗有海的星球」——目标从竞速换成寻找，情绪从紧张换成远行（「这不是逃命，是远行」）。
6. **文案文学性**：「从一颗淡蓝色的小点出发，去另一颗淡蓝色的小点。中间隔着的，是我们全部的好奇心。」——把「Pale Blue Dot」梗落到中文语境，结尾开放式提问「你想去哪一颗」引评论。

## 与自研项目对照（重点）

- **vs solar-voyager（同母题直接竞品）**：同样是「从地球出发飞向深空」的航天叙事；它把多玩法压进三手势 + 60–90 秒单局，solar-voyager 可对照其**单局节奏切分**（六阶段各占多少秒）与**尺度递进 HUD** 的做法。
- **vs rocket-launch**：发射蓄能-落绿区、卡门线阈值等真实航天节点复用方式可对照。
- **工程路线同构**：零图片零音频 + 参数化绘制，与 defcon/air-tycoon 的零依赖路线一致；其 100 KB 装下六阶段玩法的体量控制值得拆包研究。
- **可借鉴但勿抄**：尺度尺 HUD 的分格设计、真实天体数据卡（TOI-700 d 等）的科普彩蛋位——vibeknow/rocket-launch 也可参考「真实数据即内容」的做法。
