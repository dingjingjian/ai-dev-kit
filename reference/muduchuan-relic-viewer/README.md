## 亮点拆解

1. **界面即展陈设计**：宣纸底色 + 青铜绿/印泥朱双配色、竖排书法标题、馆徽 + 中英双馆名排布——整个页面按博物馆展签/画册的版式语言做，3D 文物嵌在「展签」中央；「拖动旋转 · 滚轮缩放」提示语用竖排小字藏在展品下方。
2. **功能清单完整**：全器赏鉴（视角下拉）、揭顶观乐（剖切屋顶看内部乐师）、缓缓转动（自动旋转）、细节导览（分步聚焦）、回到初见（重置机位）、生成文物图鉴（导出产物）——六个功能覆盖「看全貌 → 看内部 → 看细节 → 留纪念」完整观展动线。
3. **底部元信息条**：「春秋｜青铜器｜高 17 厘米」——文物档案字段直接落版，科普严谨感拉满（与下一个蓝点的真实系外行星数据同理：真实信息即内容）。
4. **内容策略是教程**：不炫成品炫流程——「全流程拆解 + 零基础」定位收割想入场的创作者，赛道卡位与纯作品笔记错开；金句「技术已经不难，重要的是想法、创意与审美 sense」立人设。
5. **方法论输出**：「小步迭代、慢慢打磨，不要急于求成」——与本项目 vibe coding 的迭代纪律一致。

## 与自研项目对照

- **vs 掌上博物馆（同赛道双样本）**：掌上博物馆押 T-72 军事模型 + 部件导览，本作押馆藏文物 + 展陈式版面——同是 3D 观展，一个「实验室风」一个「博物馆画册风」，两种视觉路线可直接对照选型。
- **vs vibeknow 科普方向**：molecule / rocket-launch 的科普页可借鉴其展签式版面语言（馆藏元信息条、竖排标题、底色纸感）；「生成文物图鉴」的导出钩子与绘课单网页文件输出的思路同构。
- **「揭顶观乐」剖切视图**：与掌上博物馆「半透明分解视图」同思路，是 3D 文物展示的通用招式。
- **教程型内容选题**：「全流程拆解」笔记本身也是本项目小红书运营可复用的内容形态（不只是成品展示）。
