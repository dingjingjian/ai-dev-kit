## 简介

把《哆啦A梦的家》做成可自由探索的 3D 寻宝游戏：进大雄家翻抽屉、开柜门、戴竹蜻蜓飞高处、用穿墙圈进隐藏藏宝室，共收集 50 件秘密道具。道具之间有解谜链——看见不等于拿得到，需用其他道具（缩小灯/放大灯/包袱巾/美食桌布/记忆面包）创造条件。

## 亮点

- **能力解锁式探索结构**：50 件道具 = 34 件自由寻找 + 16 件藏在 8 种能力对应的小冒险里——收集进度有清晰的分层设计，长线可玩性有保障。
- **「看见 ≠ 拿到」的道具解谜链**：挡路积木要缩小、米粒大铅笔要放大、坏盒子先用包袱巾修好——道具互为钥匙，形成轻解谜闭环而不是纯点捡拾。
- **3D 空间纵深**：地面搜索 + 竹蜻蜓飞高 + 穿墙圈进暗室，垂直与隐藏空间三个层次，探索感立体。
- **叙事化文案**：以「客人串门 → 帮忙做家务」的角色转变讲故事，金句「最后再开一个抽屉——这是我今天最不可信的一句话」精准戳中探索欲；结尾开放式提问（第一件想找什么）引互动。
- **视觉包装**：笔记配图是 7 页图集式的绘本风封面（哆啦A梦 + 任意门 + 大雄家外观），底部「50 件秘密道具 进去找一件再走？」做钩子，制作感强。

> 大雄，你家墙后面怎么还有宝藏。
