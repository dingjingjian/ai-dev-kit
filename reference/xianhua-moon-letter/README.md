1. **品牌化包装**：工具自有品牌名「月下寄笺局 / MOON LETTER · MID-AUTUMN」——不是「中秋小工具」这种功能命名，而是一个有身份感的「局」（机构拟人），宣传图走版画风格（克莱因蓝信封 + 橙月牙），美术统一克制（≤2 主色）。
