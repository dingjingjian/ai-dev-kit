## 一句话定位
把「月亮的 15 种圆缺形态」映射成「C3—C5 的不同音高」的网页互动音乐小工具。选择一个月相，它就会成为五线谱上的一枚音符。

## 核心玩法
- **月相 → 音高**：15 种月相分别对应 C3—C5 音阶上的不同音高（越圆音越低、越缺音越高）。
- **输入方式**：短按默认输入半拍；长按可以写下更长的音符。
- **休止符**：用一枚星星表示。
- **实时落谱**：输入时，月相会实时落到五线谱上。
- **播放反馈**：播放时，当前经过的月亮会反色亮起，乐谱自动跟随旋律向前移动。

## 配置与分享
- **7 种合成音色**：风格差异较大的预设音色。
- **4 种主题色**：可切换的界面配色。
- **月相谱卡**：支持保存与分享。
