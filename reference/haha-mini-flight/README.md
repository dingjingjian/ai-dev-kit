## 简介

Q 版 3D 模拟飞行小游戏：从机场跑道起飞，在开放天空中飞行游览。宣传图中展示至少 4 架不同涂装的机型（螺旋桨机 MINI1263、特技机 MINI3306、喷气机 MINI0481、客机 MINI1644），疑似多机型可选。

## 亮点

- **多机型阵容**：4+ 架 Q 版飞机（螺旋桨/特技/喷气/客机），机身带注册号（MINI1263 等）与作者水印——机型差异可能对应不同飞行手感。
- **模拟飞行轻量化**：把专业模拟飞行简化为「点击起飞」的 Q 版体验，同时保留机场、塔台、海岸线场景等航空元素。
- **海报级宣传图**：封面为完整构图的海报（标题字效、四机编队、海岛机场背景、slogan「起飞！去看看更大的天空！」），制作规格明显高于普通截图笔记。
