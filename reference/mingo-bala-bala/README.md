## 亮点拆解

1. **单一实体感解压**：一颗大球占满主界面，戳/按/扒拉三种触觉动词对应三种反馈——与捏捏乐同为纯触觉解压生态位，但交互载体（球 vs 捏捏）与质感（果冻高光 vs 3D 拟物）不同。
2. **照片上传自定义**：「上传老板照片狠狠旋转它」——自定义玩法自带梗传播力（老板球/爱豆球），把 UGC 内容变成社交货币；截图底部「+」即自定义入口，7 款预设球（笑脸/云朵/小熊/小猪…）作 SKU 基底。
3. **粉圈密码解锁机制**：「同担」输入解锁密码可开「专享同担五球」（#wmls #5525 为粉圈暗号）——**把粉丝社群运营做进产品里**：圈外人看是彩蛋，圈内人拿到专属身份认同，这是今日归档里独有的社群分层设计。
4. **结果分享闭环**：「解锁了好玩的球球评论区分享」——UGC 征集 + 评论区二次传播，与哆啦A梦/捏捏乐的征集钩子同款但换了对象（征集的是玩家的自定义成品而非选题）。
5. **桌面陪伴形态**：界面带实时时钟/日期（19:22 · 09-19 星期六），往「桌面摆件/陪伴挂件」方向走，而不只是打开玩三分钟的游戏——留存场景更日常。
6. **关注转化钩子**：「喜欢就点个关注」直球要关注，节令（中秋前上班族）+ 情绪（解压）+ 粉圈三波受众叠加引流。

## 与自研项目对照

- **vs #vibetool 赛道**：此前对标库该赛道只有掌上博物馆（3D 文物，重考据），这条是**轻互动工具**路线——#vibetool 不必然重，单一触觉反馈 + 自定义 + 社群彩蛋也能成作品，赛道宽度样本 +1。
- **社群密码解锁**：粉圈暗号换专属内容的机制，可迁移到任何自研作品的运营层（如 WorkBuddy/绘课的用户分层彩蛋），成本低、辨识度高。
- **照片自定义 + 梗传播**：与烟花秀「上传照片铺进夜空」同一招式——让用户把自己的照片/情感投射进作品，是低成本高传播的通用配方。
- **待平衡验证**：球的物理回弹/旋转手感（果冻质感 = 软体模拟 or 骨骼缩放）是解压体验的成败点，与捏捏乐同属「慢回弹曲线」待拆项。

## 待拆解问题

- 球体的软体物理实现（顶点位移/缩放假装/预制形变动画）与回弹曲线参数。
- 照片贴球的映射方式（球面 UV 贴图？畸变处理？）与「旋转」交互的惯性参数。
- 解锁密码的校验机制（前端硬编码即可，但如何防扩散/是否在意扩散）。
- 时钟/桌面陪伴形态是否有常驻使用场景设计（如整点彩蛋）。
