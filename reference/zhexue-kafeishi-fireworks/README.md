## 简介

用户在虚拟夜景（城市天际线 + 夜空）下「放烟花」的互动小工具：按下中部的开关打火器，烟花升空绽放；支持换城市背景与导入自己的照片融入夜景。

## 亮点

- **换背景**：六座城市（北京、上海、广州、重庆、香港、澳门）+ 自定义照片背景；照片可选「贴地对齐地平线」或「铺满整片天」两种贴合模式，另提供「暗夜」纯黑背景降低亮度。
- **选照片抠图**：沿轮廓手绘一圈即可裁出主体（如猫、人像），也可整张直接使用——把「我站过的江边、窗边、天台」铺进夜空，强情感化个人化体验。
- **仪式感交互**：中间实体感的「按下」开关（打火器造型）作为核心触发，配合左下角选照片 / 右下角「汇演 / 发笔记」按钮，操作动线清晰。
- 文案有情绪引导：「把你站过的江边、窗边、天台，铺进夜空」，情感化叙事而非功能罗列。
- 界面提示抠图建议「长边 512–1024」，对输入图片尺寸做了引导，降低低端机处理压力。
