## 简介

把「科目二」驾驶考试做成关卡制停车解谜游戏：3D 俯视停车场里把车开出库，周围是挡路的车辆，按用时/擦撞次数/挪车次数结算星级（1–3 星）。关卡有主题分类（如「第 1 关 · 直出」）。

## 亮点

- **三维结算面板**：通关后并列展示 用时 00:33 / 擦撞 0 / 挪车 4 三项指标 + 星级——评价维度透明且各自可优化，天然支持「重打冲三星」的复玩动机。
- **关卡结构化**：「出库 · 第 1 关 · 直出」的命名即关卡设计语言（场景类型 + 序号 + 考核点），科目二题库本身就是现成的关卡清单（直出/倒库/侧方/坡道…）。
- **全民共鸣的题材**：科目二是国民共同记忆，痛点真实（「过道窄到怀疑人生，方向盘打死也就那样」），题材自带话题与代入感。
- **克制画风**：低多边形俯视视角，被蹭车辆统一灰暗色、玩家车高饱和红色，视觉焦点管理清晰；结果页底部弱化品牌（「科目二挑战赛 · 小红书小工具」）。
- **挑战式文案**：「你来试试？」+ #一把进 话题，直接下战书引互动。
