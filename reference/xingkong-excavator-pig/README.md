## 简介

把「广西洪水挖掘机抓猪」网络热点做成的 3D 操作游戏：开挖掘机在庄园里追猪，左手控制底盘追、右手控制机械臂抓，抓到后送回围栏。本条笔记是一篇**用户反馈驱动的迭代复盘**：因女玩家普遍不会开挖掘机（第一人称频繁掉河），连夜把默认视角改为第三人称（半俯视）。

## 亮点

- **热点题材借势**：广西洪水挖掘机抓猪是现成的全网热梗，题材自带流量与搜索词。
- **用户反馈驱动迭代的完整叙事**：女玩家吐槽 → 博主震惊 → 一对一教学 → 发现性别/经验差异 → 听劝连夜改默认视角 → 竖屏实测「巨爽」→ 发笔记告知新版上线——一整条「听劝」故事链，把版本更新写成了连续剧。
- **视角决策的实证**：第三人称半俯视让「挖掘机、机械臂、奔跑的猪、动物庄园一目了然」，双手分工（左手追猪右手瞄准）更顺——由玩家实测得出而非拍脑袋，且公开征求「第一人称 vs 第三人称」投票延续互动。
- **降低认知门槛的教学**：按键说明 + 视角切换指引，帮非传统玩家（不懂工程机械的女性用户）跨过上手坎——**受众细分意识**在参赛作品里罕见。
- **结算动线完整**：追 → 瞄 → 抓 → 送回围栏，任务闭环清晰。
