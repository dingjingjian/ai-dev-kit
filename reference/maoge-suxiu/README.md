## 简介

把照片/图形转成「苏绣刺绣效果」的国风小工具：将图片处理为仿真针迹（苏绣/缎绣针法），带飞针动画逐针「绣」出来，可调针法密度、针数、速度与丝线配色，成品可储图。复现的是 DOTA2 国际邀请赛（TI）今年的苏绣主题视觉。

## 亮点

- **针法拟真**：苏绣 / 缎绣两种针法切换，密度（密/中/疏）与针数（8/12/16/24）可调——不是简单贴滤镜，而是按针迹逐针绘制。
- **飞针动画**：「施针」触发逐针刺绣过程，带速度滑杆（慢/快，数值如 300）——把「过程」本身做成可观赏的核心体验。
- **工作流完整**：呈图（载入图）→ 施针（绣制）→ 储图（导出），三步动线清晰。
- **丝线配色**：顶部色板（红/青/藏蓝/黑）可换丝线颜色，界面标注「苏绣 · 丝理」。
- **统计与引导文案**：完成后显示「绣成（缎绣）· 3807 针 · 7 色 · 留白 2%」；底部提示「图宜简洁、底色纯、主体明者，绣效尤佳」——用参数化结果反馈 + 选图引导提升成功率。
- **文化嫁接热点**：借 TI 2026 苏绣主题的热度做国风复现，选题自带传播点。

## 备注

- 可借鉴点：①「逐针绘制 + 过程动画」的生成式体验（过程即内容，比只出结果图更有观赏性）；②参数化反馈（针数/色数/留白率）给作品「手作感」定价；③选图引导文案降低差结果率；④热点事件（TI 主题）+ 传统工艺（苏绣）+ AI 工具三重嫁接的选题方式。
- 博主自述「优化空间还很大」，属初步复现版本，效果细节未达理想态。
- 待拆解问题：针迹路径生成算法（轮廓 → 走线方向/丝理如何决策）？密度参数与针数的关系？逐针动画的调度实现？
- 与「拼豆三兄弟」（拼豆图纸导出引擎）在「像素/针迹化手作图纸」方向同构，可对照借鉴其走线与统计逻辑。
