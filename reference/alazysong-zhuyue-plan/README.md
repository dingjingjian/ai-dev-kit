## 亮点拆解

1. **强视觉包装**：复古未来主义（Retro-Futurism）+ 金色星图/地球/月亮，HUD 直接写 "TARGET / LUNA + DIST 384400 KM" 和 "GRAV WELL PULL x1.2"，把天文科普数据做成街机 UI。
2. **中秋情绪选题**："月亮被偷走了" 把节令情绪游戏化，与 piece-of-moonlight（月相音乐）、xianhua-moon-letter（月亮信）同属中秋/月亮赛道，但做成了操作型街机。
3. **难度分层**：四档难度，"最难那档作者自己都没打过"——既是挑战性钩子，也暗示关卡/数值有深度。
4. **话题标签聚焦**：同时打 #vibegame #小红书月亮节 #月亮创作季，明显定位游戏 + 中秋活动双流量。

## 与自研项目对照

- **同赛道样本**：与下一个蓝点（太空尺度）、piece-of-moonlight（月相音乐）同属"天文/月亮"题材，但它是街机动作，适合作为"节令题材 + 街机玩法"的参考。

- **待拆解问题**：四档难度的核心操作方式（点击？拖拽？重力弹弓？）、关卡长度、失败/胜利条件、是否有音效或粒子反馈。
